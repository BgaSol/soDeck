# Docker 变更记录

## 0.1.0（发行候选）

- 新增容器侧栏、主区域详情和最近日志三个独立视图，支持现有工作台的分屏与移窗协议。
- 支持容器搜索、状态/健康筛选、Compose 项目排序、隐藏环境变量值、日志快照搜索与复制。
- 支持单容器启动、停止、重启、暂停、恢复及停止后的删除，保留挂载卷。
- 支持按需资源快照；复用现有短命令能力，中断操作不自动重发。

本机验证与限制见[实施记录](../../docs/implementation-docker-plugin.md)。本版本正在通过独立 Package plugin 工作流进行五平台原生构建和实际归档验收；完成后发布同一份草稿附件，发行来源与实际验证范围在本记录补齐。
