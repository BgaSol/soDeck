# 文件插件

侧栏浏览真实 SFTP 目录，中央按规范路径去重打开文本编辑页，支持 1 MiB 内 UTF-8（可含 BOM）、LF/CRLF，以及单文件流式下载。二进制、非法 UTF-8 和混合换行只允许下载，避免无损性问题。

0.9.0 编辑器提供行号、右侧彩色缩略图、当前正文搜索和按文件类型着色；包含未保存修改，可手动选择语言，保留既有字体/换行显示设置。超过 1 MiB 的文件不允许编辑，修改也不能突破原始编码字节上限。`Ctrl/⌘F` 查找，Enter/Shift+Enter 或 F3/Shift+F3 导航；高密度结果显示“1,000+ 处”，仍可检索全文。正式发行与平台验收边界见[实施记录](../../docs/implementation-file-editor-search.md)。

保存校验远端内容摘要、属性和链接目标，先写同目录临时文件，服务器支持 OpenSSH 原子替换才提交。外部修改拒绝覆盖；提交时失联提示结果未知。草稿和终端不随隐藏、断线或移窗而重建；进程崩溃后不承诺草稿恢复。

“下载远端”下载服务器当前版本，“导出草稿”导出编辑页当前内容（含未保存更改），断线后仍可导出。任务中的成功项默认收起，可展开查看；冲突、失败和需要核对的结果保持在“需要处理”中。列表字号在真实目录树上生效。

0.2.0 提供紧凑目录树：多分支展开、路径定位、独立分页、右键下载/复制路径/刷新和键盘导航。单击选中、双击文件打开中央编辑器；移窗和重挂载恢复展开、选中和滚动元数据。保持原有 UTF-8/BOM/换行、保存冲突、草稿与下载能力。

`node scripts/package-plugin.mjs --plugin files` 独立打包，设置中添加产物目录后重启。0.3.0 需要核心 0.8.4；旧核心会明确提示升级。`npm run files:test` 使用隔离 OpenSSH 与实际插件 UI 验证。版本在 Cargo.toml，标签 `plugin-files-v0.3.0`。

0.3.0 增加文件/文件夹批量上传下载、同名处理、取消和失败项重试，支持远程创建/改名/删除/同机复制移动。本地文件粘贴与拖入共用上传流程；不支持远程系统粘贴或拖出。新能力为 `files.operations.v1` 与 `files.localInputs.v1`。接口、原生包验证和系统桌面互操作限制见 [实施记录](../../docs/implementation-file-management.md)。
