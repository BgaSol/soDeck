# SoDeck

你的远程工作台。

跨平台 SSH 桌面客户端，采用 Tauri 2、React、TypeScript 和 Rust。配置保存在本机 SQLite 文件中，无需部署后端。

## 已实现

- SoDeck 统一品牌与应用图标；点击主窗口或独立会话窗口左上角的品牌区域可查看版本信息。
- 一体化窗口顶部栏：主窗口和独立 SSH 窗口将会话标签合入 48px 顶部栏，保留窗口拖动空白；标签溢出时支持横向滚动和全部会话菜单。Windows 使用自定义标题栏，支持拖动、双击最大化和窗口控制；macOS 使用原生红黄绿按钮与覆盖式标题栏，Linux 保留系统装饰。主窗口、独立会话、编辑器和日志等窗口共用外观，关闭仍执行原有退出及未保存检查。平台配置与验证范围见 `docs/window-chrome.md`。
- Tab 栏“＋”打开服务器选择窗口：新增、编辑、删除，名称/地址搜索，多标签与标签筛选。
- 单层跳板连接：本机 → A → B，A/B 分别认证及核对指纹；终端、文件、Docker 和日志统一使用该路径。
- 中间 SSH 交互终端：密码、私钥文件或 SSH Agent 认证，主机指纹确认，窗口尺寸同步。SSH 密码可直接保存到本机 SQLite，后续连接自动使用。
- 多 SSH 会话 Tab：每页独立保存终端、文件目录、Docker 状态；切换时后台连接继续运行，同一服务器可以同时建立多个连接。
- 会话标签可拖动排序；拖出主窗口成为独立窗口，也可拖回主窗口标签栏。移动时保留原 SSH 连接、终端输出和滚动位置、文件目录、Docker 树及面板尺寸。右键菜单提供相同的移动入口。
- 左侧 SFTP 文件树：以 `/` 为根，首次按路径展开到登录目录，其他分支按需读取；终端目录变化后自动展开并定位。支持 UTF-8 小文件独立窗口编辑，以及文件和文件夹下载。编辑支持查找、语法高亮、保存冲突提示；下载支持递归结构、进度、取消、重试和同名处理。
- 新建远程文件/文件夹、选择或拖入本地文件上传；同服务器支持复制、剪切、粘贴和 Shift 拖动移动，跨窗口共享远端剪贴板。不同服务器之间使用 rsync over SSH 直传，所有任务统一显示在底部面板。
- NetBird 客户端管理：右侧 NetBird 页查看 Linux 原生客户端状态、可见节点与日志，执行单次 Ping / TCP 检测；经路径预检后连接、断开或启动 / 重启已确认的服务。操作回执持久化，结果不明时只核对、不自动重试。支持范围与验证见 [NetBird 实现说明](docs/netbird-client-implementation.md)。
- 右侧 Docker 树：连接后自动检测，镜像与容器列表，15 秒刷新和手动刷新。
- Linux 服务器资源监控：终端底部显示 CPU、内存和网络摘要，右侧可切换“监控 / Docker / NetBird”；支持各核心、负载、Swap、网卡选择和最近一小时趋势。磁盘总览与文件树共用容量缓存，同一连接身份的多个窗口共用采样，慢挂载不影响实时指标。无需安装 Agent，历史仅保存在当前运行内存中。指标详情在右栏内查看，大图可在独立监控窗口打开，共享采样且不影响终端布局。Docker 信息集中在 Docker 页，连接信息与本客户端通信摘要常驻终端底栏，点击“通信详情”向上展开趋势，按监控查询、终端日志及文件操作区分开销；后台通信独立累计。设计与验证见 [资源监控](docs/resource-monitoring.md)。
- 运行中容器的独立原生终端窗口。重复进入同一容器聚焦已有窗口；切换主窗口服务器不改变容器目标，关闭窗口只结束对应 SSH/exec 会话。
- 文件编辑器自动识别 Java、JSON/JSONC、Shell、JavaScript/TypeScript、Python、Go、Rust、C/C++、YAML、TOML、INI、PowerShell、HTML/CSS/XML、SQL、Markdown、Dockerfile、Nginx 等语言；底部可手动切换，高亮按需加载，切换保留修改、光标和撤销记录。
- 容器独立日志窗口：日志永久保存在本地，支持全历史中文搜索、时间和输出流筛选、分页虚拟列表、等级/JSON/异常/ANSI 高亮、原文复制与导出。关闭主会话 Tab 不影响日志接收；关闭日志窗口停止采集，重新打开保留历史并尝试补采。
- Apple 风格的桌面界面：中性灰层次、轻磨砂工具栏、圆角会话与面板、统一的弹窗和选中态，界面跟随系统深浅主题。
- 左侧远程文件、中间终端、右侧服务独立排列；两侧宽度可拖动调整，分隔条获得焦点后可用左右方向键调整。支持减少动态效果、减少透明度和提高对比度的系统偏好。

## 开发运行

需要 Node.js 22.12+ 和 Rust stable。首次安装依赖后启动桌面端：

```sh
npm ci
npm run desktop
```

各系统还需要 Tauri 的原生构建依赖：

- **Windows**：Visual Studio 2022 Build Tools 的“使用 C++ 的桌面开发”（包含 Windows SDK），以及 Edge WebView2 Runtime。
- **macOS**：Xcode Command Line Tools（`xcode-select --install`）。
- **Ubuntu 22.04/24.04**：`build-essential libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev patchelf libssl-dev pkg-config`。其他发行版安装对应软件包。

只运行 `npm run dev` 可查看浏览器中的界面；SSH 和数据库功能需要桌面端。

首次安装 Rust 或 C++ 构建工具后重新打开终端，使环境变量生效。Windows 可直接双击已构建的 `src-tauri/target/release/sodeck.exe`，无需启动 Vite。

## 构建与检查

```sh
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri -- build
```

安装包输出到 `src-tauri/target/release/bundle/`。也可使用 `npm run tauri -- build --no-bundle` 只构建当前系统的可执行文件。Windows、macOS、Linux 分别在对应系统构建；仓库包含三平台 CI 配置。

## 系统设置与开发者模式

各窗口标题栏的齿轮按钮打开“系统设置”。开发者模式默认关闭，开发启动与安装包使用相同规则：关闭时屏蔽浏览器原生右键菜单、页面刷新和开发者工具入口；开启后允许这些操作，并提供“打开当前窗口开发者工具”按钮。文件树、会话标签、服务器列表的业务菜单，以及终端输入、编辑器快捷键、业务刷新按钮继续工作。关闭时输入框的原生右键编辑菜单也会隐藏，键盘复制粘贴保留。

勾选后自动保存，下次完整启动生效。设置页同时显示当前生效状态与待生效提示；本次运行中新开的窗口仍沿用启动时的状态。设置修改不会刷新页面、重建窗口或中断连接；重新启动仍需正常退出并处理现有任务和未保存文件。设置独立于服务器数据库，保存在 Tauri 应用配置目录的 `settings.json` 中（版本 1，`developerMode` 布尔值）。读取失败时以关闭模式启动并显示错误，保留原文件；保存失败时保留上次成功保存的值。

运行 `npm run test:settings` 验证 Chromium/WebKit 交互，需先安装 Playwright 浏览器。该套件由 Rust 导出实际插件初始化脚本，检查保存、跨窗口通知、失败恢复、调试入口、业务菜单及 xterm 按键；原生菜单与检查器仍需分别在各平台桌面应用中验收。

## 品牌资源

产品名称与版本来自 `src-tauri/tauri.conf.json`，界面通过 `src/brand.ts` 共用这些信息；原生辅助窗口统一使用“内容 · SoDeck”标题。技术包名与可执行文件名为 `sodeck`，Windows 安装包使用 SoDeck 产品名。

`src-tauri/icons/source.svg` 是应用图标的源文件，界面及浏览器图标直接引用它。修改后运行 `npm run icons`，同步生成桌面与安装程序使用的 PNG、ICO、ICNS 资源。

## 数据与连接行为

SoDeck 沿用原应用标识 `com.sshworkspace.desktop` 和数据目录，已有服务器配置、主机指纹、日志及终端历史继续使用。内部通信标记、历史导出格式与传输临时文件前缀保持兼容，不随品牌更名替换。

数据库名为 `servers.db`，位于 Tauri 应用数据目录：

| 系统    | 默认路径                                                               |
| ------- | ---------------------------------------------------------------------- |
| Windows | `%APPDATA%\com.sshworkspace.desktop\servers.db`                        |
| macOS   | `~/Library/Application Support/com.sshworkspace.desktop/servers.db`    |
| Linux   | `${XDG_DATA_HOME:-~/.local/share}/com.sshworkspace.desktop/servers.db` |

数据库保存服务器配置、标签、SSH 密码和已确认的服务器主机指纹。SSH 密码直接以明文存入本地 SQLite，编辑服务器时可替换或明确清空；已保存密码不会返回到前端或回填输入框；私钥口令只保留在当前连接所需的内存中，私钥文件本身不会复制进数据库。

程序不升级或迁移旧数据库。若打开了缺少当前必需字段的旧库，会显示实际数据库路径，并提供“备份旧库并重建”。确认后由正在运行的程序先将旧库完整备份到同一目录的 `servers.backup-*.db`，再创建空的当前结构；备份失败不会清空旧数据，结构正常的数据库拒绝重建。请以实际双击启动的程序为准验证，开发工具与桌面启动可能访问不同的文件系统视图，路径文字相同不代表是同一个文件。

重建使用应用内确认弹窗，显示实际数据库路径；取消或按 Esc 不执行重建。处理期间禁止重复提交和关闭弹窗，失败可查看原因并重试，成功后显示备份路径。该流程不依赖 WebView 的 `window.confirm()`。前端回归使用 `npx playwright install chromium webkit` 后运行 `npm run test:database`，以模拟 IPC 检查 Chromium/WebKit 交互；真实 SQLite 备份由 `cargo test --manifest-path src-tauri/Cargo.toml db::tests` 验证。

密码认证的服务器已保存密码时，新建会话和重新连接直接使用该密码。未保存密码时，在连接弹窗输入，认证成功后自动保存；清空密码后恢复为连接时输入。密码认证失败后会在当前连接中再次提示，允许更正两次。首次连接或主机指纹变化先核对指纹，再发送认证信息。

配置跳板时，先保存可直接连接的服务器 A，再编辑目标服务器 B，将“连接方式”设为“通过跳板机”并选择 A。B 的地址使用 A 所在网络能访问的 IP 或域名；本机无需解析该地址。A 必须允许 SSH `direct-tcpip` 转发并能访问 B 的 SSH 端口。不依赖已打开的 A 终端，也不需要在 A 上安装客户端或复制 B 的私钥。

当前只支持单层跳板。不能选择自身、引用另一条跳板路径，或把已被引用的 A 改成跳板连接；删除 A 前须先解除 B 等配置对它的引用。A/B 各自支持密码、私钥及 SSH Agent，指纹按直连/跳板网络分别保存。每项业务独立建立自己的转发连接，关闭主终端不会中断下载、文件编辑、容器终端或日志；退出应用会取消连接与下载并等待收尾、刷新日志存档。

点击 Tab 栏右侧“＋”打开服务器选择窗口，单击只选择配置，双击或点击“连接”创建独立会话。同一服务器可重复连接，标题以 `服务器 · 2` 等编号区分；已有会话通过 Tab 切换。连接成功后关闭选择窗口，失败时保留原因并可在同一待连接 Tab 重试；取消会释放本次未成功连接并返回原会话。

切换 Tab 时终端、目录和 Docker 面板一起切换。后台 SSH 保持连接并接收输出，目录路径、选中文件和树展开状态各自保留。Docker 按已验证连接身份共享采集，前台约每 15 秒、后台约每 60 秒更新；镜像仅在对应页面可见时按需读取。关闭一个 Tab 只结束其主 SSH 会话，其他 Tab 和独立容器窗口继续运行。断开后保留 Tab 和终端输出，可手动重新连接。方向键/Home/End 可切换 Tab，聚焦 Tab 时 Delete 可关闭。

会话标签与窗口控制共用顶部一行，标签过多时可用滚轮、左右按钮或“全部会话”菜单定位；“＋”始终可见。拖动标签可以调整顺序，靠近标签区边缘会自动滚动。将主窗口的标签拖到窗口外会打开独立会话窗口；将独立窗口的标签拖到主窗口标签区可放回指定位置，放到顶部拖动空白则追加到末尾（空主窗口也可接收）。右键标签也可选择“移到独立窗口”或“移回主窗口”，独立窗口顶部另有移回按钮。移动期间原 SSH 连接继续运行，终端输出、远程目录、监控详情、通信偏好和 Docker 搜索筛选随标签转移。连接或认证尚未完成时，先完成当前步骤再移动。

双击远程文件，或选中文件后点击编辑按钮，可打开独立的在线编辑窗口。仅支持不超过 1 MB 的 UTF-8 文本；二进制、无效 UTF-8 和更大的文件会给出提示。保存前检查远端文件是否已被其他操作修改，冲突时可重新加载或明确覆盖。编辑窗口有未保存内容时关闭会提示；主窗口退出也会提示。远端保存保留原文件权限、UTF-8 BOM 和换行格式，服务器需要支持安全替换文件的 SFTP 操作。

远程文件树始终以 `/` 为根，首次只展开到登录目录并读取这条路径的直属内容，其他分支首次展开时读取，收起后保留缓存。路径框可定位任意目录，刷新只读取当前目标的一层。主终端在提示符返回时上报实际目录，成功 `cd` 后自动展开、加载并定位，终端继续接收键盘输入；组合命令需等待整条命令结束。Bash、zsh、fish 提供会话临时集成，不修改远端启动文件；其他 shell 或服务器拒绝集成时使用普通 SSH shell，文件树仍可手动浏览。Bash 使用临时 rc 文件加载登录配置，少数依赖 `login_shell` 标志或 `.bash_logout` 的配置与原生登录 shell 有差异。嵌套 SSH、切换账号和容器内目录暂不映射到宿主 SFTP 文件树。

Linux 远端的目录挂载点在文件树中显示挂载来源、文件系统使用率与容量条；点击来源或使用率，或右键“查看挂载详情”，可查看挂载位置、文件系统、只读状态、总容量、已用和可用空间。根目录、嵌套挂载和绑定挂载分别识别，普通子目录不重复显示容量，符号链接保留自身身份。面板可见时约每 30 秒刷新，手动刷新目录也更新挂载信息；查询失败保留上次数据，不阻塞目录操作。需要远端可读取 `/proc/self/mountinfo` 并支持 `stat -f -c`，SFTP 与命令执行的挂载视图必须一致。能力限制与验证方法见 [挂载信息](docs/remote-mounts.md)。

文件或目录右键菜单的“复制绝对路径”将右键目标的原始路径写入系统剪贴板；多选时仍只复制右键目标，符号链接复制链接自身路径，空白区域可复制当前目录路径。此操作不改变应用内部的文件复制／剪切状态，不附加引号或 Shell 转义。

选中文件或文件夹后点击下载按钮，也可从右键菜单下载。文件夹会递归保留层级、隐藏文件与空目录；符号链接和特殊文件会跳过，并在任务结果中计数。下载前选择本地文件夹与同名策略：自动改名、覆盖或跳过。底部任务面板显示进度，可取消或重试失败任务；下载在后台运行，主终端可继续操作。

选中服务器后可点击列表底部“删除”，也可使用右键“删除服务器”或编辑窗口的“删除”。确认框显示名称和地址；确认后删除本地配置、保存的密码及标签关联，不操作远端服务器和文件。该服务器仍有打开的会话标签页、独立会话、容器终端、日志或文件编辑窗口时，需先关闭相关窗口；未完成的下载需等待结束或取消。删除失败保留配置并显示原因，成功后选中筛选结果中的相邻服务器。

新增、修改服务器配置不会关闭已有会话；会话显示建立连接时的配置，手动重新连接使用最新保存的配置。打开的标签页属于运行时数据；服务器和容器终端输出另存为本地终端历史，不写入服务器配置数据库。

首次连接或主机指纹变化会提示核对；后续 SFTP、Docker 和容器连接均校验该次连接确认的指纹。文件编辑窗口、容器窗口和日志存档以已验证的连接路径区分目标；容器还绑定 Docker 引擎地址及完整容器 ID。退出整个应用会关闭所有连接。

远程 Docker 功能面向具有 POSIX shell 和 Docker CLI 的服务器，使用当前 SSH 用户权限；支持 Unix socket/DOCKER_HOST，保留当前上下文解析到的引擎地址。需要上下文专用 TLS 证书或 SSH transport 的 Docker context 尚未完整支持。检测失败、权限不足、没有可用 shell 等情况会显示错误，不会自动 sudo 或修改远端服务。容器进入优先 `/bin/bash`，明确不存在时尝试 `/bin/sh`。

本版本暂不提供多层跳板、批量执行和凭据保险库。SSH Agent 是否可用取决于系统和 libssh2 支持的代理接口，可使用密码或私钥文件连接。

## 终端历史

服务器终端和 Docker 容器终端自动保存客户端实际收到的输出。终端工具栏的“历史”在原面板中打开只读虚拟列表；实时终端持续接收输出，查看历史不会重建终端或改变 PTY 尺寸。阅读时有新输出只显示提示，“返回实时终端”恢复键盘焦点。终端自身仍保留 5000 行即时回滚缓冲，本地历史不受此限制。旧版本尚未存档的内容不能补回。

“清理显示”保留当前提示符行，之前内容保留在历史中。清屏、会话开始和结束均有分隔；远端 `clear` 等实际屏幕清除由控制序列识别。全屏程序内部重绘不反复产生清屏分隔，行内覆盖和屏幕交互以可展开记录显示。每次重连建立新会话，可通过会话选择器回看；窗口迁移沿用同一历史会话，不重复记录迁移回放。

主页面右上角的“终端历史”和终端内的“全局历史搜索”打开独立窗口，断线、应用重启和删除服务器配置后仍可离线查看。搜索范围包括当前会话、当前服务器/容器、全部终端，支持中文子串、大小写和时间范围。搜索固定索引快照，有新记录时可更新；结果支持定位上下文、只读恢复屏幕。回放按原始输出和尺寸事件恢复，可定位命中处或读取到保存末尾，不向远端发送输入。

独立历史窗口采用会话导航与记录阅读双栏布局，会话按日期分组，显示服务器/容器、连接时间和状态；窄窗口及终端内历史使用会话选择器。搜索范围直接显示，大小写和起止时间位于“筛选”，文本与原始记录位于“导出”菜单。

点击记录正文或时间可选中记录，Shift 点击另一条记录选择范围；底部显示复制、范围导出和“查看当时屏幕”。正文仍可拖选文本。搜索结果通过“查看前后记录”定位到所属会话；历史屏幕只读，返回后保留阅读位置并恢复操作按钮焦点。文本导出保留历史文本版本与事件标记；原始记录导出为带时间、顺序、尺寸和 Base64 输出字节的 JSONL。单次复制最多 8 MiB，更多内容使用导出。

数据位于应用数据目录 `terminal-history/`：`catalog.sqlite` 保存来源和会话；`sessions/<会话 ID>/raw-*.sqlite` 保存原始字节及事件，`view-*.sqlite` 保存可重建的阅读记录与 FTS5 搜索索引。分片约 256 MiB 轮换，默认不自动删除。原始记录通过有界后台队列批量提交，索引独立追赶；展示缓存最多 5000 条或约 16 MiB。队列溢出和写盘失败会明确提示记录异常，终端继续可用；缺失部分不能补回。正常退出等待原始记录写完，异常退出恢复已提交部分并标记中断，突然断电时尚未提交的尾部不保证保存。只保存终端回显，不采集认证密码或原始按键。

验证：`npm run test:terminal-history`；后端 `cargo test --manifest-path src-tauri/Cargo.toml --lib terminal_history`。百万条索引检查：`cargo test --manifest-path src-tauri/Cargo.toml --lib terminal_history::store::tests::million_records_remain_pageable -- --ignored`。真实 SSH/跳板/容器终端和迁移字节保真使用 `jump_real_ssh_sftp_docker_terminal_and_failure_paths` 联调测试。

## 上传与服务器直传

同一服务器的文件树中，拖拽默认复制，按住 Shift 拖拽执行移动。工具栏、右键菜单与 Ctrl/Cmd+C、X、V 提供复制、剪切、粘贴；空白处右键可粘贴到当前目录。快捷键仅作用于文件树。剪切后项目淡显，Esc 清除剪切标记；复制可重复粘贴，剪切项目执行期间不能再次粘贴，部分成功只移除已移动项目的标记。剪贴板由应用共享，不占用系统剪贴板，重启后清空。

同服务器按已验证的完整连接身份识别，支持同配置的多个会话和窗口，不要求真实地址或另一次 SSH 认证。复制使用服务器上的 `cp`；同文件系统移动优先 SFTP 改名，目录冲突时逐项合并；跨文件系统移动先暂存、SHA-256 校验和提交，再逐项删除来源。删除失败显示“已复制，来源未删除”，重试只继续剩余步骤。来源变化时保留来源；来源目录只在为空时删除，编辑器打开的文件及父目录不能移动。首版面向 Linux，需普通文件工具、`stat`、`sha256sum`，不需要 rsync/sshpass。

同目录拖拽或移动不产生任务；显式复制粘贴到原目录需选择自动改名。禁止复制／移动到自身及子目录。跨服务器剪切或 Shift 拖拽明确拒绝，跨服务器复制继续使用以下真实地址策略。

文件面板顶部的“新建”菜单可创建空文件、文件夹；目录右键菜单也提供入口。同名项目会报错，不会清空已有文件。“上传文件”使用系统文件选择器，支持多选；从 Finder/资源管理器拖入文件或文件夹也可上传。拖到目录行时以该目录为目标，拖到文件树空白处时使用当前目录，普通文件行不接收拖入。

文件和文件夹支持通过工具栏、右键“删除…”以及文件树内的 Delete（Windows/Linux）或 Cmd+Backspace（macOS）永久删除。支持多选，父目录与子项合并处理。确认框固定服务器和完整路径；确认后关闭弹窗并在后台执行，右下角“文件任务”统一显示上传、下载、直传、复制、移动和删除。可按全部、进行中、需处理筛选，查看详情、停止后续删除或移除已结束的记录。结果区分已删除、已不存在、部分失败和待核对；断线后的核对只检查当前路径状态，不自动重新删除同名项目。重新发起删除会重新检查并弹出确认，生成独立任务，保留原结果。

删除仅通过 SFTP 处理普通文件、目录和符号链接，链接只删除自身。根目录、符号链接祖先路径、挂载点以及包含其他挂载点的目录不能递归删除；无法核验 Linux 挂载信息时也拒绝递归删除目录。已打开的编辑器及重叠的传输、下载或待核对任务会阻止删除。所有窗口按受影响目录刷新，已失效的远端剪贴板引用会清理。已确认任务不因收起面板、关闭文件标签页或独立窗口而停止。删除、下载历史保存到本地 `file-tasks.sqlite`；已有传输执行记录继续用于恢复。删除请求发送前记录待确认操作，重启后保留已知结果并提示核对不确定项目，不会自动继续删除。恢复核对或重试需重新连接身份一致的服务器，任务记录不保存密码。移除历史不会清除未确认操作或临时资源；不提供回收站或撤销。

要从 A 复制到 B，先连接两个服务器并将其中一个会话移到独立窗口，在 A 的文件树选中项目后拖到 B 的目录。Cmd/Ctrl 单击多选，Shift 单击或 Shift+上下方向键选择连续项目。确认框固定显示来源、目标服务器与目录，并选择“保留两份”“跳过同名”或“覆盖文件、合并目录”。也可以通过工具栏或右键菜单的“复制到另一台服务器…”选择已连接会话中打开的目录，全程可用键盘操作。复制保留源文件；递归保留隐藏文件与空目录，跳过符号链接和特殊文件。尽量保留普通权限与修改时间；合并目录不改其原有权限，属性保存失败会显示说明。覆盖采用临时文件加安全重命名，不预先删除旧文件；目标 SFTP 不支持安全替换时明确报错。

在 B 的服务器编辑窗口填写“真实地址”和“直连端口”：它们是 **A 能直接访问 B 的 SSH 地址**，不改变本机连接 B 的普通地址、端口或跳板路径。支持 IPv4、裸 IPv6 和域名，端口单独填写，默认 22；“使用当前连接地址”可显式复制现有值。缺少地址时可在复制确认框中直接填写；保存后会再次展示本次固定使用的地址、端口和账号，再开始传输。确认之后修改服务器配置不会改变已创建任务的连接目标。

本机上传使用 SFTP；服务器直传使用 A 上的 rsync over SSH。首版直传要求 Linux，A 安装 rsync/OpenSSH，B 支持 rsync/SSH/SFTP。密码认证另需 A 安装 sshpass；可以使用目标已保存的密码或输入本次密码，也可以指定 **A 上**可非交互使用的私钥路径。本机私钥和 Agent 不会自动转发。密码经加密控制连接的独立输入描述符传给 A，不写入命令参数、任务记录或远端密码文件。

本次直传使用目标的 `directHost` / `directPort` 和已验证主机密钥；客户端管理连接沿用普通地址和跳板策略。会从 A 实际验证连接、认证及目标临时目录的可见性，失败时明确报错，不降级为本机中转。

两种传输都先暂存、再校验、最后逐文件提交。覆盖通过原子替换实现，不预删旧文件；跳过策略合并目录并保留同名文件，改名策略保留两份。复制隐藏文件和空目录，跳过链接与特殊文件；可选 SHA-256 复核。默认最多三项数据传输，最终提交按主机身份和目标路径协调，旧任务中断不再封锁整台服务器。

任务计划、完成项目、执行尝试和待确认提交保存到独立的 `transfer-receipts/tasks-v3.sqlite`。重试只处理未完成项目；直传仅在旧执行确认停止后允许复用临时数据，否则使用新临时目录。本机上传重试从头发送未完成文件。临时清理是独立动作，清理失败不会把已完成任务改为失败。取消和断线不能保证远端立即退出，未确认的执行只保留自己的临时目录，不自动提交；最终提交回复丢失时仅相关路径需要核对。

服务器数据库不迁移。旧执行器回执和远端目录保留，不用新协议自动清理旧任务。功能规则见 [文件传输设计](docs/file-transfer-design-v2.md)。

## 语法高亮与容器日志

编辑器优先使用手动选择的语言，其次按特殊文件名、扩展名、首行 shebang 识别，无法识别时显示纯文本。支持 `.env.*`、`.bashrc`、`Dockerfile.*` 和 Nginx 目录下的 `.conf`；普通 `.conf` 不强行判断语言。语法分析在本机完成，不执行文件内容。

Docker 树中点击“日志”打开独立窗口，立即显示本地存档。首次采集自动读取远端仍保留的全部历史，成功后衔接实时日志；旧版只取过最近 1000 行的存档也会自动补取历史。历史读取中途关闭或失败，下次重新补取并去重，只有完整读取成功才记录历史同步完成。原始字节、解析记录及 FTS5 trigram 索引保存在应用数据目录 `logs/<来源 ID>/`，SQLite 分片约 256 MiB，轮换不删除历史，也不受服务器配置删除影响。关闭日志窗口停止采集并写完已收到内容；正常退出等待日志任务收尾。重新打开和重连按最后 Docker 时间戳回退一秒补采，远端已轮转的日志无法补回。

去重在完整日志进入档案前进行：同一来源内匹配完整精度 Docker 时间戳、输出流及原始字节，按跨采集批次的出现次数抵扣，保留同一次输出中的真实重复次数。匹配的重放不新增原文、搜索记录或导出内容，不再显示“可能重放”。SHA-256 索引缩小候选范围后仍逐字节核对；缺少有效时间戳的内容保守保留。网络拆包和长行用有界内存组装到持久化暂存区；中断留下的半行可续写原记录，异常退出的暂存尾部在重开采集或离线存档时恢复。旧存档首次重新采集时原地建立去重索引，已有的历史重复记录不自动删除。

窗口打开自动采集，关闭停止；工具栏不再提供行数选择、刷新视图、恢复采集、全历史补取或停止采集。临时断线按 1、2、4、8、16、30 秒退避重试，容器停止时每 5 秒检查并在启动后接续；认证、指纹、Docker 权限/驱动或写盘错误保留档案并显示原因和“重试”。本地存档入口保持离线阅读。

前端使用分页虚拟列表，缓存最多 5000 条或约 16 MiB，向上/下滚动自动从本地加载历史。向上滚动或查找暂停自动滚动，采集和保存继续；“跳到最新”恢复跟随。搜索覆盖全部本地历史，支持中文子串、大小写、时间范围和 stdout/stderr 筛选；一两个字符使用可取消的分段扫描。搜索结果固定在查询开始时的序号范围，有新日志时才显示“更新搜索结果”，点击“上下文”查看附近日志。

高亮默认开启，包括日志等级、时间戳、JSON 字段、异常位置、安全 ANSI 颜色及搜索命中，复杂解析在 Worker 中处理并使用有界缓存。时间戳、换行与高亮开关只影响展示；stderr 独立标记，TTY 元数据随存档保留。超长物理行按 64 KiB 片段保存，显示部分折叠，原始字节完整保留。点击序号、Shift 点击结束序号，或输入范围可复制原文、导出范围；“导出全部”流式导出原始传输内容。复制超过 8 MiB 时提示使用导出。服务器列表上方的“本地日志”可在离线或容器删除后查看、搜索和导出存档。

“本地日志”在独立窗口中展示存档列表，重复点击会恢复并聚焦已打开的列表窗口。支持按容器、服务器、地址或容器 ID 搜索，按最近日志、服务器名称或占用空间排序；列表显示日志条数、占用空间与最近日志时间。点击一行打开日志查看窗口，返回列表时自动刷新，也可手动刷新。

日志列表界面回归：`npm run test:logs`。真实桌面多窗口与离线日志回归沿用 `tests/features.spec.ts`。

## 跳板连接回归

先运行 `npx playwright install chromium webkit`，再运行 `npm run test:connection`。套件在 Chromium/WebKit 中模拟 IPC，检查逐跳认证提示、连接 ID 返回前取消、认证等待期间取消、键盘切换、配置选择、密码保留/替换/清空，以及应用内放弃修改确认；同时检查深浅色和小窗口布局。真实传输测试使用独立的 A/B SSH 测试服务，各自有独立账号和主机密钥，B 的测试域名只能由 A 解析转发；Docker 命令由测试服务模拟。

```sh
# 先按 tests/requirements.txt 准备 .qa/venv；也可设置 SSH_TEST_PYTHON
```
