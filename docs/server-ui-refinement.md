# 服务器界面第二版：列表与详情分栏

日期：2026-10-19。状态：已实现。

## 视觉方向

把服务器首页整理成适合长时间使用的桌面工作区。采用安静的中性色、清晰的文字层级、连续的分栏和克制的选中态。首屏仍以服务器列表为主，右侧提供选中配置的查看与操作。

本次使用 Emil Kowalski 仓库中的 `apple-design` skill：`emilkowalski/skills` → `skills/apple-design`，已安装到 `C:/Users/bgaso/.codex/skills/apple-design/`。参考其即时反馈、空间一致性、字号与字重配合、减少动态效果和设计克制等原则。没有增加动画依赖，也不仿造 macOS 的窗口按钮。

## 布局与操作

| 区域 | 第二版处理 | 目的 |
| --- | --- | --- |
| 首页标题 | 标题、总数、简短说明；新增入口保留 | 明确当前位置，保持首屏直接开始工作 |
| 服务器列表 | 名称、账号地址、路径与标签按行排列 | 减少横向扫视，保持名称可读 |
| 选中态 | 浅色独立背景、细描边、图标强调 | 清晰标记选中项，避免大面积高饱和底色 |
| 配置详情 | 显示账号、认证、连接路径、标签和直传地址 | 次要信息有固定位置，不挤占每一行 |
| 主操作 | 详情区突出连接，复制和编辑为次级操作 | 明确操作优先级 |
| 配置编辑器 | 扩大宽度，统一控件和分组间距；只保留一个主按钮 | 减少拥挤，区分保存与保存并连接 |

列表保留双击连接、行内连接、复制、更多菜单和方向键选择。选中配置立即更新详情，不引入切换延迟或反复进场动画。

## 自适应与可访问性

- 宽度大于 1000 CSS px：列表与详情并列，列表占主要空间。
- 宽度不超过 1000 CSS px：默认保留整宽列表，通过标题栏“查看服务器详情”切换详情。返回保留搜索、选中项和滚动位置。
- 详情支持返回按钮与 Escape；图标操作有可访问名称和提示。
- 名称使用 16px 字体；长名称可换行，地址可复制并在详情中完整查看。
- 深浅主题使用对应的语义颜色；连接状态同时显示文字和状态点。
- 按压反馈保持轻微缩放；减少动态效果时移除变换与过渡；高对比度模式强化选中轮廓。
