# SoDeck 1.0.1

- 同一服务器只保留一个顶层工作区标签，终端改为服务器页内的二级标签，支持新建、切换、关闭、重命名、排序与溢出列表。
- 每个终端独立保持连接、输入输出和历史；文件、监控、Docker 与 NetBird 使用共享工具连接，关闭全部终端后仍可继续使用。
- 拆出独立窗口或移回主窗口时整体移动服务器工作区，保留所有终端连接与状态；迁移失败时恢复原工作区。
- 文件浏览位置与终端目录分离，通过“定位到当前终端目录”显式同步，避免多个终端互相影响。
- 重做系统设置窗口，使用分类导航和独立详情面板，更快找到通用、终端、软件更新与诊断设置。
- 优化主题、开发者模式和终端复制粘贴设置的分组布局、即时反馈、状态提示与键盘可达性。
- 适配窄窗口、深色模式、减少动效和高对比度环境，避免设置内容横向溢出。
- 增加系统设置分类切换、焦点管理和响应式布局回归测试。
