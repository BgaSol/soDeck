# SoDeck 1.0.0

- 工作区新增两侧工具入口，可独立收放远程文件、Docker、服务器状态和 NetBird，收放时保留面板内容与终端连接；适配窄窗口和放大字号。
- 端口转发新增内网代理，支持 HTTP、HTTPS CONNECT 和 SOCKS5，提供配置指南及连通性测试。
- 修复代理访问慢目标时反复重连的问题，单个目标超时不再中断其他已连接页面。
- 统一服务器配置窗口，支持在同一份草稿中编辑或另存为新服务器，并改进快捷操作、服务器选择和已保存密码复制。
- 新增自动检查和后台下载更新，可分别开关；关闭设置后下载继续。
- 下载和验证过程中可以取消，同一版本不会自动反复下载。
- 安装由你确认，普通退出不会触发安装。安装前会检查文件任务并说明需要断开的会话；工作状态变化时会重新确认。
- Windows EXE、Linux AppImage 提供应用内更新；MSI、DEB 和 macOS 提供对应安装包入口。
- 安装包会校验签名与版本，安装后在下次启动时显示实际更新结果。

已有服务器配置和本地数据位置保持不变。
