# SoDeck 使用指南

本指南介绍日常操作。各版本的功能变化、升级要求和验收范围见 [GitHub Releases](https://github.com/BgaSol/soDeck/releases) 与 [版本记录](releases/)。

## 安装与插件

从 [核心下载入口](https://github.com/BgaSol/soDeck/releases/latest) 选择对应系统和架构的安装包。各平台的安装和升级方式见 [分发文档](distribution.md)。

Windows 新安装默认面向这台电脑的所有用户，安装及核心升级需要管理员确认；日常启动无需以管理员身份运行。旧用户安装改为系统安装的步骤见分发文档中的“Windows 安装范围与图标”。

核心安装包不包含业务插件。打开设置 → 插件管理，未安装任何插件时直接显示“官方插件”，可安装终端、文件、网络隧道和系统状态。安装完成后留在列表，显示“重启后启用”，可继续安装下一款，最后统一重启。“已安装”管理启停与详情；“从本地添加”选择包含 `plugin.json` 的已解压插件目录。

官方名单从仓库自动读取，新增插件不再要求升级核心来更新名单。打开插件管理时异步获取，成功结果缓存一小时；“刷新列表”可立即重新获取。网络失败时保留上次成功列表并显示提示，首次没有缓存时显示错误和重试入口；本地添加与已安装插件仍可使用。列表中出现插件不代表已有适合本机的正式包，安装时会检查版本、核心 API 和平台。

启用和关闭只保存期望状态，重启后统一生效；应用启动时按保存配置加载插件。可以连续修改多个插件，再重启一次。

核心与插件独立更新。设置 → 软件更新按“SoDeck 应用”和“已安装插件”展示，插件中需要处理的项目优先排列。可检查全部、下载全部或选择部分，失败项可单独重试；插件管理中的更新入口会定位到此页的对应项目。准备完成后按提示统一重启。插件有兼容要求时，先升级核心，再升级插件。没有更新来源的本地插件通过手动更新维护。

展开“更新说明”可按 Markdown 阅读标题、列表、强调、代码、引用和表格；网页链接在系统默认浏览器打开。

关闭插件并重启后，可以移除其登记；移除登记不删除插件程序、数据、消息和日志。

### 下载与网络（加速分支，尚未发布）

设置 → 软件更新 → **下载与网络**默认开启“GitHub 不通时使用加速地址”。客户端先访问原始地址，失败后尝试启用的自定义地址和内置地址；近期失败的地址短时跳过，恢复后重新优先直连。此设置覆盖版本检查、官方插件目录与配置、更新清单、核心安装包和插件安装包，包含首次安装、单项/批量更新及后台检查。

可添加最多 10 个 HTTPS 转发前缀，例如 `https://example.com/proxy/`；客户端会在前缀后追加完整 GitHub URL。地址不能包含用户名、密码、查询参数或片段。填写名称后可上移、下移、停用或删除，点击“保存设置”应用。保存冲突时当前输入保留，可“重新读取已保存设置”后再编辑。保存只影响后续任务，正在下载的任务继续使用原设置。

内置地址可逐个停用；标记“仅清单与安装包”的地址不用于 GitHub API。“测试”只访问选中的地址，分别检查发行 API、插件目录与配置、更新清单和最多 64 KiB 的包首段。测试成功不等于完整包已通过校验，也不保证后续一直可用。

下载中断或校验失败会换地址从零重新下载，进度可能回到起点。全部失败时可展开“查看原因”核对尝试过的地址，再修改设置或重试。更换节点保留已有候选和已经准备好的更新。核心包继续使用 Tauri 官方签名验证，插件继续校验 SHA-256、平台与清单；第三方节点可能限流或缓存旧资源。使用详情及本轮验证范围见[实施记录](implementation-update-acceleration.md)。

## 管理与连接服务器

服务器管理页面支持新增、编辑、复制、删除、搜索和分组，也可以维护 SOCKS5 代理。访问路径中可混合排列 SSH 跳板与 SOCKS5 代理。

1. 新增服务器，填写地址、端口、用户名，并选择密码或私钥认证。
2. 按需要配置访问路径和是否记住认证秘密。
3. 单击服务器查看详情，双击连接并进入工作台；详情中也可以点击“连接服务器”。

已连接时会切回现有工作台，连接中会复用同一次尝试。首次连接到每站 SSH 服务器时，确认该站主机指纹后才提交凭据。

SSH 认证失败时，可以重新填写密码或私钥口令。整条连接成功后，勾选记住的补填值才会保存并替换旧凭据；输错、取消或连接失败不覆盖原凭据。未勾选记住的补填值仅本次连接有效。

断线后，工作台底部显示“重新连接”，也可以从服务器管理页面再次发起连接。

目录中的会话状态来自已有连接，不进行在线探测。连接失败的站次、阶段和原因保留在详情连接卡中，可重新连接或编辑资料。主机身份确认中的原、新指纹可分别复制核对；复制不会表示信任。

## 使用工作台

一级标签按服务器组织工作区，中央区域可以有多个标签组。同一服务器的页面可以分布在多个窗口，仍复用原服务器连接。一级加号提供服务器选择入口，每个中央组的加号在该组执行插件声明的默认行为；终端插件推荐“新建终端”。新连接留在发起窗口；定位已有工具或文件时会跳到它所在的窗口。

两级标签栏保留标题、状态、× 和＋，整理操作通过右键或聚焦后按 Shift+F10/菜单键打开。右键非活动标签不切换当前内容，Esc/Tab 收起菜单并返回入口焦点。右键分屏标签栏空白处提供“左右分屏”“上下分屏”，多分屏时还有“取消此分屏”；取消会按阅读顺序合并到前一个分屏，没有前一个则合并到后一个，保留页面、草稿和会话。分屏可以嵌套，每组独立切换页面；拖动分隔线调整比例，方向键每次调整 5%，Shift 加方向键调整 10%，Home/End 移到当前可用范围两端，双击回到一半，Esc 取消当前拖动。空间不足的拆分入口会禁用；窗口过窄时临时只显示当前分屏，通过“其他分屏（数量）”访问其他区域，列表保留未保存与错误提示，扩大窗口后恢复完整树。

右键中央页面提供“移到右侧分屏”“移到下方分屏”“移到新窗口”和“关闭标签”。已有有效来源时显示“返回原窗口”，否则主窗口仍有同服务器工作台时显示“返回主窗口”；返回优先使用原组与相邻标签的位置，原组消失时回到该窗口的当前组。中央工具提供“停靠到侧栏”和“隐藏工具”，以及适用的移窗、返回入口。拖动一个页面标签、标签组栏的空白处、工具面板标题，松到另一组的中央可合并，边缘可新建分屏；拖出应用窗口形成独立窗口。服务器顶部标签拖动或菜单移动的是该窗口内的整份服务器工作台。编辑弹窗需先完成或关闭后再移动。

主窗口的服务器右键菜单只有“移到新窗口”和“关闭标签”；独立窗口提供“返回主窗口”和“关闭标签”，多个服务器标签时还可移到新窗口。“关闭标签”与 × 相同，只处理当前窗口中的该服务器工作台。移动成功后回收空独立窗口。新窗口按来源组或工作台尺寸估算，并限制在目标屏幕可用区域；返回主窗口会同时显示主窗口并取消最小化。

工具菜单可以停靠到左侧、右侧、中央或新窗口，也可把工具拖回左右停靠区。工具隐藏继续后台工作；已有单例工具在另一窗口时，入口会定位过去。页面、组和整工作台的跨窗迁移均需要 UI v2 插件，旧 UI v1 插件可继续使用同窗布局。Wayland 使用菜单移到新窗口和返回，同窗拖动继续可用；不提供任意已有窗口目标列表。

移窗保留原业务实例、草稿和终端会话，目标准备期间保留源页面；交接输入时暂时停用源输入，失败返回原位置。文件目录跟随本服务器最近实际操作的终端，切到文件编辑器或其他窗口不会换掉跟随目标。

每台服务器记住分屏树、比例、侧栏宽度、工具停靠和浮窗尺寸。启动仍显示服务器管理；主动连接时恢复首份工作台结构，终端、文件和任务按原启动策略新建，不恢复旧命令或旧文件。额外历史窗口不自动重开。布局损坏保留原文件并提示，当前工作台仍可操作。

拖动两侧分隔线调整宽度，松手后保存；聚焦分隔线后可用左右方向键调整。Esc、失焦或切换工作区会取消尚未松手的调整。空间不足时先限制侧栏宽度，再临时隐藏侧栏；放大窗口后恢复偏好。保存失败会提示并恢复已确认宽度。

同一个面板菜单入口再次点击会关闭菜单；Esc 返回入口，点击其他位置保留新位置的焦点。面板菜单中的“新工作区自动展开”只改变新工作区的默认偏好。

主窗口和拆出窗口的顶部空白区域可拖动；双击在最大化与原窗口大小、位置之间切换。服务器标签和顶部按钮保留各自操作。

- **终端**：可打开多个远程 shell，使用同一服务器连接；工作区移窗时保留原终端会话。
- **文件**：单击选中目录树条目，双击文件打开中央编辑器；支持文件和文件夹批量上传下载、远程文件管理以及保存冲突检查。
- **网络隧道**：管理当前服务器的 TCP 转发和 SOCKS5 代理。默认绑定本机回环地址；关闭工作区、服务器断线或插件退出后释放端口。

插件的详细能力、使用限制和开发入口见 [终端](../plugins/terminal/README.md)、[文件](../plugins/files/README.md) 与 [网络隧道](../plugins/network-proxy/README.md)。

文件右键菜单按单文件、目录、多选和空白区域提供对应操作。“新建”和“上传”在子菜单中；展开/折叠使用目录箭头、双击或方向键。粘贴只在有有效本地文件或当前连接的远程复制/剪切来源且目标有效时可用；复制路径产生的文字不会启用文件粘贴。多选时保留选择范围，目录写入操作进入右键目录，空白菜单使用文件浏览器根目录。

文件任务按需要处理、进行中和已完成展示，成功项默认收起，可展开查看结果；冲突、失败和需要核对的结果不会自动藏入成功摘要。“下载远端”获取服务器当前版本，“导出草稿”获取此页当前内容，包含未保存更改，断线后仍可导出。

登录终端退出后可点击“新建终端”打开新的 shell；指定命令终端显示“重新打开终端”，使用原启动命令、标题和目录策略创建新页面，原页保留输出。连接断开时先从工作台重新连接。默认行为提供者不可用时，“打开插件管理”进入设置，安装或启用后重启生效；不会自动改用其他行为。

默认行为等待超过 5 秒时显示“结果尚未确认”，按钮暂时禁用，工作台查询原结果。切换工作区或移窗后恢复查询，后台完成不会抢当前焦点。指定命令终端的目录集成关闭，其目录控制序列不会导航主机文件侧栏。当前源码的接口与验证范围见[默认行为与通用终端实施记录](implementation-default-behavior-terminal.md)。

## 关闭与重启（整改分支，尚未发布）

关闭页面、工作区、窗口或重启应用时，会先同步目标窗口中的组件输入，再统一处理未保存内容。可选择保存、放弃或取消。应用退出和重启同时检查服务器表单以及所有组件设置草稿，包含当前未选中的页面。需要在原服务器表单完成校验时，取消关闭后回到原表单处理，再发起关闭。

保存失败或输入无法确认时保留页面和草稿。已接受的保存仍在执行时，取消要先核对原调用，不能立即重新开始编辑；未知输入只有明确放弃后才继续关闭。开始资源清理后不能撤销，失败显示未完成原因，选择“继续完成关闭”续办原步骤。后台状态组件随工作区释放，收起侧栏只改变显示。

窗口意外消失时，核心按实际归属回收资源；尚未持久化的界面输入可能无法恢复。更新安装失败后，已经停止的会话保持停止，可重试收尾或退出应用。系统安装器仍在执行时需等待原尝试结果。

## 组件共享状态与文件联动（核心 0.13.0 起）

文件侧栏的「跟随终端」默认开启，也可在文件列表设置中保存开关。只有当前活动终端的可靠目录报告会触发定位；同一路径重复报告不会打断手动浏览。隐藏、断线、目录未知或关闭跟随时保留当前位置。重新开启跟随会定位当前有效目录。

核心 0.14.0、终端 0.4.0 和文件 0.6.0 起，新终端默认自动识别远端 Linux Bash（4+）/Zsh 的目录，无需填写主机名或修改服务器的启动配置。先更新这三个组件并重启，再新建终端；旧会话不会补注入脚本。首次提示符和后续目录变化自动定位，普通命令结束不会打断手动浏览。

文件树底部显示实际跟随状态。展开可查看原因、shell、最近确认时间，并使用“定位到终端目录”重新定位。进入嵌套 SSH、容器、sudo 登录或子 shell 时保留原位置；返回外层提示符后恢复。自动模式通过临时标记检查终端与文件服务的文件系统对应关系，无法对应时保留位置，不猜测同名路径。

终端设置的“目录联动”可选择自动识别、兼容已有 OSC 7 配置或关闭，选择只影响新终端。远端 Fish、PowerShell、非 Linux 系统，以及冲突的 Bash DEBUG 钩子/调试选项，继续提供普通终端并说明自动识别不可用。

已有 OSC 7 脚本可选择兼容模式，并填写“兼容模式主机名”。该模式仍要求用户确认与文件服务使用同一文件系统；进入容器、chroot 或嵌套 SSH 前关闭跟随。不会混用自动与手动报告。UNC 和未知文件系统映射仍不支持。完整实现与验证边界见[终端目录实施记录](implementation-terminal-directory.md)。

系统状态插件将采集到的挂载与容量发布到核心。文件树匹配的节点显示「挂载」或「只读挂载」，悬停查看来源扫描覆盖、容量及过期状态。拓扑与容量分别计时；部分扫描缺项保留旧事实并让它过期，来源退出则移除其标记。多个来源时明确选择一个，容量只与同一来源的挂载关联。Windows 当前提供固定本地卷主路径，macOS/BSD 使用 df 部分信息；这些结果不声称完整系统拓扑。

实际验证范围见[组件通信实施记录](implementation-component-communication.md)。

## 系统状态插件

先升级到核心 0.10.0，再从设置 → 插件管理 → 官方插件选择「系统状态」，安装后重启启用。也可导入 `npm run plugin:build -- --plugin system-status` 生成的本地目录。插件需要 `session.exec.v1` 和 `ui.background.v1`，旧核心会提示升级。

连接服务器后默认在右侧展开。收起、切换服务器和移窗仍采集；关闭工作区结束采集。刷新合并为一轮，暂停/恢复只影响当前工作区，暂停时刷新一轮后保持暂停。组件设置的 3/5/10/30 秒只影响动态指标；拓扑 30 秒、容量与运行时间校准 60 秒，规格按连接或刷新读取。

面板先显示服务器概况、CPU/内存、选中网卡的接收与发送，再列出各挂载的已用和剩余空间；容量使用率达到 85% 时标注“空间偏紧”，不自动弹出通知。磁盘 I/O、设备规格和采集来源按需展开。趋势保留五分钟，悬停可查看读数；聚焦曲线后用左右方向键逐点查看，Home/End 到两端，Escape 关闭读数。首轮速率显示采样中，断线和暂停保留旧值及最后成功时间，刷新失败保留数据和原因。Windows 未映射的网络数据按性能计数器实例显示；缺少可靠数据源的指标显示不可用。兼容和包验证范围见[实施记录](implementation-system-status.md)。

系统名旁显示远端 CPU 架构，常见名称统一为 x86_64、ARM64 等；读取不到时显示“架构未识别”。展开设备信息可查看独立架构项、处理器完整型号与核心数。

## 外观、日志与消息

设置默认打开外观；左侧“偏好设置”包含外观和已安装插件的组件偏好，“应用管理”包含插件管理、软件更新、应用与数据。外观提供跟随系统、浅色、深色和多巴胺主题，选择后保存。主题同步到工作台和官方插件。

状态、设置和消息入口位于窗口右上角。插件日志用于排查问题，重要消息面向用户；普通错误日志不会自动弹出通知。插件详情可查看对应来源的日志。

组件偏好的保存操作始终位于内容底部；终端和文件编辑器的字体样本随草稿字号、行高变化，保存后才应用于组件。日志的“清除筛选”一次重置来源、级别、正文和时间范围，保留暂停状态。设置的“应用与数据”提供在线使用帮助入口。

## 数据与凭据

应用设置、服务器资料、插件数据、日志和消息保存在系统应用数据目录，独立于安装目录。

选择记住的密码和私钥口令以明文保存在 `servers.json` 中；私钥只保存路径。未记住的秘密不写入该文件，仅在当前运行中使用。新建服务器、切换认证方式和认证重试表单默认勾选记住，可以按需要取消。

服务器资料异常时保留原文件，并提供从上一份有效备份恢复的入口。
