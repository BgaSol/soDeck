# 两级 Tab 新建入口重新规划

状态：提案，尚未实施。2026-11-05 按用户要求回退上一版两级 Tab 加号方案；其他已确认改动保留，本轮停止发行。

## 目标与范围

让用户从两级标签附近找到打开服务器和新建组件的入口。以现有服务器目录、连接流程和组件创建菜单完成操作，先完成一个小范围、可直接验收的改动。

上一版同时加入了服务器搜索浮层、跨窗口新建资料、拆分创建按钮、默认类型的跨窗口和重启持久化，以及核心布局操作。实现与发行验收被绑在一起，反馈周期过长。这些扩展已经回退。

## 建议的第一版

| 入口 | 点击结果 | 复用的能力 |
| --- | --- | --- |
| 一级 Tab 末尾的 `＋` | 显示现有“服务器管理”，切到服务器列表并聚焦搜索；用户从既有目录选择服务器、连接或新增资料 | 现有目录、搜索、资料表单、认证和工作区定位 |
| 独立窗口的一级 `＋` | 定位主窗口，并打开同一服务器目录入口 | 既有请求主窗口处理动作的通道 |
| 二级 Tab 的 `＋` | 复用现有组件创建入口；只有一个可创建类型时直接创建，多个类型时显示已有创建菜单 | 现有组件声明、创建动作及菜单 |
| “全部页面”入口 | 继续只切换已打开页面 | 现有页面列表 |

一级入口的代价是需要进入服务器目录；它同时保留目录已有的搜索、分组、编辑和连接反馈。若后续实际使用仍觉得步骤过多，再单独评估搜索浮层。

第一版不保存默认组件类型，不修改 `ui-layout.json`，不增加插件 API、生产依赖或新连接状态。文件编辑器继续通过文件资源打开。快速创建默认类型作为后续独立需求重新评估。

## 样式规则

- 按 apple-design 的清晰层级、直接反馈和克制原则处理入口。两个 `＋` 使用同一套公共图标和按钮规则，图标 16px、命中盒 28px；按下即反馈，键盘焦点清晰。
- 按钮固定在标签滚动区域之外，长标题与标签溢出不遮挡操作；沿用现有一级 44px、二级 36px 的条高。
- 继续使用公共主题变量。浅色、深色为 1px 结构线，多巴胺为 2px；加号按钮不单独绘制黑框，不在业务组件重新定义色板或边框粗细。
- 保留已完成的底栏简化、三主题、终端剪贴板及原有移窗和关闭行为。

## 可验收行为

1. 主窗口、独立窗口均能通过一级入口到达现有服务器目录；搜索、创建资料和连接沿用原来的流程。连接失败不创建工作区，已有连接仍定位原工作区。
2. 二级入口覆盖零个、一个、多个可创建类型；无类型时明确提示原因，按资源打开的编辑器不列入直接创建菜单。
3. 浅色、深色、多巴胺及窄窗口中两个入口都可见，菜单不越界；Tab、Enter、Esc 可操作，关闭菜单后焦点回到触发按钮。
4. 不新增配置字段，重启后不存在需要迁移的新建偏好。底栏点击不再弹出连接菜单，断线重连继续可用。

## 实施和交付顺序

先确认这份交互范围，再单独实施和验证。前端与相关核心小改通过类型、格式、相关测试和正式前端构建后，提供真实界面供检查。交互确认完成后再准备版本、运行既有五平台打包及实际包验收，最后单独发布。

本轮只交付旧方案的回退和这份提案，不创建新版本标签、不继续打包或发布。已有发行验收暴露的烟测重复回复和 SSH 限时问题另行定位，不混入 Tab 交互实现。
