# 两级 Tab 与右键菜单精简实施

日期：2026-11-09。功能方案见[两级 Tab 与右键菜单精简](plan-tab-interactions.md)，发行来源与五平台报告集中记录在[核心 0.19.0](releases/v0.19.0.md)。

## 已实现行为

一级与二级标签栏删除三个点。服务器菜单最多三项；普通页面只保留两个分屏方向、移到新窗口、适用时单一返回入口及关闭。中央工具提供停靠与隐藏，侧栏面板和插件正文的业务菜单保留各自职责。右键非活动标签保持当前内容，菜单指向被点击对象；支持 Shift+F10/菜单键、方向键、Enter、Esc/Tab，失焦和对象变化时收起。

分屏标签栏空白右键提供左右/上下分屏及适用时“取消此分屏”。取消按阅读顺序合并到前一组，否则后一组；复用核心原子合并，不进入关闭流程，不释放页面实例。移动唯一页面创建分屏时保留显式空源区域；填入页面后恢复普通空区域回收。空间不足时禁用分屏并显示统一说明。窄窗口以“其他分屏（数量）”访问隐藏区域，显示页面名称和未保存/错误状态，扩大后恢复原布局。

移窗、关闭沿用既有请求回执和生命周期。关闭服务器标签的对话框使用对应范围名称；失败页面的“重试显示”位于错误内容中，不占普通菜单。此前空标签组关闭一直等待的缺陷已单独提交修复：初始化关闭输入时包含发起窗口，使无页面的输入确认也能完成，原因与回归见[关闭实施记录](implementation-close-lifecycle.md)。

## 验证

本机布局集成已通过：真实核心与 UI v2 插件、唯一页面分屏、显式空分屏取消、有内容合并、草稿/iframe 连续、独立创建、分隔线键盘与取消、窄窗口导航、单页移窗/原位置返回、内部双工作台原子返回、工具实际停靠。三主题及 540×360/1280×800 截图已渲染检查。

Windows x86_64 本机类型、Rust 格式、正式前端构建、91 项脚本、209 项核心测试（12 项远端用例按标记跳过）通过；扩展后的两方向分屏回归单独重跑通过。9 项浏览器交互、完整工作台 UI、布局 UI 和正式打包前端 UI 全部通过，页面错误为空。核心回归覆盖两方向唯一页面分屏、旧 revision 拒绝、合并实例不变、填入显式空区域后的回收及多页分屏。界面回归覆盖错误局部重试、右键重复打开、非活动标签、菜单键/Tab/Esc 焦点和短菜单位置。设计检测器无发现，三主题和窄/宽窗口截图已检查。

## 边界

没有新增生产依赖或修改业务插件版本。普通菜单主动移除整组移窗、已有窗口目标列表、批量返回、手动放大和历史额外窗口恢复；内部系统流程仍可使用既有核心能力。Wayland 的菜单保留新窗口/返回，任意已有窗口移动依赖平台已有拖拽能力。

浏览器截图和输入测试不能代替五平台原生安装包验证；本版本的五平台包已完成原生架构、安装/解包、启动、重开和退出，Windows 原生窗口中的右键、键盘菜单和终端迁移验收也通过。原始运行及独立插件组合报告见版本说明。本轮不增加中键关闭、新全局快捷键或插件权限体系。
