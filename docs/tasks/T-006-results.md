# T-006 实施与验证记录

2026-10-25 · 适用方案 T-006 r2 / F-CORE-008 r2 / F-TERM-002 r2 / UI r8 / 主题 r1

本次交付 Windows x64 开发包，核心 `2.0.0-dev.3`、SDK/API `3.0.0`、终端 `0.3.0`、`workspace.v3`、`ui.presentation.v1`、布局 schema 3。实现及本机开发包已交付，必需环境验证仍有缺口，任务保持开发中；不记为工程全部完成、用户已验收或发布。

## 1. 实现与入口

- 配色唯一来源为 `themes/graphite.json`。完整覆盖语义/交互状态、阴影、遮罩、终端前景/背景/光标/选区/滚动条、ANSI 16 与扩展 240 色。核心完整校验并分发只读快照；SDK、外壳、插件与原生菜单消费同一份数据，无效主题整份回退。远端真彩色保留原意。
- 主界面保留服务器与页面两层 Tab，中央单组；移除终端会话列表、分屏、底部终端位置和重复工具栏。长名称裁切并保留完整提示；溢出时提供可搜索列表。没有系统生成的 Tab 省略号或更多按钮。
- 右键和键盘菜单由核心原生呈现，仅向来源返回选项 ID，插件执行业务。菜单运行在独立原生消息线程，打开立即回执，避免阻塞 Tao 的调用处理。支持取消、一次结束、绑定代次及有界结果查询；终端画面持续可见。
- 通用文本命令声明承载重命名，插件校验业务状态与名称；核心不识别终端命令名。普通模态保留草稿，IME 组合时不误提交。
- 有选区 Ctrl+C 复制成功后清除原选区，无选区 Ctrl+C 中断；保留 Ctrl+Shift+C。三种粘贴键位与菜单共用一次读取/提交路径，过期焦点、挂载或 PTY 结果丢弃，不自动重放失败输入。
- 布局先备份再合并，插件按归属退役视图；未知缺失视图保留恢复占位。写入失败保护原文件，可在应用菜单重试保存有效候选。重启显示结束占位，显式重连在同一视图创建新 PTY。

启动：`.local/dev/SoDeck-v2-T006/Start-SoDeck.cmd`。运行数据在本包 `data/`，未覆盖 T-004 包或原数据。T-005 的直接启动/设置、主题选择/编辑/热切换不在本包。

工作区基线为 `557728f3d71a4aec0ddbf5be5a1deff65d9a0a78`，分支 `codex/t-006-workbench-interaction`，验证对象是未提交工作区，包含既有 T-004 改动。初始文件备份在 `.local/t006-baseline/`，未重置、提交、推送或发布。最终产物 SHA-256、构建时间与 dirty 标记以包内 `build.json` 为准。
