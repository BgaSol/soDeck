## 1. 目的与设计判断

推测用户希望 SoDeck 成为打开服务器后可以直接工作的桌面工具：主要空间留给终端，需要时从两侧取用工具；创建操作采用合理默认值；列表优先展示可以行动的信息；焦点、滚动和窗口状态始终可靠。

本轮沿用三主题与现有插件架构，用同一套公共控件修整现有流程。使用已读取的 `apple-design`：控件按下即时反馈、入口靠近操作对象、展开与收起方向一致、动效可中断、常用项优先、键盘及减少动态效果可用。多巴胺继续无投影，尺寸和命中区域不随主题改变。

用户已澄清：第 3 项为服务器分组，添加时选择或新建，并有独立管理页；第 5 项另一插件为 `sodeck.files`。这些是需求澄清，不是本方案编码确认。

## 3. 两个主要流程

### 3.1 添加服务器

推荐约 600px 宽、内容限高滚动、底部操作固定。使用内容分组，不增加填写向导。

```text
添加服务器
显示名称 [                         ]
主机地址 [                 ] 端口 [22]
分组     [未分组          v] [新建分组]
认证方式 [密码            v]
用户名   [          ] 登录密码 [         ◉]
                       ☑ 在此设备上记住密码
连接方式 [直接连接        v]
（选择跳板时才展示跳板与路径）
                          [取消] [保存并打开]
```

分组是服务器整理属性，名称、凭据和 SSH 路径保持各自职责。管理页从服务器选择器进入；删除分组后服务器回到“未分组”，不删除服务器或断开连接。具体事务、取消和异常见 SM 流程。

### 3.2 网络隧道

右侧按钮名称“网络隧道”，默认收起；点击展开约 360px 的工具侧栏，与左侧文件树并存。常规窗口挤出中央空间；窄窗口优先确保终端最小宽度，必要时临时收起另一侧栏，窗口放宽不强制重新展开。侧栏可调整宽度，不另开 OS 窗口。

```text
文件侧栏 │ 终端 1 │ 终端 2 │ ＋          │ 网络隧道 · 当前服务器   [收起]
         │                              │                       [＋ 创建]
         │         终端内容             │ 内网代理 · 运行中       [停止]
         │                              │ 127.0.0.1:实际端口       [复制]
         │                              │
         │                              │ 10.0.0.8:3306 · 已停止   [启动]
```

列表首要信息是类型、名称/自动标题、真实入口、状态和启停。单击规则进入同一侧栏的详情页，可返回列表；编辑、删除、连接检查、流量和完整路径在详情中，避免一行堆放多个按钮。新建统一从“创建”进入，默认内网代理，切换“端口转发”才显示目标地址与端口。

名称留空时以“内网代理”或“转发至 主机:端口”生成标题；不因名字为空阻止创建。两种类型均默认自动端口，手动选项才展开端口输入；就绪后显示实际地址并可复制。自动分配在下次停止后启动可能变化，界面明确说明；已有规则的手填名称和固定端口不被覆盖。

收起侧栏、切换服务器和收到状态更新均不停止隧道，也不强制打开侧栏。停止是明确操作；关闭服务器工作区/明确关闭逻辑视图或退出 App 按现有生命周期释放。默认右停靠，保留显式移到中央/独立窗口能力以兼容已有使用方式；移动保持同一视图与运行。

核心负责分组持久化、数据库预检/备份重建、插件元数据、窗口/停靠与入口；终端负责 xterm 适配；文件负责目录和容量语义；网络插件负责规则、表单和业务流程。公共 `@sodeck/ui` 统一焦点、加载指示和窗口控制样式。新公开契约保持向后兼容，按能力协商接入；不跨插件直接通信、不把业务放回核心。

数据库只读核实：core.sqlite保存服务器/路径、主机信任、调用记录和settings，secrets为独立加密文件；插件storage.get/set、包/激活状态以及主题/窗口偏好另存文件。重建清空核心库业务数据并启用空凭据目录，独立文件保留；旧规则不自动匹配同名新服务器。备份必须包含已提交WAL及加密凭据，验证成功且新库就绪后才替换；失败/中断按启动规格保留恢复路径。此规则替代r2增量迁移提案，不改写历史任务的迁移事实或插件API兼容。
