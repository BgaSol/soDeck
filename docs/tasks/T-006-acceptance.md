# SoDeck v2 · T-006 开发包

本包为 Windows x64 开发构建：核心 2.0.0-dev.3、终端 0.3.0、API 3。不是发布版本。具体检查、证据及剩余验证见包内 RESULTS.md（仓库来源 docs/tasks/T-006-results.md）。实际截图在 screenshots，脱敏测试摘要与日志在 evidence。

双击 Start-SoDeck.cmd 启动。数据保存在本目录 data，不读取旧 T-004 开发包数据。保留启动脚本是现有开发包的行为；T-005 的直接启动与设置功能尚未纳入本次。

1. 添加隔离测试服务器，打开工作区，新建两个终端并切换。顶部保留服务器与页面两层 Tab；左侧没有会话列表，终端没有分屏入口。
2. 右键服务器或终端 Tab：修改名称、拆出或返回、关闭。按 Esc、点击菜单外部、切换窗口，检查菜单收起。长名称裁切，完整名称通过悬停提示和溢出时的可搜索列表查看。
3. 有选区时 Ctrl+C 复制并清除选区；再次 Ctrl+C 发送中断。Ctrl+Shift+C 明确复制。Ctrl+V、Ctrl+Shift+V、Shift+Insert 及右键菜单粘贴均只提交一次。
4. 终端右键可改字号。远端捕获鼠标时使用 Shift+右键或 Shift+F10 打开本地菜单。菜单关闭后继续输入，检查原会话及输出保持。
5. 拆出终端和完整工作区，返回主窗口。退出应用后重新打开，保留结束占位；重新连接创建新 PTY，不恢复旧句柄或重放命令。

所有应用配色集中在 themes/graphite.json，核心完整校验后向各窗口及插件提供同一主题快照。本次没有主题设置或热切换页面。无效主题整体回退，错误会显示在主界面。

升级/回退：请在数据副本测试。旧布局升级前生成 workbench.pre-v3-*.json 备份；旧核心不能读取 schema 3 或 API 3 插件。回退时使用原 T-004 包、原插件数据世代和布局备份，保留新目录用于排查，不用旧包覆盖新数据。

构建来源、版本与 SHA-256 在 build.json。用户验收和发布独立于工程测试，本次不执行发布。
