# T-008 试用说明

本目录为 Windows 开发版：核心 `2.0.0-dev.5`、文件 `0.1.0`、原终端 `0.4.0`、SDK/API `4.1.0`。双击 `Start-SoDeck.cmd`，试用配置保存在本目录 `data`；不自动复制旧包或日常数据。远端首轮支持 Linux/OpenSSH，只读浏览。

1. 添加或打开一台 Linux 服务器，按提示完成主机信任和认证。应自动出现首终端和左侧“文件”，连接就绪后显示 `/`；没有可用连接时可在文件面板“连接并读取”。
2. 展开目录，检查文件行右侧大小；选中文件查看精确字节数。输入绝对路径可直接定位，刷新和隐藏文件按钮位于树上方；目录不递归计算大小。
3. 选择带“挂载”标记的目录，下方检查挂载位置、来源、文件系统、读写状态、容量及高级信息。普通后代与挂载点区分；权限或命名空间无法确认时显示未知/不可用。
4. 打开第二台服务器，分别定位不同目录并切换。各自选择保持；将完整服务器工作区拆到新窗口、合并回来或移动文件侧栏，终端和文件归属应保持。
5. 关闭最后一个终端后继续浏览文件。关闭服务器再打开会从新现场开始；通过“应用 → 退出 SoDeck”完整退出后重启，应为空工作台，已保存的服务器配置仍在。“×”只收起托盘，保留本次会话。

真实截图见 `screenshots/graphite.png`、`screenshots/network-mount.png`，检查结果见 `RESULTS.md`，版本和哈希见 `build.json`。已验证 Windows 原生、隔离 Debian、真实 CIFS/bind/Btrfs 等挂载、独立更新/回退及性能；200% 系统缩放和 150% 文字放大已测，150% 系统缩放仍待补验。此包不是安装器或正式发布，用户验收尚待反馈。
