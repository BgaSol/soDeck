- 两套独立完整主题：灰白浅色、蓝灰深色，蓝紫选中与焦点，品牌空态和主题预览点缀柔和渐变。按 apple-design 统一系统字体、留白、圆角、表单、状态和按下反馈；实际工作内容保持实色。
- 各窗口“应用 → 外观”立即切换并持久保存。首次默认深色；终端跟随全局。系统高对比优先；保留所选明暗，不增加自动跟随系统或终端独立主题。
- 核心原子偏好保存、字符串修订与冲突检查、完整主题快照及预留状态容量。App 主题复用 `state.open/ack/close`，窗口由真实来源绑定；关闭工作区不会删除主题。单文档 SDK 订阅统一应用变量，失败保持最后完整主题并显示重试入口。
- `@sodeck/ui` 提供基础 CSS、通用通知与主题预览；没有业务调用。外壳累积 CSS 已整理；终端在原有 xterm 实例上换色，文件控制器保持原实例。文件实际行高测量用于虚拟范围、滚动与点击位置。
- 原生窗口和插件首屏注入当前主题底色；实时改变 native 背景和菜单。新插件实时更新；旧插件保持挂载主题到自然重挂载，外观页显示限制。API/能力不兼容的新包由旧核心拒绝。
