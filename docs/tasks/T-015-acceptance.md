# T-015 Windows 试用说明

对应任务 r3 / 代码方案 r2。应用 2.0.0-dev.12，API 4.8.0；终端 0.8.0、文件 0.5.0、网络隧道 0.2.0。使用 release profile 构建，未正式发布。

直接双击 `sodeck-desktop.exe`。需要已安装的 Microsoft Edge WebView2。此目录的 `portable.json` 使数据存于旁边的 `data/`，不使用 v1 或系统目录中的日常数据；保持 resources 与程序一起移动。目录包没有 CMD 启动器。

## 建议验收

1. 添加服务器：聚焦首尾输入框及密码框，检查边缘完整；用户名/密码同排。新建分组并选择，取消服务器表单后分组仍存在；在“打开服务器 → 管理分组”改名、删除。
2. 打开服务器后使用最后一个终端 Tab 后的“＋”。缩放窗口、调整字号、展开两侧工具，确认滚到底时末行和光标完整；查看历史时不被强拉到底。
3. 点击右侧“网络隧道 → 创建”。名称留空、默认自动端口，保存并启动后显示实际入口。收起列表继续运行，停止后不可复制过期入口。编辑与创建表单可以取消。
4. 文件树应直接显示隐藏文件；展开目录有加载反馈。挂载卷显示容量条，不再显示节点详情。调用记录中查询区固定，只有结果区滚动。
5. 切换多巴胺、浅色和深色，检查右上角三枚窗口按钮尺寸和悬停反馈。关闭主窗仍收起到托盘；应用菜单或托盘“退出 SoDeck”才结束全部会话。

## 数据库规则

数据库结构版本不一致时，启动先弹出提示，再将旧库和加密凭据备份至 `data/backups/core-schema-reset/`，建立空数据库。旧服务器、信任记录和数据库设置不会迁入；独立插件包、配置文件和外观偏好保留。失败不会自动覆盖可恢复的旧数据，会显示错误及日志位置。不要用日常数据测试重建，可使用独立副本。

启动日志：`data/logs/startup.log`。数据目录不可用时，原生错误提示给出临时诊断日志路径。具体工程验证、证据和尚未完成项见随包 `RESULTS.md`；本说明不是用户验收记录。
