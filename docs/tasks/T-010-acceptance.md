# T-010 试用说明

本目录是 Windows 开发包：核心 `2.0.0-dev.6`、终端 `0.5.0`、文件 `0.2.0`、插件 API `4.2.0`。双击 `Start-SoDeck.cmd`，本包的配置只保存在 `data`。连接 Linux/OpenSSH 服务器，按提示完成主机信任与认证；左侧文件树跟随当前选中的终端。

1. 在同一服务器新建两个终端，分别 `cd /tmp`、`cd /etc`，切换终端。左侧文件树应定位到各自目录；失败的 `cd` 不应跳转。打开第二服务器后，两边的文件树应互不影响。
2. 在文件树手动定位到另一目录，再在终端输入不改变目录的命令。手动位置应保持；下次成功改变终端目录后再跟随。关闭“跟随终端”可持续手动浏览，“定位到终端目录”仅执行一次，不改变开关。
3. 收起文件侧栏后连续 `cd`，重新展开时应只定位最新目录。编辑路径输入框期间到达新的终端目录，不应覆盖输入；取消文件读取后跟随暂停，明确重新开启或单次定位才恢复。
4. 在终端页脚关闭“Shell 目录集成”，新建终端应继续正常登录和运行命令，但文件树显示无法跟随；已打开的终端仍按原方式工作。重新开启后新建或明确重连，Bash 目录跟随恢复。设置跨 App 重启保留。
5. 拆出并合并整个服务器工作区，终端和文件树归属保持。关闭服务器工作区再打开，应从新现场开始；完整退出并重启后工作台为空，但服务器配置保留。

Shell 集成默认开启，SSH exec 登录可能额外读取一次非交互 `.bashrc`；有启动脚本副作用时可关闭本设置。首轮自动跟随验证 Bash 5.1/5.2；Zsh 可正常作为普通终端使用但不自动跟随。目录映射不能证实时明确降级，不会向已有终端注入 `pwd`。本包不是安装器或正式发布，用户验收尚待反馈。实测、截图、环境和限制见 `RESULTS.md` 与 `evidence/`、`screenshots/`。
