## 3. 工作区核实与设计影响

2026-10-27只读核实：

- 当前分支v2，大量未提交修改；本轮不回退、不运行新工具或实测服务器。
- core/network资源组已有按listener接入侧统计的累计字节，网络插件run/details显示发送/接收；不是所有SSH业务的统一通道计量。统一监控需保留旧口径，另增明确通道/传输视角。
- connection-status已有连接状态/路径入口；SSH transport内部桥有分段上/下行计数，不能将各层相加当作全局流量。
- ssh.rs使用keepalive_send维护连接，不能将发送成功直接当作有匹配响应的往返测量。
- SFTP由ssh2内部操作，统一通道计量需核实其低层采集适配；不能从返回条目JSON大小估算。
- T-016公共历史、问题、证据与存储仍是设计，四功能没有可直接引用的完成实现；本任务代码稿需明确交付所需公共子集并统一预算。
- 已读取apple-design（同一对话首轮），本次按层次、即时反馈、稳定空间/焦点、系统字型和无障碍使用；没有强加玻璃或动画库。

受影响消费者：核心连接/PTY/SFTP/exec/direct-tcpip、宿主身份与公共SDK、外壳状态栏及管理窗、公共UI图表/摘要、三个业务插件的可选用途标签与定位。历史与诊断按T-016统一服务衔接，插件不直接读库也不互调。现有插件/API返回形状及其他任务实现不由本轮文档改变。
