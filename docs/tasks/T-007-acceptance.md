# SoDeck v2 · T-007 开发包

双击 Start-SoDeck.cmd。此包为 T-006 基础上的服务器表单与选择器修订，运行数据在本目录 data；原 T-006 包及数据保留。核心仍为 2.0.0-dev.3、终端 0.3.0/API 3，具体任务、时间与 SHA-256 由 build.json 区分。

1. 点击顶部“＋”打开服务器选择器。搜索图标与输入同行，列表显示名称、地址和已打开状态；编辑/新窗口/删除按钮有提示，底部显示数量和添加入口。
2. 添加服务器，填写连接信息和可选登录密码。默认勾选“在此设备上记住密码”，密码加密保存；可以显示/隐藏输入。留空也可以保存，连接时再询问。
3. 保存后打开终端。新主机仍需确认指纹；预设密码正确时无需再次输入。正常退出后重启，记住的密码仍可使用。
4. 编辑服务器时不回显旧密码，留空保持；输入新密码可替换。取消勾选记住并输入密码保存，只在本次运行使用。保存失败会说明档案是否已保存，草稿保留，重试不会重复创建。

已有运行终端沿用原连接，新终端使用新配置。修改地址、端口、用户名或认证类型会使旧凭据失效。所有配色继续使用独立 themes/graphite.json。

实际原生宿主截图在 screenshots/native-picker.png 和 native-editor.png；浏览器两主题截图在同目录。测试记录见 RESULTS.md 与 evidence。Windows Tauri/DPAPI/隔离 SSH 已验证，浏览器覆盖保存失败与重复提交；不是正式发布，T-006 原有平台验证缺口见其记录。
