# T-026：统一桌面交互，隐藏 WebView 浏览器入口

任务状态：待方案确认 · 任务类型：功能/体验修正 · 修订：r1 · 更新日期：2026-10-28\
来源：[产品 P-67](../product.md) · 功能：[F-CORE-030 r1](../core/desktop-interaction.md)

## 1. 本次方案

用户反馈右键出现“检查”等浏览器菜单，先要求理解意图，随后明确：“你设计一个方案。我确认后你再开始改。”本轮只编写方案与测试流程，不修改应用、测试、原型或构建代码。

推荐由核心内置桌面交互模块统一处理 Tauri 外壳与 raw Wry 插件表面：移除浏览器菜单项目及内建快捷动作，保留业务菜单、原生文本编辑、终端按键/远端鼠标、系统缩放/窗口菜单；普通启动默认关闭开发工具，显式开发运行沿用现有调试通道。导航与未处理拖放不能把应用替换成网页。

本期 Windows，覆盖主/子窗口、设置/监控、应用菜单和插件弹框/内容，及移动和故障重建路径。模块随核心交付，不新增可卸载业务插件或第三方依赖；不变更公开 API/SDK、数据库、权限、插件生命周期及现有主题。实现、错误处理和完整边界以功能规格为唯一来源。

范围内技术细节由AI处理；需要用户确认的是整个 r1 方案，特别是核心常驻模块、标准编辑菜单、关闭整页缩放但保留系统/业务缩放、普通启动与开发调试的区分。用户未明确确认前不得进入编码。
