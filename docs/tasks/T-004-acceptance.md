# T-004 Windows 开发包

核心 `2.0.0-dev.2`，终端 `0.2.1`，插件 API 2。这是本机调试构建的目录包，尚未生成正式签名安装器或发布版本。

双击 `Start-SoDeck.cmd` 启动。需要 Windows 与 WebView2；数据保存在包内 `data/`。旧 T-003 开发包保留在独立目录。首次配套升级须保留旧核心、插件和数据副本；旧 `0.1.x` 终端不能直接用于新核心。

## 建议验收

1. 点击顶部“＋”添加/打开隔离测试服务器 A、B。确认服务器是顶部 Tab，没有另占一行的标题栏；再次打开 A 会定位已有工作区。
2. 在 A 新建两个终端，调整分屏并输入内容。通过服务器 Tab 菜单或拖动把 A 移到新窗口，确认内容与会话继续；把服务器 Tab 拖回，或通过窗口菜单合并。
3. 单独弹出一个终端，再移动整个 A 工作区。点击终端返回入口，确认它回到 A 当前所在窗口；切换 A、B 不串输入。
4. 试用最大化、还原、Snap、拖拽排序及 Esc 取消；输入中文后拆合窗口，确认光标与输入正常。
5. 主窗口右上角“×”收起到托盘；恢复后会话继续。关闭 A 的服务器 Tab 会结束 A 所有会话（包括弹出的终端），B 保持运行；应用菜单明确退出会结束全部资源。

## 实现与验证范围

一个 App 共享一个终端业务 worker，每个终端有独立会话和显示表面。核心提供窗口/工作区、通用视图/命令/元数据、迁移和关闭生命周期。切换窗口不会增加插件业务实例或重建 SSH。

沿用 App 总计 8 个终端/PTY、最多 2 个单视图独立窗口的限制；完整工作区子窗口没有新增产品数量上限。关闭与移动不同：移动保持会话，关闭工作区结束所属会话，退出结束 App 全部资源。

测试使用 Windows 单显示器、真实 WebView2、Microsoft Pinyin 和本机 Paramiko SSH/PTY 协议服务；回送服务不能代表 Linux shell。Linux/OpenSSH、不同 DPI 双屏、完整屏幕阅读器/系统文字缩放、输入法候选窗精确位置以及安装器仍待验证。完整结果在源码仓库 `docs/tasks/T-004-results.md`，工程验证与用户验收分别记录。
