# 通信监控 Windows 开发试用包

版本：2.0.0-dev.15，包修订2，API/SDK 4.9.0；按用户2026-10-27最新指令收束，问题记录、知悉和通知留待后续独立规划。

双击同目录 `Start-SoDeck.cmd`，也可直接打开 `sodeck-desktop.exe`。包修订2已补齐插件索引和便携配置，两种普通启动均已验证。应用数据写本目录下 `data`，不会读取日常数据库。需要 Windows WebView2 Runtime。本包是未签名的 debug 开发目录包，不是正式安装或发布版本。

若已打开旧包并看到缺少 `bundled-plugins.json` 的错误，请先通过“应用→退出”结束程序，再从同一目录启动。修复保留现有数据；旧包可能写入系统应用目录的配置没有自动迁移到包内 `data`。

## 现在可用

1. 添加测试服务器并打开终端，在底部查看发送/接收速率；点击底部摘要或应用菜单“通信监控”打开独立窗口。
2. 概览查看当前服务器或全部服务器、累计流量、实时趋势和来源；通道数据与外层传输分别查看，不能相加。
3. 历史按时间查询、对比；设置切换字节/比特单位，或关闭后续历史保存。正常退出后历史保留，SSH会话不恢复。
4. 诊断对已有SSH连接执行一次响应检查，或明确开启每5秒持续检查；关闭监控窗口不结束业务连接，持续开关独立保留。该测量包含SSH处理时间，不是ICMP延迟或丢包率。

## 本包范围

没有问题列表、已知悉、通知、主动带宽测速、导出证据入口。测速底层实验不作为产品功能交付；细粒度资源历史、完整容量与吞吐压力验证仍未完成，不能据本包声称原完整方案全部完成。

累计流量是SoDeck所持SSH连接的计量，不代表操作系统所有流量；缺口和部分覆盖会明确显示。只完成Windows开发包运行检查，未验证正式安装及其他平台。

本包使用独立数据目录。若主动复用旧开发数据，core schema4→5会按已确认策略提示、完整备份并重建，服务器/凭据/信任不自动迁入。

验证证据见 `evidence`，构建指纹与文件校验见 `build.json`。用户验收、Git提交/推送与正式发布尚未执行。
