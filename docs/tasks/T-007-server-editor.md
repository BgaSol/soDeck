# T-007：服务器预设密码与选择器整理

2026-10-25 · 方案 r2 · 状态：待验收，用户已确认默认记住密码

## 1. 用户要求与边界

用户明确要求“添加服务器的时候，允许提前把密码设置好”，并指出打开服务器弹窗外观不佳。核心/插件边界不变：档案和凭据由核心管理，终端继续消费公共连接能力。颜色仍完全独立，沿用 T-006 的主题数据；保留当前运行包、数据和全部未提交改动，不操作用户截图中的日常服务器。

只读核实：ServerDialog 只有配置字段，尚未接入已有 auth.set；核心已有临时凭据与 Windows DPAPI 加密保存、日志脱敏和主机信任先于认证机制。截图的搜索图标换行源于 `.dialog label` 的 column 规则覆盖 `.server-search`，输入框也被通用样式二次绘制。

## 2. 具体方案

1. 添加/编辑服务器时，密码认证下增加可选密码框和显示/隐藏按钮；留空继续允许保存档案，连接时再询问。编辑既有档案不回读旧密码，用“已保存密码，留空保持”状态说明；若主机/端口/账号/认证类型改变，旧凭据仍按已有核心规则失效。切换私钥认证清空本次密码草稿，不提交密码。
2. 提供“在此设备上记住密码”复选框，按用户本轮明确选择**默认勾选**；未勾选仅本次 App 运行使用，勾选后由已有核心服务加密保存。该默认值只适用于本次服务器编辑入口，原连接认证提示行为不变。密码不进入服务器配置、布局、插件参数或日志。保存不主动连接，不跳过首次主机指纹确认。
3. 保存先提交档案，再通过 auth.set 提交非空密码。凭据失败时明确显示“服务器已保存，密码未保存”，保留草稿与服务器 ID；重试不能重复创建档案，取消不能谎称回滚已保存配置。保存期间禁止重复提交和关闭；成功/关闭清空本地秘密草稿。异步结果不更新已销毁界面。
4. 选择器使用约 560px 宽的紧凑弹窗，标题/说明/搜索/列表/底部操作形成清楚层次；搜索图标与输入在同一行，只有一层输入框。服务器行统一图标、名称、地址和已打开状态，操作按钮对齐并具有完整提示，长名裁切可查看全文。底部左侧显示数量，右侧放添加按钮；少量数据不留下大块空白，长列表独立滚动。空态、无匹配、小窗口、键盘焦点和浅/深主题都覆盖。
5. 使用 apple-design 的熟悉操作、文字层级、稳定间距、即时按压反馈与清楚焦点；本次没有新手势或弹跳动效。复用现有语义色，不增加组件色值。

交付采用独立修订目录，不替换正在运行的 T-006 EXE/data。若未得到密码方案确认，先完成已确认视觉目标内的缺陷修复，密码保持未实施并明确记录。
