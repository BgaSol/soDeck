## 实现结果

- 身份确认：约 480px 的紧凑对话框，单一服务器摘要、完整可选择/复制的等宽指纹、次级算法信息和固定操作区。直连去掉重复路径；多跳保留当前核验节点与默认折叠路径。身份变化显著警告，并同时呈现新旧指纹；信任仍使用原 challenge，不改变安全语义。
- 隧道侧栏：沿用宿主唯一标题，顶部只有数量和创建，空态不重复创建入口。无粗边卡片的规则行展示用途、文字状态、实际入口以及启停/复制。独立滚动、贴底统计；保存和复制在底部短暂反馈，不挤占列表。
- 隧道详情：名称/状态/启停、实际入口、连接与流量优先；路径、检查、用法和诊断默认收起。保留创建/编辑原生模态、运行配置变更提醒与删除确认。
- 公共 UI 提供身份摘要、代码值、工具行、资源条目、状态和折叠分区。按 apple-design 使用清楚层级、即时反馈、稳定命中区域和键盘路径；三主题同几何，多巴胺无投影，颜色来自主题令牌。
