# SoDeck v2 · T-011 外观开发包

核心 2.0.0-dev.7 · 终端 0.6.0 · 文件 0.3.0 · API/SDK 4.3.0

Windows 本地开发包，非安装器、非正式发布。双击 `Start-SoDeck.cmd`；本目录的 `data/` 保存独立配置，不影响已有开发包。首次默认深色。

## 请体验

1. 打开“应用 → 外观”，切换浅色/深色。检查预览、选中与焦点，按 Esc 关闭；从应用菜单明确退出后重启，所选外观应保持。
2. 新增或编辑测试服务器，查看搜索、密码、认证、插件及资源等弹窗。文字应清楚，控件可达，浅色中没有残留暗底。
3. 打开终端与文件侧栏；从另一窗口换色。终端会话、输入、选区、文件路径草稿与浏览位置应保持；正常 cd 后文件继续跟随。
4. 将终端或完整工作区移到独立窗口，切换主题后再合并回来；所有当前版本表面应一致。关闭主窗仍收起至托盘，明确退出才结束会话。
5. 按日常屏幕缩放检查大小、间距和长名称；反馈过亮/过暗、密度不合适或难以辨认的具体页面。

打开服务器工作区时会自动创建初始终端，完整重启为空工作台；保存的服务器和外观偏好保留。文件浏览仍为只读。本次没有新增自动跟随系统、终端独立配色或完整设置页。

如果自行换回旧终端/文件插件，已挂载旧视图会保持旧配色，到自然重新打开时应用新色；外观页有兼容说明。系统高对比优先于所选明暗。

实施与证据见 `RESULTS.md`、`evidence/`、`screenshots/` 和 `build.json`。用户验收状态：**待用户体验确认**。方案确认、工程检查和用户验收分别记录。
