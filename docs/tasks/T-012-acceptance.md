# SoDeck v2 · T-012 三主题开发包

核心 2.0.0-dev.9 · 终端 0.7.0 · 文件 0.4.0 · API/SDK 4.5.0 · 公共UI 1.1.0

Windows 目录开发包，双击 `Start-SoDeck.cmd` 启动。本目录 `data/` 保存独立配置；全新配置默认多巴胺，已有有效浅色/深色偏好保留。本包不是安装器或正式发布。

## 体验步骤

1. 查看顶部服务器标签、文件标题和终端工具条：多巴胺保留奶油底、糖果色块和单描边，按钮、菜单、弹窗及Logo没有偏移投影，顶部连接处没有细缝或重叠黑线。
2. 打开“应用 → 外观”，自由切换多巴胺、浅色、深色。按Esc关闭后再次打开；明确退出再重启，选择应保持。
3. 查看服务器选择、编辑、认证、插件及运行资源页面；检查按钮、输入框、菜单分组、长名称和焦点。菜单支持方向键、Home/End、Enter、Esc及Tab。
4. 在测试服务器打开终端和文件侧栏，拆出终端或整个工作区，切主题再合并；会话和文件路径草稿应保持。应用菜单覆盖终端期间输出继续，取消菜单的按键和点击不会发送给终端。
5. 查看新小终端Logo。主窗“×”仍收起至托盘，应用菜单“退出 SoDeck”才结束全部会话。文件浏览仍为只读。

旧静态插件只在重新挂载时换色；旧实时插件可换色但保留旧控件风格，外观页会说明。随包两个插件已完整使用公共设计系统。

实测结果见 `RESULTS.md`、`evidence/`、`screenshots/` 与 `build.json`。当前只有单显示器，混合DPI双屏未实测；Alt+Tab专门截图、浅色Windows任务栏及屏幕阅读器语音朗读未完成，不将它们计为通过。用户验收仍待体验反馈，未提交、推送或正式发布。
