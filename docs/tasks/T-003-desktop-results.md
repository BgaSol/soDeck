# T-003 Windows 桌面交付与验证

日期：2026-10-25 · 构建：`2.0.0-dev.1` · 分支：`codex/t-003-core-terminal`

本记录汇总可运行开发包及已执行范围。本批仍有待验收子场景，未将整份核心设计、全部测试流程或正式发布标为完成。

## 运行与实现

本机开发包：仓库根目录 `.local/dev/SoDeck-v2/Start-SoDeck.cmd`。双击后使用同目录的执行文件、终端 0.1.0 签名包和公钥，数据放 `data/`。关闭主窗口进入托盘；结束程序用菜单或托盘中的“退出 SoDeck”。构建与复跑命令见[开发入口](../development-entry.md)。

已实现 Tauri/Rust 核心、React 外壳、版本化 SDK、独立 QuickJS 业务进程、独立签名终端 UI/worker 包。核心提供服务器、DPAPI 凭据、主机指纹、SSH/PTY、租约与逐次调用记录；工作台以插件清单声明约束视图默认位置、作用域及支持的移动位置。终端使用实际 xterm.js，具有会话列表、输入输出、字号、重命名、关闭/重连和视图迁移。没有引入插件权限清单或第三方插件产品。

窗口交接保持同一 PTY：源视图准备快照、目标恢复并就绪、提交新挂载代次后撤销源输入；同窗口移动保留表面。主窗口与独立窗口共用隔离 shell profile，插件表面使用另一个 profile。屏幕正文只在内存迁移，不写入调用记录或持久布局。渲染器故障可恢复同一 PTY，并明确说明无法恢复的旧屏幕；业务进程故障撤销实例并释放其资源。
