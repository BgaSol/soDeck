# T-009 试用说明

本目录为 Windows 开发版：核心 2.0.0-dev.4、终端 0.4.0、插件 API 4。双击 `Start-SoDeck.cmd` 启动，试用数据保存在本目录 `data`。这是独立试用目录，不自动复制或覆盖 T-007 等旧包的数据；已有数据目录升级时，程序会保留服务器、记住的凭据、主机信任及插件设置，只退役旧工作现场快照。

1. 打开程序：应只有主窗口，没有上一次的服务器 Tab 或空终端。有服务器档案时显示“打开服务器”，没有时显示“添加服务器”。
2. 新增服务器并“保存并打开”，或从选择器打开已有服务器：应自动出现一个终端并开始连接。首次主机信任和必要的认证仍需正常完成。
3. 重复选择已打开的服务器、切换、移到新窗口或从托盘显示：原终端继续使用，不多开。关闭最后一个终端后，服务器 Tab 可以保持为空。
4. 连接失败或取消后，在原终端页“重新连接”；应复用该页。编辑服务器只保存信息，不自动打开新的工作区。关闭服务器 Tab 后重新打开，则创建一个新的首终端。
5. 从“应用 → 退出 SoDeck”完整退出，再启动：工作区为空，服务器和已保存配置仍在。“×”继续收起到托盘，属于同一次运行，不清空会话。
