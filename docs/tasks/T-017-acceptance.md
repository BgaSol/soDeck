# T-017 Windows 试用说明

应用 **2.0.0-dev.13**；网络隧道 **0.2.1**；公共 UI **1.3.0**。本次重新设计服务器身份确认框和网络隧道列表、详情。终端 0.8.0、文件 0.5.0、API 4.8.0 与数据库结构 v4 保持不变。

双击目录中的 `sodeck-desktop.exe`。这是 Windows release 目录包，需要 Microsoft Edge WebView2；保持 `resources/` 与程序同目录。解压后直接启动，无命令窗口启动器。

## 查看新版

1. 在尚未信任的服务器上发起连接：确认框应只有一处服务器摘要，完整指纹可选中、复制，算法在其下；底部始终能取消或信任。多跳时显示当前核验节点，完整路径可展开。已信任的服务器不会为展示新界面再次要求确认，不必删除日常信任记录。
2. 展开右侧“网络隧道”：标题只显示一次，顶部一处“创建”；空态简洁，统计贴底。创建代理时名称可留空，默认自动分配端口。
3. 启动一条规则：列表显示真实本机入口和文字状态，可直接复制、停止；点击名称进入详情，路径、连接检查和用法按需展开。停止后不能复制过期入口。
4. 切换浅色、深色、多巴胺，调窄侧栏与窗口：文字和操作应完整，长内容可滚动。收起或移动隧道面板后，运行中的代理继续可用；明确关闭所属视图或退出程序才释放资源。

## 数据与旧版本

T017 使用自己目录旁的 `data/`；交付包不带任何测试或日常数据。当前打开的 T015 不会自动变成新版，请启动 T017 查看。

如需继续使用 T015 中的服务器配置，请先从旧程序的应用菜单选择“退出 SoDeck”（关闭主窗口只会收起到托盘），保留旧目录作备份，再将旧目录的整个 `data/` 复制到尚未运行过的新目录。两个版本数据库结构同为 v4，本次不会因此重建数据库。不要只复制 SQLite 而遗漏加密凭据等文件，也不要在旧程序运行时复制数据。

复制整个 `data/` 也会保留已安装的网络插件 0.2.0。启动 T017 后打开“插件”，在“从本地包准备更新”中输入 **T017 目录下 `resources/network-proxy.sodeck-plugin` 的完整路径**，点击“准备更新”，从应用菜单退出后再次启动。插件页显示网络隧道 **0.2.1** 即为新界面；已有隧道规则保留。全新数据目录首次启动已直接使用 0.2.1，无需此步骤。

其他结构版本继续遵循此前确认的规则：启动提示后备份旧库，再建立空库，不做迁移。工程结果、验证层级与限制见随包 `RESULTS.md`；本说明不是用户验收记录。
