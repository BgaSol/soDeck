# T-017 r2 Windows 试用说明

应用 **2.0.0-dev.14**、网络隧道 **0.2.2**、公共 UI **1.3.1**。本次按文件面板重新调整网络隧道的工作面、连续行、选中轮廓和底栏，并修复右侧面板左边框缺失。指纹框沿用上一版；API 4.8.0、终端0.8.0、文件0.5.0、数据库v4不变。

双击目录中的 `sodeck-desktop.exe`，需要 Microsoft Edge WebView2。保持resources与程序一起移动。此目录是独立便携包，数据存于旁边的data，不会自动替换已经打开的T015/T017。

## 查看效果

1. 同时展开左侧文件、右侧网络隧道。检查两侧朝向终端的分隔边框：文件右侧、网络左侧都应完整可见，颜色和粗细一致；移动面板后边框跟随停靠方向。
2. 对比文件和网络列表：相同工作面、普通线性图标、连续全宽行。网络条目显示名称与入口/转发目标，右侧保留文字状态、复制及启停；选中后使用同样轮廓，底部使用同样实底、上边框和高度。
3. 创建/启动代理，复制实际入口；点击名称进入详情，再返回列表。路径、连接检查和用法仍可展开。收起/移动面板应保持代理运行，明确关闭视图或退出程序才清理。
4. 切换三种主题、调窄侧栏：边框和底栏应保持一致，长名称/地址可换行，滚动不会带走顶部或底部操作。

## 沿用已有配置

先从旧版应用菜单选择“退出 SoDeck”（主窗口×只是收起到托盘），保留旧目录作为备份，再将整个 `data/` 复制到尚未启动过的新目录。不要在程序运行时复制，也不要只复制SQLite遗漏加密凭据。当前数据库结构相同，不会触发重建。

复制data会保留已安装的旧网络插件。启动dev.14后，在“插件 → 从本地包准备更新”输入本目录 `resources/network-proxy.sodeck-plugin` 的完整路径，点击“准备更新”，退出后再次启动。确认网络隧道当前版本为 **0.2.2**。已验证0.2.1→0.2.2保留原规则与固定端口；没有自动恢复旧运行会话。

新数据目录直接使用新版插件，无需准备更新。左侧分隔边框由宿主负责，因此这一项需要dev.14程序，单独更新插件无法修复旧宿主的边框。其他数据库结构版本仍遵循已确认的提示、备份、重建规则。本说明不是用户验收记录，验证及限制见RESULTS。
