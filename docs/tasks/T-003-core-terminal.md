## 1. 本次交付

交付 Windows 可运行的核心和实际终端插件：添加服务器 → 主机身份/密码或密钥认证 → 真实 SSH/PTY → 多会话终端输入输出 → 分屏、停靠和独立窗口 → 关闭/托盘/退出；终端包能独立构建、更新并在重启后生效。没有独立测试插件或 Mock 产品阶段。

核心负责配置、秘密、连接、PTY、租约、逐次调用记录、插件运行/更新和统一工作台。终端插件负责会话列表、终端渲染、输入和设置。会话列表默认左侧，终端默认中央；同一终端可以移到底部或独立窗口，保持原连接。窗口迁移以 v1 已验证机制为基础，重构为插件视图接入。

本批建议采用 Tauri/Rust、React/TypeScript、xterm.js、独立 QuickJS 业务进程及 Windows raw Wry 视图，详见技术方案。原生输入、故障恢复、真实 PTY 及独立更新是本批必需验证；不通过则修正实现，不能交付占位终端。

本批明确后置：Docker、NetBird、SFTP/文件管理、隧道、跳板、Agent/MFA、终端历史回放、关闭后的会话托管、在线市场、v1 数据导入及正式发布渠道。隐藏/切换/托盘继续运行已包含。验证 Windows 与 Linux/OpenSSH，不宣称其他平台已支持。

## 3. 实施与验证

1. 建立独立开发入口、数据目录和最小真实终端包；接通核心服务器、认证、连接租约、PTY、记录和终端实际输入输出。
2. 接入会话列表、多工作区、双区域、三种承载及 v1 迁移机制；完成故障、焦点、中文输入、托盘与退出。
3. 形成终端前后两个实际版本，独立打包并验证准备更新、重启激活和恢复；提供可运行开发包、命令及实际界面证据。

SSH-01 至 SSH-08、TERM-01 至 TERM-12、UPD-01 至 UPD-05 全部为本批必要流程。自动化能覆盖的逻辑由自动化执行；中文 IME、多屏和可访问性按原生操作留下证据，不将浏览器结果代填。

公共回归：COM-01 至 COM-10、LOG-01 至 LOG-08；来源 A/B 部分为契约夹具，实际终端来源单独验证。RES-01/02/03/06/08/09/11 验证连接/PTY及契约身份；RES-04/05/10 仅本批默认关闭、实例失效和退出部分，显式托管/隧道分支后置；RES-07 端口监听不属于本批。WB-01 至 WB-14 执行真实终端适用部分，未保存业务草稿用契约夹具，保留会话分支后置。结果按子场景写出覆盖范围，不能整项标绿掩盖未做部分。

负载、去重/队列限额、日志存储异常、20 次资源创建/关闭和 10 次窗口往返按技术方案固定；不重复编造第二套阈值。隔离服务、故障注入、恢复和清理见各自流程。v1 原生结果是参考，本次 v2 测试必须重新产生证据。
