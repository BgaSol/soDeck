# T-018 文件列表试用

组合版本：Windows dev.14宿主 + 文件0.6.0（公共UI1.4.0）+ 原终端0.8.0/网络0.2.2。本次核心可执行文件复用已验证的T-017 r2，没有新增核心/API/数据库版本。

## 沿用已有配置

1. 在当前dev.14应用的插件管理中，为“文件”准备更新，选择工作区 `resources/sodeck.files-0.6.0.sodeck-plugin`。
2. 保存当前工作，从应用菜单退出，再启动原来的应用。更新按既有规则在重启后生效，准备时运行中的旧文件0.5.0继续可用。
3. 打开服务器，文件底部应显示0.6.0；目录、终端跟随和原服务器配置继续使用。

本说明不要求复制或覆盖数据库；当前运行包没有被本任务替换或关闭。

## 独立试用

双击本目录`sodeck-desktop.exe`，或从仓库`.local/dev/SoDeck-v2-T018/sodeck-desktop.exe`启动。ZIP为相邻`SoDeck-v2-T018.zip`。独立目录首次使用自己的空data，不自带原服务器配置、测试凭据或开发私钥；这是未发布的开发目录包，使用本地开发签名。

## 验收

- 根目录及其他卷没有“挂载”标签或第二行细条；整行背景按用量填充，右侧“已用 / 总量”与文件大小对齐。
- 正常绿色、80%起黄色、90%起红色；悬停行查看百分比/等级，选中轮廓和键盘定位仍清楚。规则在公共UI、色值在主题，文件插件只提供数据。
- 切换多巴胺/浅色/深色、收起/展开目录、滚到末尾、终端cd后跟随，检查内容与命中。大字或深层路径必要时在树内部横向滚动读取完整容量。
- 容量读取中、不支持统计、零总量应显示对应文字；普通目录不冒充卷容量。

结果与模拟/真实验证边界见同目录`RESULTS.md`或仓库`docs/tasks/T-018-results.md`。工程验证不代表用户视觉验收，也不等于安装器或正式发布。
