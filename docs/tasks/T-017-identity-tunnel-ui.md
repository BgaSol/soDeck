## 设计

### r2：按文件面板统一网络 UI

用户否定 r1 网络部分的视觉，明确“好好学学文件部分的ui设计，边框，风格，底部。你继续改”。本轮直接实施，无需重复确认；指纹框及所有网络业务保持。本节替代下面 r1 第2项的独立资源卡片、淡分隔与中性透明底栏，不把 r1 工程测试通过解释为视觉验收。

- 以文件插件实际渲染的 `--canvas` 工作面、公共 Toolbar/StatusBar 和 TreeRow 行选中规则为参照。文件CSS中的surface声明会被SDK首屏主题背景覆盖；按三主题实际渲染比对统一，不能只照抄该声明。网络面板铺满同样工作面，保留宿主唯一标题和外边框，不额外套卡片。
- 顶部为“名称”与创建操作；连续全宽列表、16px普通线性图标、两行信息（名称、入口/转发目标），移除图标色块与逐条分隔线。整行hover/选中反馈和4px选中轮廓与文件一致；启停/复制为右侧小按钮，状态保留文字。
- 底部直接使用文件相同的默认 StatusBar：同样的实底、上边框、最小高度、字体、左右留白；左侧数量/运行状态/短暂反馈，右侧插件版本。列表独立滚动。详情取消大图标身份卡，入口框使用现有控件边界；折叠分区与三主题令牌保持。
- 公共UI增量只包含Surface平面变体、资源行排版及入口框边界变体；插件CSS只负责布局，不私写颜色/描边。继续使用apple-design的空间一致性、即时反馈和可达性，不增加装饰动效。
- 版本：网络0.2.2、UI1.3.1、应用dev.14，提供独立插件更新包及T017-r2目录包。保留正在运行的T015/T017及其数据，不覆盖旧包；无数据库/协议变更，无Git提交。

返修测试（证据 `.local/test-results/t017-r2/`）：R2-01在同宽同主题浏览器中并排展示文件和网络，逐项核对工作面、底栏颜色/上边框/最小高度/留白与行选中样式，三主题截图人工审查；R2-02覆盖320px/200%文字、长名称/地址、空态、加载、失败、列表滚动/返回、启停/复制及焦点，复用现有网络和文件浏览器用例；R2-03隔离原生三节点协议链重新执行创建、认证、HTTP/SOCKS、移动/隐藏/关闭，并验证0.2.1→0.2.2重启更新规则保留；R2-04执行check、公共与受影响契约测试、构建、release中文路径启动、签名/哈希白名单核查。继续沿用原有清理规则。

用户追加“网络隧道部分，左侧少了边框”：核实宿主所有侧栏都固定画右边框，右侧面板因此缺少朝向中央内容的分隔。改为按停靠边分别画内侧边框：左侧右边、右侧左边，沿用相同1px主题边界，原生WebView测量内容区域避开边框。此修复归宿主通用停靠外框，不在网络插件重复描边；移动后自动切换边界。R2-01追加三主题左右同时展开时描边/内容几何断言，R2-03截图检查右侧边框及移动后的边界。

### r1设计与交付历史

r2已完成：文件/网络三主题样式对齐、左右侧栏分隔、27项受影响浏览器检查、原生网络及移动/清理、0.2.1→0.2.2更新、release隔离启动均通过。入口与分层证据见[r2实测](T-017-r2-results.md)、[dev.14试用](T-017-r2-acceptance.md)。用户视觉验收仍待确认；原T015/T017运行包与数据未修改。

1. 身份弹窗：约480px宽、内容自适应高度、底部动作固定。标题下仅一处服务器身份摘要；直接连接不显示“目标1/1”和重复路径卡片。完整指纹作为主要可选择/复制的等宽内容，算法次级显示；首次连接用简短说明，身份变化时显著警告并同时显示旧/新指纹。多跳只显示当前核验节点与进度，完整路径默认折叠、支持原有有界分页。取消、challengeId、信任范围和认证重试不变。
2. 隧道侧栏：保留宿主单一标题与收起/移动功能；插件顶部为轻量数量/创建工具行，不重复标题或彩色标题带。空态为小图标和简短说明，只有顶部一处创建入口。规则改为无粗边框的紧凑行：名称/类型、状态、实际入口、启停和复制；固定转发显示目标。列表独立滚动，底部安静显示运行统计与本机范围并贴底，分页仅超过一页显示。
3. 详情：返回列表、名称/状态和主要启停在上，实际入口单独突出；活动连接和流量紧凑展示；路径、检查、用法和诊断使用可展开分区。运行配置变更/失败仍明确，删除保持确认。保留现有原生编辑表单及全部规则和运行语义。
4. 公共UI：身份摘要、可复制代码值、紧凑资源行、轻量状态/空态和折叠分区由公共组件提供，插件只组合业务和布局。三主题同几何、多巴胺无投影、全部颜色用主题参数。apple-design用于层次、克制装饰、即时按下反馈、可中断与减少动态、键盘和放大文字；原生WebView祖先不加transform/filter。
