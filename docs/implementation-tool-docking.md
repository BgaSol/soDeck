# 侧边工具入口与停靠实施记录

日期：2026-11-10。整改基线 HEAD `2c0d371`，本机验收时核心为 0.20.1、终端为 0.7.1。功能及代码方案见[功能设计](plan-tool-docking.md)、[代码整改方案](plan-tool-docking-coding.md)。后续按用户要求准备核心 0.21.0 与终端 0.7.2 独立发布，发行来源及正式验收统一见[核心版本记录](releases/v0.21.0.md)和终端 CHANGELOG。既有系统状态插件等未提交修改保留，不属于本次整改。

## 改动与边界

核心 Host 以稳定定义 key 的工具槽位管理左右位置和顺序，viewId 可为空；原 viewIds 只从槽位派生，快照只读。入口投影依据实际 Host，不读取默认侧来绘制按钮。普通按钮移动、同侧排序、面板移侧、中央停靠、移窗与关闭回收使用同一槽位规则。可见工具移侧保持展开，收起工具保持收起；同窗保留 iframe、Surface 和插件业务实例。

按钮可拖到同工作台两侧工具条，并使用插入线预览；达到 6 CSS px 后才捕获指针，窗口外与中央落点取消。右键/键盘菜单提供移侧、上移、下移及置顶；标题仍支持中央与原生窗口迁移。Esc、失焦、丢失捕获、切换服务器、Context/实例/布局修订变化均取消手势，迟到松手不提交。展开的未固定工具保留临时按钮，溢出入口以完整稳定 key 排序。两侧更多清单共用完整工具列表，标明实际侧和展开/收起；中央工具可显式停靠，其他窗口的工具定位到原窗口后使用原菜单移窗或返回。

核心本地 moveTool 回执与既有移窗回执共用编号空间和 4096 项额度，终态五分钟后返回 expired，重启清理；重复同编号查询既有结果，参数变化拒绝。过期记录不回收成可重放的新编号，达到额度后拒绝新请求。布局结果与保存结果分别返回。写盘失败保持已提交位置，重试只保存最新快照；迁移/关闭期间保存 deferred，对外回执为 pending，在既有流程结束时保存并更新回执。快照单独提供当前布局保存错误，状态栏重试提示只跟随最新保存结果。

workbench-layout.json 升为 schema 2，增加工具入口顺序，并保存纯槽位。兼容读取 schema 1，首次成功写盘保留 .bak；旧实际位置优先，重复历史 key 优先主槽、再按槽号择一。损坏或未知版本不覆盖。布局只保存结构和定义位置，不保存会话、viewId、Surface、命令或正文。ui-layout.json 的固定状态与初始化推荐仍为 schema 1，推荐变化不移动现有布局。

终端只删除 release.json 的 defaultPinned/locateEntry 推荐，仍为中央多实例页面。宿主继续接受旧清单但不将 editor/dialog 放入侧栏或更多工具。终端业务、文件、Docker、网络隧道及系统状态业务未因停靠新增 API、侧别设置或生命周期分支；没有新增生产依赖。核心包与终端包独立构建。

## 复现与回归

改动前新增核心回归“工具移右后入口跟随实际侧、排除旧终端定位入口”，执行后失败：旧快照没有 tools 实际位置投影。前端原实现按 preferences.side/order 绘制入口，面板按 Host 绘制，导致移侧后错位；恢复逻辑也会为收起历史工具创建页面。

增加纯槽位、活动状态、顺序与原位无操作、错误参数原子拒绝、重复回执、过期修订、跨服务器隔离、保存失败/deferred/只保存重试、关闭重开纯入口的核心回归。真实浏览器夹具补充空工具按钮跨侧与排序、Esc/blur/旧修订取消、隐藏及展开工具移侧、键盘移侧和原 iframe 连续性。保留带旧 locateEntry 的终端夹具，验证没有侧边按钮或更多工具入口。

浏览器验收还发现重复 focus 通知会产生假修订冲突、拖动结束重复刷新会关闭刚打开的键盘菜单；分别修复无变化选择的修订和工具移动的重复刷新，并保留对应手势回归。真实文件/网络插件测试补充同窗往返拖动，检查原 iframe、目录及监听端口连续性。

## 未完成范围与风险

未进行版本发布或改动实际用户安装。Linux x86_64/ARM64、Windows ARM64、macOS ARM64 的原生包构建、包内启动退出和真实系统手势不能由本机浏览器或交叉编译替代，正式发行前仍须按现有独立工作流完成。本轮未连接生产服务器、验证 Docker Engine、多屏混合 DPI、Wayland/macOS 原生拖动；未重跑网络协议压力/弱网矩阵，网络验收范围仅上述实际 UI/转发与核心普通测试。
