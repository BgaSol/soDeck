# 在线更新实施与验收

核心和插件独立发版，从公开的 BgaSol/soDeck GitHub Releases 下载。核心标签沿用 `vX.Y.Z`；插件使用 `plugin-<目录名>-vX.Y.Z`，版本仍只有一个来源。正式 Release 的附件不可覆盖，同一版本修正应升补丁版本。

## 用户行为

- 插件管理仍在设置中。添加目录、启用和关闭只保存配置，重启后生效；启动时自动加载启用插件。旧记录没有启用字段时按禁用迁移。
- 下载插件不停止现有进程。完整性、ID、版本、API 和本机目标匹配后保存到独立托管目录。启用或本次启动已加载的插件在重启时切换，完全禁用的插件直接更新记录。
- 多项变更可以合并一次重启。退出先有界停止全部插件；重启不恢复远程任务。
- 新插件初始化失败时恢复保留的旧程序，保留错误和日志。只保证程序版本回退，不承诺插件数据迁移回退。
- 应用更新页提供检查、说明、下载进度、安装并重启。Windows NSIS、macOS app 更新包、Linux AppImage 使用 Tauri 官方 updater；DEB 用户继续使用系统安装方式，界面明确说明。
- 没有更新来源的本地插件仍可管理；可在管理页为旧 Hello 指定仓库与标签前缀，不根据 ID 猜测来源。

## 验收

1. 启停在当前进程不改变运行状态；重启按新配置加载，禁用后不再加载；配置损坏不被覆盖。
2. 本地 HTTP 测试源覆盖发现新版本、平台/API 不兼容、包校验失败、路径越界、下载失败和旧版本保留；测试源仅在测试入口使用，正式来源要求 HTTPS。
3. 已启用插件准备更新后仍运行旧进程，重开应用运行新版；新版初始化失败能回到旧程序。禁用插件更新不启动进程。原目录和独立数据保留。
4. 发布脚本校验标签与版本，自动汇总每个平台的包、哈希/核心签名，生成独立清单；插件发布不会运行核心打包。
5. 运行格式、类型、脚本测试、Rust 集成测试和本机安装包检查。五个原生目标分别构建、启动退出及插件重启切换检查，结果按实际记录。

## 依赖选择

新增固定版本的 Tauri 官方 updater（维护方 Tauri，用标准安装器代替自写安装助手）、reqwest（维护方 Hyper，HTTPS 下载）、rustls（维护方 rustls，显式初始化 HTTPS 所需的 ring 加密提供方）、semver（维护方 dtolnay，版本比较）、sha2（RustCrypto，下载完整性）、zip/tar/flate2（各格式的常用维护库，解压现有插件包）。大部分已是 Tauri 的间接依赖。替代方案是系统 shell 下载解压和自写更新器，会增加跨平台差异，不采用。插件不增加签名、权限声明或授权流程。
