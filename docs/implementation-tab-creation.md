# 两级 Tab 新建入口实施记录

2026-11-06。按 [已确认规划](plan-tab-creation.md) 完成源码实现和本机验证。本轮未改版本、未打包、未创建标签或 Release；公开 Latest 仍为 v0.7.1。

## 用户行为

- 一级加号在标签条下方展开服务器选择层，支持名称、地址、账号和分组搜索。打开聚焦搜索框，上下键选择、Enter 确认、Esc 关闭并返回加号，点击外部关闭。空目录、无结果及读取失败均有反馈，失败可重试；目录更新保留搜索和仍有效的焦点。
- 选择服务器后关闭列表，复用现有指纹和凭据弹窗。连接中显示阶段及取消入口，选择层的对应行禁用。失败提示核心实际错误；取消或失败不产生空服务器 Tab。
- 新连接创建在发起窗口；已打开工作区使用现有定位能力；重连保留原窗口和工作区身份。等待认证时关闭发起窗口会取消连接。
- 二级加号固定新建官方 `sodeck.terminal` / `terminal`，追加、选中并聚焦返回的独立 viewId。文件页和多个可创建插件并存时行为相同；原页面和草稿保留。请求期间按钮禁用，失败可重试；默认终端不可用或连接断开时显示原因。
- 新工作区自动创建首个终端的推荐布局保持原有行为。没有默认类型菜单、上次插件记忆或新增偏好字段。

## 实现与缺陷修正

`server-picker.ts` 使用原生 popover 和公共 `sd-menu`，读取同一服务器目录；连接入口集中到 `ConnectionsUi.connect`，不复制认证逻辑。核心仅调整成功接纳新工作区时的窗口归属，重连沿用现有上下文。

新终端的界面回归复现了焦点请求早于 iframe 显示的时序问题：拿到 surface token 时，页面可能尚未完成挂载或布局。现在等挂载完成且实际可见再交接焦点，并检查用户是否已切换工作区或继续操作，避免迟到结果抢焦点。

实际截图发现原生 popover 的默认 overflow 会裁掉公共伪元素描边。修正放在 `ui.css` 的公共 popover 菜单规则，列表继续独立滚动；多巴胺完整显示 2px 描边，浅色与深色显示 1px。加号继续复用无常驻边框的 `sd-icon`，业务样式只补布局、尺寸和信息层级。连接进度放在右上方，与右下角错误提示分开。

重复点击一级加号的回归复现了自动收起与手动 click 切换的冲突：浏览器先收起浮层，手动处理又将其打开。改用原生 `popoverTargetElement` 关联触发器，并在展开前刷新缓存列表的连接状态，确保再次点击可关闭且连接中行立即禁用。

没有新增生产依赖，没有更改插件协议、终端 PTY 或服务器资料格式。测试使用独立临时目录和仅测试插件进程，不接触用户连接或发行夹具。

## 验证

本机 Windows x86_64 通过：

- `npm run check`：TypeScript 和 Rust 格式检查。
- `npm run scripts:test`：12 项通过。
- `npm run test`：71 项通过，5 项环境用例忽略；覆盖核心、连接、生命周期、组件、目录、更新和工作区。
- `npm run ui:test`：目录 12 项、工作区 15 项、真实核心连接交互、正式前端 5 项；正式前端构建通过，页面无脚本错误。

新增核心回归通过隔离 SSH 服务验证新连接归属、跨窗复用、重连保持归属，以及关闭发起窗口取消认证。界面回归验证选择后关闭、认证、防重复、进度、取消、实际传输失败、重试和不留空工作区；二级入口验证独立实例、文件草稿保留、创建失败恢复和切换服务器后不抢焦点。

正式构建页面检查浅色、深色和多巴胺主题，以及 1100×720、720×480 窗口；工作区回归还覆盖长名称、标签溢出、减少动态和 125%/150% 显示比例。截图保存在 `artifacts/tab-creation/server-picker-{light,dark,dopamine}.png` 和 `artifacts/workbench-design/`。

## 验证边界

本轮未进行五目标原生打包、原生窗口切换或实际安装包与独立终端包的组合验收。Chromium 界面与 Rust 集成测试不能替代 Linux WebKit、macOS WebView 及 Windows WebView2 的实际包验证；这些仍是发行前的工作。常规 Rust 测试中另有 5 项需要独立 OpenSSH 和实际插件包的用例，本轮未重跑。

此前发行烟测的重复回复和 SSH 验收限时问题仍作为独立问题保留，本轮不通过增加重试或延长超时绕过。
