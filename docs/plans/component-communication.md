状态：主要代码与本机联调已实现，五平台原生实际包验收尚未完成；尚未发行。本文只保留待验收事项及必要上下文，当前行为以正式文档为准。

## 已落地范围与正式归属

- 核心命令服务位于 workbench::State，复用现有双向 RPC、有界队列和实际任务守卫。共享状态不承担一次动作；旧 UI actions 适配同一命令服务，原独立执行表已删除。职责见[架构](../architecture.md#组件协作)。
- commands.v1 声明/握手、单处理者路由、来源与 Context 去重、结构化回执、显式页面关联、限额与兼容规则见[插件 API](../plugin-api.md#命令默认行为与进程主动创建页面)。
- 默认创建、核心“＋”、终端重开和 Docker 请求统一使用 terminal.open.v1。入口、等待/失败和用户操作分别见[终端](../features/terminal.md)、[工作台](../features/workbench.md)、[Docker](../features/docker.md)。
- 关闭撤销与真实调用结束分开；零页面命令、关闭取消、来源释放、断线和 Host 移窗见[生命周期](../features/lifecycle.md)。
- 未新增生产依赖。按用户发布要求准备核心 0.24.0、终端 0.9.0、Docker 0.2.0；沿用独立发行机制，核心 latest，不覆盖旧版附件。

## 必须保持的边界

不新增权限声明、逐项授权、离线消息队列、自动重放、处理者优先级或故障转投。一个命令最多关联一个页面；completed 仅代表业务定义的成功，打开终端的 completed 不等于 PTY/容器已就绪。未知副作用不自动补执行。查询和纯快照不创建资源。回执终态不释放仍在实际运行的调用额度，取消关闭不复活旧意图。
