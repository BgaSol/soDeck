# MCP 0.2.0 发布收尾

状态：2026-11-18，任务模型、查询功能及已有操作页已合并实现，本机验证进行中，尚未发行。此主题只维护本计划；已实现的功能与字段已迁入正式文档。

## 已实现行为与正式归属

- 唯一运行任务身份、两个索引关联同一 Task、统一快照和 committed 水位；[架构](../architecture.md)说明职责分层。
- 接纳 busy 明确拒绝、unknown 查原票据不重发、稳定 finalizing/done、取消阶段和 UI Context 归属；[功能说明](../features/mcp.md)说明行为。
- 六工具、列表精确筛选/接纳上限分页、full/text/none、revision async 等待及 IO/等待额度；完整契约见 [MCP API](../mcp-api.md)。
- 保留已在 main 的中央操作页、设置冲突、侧栏、选择/分页/焦点和后台生命周期，摘要不冒充完整详情；超大 UI 详情明确降级。
- 无新增生产依赖或核心 API，版本由插件自身 Cargo manifest 管理；不建立恢复数据库、执行队列、通用任务框架或第二套 SDK 生命周期。

## 当前验证

- 旧夹具稳定复现 UI A 取消 B 的越界路径，现已纳入进程回归；实际读取和取消均拒绝不匹配目标。
- 本机插件单元：快照/水位交错、稳定终态、UTF-8 摘要、证据原字节/未提交尾部/损坏、IO permit 生命周期。
- 本机进程：六工具、去重/丢接纳回包、未知域 busy、文本/仅状态、插入后的稳定分页、超时/唤醒、HTTP 断开和全局/单任务容量、24 活动额度、最终元数据失败与两项清理失败。
- 本机三服务器 SSH：首次采集/补采/下载、任务查找、text/none 等待、操作页单例/关闭/重开通过。
- 本机类型/格式和 187 项脚本测试通过；最新完整界面及核心测试/构建继续收束。
