默认安装专项使用隔离回环目录和本机架构真实测试插件，验证串行处理、部分失败、整轮占用、重载不重装、重启后实际加载。五平台源码集成验收与原生包导航/生命周期分别记录，不将普通浏览器、包启动或源码进程测试声称为五平台真实公网整轮安装。核心独立打包不依赖业务插件构建或发行，业务插件不升版。不新增生产依赖、权限机制、持久任务数据库或通用调度框架。

部分成功后重启不自动补装，全失败下次空启动重新尝试；配置损坏不误判为空，运行中移除最后记录也要下次启动才触发。整轮目录和项间不能穿插更新/重启或改写登记。后续新上架不追装，用户主动重试，安装后用户统一重启。
