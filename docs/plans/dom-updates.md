## 自动化与测量边界

原始基线为 5885c0f。实际服务器与正式 main/settings 入口已加入连续 CDP composition、最终一次提交、后台刷新和从未断开的回归；正式入口同时覆盖网络地址由已保存值转为草稿的第一次输入。节点最终相同不足以通过验收。

当前长期回归还覆盖：控件属性和显式重置、实体切换、来源基线冲突、隐藏草稿关闭和部分保存失败、快照/网络/设置读取失败、组内重复 action 与嵌套重排、20 次容器销毁、按压取消、更新阅读和滚动、同窗 iframe/草稿、跨窗候选与返回。滚轮原失败是跨两个浏览器任务读取初始位置；现在在输入所在任务记录起点，保留中间帧与打断验证。

同机 Chromium 的代表性 20/50 行 DOM 投影对照（各刷新 50 次）中，旧实现移除 1000/2500 个节点，保留输入 0；新实现移除 0，保留输入 20/50。绘制中位数从约 0.1 ms 变为 0.3/0.6 ms，P95 从约 0.2 ms 变为 0.7/0.9 ms。这是微基准，说明协调成本与连续性的交换，不是实际输入延迟或原生 WebView 性能证明。正式 JS 从 376.58 kB 增至 387.64 kB（gzip 从 125.98 kB 增至 129.56 kB），包括本轮全部业务整改，不能把整个增量归于库。

本轮逐项测试与实际包来源进入[核心 0.23.11](../releases/v0.23.11.md)和[网络插件变更记录](../../plugins/network-proxy/CHANGELOG.md)，不在计划中重复维护发行证据。
