# 库边界与链路整改

状态：源码已实现，正在完成验收与发行。核心 2.6.0、MCP 0.13.0、Docker 0.12.0、文件 0.12.1、网络 0.6.1 分别打包和发布。

## 现状与决定

MCP 静态 schema、字节/组合检查和资源状态分层，服务器补丁保留省略/null 结构。Docker 的 chrono、固定容量 vte、原字节和布局预算各归插件日志模块；核心 SSH 编码和短时配置提交使用相应库，流式文件保留原生命周期。Windows 数据目录安全简化，本地扩展普通文件仍检查命名空间、文件类型和句柄身份。

文件树保留行及子节点并协调实际变化，不增加虚拟化库。Monaco 搜索和三处 POSIX quoting 保留。核心日志 500 条短/长正文局部绘制基准尚不支持扩大改造。正式规则与依赖取舍已写入[架构](../architecture.md)、[MCP API](../mcp-api.md)、[Docker](../features/docker.md)、[文件](../features/files.md)、[网络](../features/network-proxy.md)和[开发指南](../development.md#解析依赖与性能基准)。

## 剩余验收

- 最终源码的相关本地检查、真实进程与交互、正式构建；阶段通过不替代最终源码。故障夹具已经脱离固定临时名，覆盖真实目标占用和目录写入拒绝。Unix root 绕过模式位时明确跳过该场景。
- 包来源提交的五平台原生源码检查、真实 SSH/隔离 Docker 等相关业务回归；核心与四插件各自五平台原生打包、验实际包架构/资源/启动/退出。插件包使用带中文的长数据目录；核心/配置测试覆盖长路径、特殊名称、设备/数据流拒绝和原子失败。
- 同一原始包准备草稿，通过相关检查后正式发布；插件均非 Latest。核心包补远程文件/网络组合和旧版本升级，输入固定。
- UNC 没有真实共享环境时只报告路径保留断言，不声称网络共享 IO 已验。性能 JSON 不替代原生 WebView、远端 IO、磁盘扫描、8 MiB/s 吞吐、IME/DPI/读屏或长期内存；原有日志专项继续由[日志计划](docker-log-viewer.md)维护。
