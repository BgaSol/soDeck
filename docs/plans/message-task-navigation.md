## 启动条件

出现真实消息生产者与可定位目标后再做，例如文件批次失败需要直接打开该批次。目前消息没有服务器、view、资源或任务路由字段；现有行为见[日志与重要消息](../features/logs-messages.md)。

若启动，应采用可选、向后兼容的结构化定位数据，由核心校验插件来源、Owner/Context 和真实目标。不能解析消息文案或使用当前选中的服务器猜目标；目标过期时保留消息与明确回退入口，不复活旧会话或重做任务。

验收覆盖可定位目标、目标已关闭、插件停用、旧代次、无定位字段及非法身份；消息阅读/未读/聚合原行为继续有效。跨插件仍通过核心 API 或事件。

UI 复查中另有非承诺观察项：非地址字段的目标变更差异说明、复杂文件冲突动作分组、故障现场帮助。需要真实场景后单独确定范围，不能作为本次整改遗留缺陷批量实施。背景见[历史复查](https://github.com/BgaSol/soDeck/blob/8115fdcd5bed4108021a729da605fbde77afc2af/.impeccable/critique/2026-11-07T02-19-48Z__src-main-ts.md)。
