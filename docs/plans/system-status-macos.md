# 系统状态插件 macOS 剩余验收与发布

状态：2026-11-26，0.6.0 代码已实现，待真机完整验收及正式发行。功能行为、口径、边界与实现入口已迁入[系统状态](../features/system-status.md)，版本变化进入[插件 CHANGELOG](../../plugins/system-status/CHANGELOG.md)。原功能对照与设计保留于本主题的 Git 历史，计划只维护剩余范围。

## 已实现范围与当前验证

平台命令/解析与类型化采样、状态归并分离；内存、CPU、网络/磁盘基线按来源处理；历史只记本轮值或缺口；挂载与容量由一份目录关联，展示与共享共同读取。macOS 已补内存、读写速率、IP/链路身份、挂载类型/只读/系统分组和三项负载。现有五组调度与任务隔离机制继续复用，未新增核心 API、生产依赖或远端 Agent。

本地 Rust 回归、格式/类型、独立插件构建、实际 OpenSSH 插件业务及三插件共享通信已执行；UI 三主题/七宽度、旧值与失败反馈仍随最终代码核对。137 首轮通过真实核心/插件获得 16 轮有效采样（约 75 秒），随后目标 TCP 连接超时，未达到五分钟及完整生命周期验收，不能据此宣布真机通过。临时测试公钥仍需在网络恢复后清理。

## 剩余步骤与验收

- [ ] 137 恢复网络后，用[真机入口](../../plugins/system-status/tests/remote.mjs)连续采集至少五分钟，完成内存/网络/I/O、根卷/Data、隐藏采集、暂停、单轮刷新、手选接口、断线/重连与关闭退出。
- [ ] 核对临时测试认证已从 137 移除，并删除本机专用临时私钥；不影响其他认证。
- [ ] 对同一最终提交执行五平台原生源码检查和独立插件实际包构建/启动/释放/退出验收；ARM64 必须原生产物。已有[发布流程](../distribution.md)继续适用。
- [ ] 源码与业务验证通过后，发布同一份插件草稿，显式保持非 Latest；核对全部公开附件的大小和 SHA-256，保留原始包运行、来源提交、Release 与真实通过/跳过范围。

## 验证边界

当前真机仅为 Apple Silicon Mac。其他 macOS 版本、外置/多磁盘、硬件移除、原生键盘/触控板/读屏与全部网络设备未覆盖，确定性解析/身份案例由回归测试补充，不冒充设备验收。mount/df 不能观察两次轮询间来源和路径完全相同的短暂重挂载；macOS 可用内存明确为可回收余量估算。实际包进程验收与远端业务分别记录。
