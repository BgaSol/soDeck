# 网络隧道错误表达：剩余验收

状态：2026-11-27，核心 2.12.0 / API 2.2、网络隧道 0.7.0 与 Docker 0.13.2 的实现已完成，待本次 CI、实际包及发行验收。其余四插件仅同步当前 SDK 并独立发布补丁版。

已实现行为和字段分别迁入[网络隧道](../features/network-proxy.md)、[Docker](../features/docker.md)和[插件 API](../plugin-api.md)，不在计划重复维护。现场原因是目标 SSH 的 AllowTcpForwarding no；本轮不修改用户服务器配置。

剩余范围：

1. 固定源码提交的完整 Check；包括六插件 API 清单/握手一致性、原生 Rust 和相关真实业务。
2. 核心与六插件各自五平台原生包、签名/资源和实际包启动/退出；失败只重试失败目标。
3. 使用明确原始包的五平台原生远程组合，核对新核心和网络插件的基础业务；Docker 的真实 Engine 源码业务单独记录，不能由组合验收推定。
4. 正式发布原草稿附件，确认插件非 Latest，并把来源、run、实际验证/跳过范围迁入[核心版本记录](../releases/v2.12.0.md)及各插件 CHANGELOG。全部完成后删除本文。

本地已通过核心完整测试、233 项工程脚本、协议/SDK/网络单元测试、真实 OpenSSH 正常和禁止转发、网络进程/命令/UI、Docker 进程及端口 UI。曾发现的批量故障帧超限已通过紧凑摘要及最坏转义回归修正；UI 测试拦截器遗漏刷新计数已修正并重验。最终来源 CI 和实际包结果仍需单独取得。

未执行 netem、真实注销登录、物理 IME/DPI/读屏或全部 Docker 远端组合；不将历史成功结果代替本次验收。发布规则沿用[分发文档](../distribution.md)。
