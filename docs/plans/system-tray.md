# 系统托盘剩余原生专项

状态：2026-11-25，核心 2.4.0 已正式发行，托盘、桌面入口重构、窗口可见性、导航交接、偏好与消息投影已实现；本计划仅保留尚未完成的设备与专项验收。功能行为迁入[设置与桌面行为](../features/settings.md#托盘与后台运行)，关闭接入迁入[生命周期](../features/lifecycle.md)，职责迁入[架构](../architecture.md)。详细行为和代码归属以上述正式文档与实现为准，不保留第二份完成记录。

## 剩余验收

- Linux x86_64/ARM64 在真实桌面分别核对有托盘、无托盘环境的图标/菜单与窗口入口；Xvfb 原生包烟测不替代窗口管理器和桌面实际显示。
- macOS ARM64 实际菜单栏图标、原生菜单、Dock 重开与 Cmd+Q；Windows 两种架构的真实托盘鼠标操作。当前原生包烟测直接调用同一菜单处理入口，不证明鼠标命中。
- 五目标的原生输入法、读屏、混合 DPI、系统注销/关机，以及原生文件模态框/认证与收起交错的设备专项。
- 托盘创建、窗口显示/隐藏/最小化失败的实际故障注入，连续收起/恢复、文档重载/关闭/设置交错和高频消息的原生压力。已有单元和浏览器回归覆盖有限请求、旧导航确认、存储失败和必要交互，不替代实际系统故障。
- Windows 已有系统指针拆窗专项本次在混合 DPI 下未命中目标标签；后台/草稿/真实隧道与取消退出专项已通过，指针项单独复核，不能用后者覆盖前者。
