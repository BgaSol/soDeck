# 系统托盘剩余原生专项

状态：2026-11-26，2.4.1 已正式发行，实现、五平台源码、实际核心包和终端/文件/网络组合验证通过；来源与结果见[2.4.1 记录](../releases/v2.4.1.md)。功能行为维护在[桌面设置](../features/settings.md#托盘与后台运行)，退出契约维护在[生命周期](../features/lifecycle.md)，职责维护在[架构](../architecture.md)。本计划只保留未完成设备专项，不复制已完成设计或历史结果。

## 剩余验收

- macOS ARM64 的真实菜单栏鼠标/键盘、Dock 未固定/固定/最近使用区、Cmd+Tab、Finder/Launchpad Reopen、应用菜单、前台 Cmd+Q、全屏和多 Space；策略读值不替代这些实际系统入口。
- Linux x86_64/ARM64 真实有/无托盘桌面；Windows 两种架构的真实托盘鼠标操作。Xvfb 或直接调用原生菜单处理入口不证明图标实际可见和鼠标命中。
- 五目标的原生输入法、读屏、混合 DPI、注销/关机，以及认证、原生文件模态框与收起交错的设备专项。
- 托盘创建、策略切换、窗口显示/隐藏/最小化失败的实际故障注入，页面重载、迁移、关闭/设置交错和高频消息的原生压力。有限回归不替代完整故障与长期压力。
- Windows 既有系统指针拆窗专项在本地混合 DPI 下未命中目标标签；后台、草稿和真实隧道的 tray-only 结果不能覆盖该指针项。

通过的部分及时把必要证据迁入对应版本记录，并缩减本计划；全部完成后删除，不另建完成归档。历史 2.4.0 的包来源和验证事实保留在[其版本记录](../releases/v2.4.0.md)，不以新结果覆盖。
