# 工作台动效与独立发行

目标：保留 SoDeck 的三主题、紧凑工作台和现有业务语义，在所有现有功能补齐轻快、克制、连贯的反馈；完成核心及五个插件的独立发行，核心 Release 标为 Latest。用户已授权实施、提交和正式发布。

## 验收行为

- 公共按钮、焦点和复制/保存结果即时反馈；菜单、选择器、对话框从来源进入并短暂退出。退出后立即失去输入资格，不延迟业务清理。
- 管理台导航与服务器切换保持焦点、草稿、滚动和原 Surface；刷新不重播入场。
- 左右面板展开/收起、标签新增/关闭/排序、分屏与工具停靠保留空间连续性。布局与独立 iframe 挂载层同步；指针拖动直接跟手，连续输入可改向，取消恢复当前有效布局。
- 服务器树局部分支与选中路线变化有反馈，建连阶段只按实际节点和阶段推进；成功、失败、取消沿用现有导航意图。
- 文件树与传输进度、编辑器保存/搜索、终端搜索/结束、Docker 资源状态/日志详情、网络隧道启动/停止/检查/复制均使用同一节奏；正文、日志阅读锚点、远端操作及实际结果不被动画修改。
- 状态总览及系统状态的详情、容量和异常过渡保留真实读数、观察时间和采样缺口。插件安装/启停、更新的下载/校验/准备/待重启、设置草稿、主题、消息未读和关闭阶段有精确反馈。
- 按钮约 100ms、浮层约 160ms、布局约 200ms，自然减速且无常驻装饰循环。隐藏/销毁停止展示动效；系统减少动态效果停止空间运动并保留状态信息。三主题、键盘、窄窗口均可用，不新增生产依赖。
