# 既有库复用：剩余验收

## 必要上下文

本轮只包含核心清单 SemVer、工程 Markdown/CLI 解析、文件插件 JSON/JSONC 字符串修正和核心服务器选择器定位。规则已分别同步到[插件 API](../plugin-api.md)、[开发指南](../development.md)、[分发文档](../distribution.md)、[文件](../features/files.md)及其 [CHANGELOG](../../plugins/files/CHANGELOG.md)、[工作台](../features/workbench.md)。

清单校验与选择器属于核心；语言规则与编辑器构建属于文件插件；Markdown/CLI 属于工程工具。未改 SDK/RPC，也未增加共享框架。核心构建不依赖插件构建，定位 helper 只处理几何与监听。

原生 dialog 与 Monaco 内部 tokenizer 迁移已撤出本轮。DOM 差量更新、密码选区与 IME 刷新继续由[局部刷新计划](dom-updates.md)维护。
