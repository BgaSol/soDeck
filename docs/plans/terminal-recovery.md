# 终端按回车恢复：待验收范围

状态：代码与本机回归已实现，尚未发行；五平台原生包验收尚未完成。未新增生产依赖。

## 已实现边界与正式归属

登录 shell 在原标签正文按普通回车或点击恢复按钮，在线时复用 SSH，断线时走核心现有认证及目标确认。保留 viewId、streamId、标题、布局和可检索历史；新 shell 不还原旧进程、变量或目录，不调整 TMOUT。指定命令终端继续显式重开。

逻辑终端和历史随页面存续，每次 PTY 有独立 Run、不可变 Context、输入队列和取消身份。核心保存连接及运行事实，终端插件保存每页一个启动意图，活动 Surface 通过短事件推进。重挂载只继续已有意图，未知回执保留原请求条件，旧输入不进入新 Run；宿主沿用一般焦点交接，不增加终端恢复队列。

已实现行为、失败与限制归入[终端功能](../features/terminal.md)和[连接功能](../features/connections.md)，生命周期归入[架构](../architecture.md)，字段及兼容契约归入[插件 API](../plugin-api.md#终端运行与连接恢复)。终端尚未发行的变更与验证范围见[CHANGELOG](../../plugins/terminal/CHANGELOG.md)。本计划仅保留剩余验收。

## 当前证据及其边界

- 核心默认 Rust 套件与终端进程回归覆盖多次 Run、同前驱去重、迟到输入、连接回执跨 Surface、PTY/shell 拒绝和延迟确认，以及自动目录准备的回执丢失、失败清理与关闭。
- 真实插件、xterm 与隔离 Windows OpenSSH 验证同页恢复、真实断线重连、原历史检索、移窗、重挂载、指定命令重开及恢复时不抢焦点。文件、终端、系统状态联动覆盖新运行的目录报告。
- 实际锁定 xterm 输入回归覆盖 IME 事件、修饰键、长按回车、隐藏/冻结、终端模式复位和新 shell 清屏后的历史保留；大历史套件覆盖十万行检索与回放。
- 隔离 Linux x86_64 容器运行实际 Bash/Zsh 登录脚本，验证 TMOUT 空闲退出、重新登录仍使用原 TMOUT、新 shell 不保留旧变量，以及目录集成资源清理。这不是 Linux 原生核心/插件包验收。
- Windows x86_64 最终工作树构建 MSI/NSIS 与终端归档；终端包内程序握手、挂载、释放与退出通过。核心原生 WebView/Channel 配合本次终端包及文件测试目录，在隔离 OpenSSH 上通过启动确认、字体、PTY 输入、历史检查点、文件读写、移窗、资料重开及退出。包元数据沿用 HEAD，不能当作干净提交的发行来源证据；不覆盖已发布包。
