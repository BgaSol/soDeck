# Agent MCP B：短命令启动与有限等待

状态：0.4.0 源码已实现，真实业务与独立发行验收进行中。

## 目标与已实现行为

exec_start 默认有限等待稳定 done，统一返回普通任务与第一文本页；长任务到期交接、重复请求调整窗口、等待位置在新登记前取得、取消和返回失败保留原任务。单接纳入口、共用 watch 与正文读取链路、下载原出口已迁移，没有新增生产依赖或核心接口。正式契约与边界已回写 [MCP API](../mcp-api.md)、[功能说明](../features/mcp.md)和[架构](../architecture.md)。

## 当前验证

0.3.0 源码进程基线重新构建通过；16 项插件单元与新实际进程回归通过。30 次受控短命令分别一次调用取得稳定事实和完整输出；全局/每任务额度、重复请求、持续变化、固定期限、HTTP 断开、读盘错误、多页及 A 回归通过。第一次进程检查命中了旧测试产物，重建基线后通过；新增持续输出测试对端缺少 workerFinished，补齐实际协议字段后通过。
