# 容器日志工作台后续验收

状态：本地实现已形成，尚未发行；正式行为与限制见[Docker功能](../features/docker.md)，核心契约见[插件API](../plugin-api.md)。本计划只保留后续验收与仍有效的设计约束，不重复完整功能说明。

## 已形成的实现

- 核心提供非PTY的session.stream.v1，固定或滚动原字节捕获、读取水位、ACK、pin/gap与原票据查询；通过通用会话执行，Docker不持有SSH认证资料。关闭、插件退出与连接取消有资源清理。
- 核心content.export.v1提供用户选定的本机目标、分块重试、同目录临时文件与提交、进度和取消。内容解释与导出范围属于Docker。
- Docker使用一个有界协调队列，只保留采集元数据。每次读取先核对连接/Engine/完整容器ID，范围使用新读到的Engine时间；打开默认尾部预览与实时接收，停止容器读取最后保留的尾部。
- Worker负责字节分行、源纳秒时间、级别、字面查询、上下文、缩略摘要和导出固定结果。近期窗口有界轮换，阅读时保护一个窗口，停止滚动不停止接收。
- 日志页面具有连续正文、筛选清除、跨日日期、搜索导航、详情与原文复制、右侧缩略、原捕获恢复和导出。移除旧分页/行数设置路径，容器维护、文件与终端业务保持原有边界。公共主题/控件使用packages/ui，Docker布局留在插件。

## 保留的边界

- 一个容器的日志工作区；不扩展到多容器聚合、告警、统计看板、集中永久存储或整个远端全文索引。
- 最初只显示最近15分钟尾部最多2000行/2MiB正文；4MiB原捕获包含字节信封。完整范围需主动读取，超出容量或期限明确为部分读取。不能仅凭空输出判断日志轮转或历史不存在。
- 近期捕获与Worker有界轮换，阅读只保护一个窗口。搜索、缩略和导出只覆盖实际保留内容。保留完整原字节，stderr不自动等于ERROR；TTY来源合并，ANSI只安全显示，不猜测任意堆栈分组。
- CLI没有稳定日志ID，不保证无缝重连或恰好一次衔接；同时间记录不靠文本去重。重新读取前核对身份，旧捕获可继续阅读，旧命令不自动重放。
- 可信插件不新增权限声明、逐项授权或审批。核心检查API版本、参数和资源状态；插件独立发行，核心包不包含业务插件。
- 不新增生产依赖或第二套日志入口；要更大的长期索引或GB级导出，另行比较Engine API与存储需求，不堆启发式补丁。
