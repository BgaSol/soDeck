# Docker 日志剩余专项验收

日志整改已由核心 2.3.0 与 Docker 0.10.0 独立发行。当前行为、操作、失败与限制见[Docker 功能](../features/docker.md)，通用边界见[插件 API](../plugin-api.md)；本轮实际验证、失败修复和包来源分别进入[核心发行记录](../releases/v2.3.0.md)及[Docker CHANGELOG](../../plugins/docker/CHANGELOG.md)。本计划只保留未完成专项，不因已发布推定全部验收完成。

用户目前只有 Windows x86_64 单屏实体设备。五平台原生包验收已完成，本轮 Windows 原生日志覆盖 60 秒接收与 20 次回收；其他系统日志 WebView 和设备行为仍须提供独立收据。旧实现的一小时、100 次回收和设备专项结果保留在[1.1.0 记录](../releases/v1.1.0.md)，不能替代重构后的长时验证。

## 执行与收束

只使用隔离测试账户、daemon、容器、应用数据和保存目录，不访问生产服务器或宿主 Docker socket。复用现有原生 runner、固定包输入与[开发入口](../development.md)；其他平台先建立可靠驱动，有真实收据后再接 CI。每项分别记录通过、失败、未执行或缺环境，重跑成功保留早期失败和解释，只复验失败及受影响范围。

核心管理通用字节、资源及系统适配，Docker 管理源、记录、查询与页面。必要来源、包摘要、报告和资源曲线进入组件发行证据，私人系统设置和文件选择框截图不公开。范围全部完成或用户明确调整后，同步正式文档、安置证据、修复引用并删除本计划；历史通过 Git 查询。
