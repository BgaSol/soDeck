# 日志工作台剩余验收

状态：核心 1.1.0 / Docker 0.4.1 已按实际已验范围发行，以下专项仍未完成。当前行为见[Docker](../features/docker.md)，通用能力边界与配额见[插件 API](../plugin-api.md)，实际来源与证据统一进入[1.1.0 记录](../releases/v1.1.0.md)和[Docker CHANGELOG](../../plugins/docker/CHANGELOG.md)。

用户只有 Windows x86_64 单屏实体设备。五平台仍是正式支持目标；五平台原生打包及包内程序验收已经通过，不能替代新增日志的 WebView 业务或各系统设备体验。

## 执行与收束

Windows 原生入口、参数及报告方式见[开发指南](../development.md)。其他平台先做最小可靠驱动，有真实收据后接现有 CI，不将设想写成可执行命令。只复验失败平台和受影响场景，使用固定原包来源，不重复构建同版本成功包。

必要来源、包摘要、原始验收报告和资源曲线进入核心版本附件；Docker 独立版本链接这些证据。私人系统设置和文件选择框截图不公开。每项分别记通过、失败、未执行或缺环境，重跑成功保留早期失败和解释。

发行可按实际已验范围交付，但完整专项验收仍保持未完成。剩余范围全部完成或用户明确调整后，回写正式功能/架构/API 与发行记录，删除本计划并修复引用；历史由 Git 保留。
