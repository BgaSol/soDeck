# 核心界面重构与 1.0.0 发行

状态：核心代码已实现，正在验收与发行。用户已批准按原型实现核心及核心与组件交互，并发布 1.x Latest。

## 已实现范围与正式归属

- 顶部 SoDeck 完整管理台、主窗口“＋”统一连接入口、插件侧栏边界、隐藏与恢复：见[工作台](../features/workbench.md)及[架构](../architecture.md)。
- 显式连接树、紧凑节点、路径高亮、多标签 AND、旧分组 v1 → v2 迁移与独立旧备份：见[连接](../features/connections.md)。
- 公共 CSS/主题/token 集中维护、IDEA 明暗和保留的多巴胺、插件几何兼容：见[公共界面源码](../../packages/ui/README.md)和[设置](../features/settings.md)。
- 插件内部暂不改动。文件的目录组织、排序分页、定位选择、展开跟随、右键拖动、传输编辑保存与显示状态保持[原功能](../features/files.md)。不将原型模拟业务搬进插件。
- 核心会话接纳与壳导航分别控制，成功是否进入工作台由发起窗口仍有效的导航意图决定；快速成功、重复快照、改选服务器、迟到成功和已连接复用均纳入回归。

2. 正式设计系统文档与独立界面评审已完成；公共规范见[设计系统](../../DESIGN.md)。发行收尾时清理已被正式实现替代的[原型](../../prototypes/interface/index.html)。

5. 实際验证与跳过范围写入[1.0.0 版本记录](../releases/v1.0.0.md)，核对引用与附件，删除本计划及已被正式实现替代的原型/评审临时材料。
