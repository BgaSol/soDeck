## 已有验证位置

- [速度与投影回归](../../scripts/file-transfer.test.mjs)：350ms 刷新/500ms 采样、静止归零、换操作、节点保持、满字节校验阶段、旧 Context 回包与缓存回收。
- [真实进程](../../scripts/test-files-process.mjs)：满字节后刷盘失败、持久诊断字段、原身份确认不重放、失败重试计量；该刷盘错误由假核心注入，不等同真实磁盘耗尽。
- [真实 OpenSSH](../../src-tauri/tests/fixtures/files_flow.rs)：传输开始后修改源 mtime，正文全部传完后 verifySource 失败且不提交；目录/二进制/空文件、取消和原目标保留沿用。
- 核心 local_files 无覆盖/替换/无效临时文件检查；协议回归拒绝伪完成回执；MCP 回归保留已提交事实并接收后续阶段，进程/UI 验证独立证据结果。
- [浏览器交互](../../scripts/test-workbench-interactions.mjs)与[实际文件界面](../../scripts/test-files-ui.mjs)保留操作、焦点、真实进度和同窗/跨窗路径。

本地 Windows 已通过格式/类型、223 项脚本、38 项浏览器交互、文件/MCP 及 SDK 单元、MCP 真实进程/UI，以及真实 OpenSSH 文件与界面流程；最终来源 Check 与包验收另行记录，不用本地结果替代其他平台。
