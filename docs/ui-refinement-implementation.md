# UI 优化实施记录

日期：2026-10-20。用户已确认实施。按 apple-design 的反馈、可预测性、焦点归属和克制原则，进行局部重构与优化，沿用 React、原生 dialog、现有主题、图标和后台任务体系。未添加依赖，未迁移已保存数据。工作区既有日志改动保留。

## 实际改动

### A：监控与下载

- MonitorStore 分离连接事实与订阅状态。订阅失败显示“监控暂不可用”，不会伪装为 SSH 断开；主面板、摘要、挂载和流量统一标记旧数据。
- start 去重、停止后的迟到订阅释放、快速停止再启动、同代次历史保留和不同代次清空。挂载查询错误与订阅错误分别保留。
- 下载入口关闭文件菜单，弹窗初始聚焦同名处理选项；菜单键盘事件局限于菜单。退出恢复原文件行，行消失则回退到选中行或文件树。原生选择器期间暂缓恢复，返回后再处理。
- 下载标题使用 useId，避免多个工作区的同名 DOM ID 冲突。

### B：创建与设置

- 新增 createContainerDraft.ts：草稿只驻留内存，字符串数值允许编辑中空值；稳定 rowId、dirty 比较、环境变量行号、UTF-8 字节上限、名称/端口/挂载/网络/路径校验。
- DockerDialogFrame 保留一个原生模态窗口，编辑、预览和放弃提示在内部切换。预览不渲染含环境变量的表单；返回编辑恢复草稿、展开状态、焦点和滚动位置。
- 固定标题和底部操作，正文独立滚动。通过 portal 脱离响应式侧栏的 hidden/inert 祖先，缩窄窗口时仍能操作。
- 创建入口移到 DockerPanel 持有，镜像详情更新或引擎变化不会直接丢弃草稿；引擎变化释放预览，并要求再次预检。
- RestartPolicyFields 在创建和设置中共用；仅 on-failure 显示次数，0 表示不限次数，切换策略保留输入但其他策略提交 0。后端创建预览说明最终策略。

### C：操作与预览恢复

- useDockerActions 统一准备、重新检查、提交、结果不明和接受状态。首次确认才生成请求 ID，提交请求快照不随编辑变化；IPC 结果不明只核对原请求，订阅和返回值只触发一次接受收尾。
- 所有 Docker 确认入口提供重新检查。到期按钮禁用，提交时再次核对时间；刷新不会执行操作。传输刷新复用原本机文件选择结果。
- Rust DraftRegistry 用稳定 draftToken 管理最多 100 份逻辑草稿；确认 60 秒，源数据最多保留 15 分钟。重新检查替换 preview ID，旧版本不能提交；刷新回包丢失可按 expectedPreviewId 幂等取回现版本。
- renew_docker_preview 校验原会话、身份、窗口 generation、引擎与期限，远端只读预检后在锁内重新确认版本。release/submit 先完成时，迟到刷新不能重建草稿。续查不延长原保留截止时间。
- 取消或来源变化递增前端请求代次，迟到预览释放；结果不明期间禁用返回编辑和重新检查，避免生成新的操作意图。

### D：外观

- 主题偏好区分 system/light/dark 与实际颜色。兼容原 sodeck.theme 值；选“跟随系统”移除该键。
- 顶栏使用菜单与单选语义，方向键、Home/End、Enter/Space、Escape、焦点返回完整。浮层通过 portal 避免被主内容遮挡。
- 系统设置增加外观选择，与顶栏共用选项和存储；同色不同偏好仍通知，保留跨窗口同步和未保存编辑。存储写入失败时当前窗口仍能切换。

## 环境边界

- 真实 Windows WebView + 隔离 Tauri 配置 + 本机 SSH/SFTP：新增文件下载键盘/取消焦点与主题偏好用例通过。没有连接用户服务器。
- 原生“选择保存位置”窗口成功打开，但 computer-use 无法可靠执行取消（返回 coordinate input geometry is unavailable，随后窗口状态获取失败）；该完整链路未通过实测，不算测试通过。浏览器受控异步回包另覆盖选择器返回后的焦点恢复。
- macOS/Linux 实机和真实 Docker Engine 操作未在本轮执行。Rust 中需要专用 Docker Engine / Docker CLI 的 2 项测试保持 ignored。
- Vite 构建成功但仍提示主 bundle 超过 500 kB；本轮未增加无关的打包拆分。
- 调试 QA 应用、SSH fixture 和前端服务已停止；默认应用标识的 debug 构建已恢复。没有提交、推送或发布。
