# 文件编辑器搜索、缩略图与语法高亮实施记录

整理日期：2026-11-10。状态：源码已实现，本机浏览器、Windows x86_64 WebView2 与真实 SFTP 回归通过；尚未正式发行，其他四个平台原生验收未完成。目标见[功能设计](plan-file-editor-search.md)。

## 实现范围

文件插件中央编辑页从普通文本框迁移到 Monaco，提供行号、右侧彩色全文缩略图、当前正文搜索和语法着色。搜索包含未保存修改，支持大小写、循环上一处/下一处、`Ctrl/⌘F`、Enter、Shift+Enter、F3 和 Esc。

常规文件名、后缀和有限 shebang 自动识别语言；状态栏可手动更正。第一版提供 YAML、JSON/JSONC、Shell、PowerShell、Nginx、INI/systemd、TOML、环境变量、Dockerfile 和常见文本/源码的词法颜色。Nginx、TOML、环境变量和 JSON 使用插件内的有限词法规则；不提供语言服务器、配置诊断、补全或格式化。

缩略图共用当前编辑模型和颜色，可点击定位并保留正文选区。现有字体、字号、行高、Tab 显示宽度和自动换行设置仍生效，新增默认开启的“显示缩略图”。窄编辑区域使用位置标记与正常滚动条，搜索条可换行。

超过 1 MiB（1,048,576 字节）的远端文件在文件树打开入口拒绝编辑，仍可下载；核心的读取和暂存上限继续保留。编辑事务按补回原始 BOM、LF/CRLF 后的 UTF-8 字节检查，超限粘贴/程序插入不提交，原生输入超限撤销本次事务，不截断正文。

## 状态与核心边界

编辑器、搜索、语言和缩略图全部位于文件插件。核心文件 API、组件 API 与 CSP 没有变化；继续复用核心的连接、草稿、剪贴板、资源归属与安全保存。

- 本地编辑版本与核心草稿 revision 分开记录。新输入仍待暂存时，旧保存结果不能把视图标成已保存。
- 暂存仍为一份在途快照和一份合并后的最新版本；保存和导出等待完整暂存。
- 文件插件保存可选的版本 1 `editorState`，包含完整选区、逻辑滚动锚点、水平位置、搜索和语言覆盖。状态限制为 8 KiB，查询限制为 1,024 个 UTF-16 代码单元，恢复前校验字段。
- 字体和显示设置不制造正文事务。隐藏候选在没有实际布局时保留逻辑锚点，在首次有效布局后恢复，避免用零尺寸视口覆盖保存位置。
- 交接先停用用户输入，再等待在途草稿与展示状态同步；候选激活前只读，取消交接恢复源输入。搜索和着色结果在目标重新生成。
- 复制/剪切/粘贴读取真实模型选区并使用现有剪贴板桥接。正文使用自己的菜单，搜索输入框继续使用通用文本菜单；256 KiB 剪贴板限制保持不变。
- 关闭释放模型、事件、观察器、装饰和创建的 worker。不新增磁盘正文缓存或进程崩溃恢复承诺。

远端保存仍核对版本与链接目标，通过同目录临时文件保留权限并原子替换。外部修改拒绝覆盖，提交后失联仍保留结果未知语义。“下载远端”和“导出草稿”继续表示服务器版本和此页当前草稿。

## 性能与依赖

硬上限内直接使用编辑器模型检索，不建立数据库或索引。每次最多收集 1,001 处结果：1,000 处以内显示准确数量，更多显示“1,000+ 处”，最多绘制 1,000 个普通命中和一个当前命中。上一处、下一处始终查找整个文件；首次有界结果集合不会屏蔽尾部命中。连续查询合并约 120 ms。

本机 1 MiB 重复字符样例的浏览器检索报告为约 131～151 ms，包含查询合并与浏览器调度。这是几个本机样例的结果，不是五平台 P95 性能或内存验收。完整预算仍以方案为目标。

新增生产依赖仅在文件插件中：Microsoft 维护、MIT 许可的 `monaco-editor` 0.57.0，用于成熟的输入、选区、撤销、行布局、minimap 和词法着色。替代方案为 CodeMirror 6，但需要额外实现 minimap。开发依赖复用项目固定的 TypeScript 7.0.2 和 Vite 8.3.6。

Monaco 固定的 DOMPurify 3.4.15 被审计报告标记有漏洞，通过插件的 npm override 固定到修复版本 3.4.17；当前插件依赖审计为 0 个漏洞。锁文件与 Monaco、DOMPurify、marked 的许可证/第三方声明随包维护。

当前构建中编辑器公共 JS 约 3.27 MB，worker 约 304 kB，CSS 约 99 kB，语言分块按需加载。完整本机文件插件 ZIP 约 1.83 MB，包含原有字体与 Rust 程序。构建资源只进入独立插件包，不进入核心安装包。

## 未完成与限制

- Windows ARM64、Linux x86_64/ARM64、macOS ARM64 的新编辑器原生包与实际运行验收待执行。不能把本机结果当成五平台完成。
- 真实操作系统输入法、触摸/辅助技术和系统剪贴板的人机验收待执行；本轮未操作日常桌面的剪贴板。
- 完整性能 P95、长时间内存与多文件负载预算尚未测量；目前没有新增大文件模式。
- 高密度搜索的缩略图标记是有界部分集合，界面有提示；导航仍覆盖全文。长于 10,000 字符的单行可以部分按纯文本呈现，正文与搜索不被截断。
- 无正则、替换、跨文件搜索、配置诊断与自动保存；引擎撤销栈不跨 UI 重挂载持久化。
