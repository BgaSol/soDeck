# 组件独立设置与终端外观实施记录

2026-11-06，依据 [功能设计](plan-component-settings.md) 和 [代码修改方案](plan-component-settings-coding.md) 实施，已与桌面一致性、更新体验一并提交。本轮核心 0.9.0、终端 0.2.0、文件 0.4.0、网络隧道 0.2.0 独立发行；五目标结果见 [发行说明](releases/v0.9.0.md)，下文保留源码实施时的本机验证范围。

## 用户可见行为

现有设置页面新增“组件”导航，终端、文件列表、文件编辑器和网络隧道分别配置；同类组件共享所有服务器、主窗口和拆出窗口的偏好。关闭的插件仍可使用静态设置；未安装、旧版本和不受支持的声明显示说明。外观入口在设置页面，右键继续只提供业务操作。

| 组件页 | 已实现设置及默认行为 |
| --- | --- |
| 终端 | JetBrains Mono、14px、1.2 倍行高、24px 底部留白、块状闪烁光标；左右 16px/顶部 12px，颜色继续跟随主题 |
| 文件列表 | 显示隐藏条目、紧凑/舒适密度、名称字号；过滤保留远端分页，不对隐藏条目继续执行多选操作 |
| 文件编辑器 | 字体、14px、1.5 倍行高、自动换行、Tab 显示宽度；排版变化保留正文、选区和滚动位置 |
| 网络隧道 | 新建默认类型、自动/固定本机端口、固定端口 1080；只影响之后新建的表单 |

切换组件页和关闭设置保留本窗口草稿，恢复默认也先成为草稿。保存失败或其他窗口冲突不会覆盖正在编辑的值。保存成功、等待启动、用于新建、部分组件应用失败分别反馈；失败可重试当前已保存的修订。草稿不跨应用重启。

预置 JetBrains Mono、Source Code Pro、IBM Plex Mono，各携带完整 Regular/Bold WOFF2、固定源码提交、SHA-256 和 OFL 许可证。字体随终端/文件插件各自分发，普通构建不下载资源，安装后离线加载；本机字体输入已安装的字体名称。示例使用真实 FontFace.load，加载失败说明原因并回退，不以 document.fonts.check 作为加载成功依据。CJK 采用系统字体回退，不包含完整中文或 Nerd 图标字库。

## 分层与升级

Manifest 保留可选原始 settings JSON，避免未知设置扩展阻断原有插件业务。核心 settings 模块处理单页声明、约束、版本/实例选择、原子保存、备份、修订冲突和近期请求去重。通用前端 settings.ts 按声明生成表单；插件负责排版、过滤和新建默认值的效果。共享字体加载器只在核心示例与两个真实插件用例出现后提取，核心不包含业务字体和 xterm。

initialize 可发现 settings.v1 并取得页面索引；插件显式返回 settingsApiVersion 后接收带 ID 的 settings.changed。初始化读取允许重入核心，避免生命周期锁相互等待。宿主以当前窗口/surface/实例转发单页有效快照，应用回报同时校验定义和修订。旧插件和旧核心继续按缺少可选能力的路径使用默认业务。

升级下载后待重启的候选声明不会提前生效。实际程序切换后新字段补默认、兼容用户值保留；移除或类型/单位变化保留最多两份结构历史；非法旧值保留原值并以当前默认运行。新版启动失败时复用现有程序回退，设置重新选择旧定义和适用值，修订继续递增。损坏主文件可从备份恢复并保留原文件；没有可用备份时禁止覆盖。

终端修改字体/字号/行高/留白后重新 fit 并发送 PTY resize，继续使用原 PTY，清理旧几何选区、取消过期粘贴并尽量保留滚动位置。字体加载及异步应用以代次丢弃过期结果。验收发现同修订去重曾阻止字体失败后的重试，已取消该阻断，并以字体请求失败后修复再投同修订验证恢复。

文件排版只改变 textarea 显示，不改变编码、BOM、换行或草稿修订。网络设置保存不调用规则保存、启动或停止，不分配监听端口，也不覆盖已打开的新建/编辑草稿。

## 检查与构建

Windows x86_64 已执行的本机检查：

- 类型与 Rust 格式：npm run check、npm run plugin:check，以及共享 plugin-client 格式检查通过。
- npm run test：89 项通过；5 项需独立 OpenSSH/实际插件的测试由专用入口执行，不将 ignored 计为通过。
- npm run scripts:test：13 项通过，包含独立字体资产、许可证、WOFF2 文件头、摘要与越界路径拒绝。
- npm run settings:test：真实核心静态声明、四个关闭插件页面、离线字体、草稿切页/关闭重开、跨窗冲突、本机字体失败、端口约束、三主题与 12 个尺寸/缩放组合通过。
- 终端输入回归通过，包括实际 xterm、中文/IME、复制/Ctrl+C、括号粘贴、过期粘贴、主题几何保留、外观更新、旧修订拒绝及失败后同修订重试。
- npm run terminal:test：实际 OpenSSH 插件、xterm 输入输出、多 Tab、WebView 重挂载显示恢复和三主题截图通过。
- 真实 OpenSSH 文件与网络流程通过，包含编辑器排版前后正文和选区一致、默认值修改后现有规则和监听端口不变。
- 核心 EXE/MSI/NSIS 与终端、文件、网络插件分别构建通过；核心包仍不包含业务插件和字体。

Check 工作流接入设置 UI 检查并声明其 Linux 核心夹具编译依赖；既有五目标插件打包通过资产复制函数校验字体和许可证。实际包远程烟测增加三款终端字体应用、Windows 本机 Consolas、保存重开和 PTY 身份保留；该流程复用现有核心/插件包组合入口，不要求核心打包先构建业务插件。

Windows x86_64 实际包验证通过：从本轮生成的 MSI 行政解包运行包内 sodeck.exe，加载独立构建的三个业务插件，以隔离 OpenSSH 执行两次启动。通过真实 WebView/Channel/iframe 加载三款 Regular/Bold 字体与本机 Consolas，保存字号 18px/底部留白 40px 后确认 PTY ID 保持不变，并完成终端往返、文件保存下载、TCP/SOCKS5、移窗与退出；第二次启动先核对已保存的外观再继续业务。结果位于本机 artifacts/settings-native-aa6c47e499474b0a955fd0e8dae2f1b4/，终端设置修订由 1 增至 9，最终值保持 IBM Plex Mono/18px/40px。

无业务插件的包内启动/退出与服务器资料重开烟测也通过。实际包验证使用显式隔离测试目录，未修改用户正在使用的资料或安装目录。截图保存在 artifacts/settings-ui/terminal.png 与 artifacts/terminal-ui/，这些目录为本机验收输出，不随程序发行。

相关文档检查通过：104 个本地链接、13 个 JSON/JSONL 示例及差异空白检查。

## 未完成事项与边界

源码实施阶段尚未运行 Windows ARM64、Linux x86_64/ARM64、macOS ARM64 的原生实际包验收，也未发行新版本。后续 v0.9.0 的原生构建、实际包启动退出及业务组合验收结果统一记录在 [发行说明](releases/v0.9.0.md)，不以旧版本记录代替本版验收。

原生 WebView 的 CJK/框线观感、不同本机字体宽度、vim/top 备用屏幕、输入法与混合 DPI 的设备验收仍需补充。Chromium 平台模拟不等于各目标原生 WebView 验收。自定义字体为本机名称，不支持字体文件导入、枚举或字体下载市场；首版不实现破坏性迁移脚本、逐服务器覆盖或无限历史。
