# 工作台

工作台按服务器组织工作区，在中央标签组与两侧工具区域展示插件页面。主窗口保留服务器管理，独立窗口承接工作区内容；连接身份与页面显示位置分开管理。

独立窗口保留服务器标签与“＋”、功能标签、已有面板、底部连接状态和窗口操作，隐藏顶部应用状态、消息和设置按钮，以及左右工具入口栏及其占位。

## 页面与布局

- 一级“＋”选择服务器，连接成功进入发起窗口的工作区。重复连接已有服务器定位现有工作区。
- 服务器选择器跟随“＋”的位置，靠近窗口边缘时翻转或限制尺寸；入口隐藏或失效后关闭，关闭后停止位置监听。搜索和重新打开不会重复发起连接。
- 中央“＋”执行插件声明的默认新建行为，由插件决定创建自己的页面；默认终端的实际行为见[终端](terminal.md)。创建期间显示等待并防止重复提交，切换工作区后迟到完成不抢焦点。
- 中央支持嵌套左右/上下分屏、各组独立活动页、标签排序、同窗移组和合并。同窗布局调整保留 iframe、草稿与运行资源。
- 页面菜单提供分屏、移到新窗口、适用的返回入口及关闭。服务器菜单提供适用的返回主窗口、移到新窗口和关闭。右键非活动标签时保持当前内容，操作目标是被点击的标签。
- 分屏栏空白处可新增分屏或取消当前分屏。取消按阅读顺序合入前一组，否则后一组，不释放页面；移动唯一页面新建分屏时保留显式空源组。
- 组的最小布局为 280×180 CSS px，分隔线为 6 px。空间不足时临时收起侧栏或只显示焦点组，“其他分屏”入口保留名称、未保存和错误状态；扩大窗口恢复原树。无法容纳的新分屏明确禁用。

普通菜单保持精简；核心内部支持的整组迁移、已有窗口目标、批量返回和额外窗口恢复，不都作为普通菜单入口展示。接口能力不能直接当成界面已经提供的操作。

## 多标签与查找

服务器标签和每个中央分屏的页面标签保持单行。名称过长时省略，关闭入口保持可见；标签溢出后显示左右滚动按钮，到边界禁用对应按钮。列表入口显示本窗口服务器或本组页面的总数，与“＋”一起留在固定操作区；没有标签时隐藏列表和翻页按钮。

点击箭头、离散滚轮和主动定位使用可打断的短缓动，同方向连续输入合并，反方向从当前可见位置改向。触控板横向像素输入使用原生滚动，连续竖向像素输入在标签视口内直接映射横向；不会额外模拟手势惯性。Ctrl/捏合缩放不拦截。设备类型只能通过 WheelEvent 启发式判断，真实设备手感仍需校准；系统减少动态效果时关闭额外缓动。

选择、新建及关闭活动标签后露出新的活动标签。手动翻阅不会切换页面，后台刷新保留浏览位置；缩窄窗口时保持原先可见的活动标签，原先已翻出视野时保留浏览位置。各分屏滚动位置相互独立，在运行期保存，收起和恢复分屏继续沿用，不写入布局文件。

服务器列表搜索名称和 endpoint，只列当前窗口服务器；页面列表搜索标题和已有资源标识，只列当前分屏页面。列表保留标签顺序，展示当前、断开、未保存、错误、忙碌或不可用状态。关闭或隐藏沿用既有生命周期，取消或失败保留页面及资源。搜索期间刷新保留输入和选区；无匹配时显示空结果。

标签取得焦点时支持左右方向键和 Home/End；搜索列表支持上下方向键、Enter 选择、Esc 返回入口，Tab 使用正常焦点顺序。开始拖拽、离开所属工作区、关闭保护或锚点失效时关闭列表；终端正文输入不绑定这些操作。

拖拽在标签视口边缘短暂停留后自动滚动，离开、松手或取消后停止。固定按钮区不接受标签落点；松手前目标窗口确认最新几何，确认失败时取消并提示重试，避免使用旧插入位置。跨窗坐标和 Wayland 限制沿用下文的交接规则。

## 工具停靠与尺寸

工具入口可以固定、排序并在左右两侧之间移动；已打开的面板随入口共同停靠，继续复用原 view、iframe、文件草稿和网络监听。中央工具可停靠左右侧栏或中央，隐藏只影响展示。入口位置与实际停靠位置一致，已有定制优先于插件推荐值。

工具按保存的布局或插件推荐位置打开。面板标题栏只保留名称和收起按钮，不再展示布局配置下拉菜单；拖动标题栏调整面板位置，拖动侧边工具入口调整左右位置与顺序。侧边入口的右键/键盘菜单保留位置调整操作，更多组件入口继续用于寻找工具。

侧栏与中央分隔线支持指针和键盘调整；拖动过程中刷新保留捕获与原页面，Esc 取消本轮调整。结束后保存有效宽度/比例。终端只在尺寸有效、页面取得输入权时同步 PTY 尺寸，隐藏或候选页面不以零尺寸覆盖终端。

布局保存在 `workbench-layout.json`，保存分屏结构、比例、工具定义位置及窗口尺寸，不保存 Context、viewId、正文或命令。主动连接恢复适用的首份结构；恢复布局不等于恢复之前的远端会话。损坏或未知版本文件保留原件，正常保存保留备份。

## 跨窗口交接

交接依次准备只读目标、同步源输入、等待在途调用/PTY 队列、恢复目标输出水位，最后共同提交归属。提交前源实例仍存在；失败或取消恢复源输入，提交后旧 Surface 失效。目标不会通过重新执行命令恢复终端。

页面返回优先使用运行期保存的来源组与邻接位置；来源失效时回退到该工作区仍有效的默认显示部分。移走最后内容后回收空独立窗口。跨窗页面要求 UI v2；UI v1 可进行同窗布局调整，跨窗前需要升级相应插件。

Windows 的跨窗落点使用实际系统窗口命中和物理坐标。Wayland 缺少可靠全局坐标时使用新窗口/返回菜单，同窗拖动使用局部坐标。主窗口标题栏空白支持系统拖动和双击最大化/还原；标签和按钮操作不触发窗口拖动。

## 关闭与维护约束

关闭页面、组、窗口、工作区与整个应用使用[同一关闭生命周期](lifecycle.md)。隐藏工具、取消分屏和迁移页面不能误作销毁业务资源。失联窗口、跨窗保存及未确认输出必须由核心协调，页面不能自行宣布交接完成。

菜单支持 Shift+F10/菜单键、方向键、Enter、Esc/Tab；失焦和目标失效后关闭。可见性、输入权和后台运行是不同状态；系统状态采集和网络转发的业务生命周期由各自插件决定。
