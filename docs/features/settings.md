# 设置、外观与桌面行为

管理台的设置页管理应用偏好与组件显示。设置分类展开在管理台同一列侧栏中，外观、组件页面和应用与数据属于设置子项；插件管理和更新分别使用一级入口。父项显示展开状态，子项标明当前页面，侧栏与正文分别滚动。离开设置再返回时恢复最近分区和组件页面，插件和更新页不会覆盖该位置。全局偏好与组件设置由核心保存；插件实现这些设置对自身业务的效果。

## 外观和组件设置

支持跟随系统、晨曦（浅色）、星夜（深色）和多巴胺主题，主窗口、独立窗口和插件页面共用主题 token。主题即时应用并持久化，不重新挂载插件页面；终端字体和文件排版变化不重建远程业务资源。公共样式、主题登记及扩展方法见[公共界面源码](../../packages/ui/README.md)。

同一组件类型在所有服务器和窗口共享设置。终端提供字体、字号、行高、留白与光标；文件列表提供隐藏项、密度与字号；编辑器提供字体、换行、Tab 宽度和缩略图；网络隧道提供新建规则默认值。系统状态和 Docker 的采样/刷新设置见各自功能文档。

JetBrains Mono、Source Code Pro、IBM Plex Mono 字体随相关插件独立打包，附许可证和来源摘要，运行时离线加载。可输入已安装的本机字体名称；失败明确提示并回退。不提供字体文件导入或字体市场，中文使用系统字体回退。

设置页中的值先成为当前窗口草稿，切页或关闭设置可保留草稿，恢复默认也需要保存。保存冲突或失败不会覆盖输入。保存成功、等待启动、仅用于新建和应用失败分别反馈；可重试已经保存的同一修订。草稿不承诺跨应用重启恢复。

设置正文限宽，滚动区域占满设置页宽度，滚动条位于页面右边缘；宽窗口中正文右侧的留白也可滚动。非布尔字段的控件位于标题/说明下方，布尔字段使用可通过键盘操作的开关。短表单的保存区紧随字段；长表单滚动时保存区保持可达，焦点字段滚入正文而不推动整个桌面壳。恢复默认需要显式保存，主题选择继续即时生效。

关闭的已安装插件也可以配置静态声明；不支持的旧声明明确提示。升级候选在实际程序切换前不改变当前表单。核心保留兼容设置值、修订与有限结构历史，损坏文件先保留原件并尝试备份，不能覆盖唯一可恢复数据。

同一设置页的导航标记、反馈和后台读取不移除表单节点；组合输入与选区保持连续。切换到另一设置实体建立其自己的显示，迟到读取不会覆盖新实体，读取失败保留当前草稿。默认值、放弃、载入最新值由明确动作更新控件。宿主退出时的草稿处理见[生命周期](lifecycle.md)。

## 桌面交互

### 托盘与后台运行

核心 2.4.0 起，应用启动后提供系统托盘。菜单固定为“显示主窗口”“消息（N 条未读）”“设置”和“退出 SoDeck”；没有未读时显示“消息”。显示入口保留原页面和布局，消息打开现有消息中心，设置打开“应用与数据”。打开消息入口不批量标为已读。

“设置 → 应用与数据 → 关闭主窗口时”可选择“在后台继续运行（推荐）”或“退出应用”，立即保存并作用于之后的关闭，不要求重启。旧配置和新安装默认后台运行；保存失败保持原有效值。首次收起前解释一次，取消则保留窗口，确认并成功收起后不重复提示。

| 平台 | 后台运行时关闭主窗口 | 返回入口 |
| --- | --- | --- |
| Windows | 托盘建立成功后隐藏；托盘不可用则沿现有退出流程处理 | 左键单击托盘，或右键菜单 |
| macOS | 隐藏主窗口；没有其他工作窗口或必要交互时，仅保留菜单栏入口，撤去 Dock 运行身份与 Cmd+Tab；托盘不可用则沿现有退出流程处理 | 菜单栏菜单；恢复工作窗口时重新出现在 Dock |
| Linux | 最小化，保留任务栏或系统窗口切换入口；不依赖桌面一定展示托盘 | 系统窗口入口、可用的托盘菜单 |

系统拒绝收起时保留窗口并反馈原因。最小化按钮仍执行普通最小化。关闭独立窗口处理其自身页面和资源，不受主窗口设置影响；主窗口收起不隐藏独立窗口，最后一个独立窗口关闭也不退出后台主进程。

核心 2.4.1 起，macOS 收起后按实际工作窗口切换应用身份；独立窗口仍在、已最小化或位于其他 Space 时保留普通应用入口，最后一个窗口实际结束后才切换为仅菜单栏运行。普通最小化、Cmd+H 和失焦不触发该切换。显示、消息、设置、必要认证与文件对话框统一恢复普通应用身份和相应窗口；处理后保持窗口可见。正常启动仍显示主窗口，不记忆隐藏启动。用户手动固定及系统最近使用的 Dock 快捷方式由 macOS 管理，应用不删除它们。实际验证范围见[2.4.1 记录](../releases/v2.4.1.md)。

收起不结束 SSH、隧道、文件传输、插件任务或草稿，不改变页面和资源归属；插件显示通过原有可见性接口暂停/恢复，业务继续按各自规则运行。收起期间较早的连接成功不抢焦点；必须回答的认证、主机身份、关闭决定和原生文件选择会恢复所属窗口。正在处理模态交互或页面交接时需先完成该操作。真正退出、Cmd+Q 和各类重启仍走[关闭生命周期](lifecycle.md)，取消/失败后窗口保持可达。

托盘未读数随消息中心变化；普通日志或消息不主动恢复窗口，不新增系统桌面通知。后台只持续到本次进程结束，不承诺系统休眠/断网后连接保持。不提供插件自定义托盘项或全局快捷键。

### 登录后自动启动

核心 2.5.0 增加“设置 → 应用与数据 → 启动与窗口 → 开机启动并驻留托盘”（待发行，见[版本记录](../releases/v2.5.0.md)）。新安装与首次升级到本功能时默认关闭；切换立即登记或取消当前用户的登录启动，无需重启应用，不收起当前窗口，不改变“关闭主窗口时”的偏好。Windows 的所有用户安装也只修改当前用户的登录项。

开启后，在当前用户下一次登录图形桌面时自动运行。Windows 保持主窗口隐藏并提供托盘；macOS 沿用菜单栏与 Dock 身份策略；Linux 最小化并保留系统窗口入口，不依赖托盘可见。不在登录前运行，不安装系统服务，也不在退出或崩溃后循环拉起。系统可以延迟或限制登录启动。

手动打开始终显示主窗口；已有同用户、同数据目录的实例时，第二次打开只请求显示已有窗口，不重复初始化核心、插件或清理数据。重复的登录启动请求保持原实例状态。关闭/重启准备与决定阶段可以回到已有窗口；进入清理与交接后提示稍后重开，不取消原清理，不删除数据锁。旧版本没有激活入口或实例无法核对时保持数据独占并说明原因。

已启用插件按原启动配置加载；本功能不恢复上次 SSH、终端、隧道或远端任务。普通和更新重启继续显示正常窗口，不携带一次性的登录隐藏来源。登录启动不触发“首次关闭到后台”的说明，也不改变该说明是否已确认。

开关读取系统当前登记，不保存第二份开启偏好；进入本页、返回应用或本应用修改结束后刷新，不在每秒状态刷新中反复查询系统。保存期间禁止重复操作，失败就地显示原因并读回实际状态，可重新读取；无法确认时不显示虚假成功。能够识别的系统禁用会提示 Windows 启动设置或 macOS 登录项中的操作位置，SoDeck 不在刷新、启动或更新时重新开启系统禁用项。Linux 识别本应用自启动文件的 Hidden 与 GNOME 禁用标记；第三方管理工具和桌面特定策略不承诺全部可查询。

Windows 使用当前用户 Run 登记，Linux 使用 XDG autostart，macOS 使用当前用户 LaunchAgent（RunAtLoad，无 KeepAlive）。开启需要稳定的正式程序位置：Windows 已安装目录、Linux DEB 的安装位置或固定目录中的 AppImage、已移出 DMG/临时目录的 macOS 应用。AppImage 登记外层文件，不引用临时挂载中的程序。移动程序后可能需要关闭再开启以更新位置，不扫描磁盘寻找副本。开发和隔离验收模式禁止修改真实用户登录项。

正常原地更新保留登记且不重新启用被系统禁用的项目。Windows 标准卸载仅清理当前用户中指向本次安装位置的登记，更新卸载保留它；不会进入其他用户配置。macOS 应用和 AppImage 被直接删除没有可靠卸载回调，删除前应先关闭开关。后台入口建立失败时恢复主窗口并保留可读取错误；必要认证、模态交互与退出失败继续走现有显示规则。实际验证与未覆盖的登录/设备专项见[版本记录](../releases/v2.5.0.md)。

### 其他交互

- 核心与插件使用统一应用菜单；关闭浏览器的刷新、打印、查找、缩放、历史导航和开发工具等默认入口，保留文本编辑、终端控制键和业务快捷键。
- 通用文本菜单保留选区、只读/密码框限制和异步剪贴板身份校验。终端和文件编辑器使用自己的业务菜单，见对应功能说明。
- 滚动条跟随三主题；标签栏可以隐藏轨道，正文保留可操作滚动区域。菜单根据实际尺寸避开窗口边缘，长列表内部滚动，搜索后重新定位。
- 系统网页和已登记下载目录交给系统默认应用打开。目标先校验，打开失败返回应用；Windows 坏关联避免系统修复对话框阻塞调用。Shell 返回成功不等于外部应用后续操作成功。
- 主窗口及独立窗口使用一致的标题栏规则，平台按钮和拖动区域见[工作台](workbench.md)。

## 操作反馈

设置分区仅在内部切换时局部过渡；主题即时应用，去除整页底色和文字的过渡。保存、冲突及部分应用失败保留清晰文案和状态样式，输入过程不重复闪动；焦点、选区和草稿按原机制保留。节奏和减少动态效果规则见[界面规范](../../DESIGN.md#动效)。
