# 终端

终端插件复用当前服务器会话，通过 PTY 打开登录 shell 或创建参数指定的交互命令。中央“＋”触发插件声明的新建行为；侧边工具栏不提供另一套终端定位入口。

命令阅读随终端 0.10.0 独立发行；来源、五平台与专项验证范围见[终端变更记录](../../plugins/terminal/CHANGELOG.md)。

## 创建、输入与结束

- 默认创建、中央“＋”、终端重开及 Docker 进入容器通过核心命令 terminal.open.v1，终端进程统一处理；没有终端 iframe 时也可接收。
- 每个新建请求创建独立 PTY；同一请求重试复用原回执。登录 shell 和指定命令是不同创建方式，标题与目录集成策略随创建参数保存。
- Windows 有选区时 Ctrl+C 复制，无选区时仍发送中断；Linux 使用 Ctrl+Shift+C/V，macOS 使用 Cmd+C/V。鼠标报告启用时普通右键交给远端程序，Shift+右键可打开本地菜单。
- Windows/Linux 使用 Ctrl+A 全选当前终端保留的输出，macOS 使用 Cmd+A；不需要 Shift，也可从终端菜单全选。快捷键在本地处理，不向远端发送原先的 Ctrl+A 行首控制字符。
- 剪贴板与输入通过既有桥接，保留括号粘贴和 IME 规则。失焦、移窗、冻结或连接代次改变后拒绝迟到粘贴，不把文本送到另一个终端。
- 同窗切换、隐藏和移窗沿用原 PTY；目标页面恢复显示后才能输入。字体或面板尺寸改变会重新适配有效尺寸，不重新执行命令。
- 登录 shell 退出后保留输出并提供“新建终端”；指定命令提供“重新打开终端”，保留原创建配置并新建 PTY。断线后先在工作台手动重连。
- 请求先返回等待回执；页面登记完成与 PTY/远端程序就绪分开。通信超时继续查询原意图，未确认结果不自动新建或重跑。关闭、断线或来源失效会撤销未登记的创建，取消关闭不恢复旧意图；具体契约见[命令 API](../plugin-api.md#命令默认行为与进程主动创建页面)。
- Docker 创建的终端独立持有资源；关闭 Docker 来源详情页不会关闭已经登记的终端。
- 关闭终端释放对应资源；关闭应用后不保留可检索的终端档案。关闭共同规则见[生命周期](lifecycle.md)。

## 目录识别与文件跟随

登录 shell 的目录集成可选自动、手动或关闭。自动模式支持 Linux/macOS 的 Bash/Zsh，按用户配置顺序接入目录上报，使用本次终端的临时脚本，不持久修改远端 shell 配置；无法自动集成时保留终端并说明限制。指定命令关闭目录脚本注入。命令阅读与目录上报分别开关，PowerShell 命令阅读不宣称自动目录跟随。

只有有效的主机/路径及当前会话身份才能更新目录。主机身份未知、路径无效、旧代次或命令终端不能提供可信目录时，不猜测路径。手动集成可使用符合协议的 OSC 7；不同 shell/远端系统需各自验证。

终端只发布自身位置，共享状态经核心送达。[文件插件](files.md)决定是否跟随，以及手动浏览、文件系统身份和断线时怎样处理；两插件没有直接调用关系。

## 历史、搜索与彩色预览

保留 100,000 行滚动历史，当前屏幕另计。Windows/Linux 使用 Ctrl+F，macOS 使用 Cmd+F，无需 Shift，也可从终端菜单打开查找；快捷键在本地处理。支持普通子串、大小写开关、命中计数、循环前后定位、Unicode 与软换行；不提供正则表达式或远端 shell history 查询。

搜索高亮与正文选区分开，退出或断线页仍可搜索。查询最多 1024 个 UTF-16 单元，仅检索当前终端实际保留的文字；行淘汰或终端重排后丢失的文字不能继续计为命中。历史更新和查询由独立 Worker 处理，按查询、文字、视口或尺寸变化刷新；静止时不重复请求高亮和预览。分批高亮完整后一次显示，无关输出保留仍有效的历史高亮；文字或几何变化会清除失效画面。

搜索输入与操作按钮独立成行，计数和范围说明不会挤动输入框。新查询显示“正在查找”，后台追赶时保留最近完成的计数；持续落后超过 500 ms 显示“结果更新中”，完成后再更新精确计数。索引故障显示重试入口。

隐藏或移窗冻结时停止绘制、导航和自动保存，历史仍继续接收；旧回包不能在恢复后覆盖当前状态。显示、取消移窗或检查点失败后，先恢复字体和尺寸，再重新查询与绘制。移窗保存输入合并窗口内的最新搜索草稿，仅保存仍匹配该查询的当前命中；搜索 IME 组合未结束时拒绝冻结。本次搜索整改随终端 0.8.5 独立发行，验证范围见[终端变更记录](../../plugins/terminal/CHANGELOG.md)。

常驻彩色预览支持点击、拖动和键盘浏览；正常宽度为 96 px，窄页缩为 40 px。阅读框使用透明底、细轮廓和窄位置标记，搜索控件保持居中；独立发行记录见[终端变更记录](../../plugins/terminal/CHANGELOG.md)。

预览可交互时作为主要垂直滚动入口，隐藏正文边缘重复的滚动条；保留 xterm 原滚动容器和列宽，不改变滚轮、触控板、选区或远端按键。预览暂停、没有有效尺寸或强制颜色模式时恢复原生滚动条，恢复后自动切回。窄页仍保留 40 px 预览。缩略图着色／搜索索引失败不影响按终端实际行数定位，当前位置滑块仍可点击、拖动和用方向键、PageUp/PageDown、Home/End 导航；这些键只在滑块聚焦时本地处理，不抢占 shell 输入。

## 命令阅读与标记

阅读工具行左侧显示已确认的目录，右侧集中显示位置计数、“上一处／下一处”和添加标记图标；目录未知时显示“当前终端”，执行中保留最近确认的目录并在提示中说明。导航只移动当前保留历史的位置，不发送输入、修改草稿或重新执行命令。正在长输出中时，“上一处”先回到本条命令起点，再次操作才到更前一处；两端不循环。同一行的多类标记合为一个导航位置。

| 标记 | 含义与操作 |
| --- | --- |
| 命令标记 | shell 确认开始执行后，在独立左侧留白显示线框状态图标和淡分隔线；右侧有足够空白时显示执行结果，不覆盖正文，未确认不推断成功或失败 |
| 阅读标记 | 点击“添加标记”标记当前可见正文首行，也可用右键菜单标记该行；再次添加同位置书签可移除，不删除输出 |
| 输入位置 | 在终端右键菜单中主动开启“回车辅助标记”后，记录真实回车对应位置；仅当前终端生效，默认关闭，只有中性刻度，不代表执行命令 |

命令标题只从 shell 边界内已显示的文字获取，不保存按键文本、不补显密码或无回显输入。多行输入和软换行按一次提交处理；过长、无法确认或没有显示的输入不提供标题。执行中的长命令可吸顶；已确认的命令滚出视口后，在顶部保留单行标题并可“回到起点”。悬停或主动定位时用细竖线提示显示区间，后台异步输出可能混入，该区间不代表进程级来源证明。搜索打开时吸顶避让；文字选区、复制和 ANSI 颜色不含阅读图标或分隔线。

自动增强按实际能力提供。只有起点就保留导航，缺少标题不显示吸顶，缺少结束结果保持未知。Bash 4+/Zsh 使用现有启动集成；远端默认 shell 为 Windows PowerShell 5.1 或 PowerShell 7 时，在当前交互进程内包装 PSReadLine 和 prompt，不改永久 profile 或 Enter 绑定。CMD 保留原 shell，不因系统安装了 PowerShell 而替换。指定命令、其他 shell、hook 冲突或未集成环境仍可手动标记。

回车辅助只标记位置，不记录输入文字。多行续输、Python REPL 和密码提示也可能留下输入位置；粘贴文本的换行、IME 候选确认、失败发送不创建标记。已知备用屏幕接管时暂停自动标记、覆盖层、手动添加和历史导航；返回普通屏幕后继续。不能保证识别所有普通屏幕交互程序。输入刻度可以从该行右键菜单移除，或用同一菜单的“清除输入标记”移除全部输入刻度；关闭辅助只停止后续新增。

右侧预览左缘刻度用于跳到附近标记，密集时聚合；预览正文仍按原有滚动/搜索规则工作。标记和执行状态只属于本 PTY；断线、退出页仍可浏览和手动标记，新建或重开不继承。嵌套 SSH/su/tmux 不承诺内层自动识别，外层标题只表示外层执行。识别中断后保留有效起点，不用普通输出猜测边界；后续从新可靠位置继续。

终端设置可选择“自动／仅手动标记／关闭”、命令吸顶和命令行淡底；默认自动、吸顶开启、淡底关闭。阅读工具行不再提供遮挡正文的选项弹层。紧凑工具行在同一行显示已确认目录、当前阅读命令、识别／回落状态、位置计数和导航操作，不再另占底部状态栏；详细原因由原生文字提示说明，未知信息不补造。切换模式不改变目录上报或已有搜索，关闭期间不补猜历史，同时收起工具行和左侧标记留白。回车辅助只按当前终端启用并随移窗保存，新终端默认关闭。工具行支持键盘焦点，窄页以有名称的图标收起文字，不抢占 shell 常用组合键。

阅读状态与显示快照在同一水位保存，沿用现有核心历史恢复；不新增核心 API 或永久档案。仅改变书签、没有新输出时，移窗也会提交检查点。淘汰或删除的起点退出导航，不漂到新文字；清空历史清除对应标记。旧检查点没有阅读记录时从接续后开始记录，不扫描 `$`/`>` 补造命令。恢复/容量失败保留实时终端并说明阅读状态未完整保存，不通过重跑补偿。

## 恢复与维护约束

核心保存原始输出临时日志、分片显示检查点和小 UI 状态；插件解释文字、颜色和搜索结果。正常输出 ACK 不等待全量快照，移窗恢复查询、有效命中、选择、阅读位置与底部跟随。

- 每流日志和已提交检查点各限 128 MiB，全部流的日志、在途及已提交快照合用 1 GiB 配额，不能让所有终端同时用满各自上限。
- 快照按固定输出水位分片生成，后续输出继续运行；未完成上传不替换旧检查点。旧日志只有被检查点覆盖且无读者需要后才能清理。
- 写盘或额度失败明确报告恢复状态，实时输出可以继续；真正的恢复缺口不得用重新运行命令弥补。
- UI 元数据最多 8 KiB，与输出水位分离。关闭释放临时资源，启动只清理可确定属于已退出进程的恢复目录。
- 当前固定 xterm 6.0.0 与 SerializeAddon 0.14.0，对环形行观察和冻结快照使用受控内部适配；升级必须运行历史回归。
- 阅读状态作为版本化、分片隐藏控制帧附在插件显示检查点中，最多 16 MiB JSON，且与正文快照合用原 128 MiB/1 GiB 配额；核心不解释。只在恢复 snapshot 阶段接受，实时 PTY 输出不能加载阅读状态。标题最多 4096 UTF-16 单元，过长时保留无标题标记。

终端与核心统一要求 API 2.0；完整历史恢复使用同一当前契约，创建参数和恢复接口见[插件 API](../plugin-api.md)。字体配置见[设置](settings.md)。

## 操作反馈

搜索条进入与退出有短暂过渡；搜索计数、结果更新与终端结束提示即时呈现，不因文字变化反复淡化。正文、光标和历史高亮保持原位置，隐藏或移交后迟到更新不启动动效。节奏和减少动态效果规则见[界面规范](../../DESIGN.md#动效)。
