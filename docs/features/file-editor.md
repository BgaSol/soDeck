# 通用远端文件编辑与 SDK

文件编辑 SDK 将核心文件服务、标准编辑页和插件进程生命周期接在一起。组件提供当前服务器 Context 和远端文件路径，即可打开自己的编辑页；不需要安装或调用文件插件。当前正式使用方是文件插件，独立测试消费方验证自定义视图类型、来源资源和关闭保存，没有为其他业务插件新增编辑入口。

## 打开与编辑

打开入口来自已挂载的组件页面。SDK 使用来源页面自己的文件资源解析规范路径，再通过核心打开同组件的 `perResource` 编辑视图；来源没有文件资源时，由所属插件进程懒创建。文件资源仍受核心的总额度约束，不能借用其他页面或插件的 fileId。

同组件、同工作区、同规范路径复用已有页面。不同组件各自持有草稿，不提供跨组件编辑锁或协同编辑；远端发生已检测到的变化时保存拒绝覆盖。版本检查与最终替换不是原子版本比较，仍可能覆盖检查之后的外部写入。

标准页面提供保存、搜索、语言选择、草稿导出和当前操作取消。文件插件通过下载接点继续提供“下载远端”和自己的任务列表。SDK 不解释配置、不校验服务配置、不执行重载或部署。

## 文本、保存与失败

编辑上限为 1 MiB（1,048,576 字节），同时约束远端打开及修改后的原始编码字节。仅编辑 UTF-8（可含 BOM）、一致的 LF/CRLF 文本；二进制、非法编码或混合换行可以下载。超限输入拒绝或撤销本次事务，不能截断正文。

Monaco 提供行号、撤销、选区、当前正文搜索、词法颜色和右侧彩色缩略图。搜索包含未保存内容，支持大小写、循环前后查找、Ctrl/Cmd+F、Enter/Shift+Enter、F3 和 Esc；最多显示 1000 个普通命中，更多显示“1,000+ 处”，导航仍搜索全文。查询最多 1024 个 UTF-16 单元。

编辑器文本菜单按视口避让，窄编辑区和缩窗后仍可访问全部操作，极矮视口只滚动菜单内部。方向键、Home/End 可导航可用项，Esc/Tab 关闭后回到编辑器；正文滚动、隐藏或只读交接时关闭菜单，迟到的剪贴板结果不修改已变化的正文或主选区。

根据文件名、后缀和有限 shebang 判断语言，可以手动更正；支持运维常见 YAML、JSON/JSONC、Shell、PowerShell、Nginx、INI/systemd、TOML、环境变量及 Dockerfile。这里只提供词法着色，不提供语言服务器、配置诊断、补全或格式化。长于 10,000 字符的单行可部分按纯文本呈现，正文与搜索不截断。缩略图可点击，窄编辑区退为位置标记；显示设置不产生正文修改。

同一编辑器实例修改字体、行高、Tab 宽度、折行或缩略图设置时，通过 Monaco 视图快照保留多选区方向和逻辑阅读位置，并保留搜索、语言覆盖、焦点和撤销记录。隐藏期间的显示设置变化等待页面具有有效尺寸后恢复视图；跨页面交接仍使用原有版本 1 显示状态，不持久化多选区或撤销栈。

保存核对远端内容摘要、属性和链接目标，在同目录写临时文件并原子替换。已检测到的外部修改拒绝覆盖。属性/摘要检查与最终提交是分开的 SFTP 请求，不能阻止检查之后其他写入者的更新被覆盖；这是普通单写入者文件编辑，不提供原子版本比较或协同编辑。传输覆盖同样受此限制。

正文同步、元数据和光标通知分别处理。分片有上传身份、摘要和修订，失败可重试同一快照，末次提交丢回执可查询原结果。保存接受时固定修订 R，期间输入的 R+1 保持未保存。提交应答丢失标为未知，禁止直接重放保存；提交成功但后续属性读取失败仍显示已提交，同时禁止继续原位保存，须核对并重新打开。准备失败可能留下提示路径中的临时文件，不自动删除正式目标。

“下载远端”取得服务器当前版本。“导出草稿”在弹出本地对话框前固定本次正文，弹框期间的后续编辑不改变导出字节；同一请求不会重复弹框。导出不依赖远端连接、元数据或光标通知，断线后仍可使用。取消后迟到的路径选择不写入，原生对话框尚未结束时仍算在途任务。显示状态最多 8 KiB，含完整选区、逻辑滚动、搜索和语言覆盖；候选页面只读，交接先冻结输入再等待同步。撤销栈不跨 UI 重挂载持久化，进程崩溃不承诺草稿恢复，关闭释放编辑模型和 Worker。当前没有正则、替换、跨文件搜索或自动保存。

## 组件接入

进程复用 [EditorHost](../../crates/plugin-client/src/file_editor.rs)。初始化检查 SDK 使用的能力；为自己的中央编辑视图调用 `handle`，其他视图继续自身处理。`contains` 识别已登记编辑页，`entries` 供本组件业务冲突检查，`projection/refresh` 读取提交事实。打开和保存前传入短业务检查，文件插件用它保留路径批次阻断；SDK 不在状态锁内执行核心 RPC。

来源页面的 `fileEditor.resource/open` 事件交给 `source_event`，响应包在自身 `{data:...}` 中。SDK 自建的来源资源在来源最终 dispose 时调用 `dispose_source`；来源已有资源时向 UI 入口传 fileId，并由原组件负责释放。业务任务、下载和相应 busy/取消继续由使用组件处理，不交给 SDK 编辑事件分派。

UI 通过 [openRemoteFile](../../packages/file-editor/src/open.js) 打开文件，通过 [mountRemoteFileEditor](../../packages/file-editor/src/page.js) 挂载编辑页。挂载参数为 root、核心 mount 快照和可选 configureDownloads；SDK 接管该编辑页的 prepared、激活、主题、设置、flush 和释放事件，组件不能重复发送回执。同一 iframe 只挂载一个标准编辑页；加载包内 `editor.css` 后挂载。

组件继续声明自己的 editor 容器和 perResource 视图，并在开发配置 release.json 声明 `build.fileEditor:true`。设置页使用 `{id:"editor",viewTypes:["editor"],fileEditor:true}` 引用共享模板；打包展开为普通设置页，沿用组件自己的设置身份。实际接口及兼容规则见[插件 API](../plugin-api.md#文件编辑-sdk)。

## 维护与限制

UI SDK 在 [packages/file-editor](../../packages/file-editor/)，依赖和锁文件独立。构建 helper 将 JS、CSS、语言资源、Worker 和许可证复制进使用插件的 ui/file-editor，复用原有菜单、剪贴板及字体打包；核心安装包不携带业务插件，运行时不加载其他插件目录或 CDN。

SDK 源码随使用插件编译和发行，更新 SDK 不会自动修改已发行插件。核心 API 主版本和 `files.editor.v1` 保持不变；文件插件原 editor 设置 ID、字段与默认值保持不变。当前范围是会话文件系统的远端普通文本，不提供本地、容器文件、任意内存对象或后台自动打开接口。

主要回归为 [正文读取](../../scripts/file-document-read.test.mjs)、[草稿同步](../../scripts/file-draft-sync.test.mjs)、[打开与设置](../../scripts/file-editor-sdk.test.mjs)、[独立进程消费方](../../scripts/file-editor-process.test.mjs)、[编辑器 UI](../../scripts/test-file-editor-ui.mjs)和[完整文件 UI](../../scripts/test-files-ui.mjs)。独立消费方属于测试夹具，不发行，不等于第二个业务功能已经交付。
