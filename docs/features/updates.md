# 在线更新与下载网络

管理台 → 更新集中管理核心和已安装插件。官方插件首次安装入口见[插件管理](plugins.md)。核心和各插件独立发行，版本变化与包来源由各自版本记录维护。

下载网络草稿以实际值比较是否修改，切页后仍参加[关闭确认](lifecycle.md)。保存失败/修订冲突保留输入，成功后清理该版本草稿；单次诊断失败不影响其他设置页。核心状态、更新状态与网络计量分别刷新，辅助读取失败保留当前编辑页面。

## 检查、下载和应用

- 支持检查全部、选择可下载项、批量下载和逐项重试。更新说明按组件展示，未安装插件不混入更新列表。
- 默认每日自动检查，可在偏好中关闭。启动先恢复缓存，再延迟启动后台检查；失败保留上次结果并显示原因，自动重试间隔至少 15 分钟。自动检查不自动下载或重启。
- 批量下载最多两项同时进行，其余排队；一项失败不取消其他项。下载、校验和准备分别显示，未知大小显示已下载字节。
- 下载进度刷新保留设置页的滚动容器和阅读位置，不打断滚轮滚动；展开的更新说明与待应用清单保持展开。
- 准备好的核心更新、插件版本切换和启停变更汇总为待重启清单。用户选择重启后走[关闭生命周期](lifecycle.md)，处理所有窗口的草稿和任务。
- Windows、macOS 和 Linux AppImage 使用 Tauri 官方 updater；Linux DEB 通过系统安装器升级，插件仍可在线更新。
- 下载过程中不重复入队、进行全量检查或开始重启。任务失败释放占用，未知远端/安装结果不能伪装为完成。

核心包存入应用数据的 `updates/core/package.bin`，元信息同目录保存。下载校验后原子替换缓存，启动可以离线恢复并重新验签；安装前再次验签。损坏、平台不符或失效缓存不能标为已准备好。安装失败保留可重试状态；是否已经切换版本由后续实际启动确认。

插件下载前重新核对清单与候选身份，验证 SHA-256、解包路径、入口和平台。已加载程序继续运行到重启；完全关闭且未加载的插件更新后仍关闭。切换失败的回退见[插件管理](plugins.md)。

### 最新版本发现

核心与插件分别按自己的发行仓库和标签前缀检查版本。先读取轻量标签引用，按正式 SemVer 从高到低排列，只检查高于本机的标签；不请求全仓库 Release 列表，也不提供版本回退入口。更新说明使用所选清单已有的内容，格式与生成方式保持原样。

按顺序确认标签对应的 Release。原始 GitHub API 返回 404 时，表示该标签没有公开 Release，继续检查下一标签；草稿和预发行同样跳过。找到第一个公开正式 Release 后只读取它的更新清单，成功即停止。没有更高正式发行时显示当前无更新。

镜像 404 不能确认 Release 缺席，仍需按现有线路回退；原站不可达而只有镜像 404 时检查失败。原始线路跨来源重定向后的 404 也不能作为缺席。目录、清单和安装包的 404 均为读取失败。

首个正式 Release 缺清单、清单损坏、组件或版本不符、插件 API 或本机平台不兼容时立即显示原因，不再选择其他历史清单。网络故障同样不会触发版本顺延；一项失败不妨碍其他组件检查。首次官方插件安装复用相同发现方法，插件目录只负责提供官方插件及其更新来源。

标签、单个 Release 和更新清单继续使用原有 2 MiB 响应保护；本次通过缩小读取范围避免累计历史发行详情阻断检查。

## 下载与网络

软件更新页的“下载与网络”覆盖官方插件目录、GitHub Release、更新清单、首次插件安装和核心/插件包下载。

- 原始地址优先，失败后尝试启用的自定义及适用内置地址。API 与文件健康分开，最近成功线路优先；冷却影响顺序，不永久排除有机会成功的备用线路。
- 内置七个前缀，可分别停用；另可保存最多十个 HTTPS 自定义前缀，支持名称、排序、编辑、删除和单地址诊断。
- 线路改变不改变候选版本、目标平台、原始来源和校验要求。下载中断或坏包后清理本次临时文件，换线路从头下载，不拼接不同节点的包。
- 设置保存使用修订冲突检查，冲突保留输入。运行中的任务使用自己的设置快照，旧诊断/任务结果不能污染新设置。
- 诊断只测试选中的线路，分别验证 API、目录/清单和有限包首段；文件专用节点不接收 API 请求。诊断成功不保证所有资源或今后请求可用。
- 生产地址要求不含凭据的 HTTPS。测试 token 只发给原始 GitHub API，不通过代理或跨主机重定向转发。

## 维护约束与入口

核心使用官方更新签名；插件沿用清单、SHA-256 和可信扩展模型，不增加插件签名信任链或审批状态机。准备好的包不因网络设置变化重新变成未下载。公开同版本附件不覆盖，发行流程见[分发文档](../distribution.md)。

- 服务：[updates.rs](../../src-tauri/src/updates.rs)、[update_network.rs](../../src-tauri/src/update_network.rs)、[desktop_updates.rs](../../src-tauri/src/desktop_updates.rs)、[official_plugins.rs](../../src-tauri/src/official_plugins.rs)。
- 界面：[updates.ts](../../src/updates.ts)、[update-network.ts](../../src/update-network.ts)、[release-notes.ts](../../src/release-notes.ts)。
- 回归：[updates.rs](../../src-tauri/tests/updates.rs)、[update_network.rs](../../src-tauri/tests/update_network.rs)、[正式升级夹具](../../scripts/test-release-upgrade.mjs)。涵盖标签排序、缺席顺延、正式发行错误、缓存篡改、签名、错误线路、取消、候选固定、旧配置隔离和插件回退。
- 真实线路可用性随网络变化；原生安装器、历史版本升级和线上下载需在对应任务中明确验收，旧版升级样本不代表任意版本组合。
