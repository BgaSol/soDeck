# 服务器与连接

主窗口启动默认进入服务器连接页，一级“＋”（连接服务器）或管理台的服务器连接导航进入同一页面；顶部 SoDeck 的返回规则见[管理台导航](workbench.md#管理台导航)。维护 SSH 服务器和 SOCKS5 跳板资料，通过双击目标节点或详情连接按钮建立连接。用户仍保留该连接导航意图时，成功后进入该服务器工作区；等待期间切页或改选服务器，迟到成功只登记会话，不抢走当前页面。SOCKS5 资料用于连接路径，不直接创建服务器工作区。

目录搜索、筛选和表单在同一实体更新时保留原控件，搜索组合输入不会被刷新打断；目录刷新失败保留上次有效列表并提示错误。目录行使用原生双击连接，窄窗口仍为第二次点击保留选择时间。

## 资料与认证

- 支持新增、编辑、复制、删除、搜索和多标签。连接路径是有序的 SSH/SOCKS5 资料引用，最后追加目标服务器；引用节点不递归展开自己的路径。
- 核心 1.12.0 起，编辑 SSH 节点时保留兼容认证配置下的原凭据；更换主机、端口或账号不会隐式清除密码。认证方式或私钥路径变化时旧秘密不移用于不兼容配置，仍可显式替换或清除。SOCKS5 原规则不变。
- SSH 支持密码及普通/加密的 OpenSSH Ed25519、RSA 私钥。核心读取本机私钥，插件复用核心会话，不保存另一份认证资料。
- 新建资料或切换认证方式默认记住凭据，编辑已有资料保留实际选项。缺少凭据、密码失效或私钥口令错误时可补填；取消记住仅用于当前连接。
- 整条路径成功、原资料与连接尝试仍有效时，才提交勾选记住的值。失败、取消、拒绝主机指纹或后续节点失败不覆盖旧凭据；并发编辑后拒绝过期写入。保存失败明确报告，不创建工作区。
- 当前记住的密码和私钥口令以明文保存在应用数据目录，私钥保存路径。尚未接入系统凭据库。秘密不进入公开连接投影、日志或插件初始化参数。

每个 SSH 节点在认证前核验主机密钥。首次连接和密钥变化分别要求确认，变化显示旧/新 SHA-256 指纹。应用自己的 `ssh-hosts.json` 按连接路径前缀、协议、端点和有关账号区分身份，不修改系统 known_hosts；不同访问路径需要分别确认。

同一服务器资料表单刷新时，支持文本选区的控件保留焦点、选区和选择方向，包括密码框。输入值仍来自当前表单草稿；保存、放弃或重新读取按各自操作处理，不把旧对象输入带入新资料。系统 IME 组合输入的设备验证范围另见发行记录。

服务器及 SOCKS5 资料的 `createdAt`、`updatedAt` 保存为精确到秒的 UTC RFC 3339 字符串（`YYYY-MM-DDTHH:mm:ssZ`）。编辑保留创建时间，复制生成新的创建与修改时间；详情中的“最后修改”按本机时区显示。系统时间超出可格式化范围时，保存失败并保留原资料。

## 连接树与标签

服务器与 SOCKS5 共用一棵连接树，保留本机根、显式路线的前缀合并、不同路径位置及完整祖先高亮。目录仅使用约 48px 的紧凑两行节点，显示名称、协议、状态、账号地址和自身标签。未使用的代理放在本机下；被引用的代理出现在实际路线中，状态说明用途与引用数量。SOCKS5 和仅为中转的 SSH 位置不直接创建工作区；双击连接只对目标位置提供。

核心 2.2.0 起，节点身份由完整目录确定，搜索和标签只改变可见路线。同一位置既是目标又是其他路线的中转时，筛选后仍可作为目标连接；同一资料出现在不同路径位置时，位置保持独立。

展开箭头位于节点卡片内部、类型图标之前，收起时向右、展开时向下；叶节点保留同宽占位，名称与图标保持对齐。箭头默认无底色，悬停和键盘聚焦时提供反馈。连线从本机图标下沿或父卡片底部引出，在卡片外连接到子卡片左边缘，不经过展开按钮，转角轻微圆滑。当前完整路线高亮绘制在普通连线上方，折叠、窗口缩放和主题变化后按实际节点位置更新。

工具栏默认“新增服务器”直接打开 SSH 表单，旁边的箭头可选择新增 SOCKS5 代理；刷新始终显示在外。SSH 服务器、路径节点和 SOCKS5 代理的详情直接显示“编辑”“复制”“删除”，不再经由更多菜单。连接保持主操作，删除为靠右的低强调危险操作；空间不足时按钮自然换行，目录不可用时禁用资料操作。删除保留确认与引用检查。

### 节点右键操作与经节点新增

右键节点直接选中该位置并打开菜单，宽窗同步显示详情和路线，窄窗保留目录。右键卡片内的展开箭头只打开菜单，不改变展开状态；菜单不包含展开、折叠。原有单击查看、双击目标连接和树方向键行为保留。

| 节点 | 操作 |
| --- | --- |
| SSH 目标 | 连接服务器／重新连接／前往工作台；连接中可取消，等待问题时可继续确认；经此节点新增服务器、编辑资料、复制资料、删除资料 |
| 仅为中转的 SSH | 查看服务器目标、经此节点新增服务器、编辑资料、复制资料、删除资料 |
| SOCKS5 | 经此节点新增服务器、编辑资料、复制资料、删除资料 |
| 本机 | 新增 SSH 服务器、新增 SOCKS5 代理、刷新目录 |

“经此节点新增服务器”打开现有新增表单，中转预填为从本机到所点位置的全部引用，包含该节点。例如 `本机 → P → A → B` 上右键 A，新增 T 的默认路径为 `本机 → P → A → T`。同一 A 出现在 P1/P2 下时分别继承所点分支；不递归展开 A 自己保存的路径，不复制中转资料。新目标地址、账号、密码和私钥配置使用普通新增默认值，标签沿用当前标签筛选。用户可调整中转或主动改为直连。

打开表单不落盘、不探测网络，保存后选中新目标，不自动连接。保存定位使用目标实际路径，只展开所需祖先；筛选隐藏新目标时保留筛选，并可通过“显示此资料”定位。取消不留下新目标；表单中另行显式保存的代理仍按原有规则保留。保存冲突保留输入，可刷新目录并保留草稿后再次保存；失效引用与标签需要重选或移除，不自动删中转或改为直连。

编辑、复制、删除针对共享资料本身。“复制资料”沿用下文复制行为，不是复制到剪贴板；从中转位置复制 SSH 仍沿用其自身保存配置，不用当前分支覆盖。删除会移除该资料的全部显示位置；被引用、有工作区或仍在建连/取消收尾时拒绝删除，须先处理引用、关闭工作区或取消并等待结束。删除不代用户中止连接，不影响远端服务器或本机私钥文件。核心在提交边界再次校验占用与目录修订，桌面和插件写入遵循同一规则。

菜单支持菜单键、Shift+F10、方向键、Home/End、Enter/Space、Esc 和 Tab；Esc 返回来源节点，点击外部控件不抢回焦点。菜单避让窗口边缘；滚动目录、窗口失焦、切页或打开表单时关闭。连接状态更新可改变菜单项，原节点位置、角色或所需路径变化时关闭并提示重新打开，不能改用另一处相同资料执行。目录不可用时禁用写入和新连接，刷新与适用的已有会话操作仍可使用。树节点菜单和表单文本编辑菜单各自保留。

核心 2.2.1 起，上下文菜单以菜单本身为交互范围，左键点击来源卡片也会关闭，随后正常查看节点或操作展开箭头；工具栏新增类型按钮仍可再次点击关闭。点击菜单标题或所有操作均禁用时，菜单容器承接焦点，Esc 始终可取消，Tab/Shift+Tab 退出后按来源继续页面导航。状态刷新保留有效操作焦点，没有可用项时回到容器；外部弹窗、隐藏、失效或销毁后不抢回焦点。菜单关闭同时清理当前来源，命令和表单单独保存返回位置，不依赖关闭后残留的菜单状态。

目录菜单按实际触发位置轻微浮出，边缘避让后方向随之调整；入场 160ms，普通取消与外部点击在 100ms 内收尾，Tab 和执行命令仅淡出。高菜单取消缩放，退出保留当前缩放与内部滚动内容。连续右键立即让位于最新菜单，不叠加旧退出画面。表单或外部模态接管、来源失效、滚动、隐藏和销毁直接撤下；命令、取消与焦点不等待动画。减少动态效果时直接出现与关闭。核心 2.2.3 修复正式构建将 CSS 时间压缩为秒后动画近乎瞬间结束的问题，统一换算为毫秒再播放；实际发行与验证范围见[版本记录](../releases/v2.2.3.md)。

### 复制资料与筛选

服务器详情的“复制”打开预填的新增表单，地址自动全选，名称默认加“副本”；端口、账号、标签、认证方式、私钥路径与有序中转引用沿用原值。保存前不创建资料，取消不留下副本并将焦点还给“复制”；保存后选中新服务器，由用户点击连接。修改后关闭沿用现有放弃确认。SOCKS5 的“复制”仍直接保存副本，不复制代理密码。

复制服务器默认沿用原登录密码或私钥口令，不向表单回填秘密；留空沿用，输入新值替换，“不沿用原凭据”只影响新服务器。已有持久凭据默认记住，仅本次运行的凭据默认仍为临时值，可以修改记住选项。修改 IP、端口或账号不停止复制凭据；切换认证方式或私钥路径后停止沿用，配置匹配时可以主动恢复。保存时核心复制当时可用的值，新旧服务器的目标凭据彼此独立；路径仍引用原有跳板资料，不复制跳板或私钥文件。普通编辑更换端点时也保留兼容凭据；内部字段与校验见[连接与资源归属](../architecture.md#连接与资源归属)。

复制保存失败保留输入，错误区可“刷新目录并保留输入”，刷新不自动提交，记住选项保持当前选择。继续沿用时使用原服务器当前凭据；原服务器删除、认证配置变化或凭据不可用会明确报错，可填写新值或选择不沿用后保存。失效标签、中转仍保留可见提示，需移除或重选，不静默改为直连。新标签与服务器一次提交；表单内单独保存的代理仍按原有规则保留。写入失败不会留下副本或待创建标签。

搜索匹配目标及其显式中转节点的名称、地址、账号和 SSH 标签。树上方直接显示正在被服务器使用的标签，点击选中，再点取消；多选要求目标服务器同时包含全部标签，SOCKS5 不使用标签。“全部”只清标签，保留搜索。筛选临时展开完整路线，清除后恢复原折叠；无匹配时可以清除搜索和筛选。

筛选隐藏所选资料时保留详情，并提供“显示此资料”；刷新保留查询、标签、选择路径、折叠与滚动位置，失败保留最后有效树并禁用新增、编辑与建连。原树位置消失但资料仍在时定位同一资料，资料删除才清选择。窄窗口在目录与详情间切换，返回目录保留所选位置；方向键、Home/End 移动树焦点，左右展开/折叠或定位父子节点，Enter 查看。

标签在服务器表单内维护，不提供独立管理页。输入中文或英文逗号分隔的名称，或按 Enter 添加；保存前也会合并剩余输入，按名称复用已有标签并去重。已有标签逐项按 ID 保留，历史名称中的逗号不会被重新拆分，点击可从当前服务器解除。新标签与服务器一次保存，校验、版本冲突或写入失败时均不提交，取消不会留下新标签；嵌套新建的代理仍独立保存，返回后保留服务器标签与其他草稿。标签变化不改变连接身份，无需重连。

目录保存为 `schemaVersion: 2`。读取旧 v1 分组时在内存中转换为同 ID 标签，首次写入前保存 `servers.v1.json.bak`，再通过既有原子写入保存 v2；读取不改原文件，迁移或保存失败保留原件和草稿。旧核心无法读取 v2，降级前需退出并恢复 v1 备份，迁移后新增的资料及标签不会包含在旧备份中。

## 建连、断开与重连

| 场景 | 当前行为 |
| --- | --- |
| 连接中 | 显示当前节点与 TCP、SSH 握手、认证、隧道或 SOCKS5 阶段；同一资料复用正在进行的尝试，不同资料可并行 |
| 多层路径 | 只有第一站使用本机 TCP/DNS；后续地址交给上一站，最终目标域名不会强制改为开发机器解析 |
| 超时与取消 | 单个非交互阶段限时 30 秒，等待用户时间不计入；取消关闭受管传输，阻塞系统操作的迟到结果不能接纳为会话 |
| 失败 | 保留明确原因，不创建一个伪连接工作区；可以修改资料后重试 |
| 断开 | 保留工作区和适用的本地显示/草稿；依赖远程连接的操作显示不可用 |
| 手动重连 | 成功后更换 connectionId 并递增 generation；旧 Context 与旧页面 Surface 失效，不自动重放远端变更 |
| 地址、账号或路径变化 | 已有会话保留原身份，按新资料重连前确认变化 |
| 移窗 | 只交接显示归属，沿用同一 SSH 会话 |
| 关闭工作区或应用 | 通过[统一关闭规则](lifecycle.md)取消尝试并释放所属连接，迟到成功不能重建工作区 |

SSH 保活间隔 30 秒，连续 3 次未响应后断开。SOCKS5 上游支持无认证及用户名/密码，不降级认证方式。当前不读取系统 SSH config，不支持 SSH agent、交互式 MFA、主机证书或自动重连。

## 流量与资源

核心统计第一条实际 socket 的成功读写字节，包含 SSH/代理协议字节，排除 IP/TCP 头及重传；多跳不重复累加。插件业务载荷另按资源归属统计，不能与物理流量简单相加，也没有逐跳精确分摊。网络隧道显示口径见[网络隧道](network-proxy.md)。

插件只能经当前会话能力创建受管资源。关闭单个终端或命令任务不关闭共享 SSH；连接、视图和资源身份的共同规则见[架构](../architecture.md)及[插件 API](../plugin-api.md)。

## 外部打开请求（核心 1.9.0）

插件可通过核心读取非敏感保存资料，并按选择令牌打开或复用服务器；[Agent MCP](mcp.md)使用此能力。桌面与插件共用实际 Attempt、认证提示、路线和接纳规则，不重复保存凭据。外部打开只登记工作区，不切换用户焦点；缺少凭据或待确认主机指纹仍由用户在已有窗口处理。

同一原请求重试不重复派发网络，多请求与桌面可共享同一尝试。外部取消只撤销自身未完成请求；没有其他需求时才终止未接纳尝试。已接纳会话属于工作区，目标创建失败、MCP 取消或停止均不自动断开它。桌面取消与工作区关闭仍按实际连接生命周期收尾。

保存资料与在用会话地址、账号或路线不同，外部打开明确拒绝，需用户处理原会话；凭据编辑不使同一在用路线失效。完成回执固定在原 Context，断开、重连不改指向；后台 UI 创建是独立阶段，SSH 接纳不代表插件目标已经就绪。字段、额度与兼容规则由[插件 API](../plugin-api.md#服务器资料与连接)维护。

## 操作反馈

主动展开、收起分支时局部衔接可见行，选中路线通过颜色标识；刷新与筛选不重播展开。窄窗进入详情与返回目录采用对应方向。连接阶段和凭据提示即时更新，认证、焦点和取消不等待动效。节奏和减少动态效果规则见[界面规范](../../DESIGN.md#动效)。

详情及编辑预览中的路径节点统一使用圆形图标：本机、SSH 跳板和目标服务器使用服务器图标，SOCKS5 使用网络图标；节点类型、地址、解析位置和定位操作继续保留。编辑步骤也使用对应图标，键盘操作仍按站序标识。

目标服务器详情的连线读取真实连接快照：连接中的当前网络段向下流动，SSH 隧道和 SOCKS5 转发显示在来源节点通往下一站的线上，已完成的段保留淡色。准备资料、补充凭据、读取私钥及等待主机确认时不流动；失败显示当前节点并停止流动，取消和断开恢复静态。成功后的慢速流动表示会话已连接，不表示逐跳流量或速率。中转资料和未保存的编辑预览保持静态；旧快照节点数与当前路径不同时不显示旧进度。详情滚出可视区域、应用在后台或管理器销毁时暂停；系统减少动态效果时以静态线色及文字保留状态。
