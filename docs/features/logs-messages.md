# 日志与重要消息

日志用于排查问题，重要消息用于向用户报告需要知道的结果和中断。它们是两个独立接口，日志级别不决定是否弹通知。

日志和消息各自在管理台中使用完整页面。顶部消息入口打开同一个消息页；切回工作台保留会话和插件页面。

## 日志

核心和插件日志统一存储，附加核心接收时间、插件来源和本次进程实例。插件可写 debug/info/warn/error，并附结构化字段；stdout 保持 RPC 协议，stderr 作为诊断。

日志页可按来源、级别和时间筛选。插件启动、停止、异常退出及受管操作失败保留来源；插件不能通过提供字段冒充另一个实例。当前 JSONL 日志每份约 10 MiB 轮转，最多五份；界面查询为有界结果，不能当成永久审计仓库。

日志页采用紧凑列表与右侧详情，支持正文搜索。列表展示接收时间、级别、来源和正文摘要，选择记录后查看完整正文、产生方、插件/实例/记录 ID，以及可折叠的结构化字段。字段按实际 JSON 显示，正文和字段均为纯文本。已卸载来源按原 ID 回退；核心产生但关联插件的记录仍保留“核心产生”事实。“核心产生”筛选包含所有核心记录，插件筛选同时包含核心关联记录和插件自行报告。

查询为满足条件的最近最多 500 条，按接收时间升序显示，条数不是历史总数。写入阶段可能截断长正文或裁剪过大字段，界面不能恢复未保存内容。

普通页面切换保留日志筛选、暂停状态和暂停时已显示的记录。暂停只停止界面更新，后台继续记录；点击“继续显示”恢复查询。从插件详情的“查看日志”进入时改为该插件来源并恢复显示，状态页的“查看日志”改为全部来源并恢复显示，其余筛选保留。

暂停中修改或清除筛选只改变待应用条件，冻结列表与详情保留，继续显示后应用。查询中或失败时保留上次成功结果并说明状态，失败可重试。搜索在中文组合输入结束后防抖提交；无效时间或开始晚于结束不发出查询。复制记录输出当前已显示结果的 JSONL，详情可复制本条，暂停时复制冻结内容。

首次显示定位最近记录；阅读历史时保持记录锚点，可用“查看最新”恢复跟随。500 条窗口移出旧记录时不保留无限历史；明确选择的记录最多额外保留一条详情快照，并说明已移出当前结果。新筛选成功应用后清除旧选择。记录接收时间带日期，详情显示毫秒。

日志与消息接收时间保存为 Unix 毫秒时间戳，界面按本机时区显示。日志起止筛选使用本地日期与时间，输入精度为分钟，提交时转换为毫秒时间戳；清空输入移除对应边界，零时间戳也是有效边界。夏令时重复或不存在的本地时间按系统日期规则解释。

查询磁盘 JSONL 日志时，每行最多 16 KiB（含换行）。遇超长行或不可恢复的读取错误，保留此前读到的记录并停止读取当前文件，继续其余轮转文件，再合并内存回退；未超长但 JSON 格式错误的行仅跳过该行。读取中断的重试规则见[插件 API](../plugin-api.md#清单与初始化)。

## 重要消息

消息包含标题、正文和 info/success/warning/error 类型，由核心附加身份、时间和未读状态。消息中心展示历史及未读数，支持已读操作。最多保存 1000 条，超过后淘汰最旧条目。

消息列表展示来源、类型、标题、摘要、时间、重复次数及未读标识，右侧阅读完整正文，技术来源信息按需展开。全部/未读分别显示计数，没有选择时不自动标为已读。选中后立即阅读，已读状态在核心保存成功后更新；失败保留正文、未读和可重试提示。

未读列表移除已读行时保留所选详情，并把已移除行的键盘焦点交给附近未读行或筛选入口。快速选择不被旧回执切回先前消息；去重更新沿用 ID、更新正文与次数并再次成为未读，刷新不自动补发已读操作。标为已读作用于核心执行时的 ID 或全部消息，不提供消息版本比较。选中消息被保存限额淘汰时明确说明。

查看插件按真实 ID 定位；已移除插件保留历史身份并说明不可定位。顶栏与托盘只打开消息页，短暂消息提示可定位指定消息；过期目标不猜测替代消息。

托盘复用同一未读数，发布、去重更新、插件异常和标为已读成功后更新菜单文字；普通日志不触发这项投影。托盘入口打开消息中心，不自动批量已读。后台消息不主动显示主窗口，也不增加系统通知，平台操作见[桌面行为](settings.md#托盘与后台运行)。

发布参数独立选择 `notify`，并可通过去重键更新同一事件；普通错误可以留在消息中心而不打断用户。数据写入失败明确提示并保留原文件。需要排障的失败不得只留短暂提示而失去来源。

当前消息没有通用的“跳到对应业务任务”路由；不能解析标题或正文猜测导航目标。消息到任务的后续设计仍待确定。

## 维护约束与入口

不写入密码、私钥口令、完整远端正文或容器环境变量等秘密。生命周期日志由核心产生，业务含义由插件报告；消息接收成功不证明远端操作已经成功。

## 操作反馈

两页按实体保留选择、展开与阅读位置，计数和状态文字即时更新，不逐行播放动效。内容区较窄时改为列表与详情单栏切换，返回动作恢复有效列表入口；应用最小窗口尺寸保持原设置。页面读取只在实际可见时进行，每页最多一个读取在途，过期回包不覆盖新意图；应用收起后仍由核心持续记录及保存消息。共享存储告警与页面读取/写入错误分别显示，不把失败后的空集合当成正常无记录。节奏和减少动态效果规则见[界面规范](../../DESIGN.md#动效)。
