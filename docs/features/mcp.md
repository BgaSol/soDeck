# 机器人接口

独立插件“机器人接口”（`sodeck.mcp`）通过 MCP 协议让同一主机上的 Codex 等客户端使用 SoDeck 已连接的服务器，执行调查命令、查询输出和下载证据。命令内容与调查判断由客户端负责。核心安装包不含此插件；最低核心版本为 1.5.0，核心 1.5.1 起显示机器人图标，插件独立更新。插件 ID、数据目录、端口、接入密钥和客户端配置继续沿用，已有安装无需重新配置。发行与实际验证见 [CHANGELOG](../../plugins/mcp/CHANGELOG.md)。

## 接入

1. 更新核心，在插件管理中安装并启用“机器人接口”，重启 SoDeck。
2. 连接需要调查的服务器。每个工作区自动登记后台目标，不需要打开终端或保持页面可见。
3. 打开服务器侧栏的机器人图标“机器人接口”，点击“复制 Codex 配置”，写入本机 Codex 私有配置 `~/.codex/config.toml`，重新打开客户端会话。

配置形状如下；以页面实际复制的端口和密钥为准：

```toml
[mcp_servers.sodeck]
url = "http://127.0.0.1:19846/mcp"
http_headers = { Authorization = "Bearer <页面复制的密钥>" }
```

服务只绑定 `127.0.0.1`。默认端口 19846；组件设置允许 1024–65535，修改后重启 SoDeck并重新复制配置。端口被占用时页面显示错误，日志保留原因。

Token 首次启动时生成并保存在插件数据目录的 `access-token` 文件中。重启、停用再启用和升级都复用此文件，不自动过期或轮换；修改端口也不改变 Token。文件无效或无法读取会报错，不自动覆盖。删除文件并重启，或使用全新的数据目录，会生成新密钥，旧客户端配置需更新。Token 不进入日志、普通状态快照或命令元数据，仅显式查看/复制配置时提供；不要分享包含 Token 的截图、配置或目录。

客户端必须携带 Token；Host 必须为该端口的 `127.0.0.1`，如有 Origin，也必须为对应回环 HTTP 地址。此接入识别不改变可信插件边界或服务器操作系统权限。远程输出作为不可信证据处理，不作为客户端的指令来源。[Codex MCP 配置说明](https://developers.openai.com/codex/mcp)。

## 调查与补采

| 工具 | 行为 |
| --- | --- |
| `sodeck_targets_list` | 查询当前后台目标、完整 Context、真实端点/账号摘要、连接状态与 closing |
| `sodeck_exec_start` | 用 targetId、requestId、command 启动非交互命令或多行脚本，立即返回 taskId；timeoutSeconds 默认 300，范围 1–3600 |
| `sodeck_task_get` | 查询 taskId 的原生执行/传输事实、本地证据状态及有限输出页；cursor 为十进制字符串 |
| `sodeck_task_cancel` | 请求取消；继续查询实际结果，已完成任务不回滚 |
| `sodeck_file_download` | 用 targetId、requestId、remotePath 下载一个普通远程文件，返回 taskId；完成后提供本地文件路径 |

先列目标并明确选择服务器；三个目标可以分别采集。对每次启动保持固定 requestId 与参数，HTTP 断开后用同一请求重试会得到同一 taskId；相同身份修改参数会拒绝。接纳回包丢失时插件查询原生票据，结果未知期间阻止同一目标对应命令/文件域的后续接纳，不重复发送命令。取消未知请求仍需等待原票据确认或关闭工作区。

用 task_get 查询完成与下一游标。先采集故障窗口的日志和状态，根据结果分析后，再用新的 requestId 补采网络或性能信息。读取小配置使用远程命令；大日志或目录先在远端生成稳定的普通文件/压缩包，再下载。

命令使用远端非交互 shell，不使用本机 PowerShell；没有 PTY、stdin 或交互认证。通用命令可以修改、删除远端数据，工具如实声明这一行为。工具缺失、权限不足和非零退出码保留远端实际结果。取消、期限或断线仅尽力终止自己的远端通道，不证明脱离的子进程已经结束，也不撤销副作用。

## 证据与状态

每次运行在插件数据目录的 `evidence/<运行编号>/<任务编号>/` 保存 `metadata.json` 以及命令的 `output.jsonl` 或下载的 `download.bin`。元数据保存目标端点/账号、完整 Context、原参数、最近原生事实、观察时间和本地保存结果。命令输出保存核心完整信封，包含原字节 Base64、来源、序号与接收时间；预览只是每页有损 UTF-8，跨页字符和二进制分析应读取原字节。

`done` 表示插件结束本次采集，不能单独证明成功。检查 `native` 的退出/传输结果和 `evidence.complete`。非零退出码仍可有完整输出；取消、输出截断或保存失败不能标完整。`resourceReleased` 与 `cleanupError` 单独说明原生清理结果，清理失败不抹去已经保存的证据。释放后 task_get 返回最后观察的快照和同一落地文件，不重新查询不存在的原生任务。

下载复用核心流式复制、源版本检查、独占新文件提交和取消。已有目标不覆盖，变化中的源文件不能标完整。没有下载总时间/大小期限；单次 SFTP 请求有期限，持续有进度的慢传输可以继续。保存失败或磁盘不足保留失败，未提交的临时文件按原复制流程清理。

状态页显示当前服务器最近 50 个任务，可取消、刷新、打开证据目录和复制接入配置。隐藏只暂停页面刷新，后台任务继续；关闭工作区、停用插件或退出 SoDeck 按核心已有资源生命周期取消并清理。重连使旧目标不能接纳新任务，重新查询取得新目标。

## 限制与恢复

- 同一主机、同一用户可访问本地证据；不提供远程 AI 网关或公开 HTTP 服务。
- 命令最长 16 KiB，每条捕获最多 16 MiB 编码后信封；超额停止采集。输出页最多约 16 KiB 原始 JSONL，使用 nextCursor 继续；更大的资料用下载。
- 单次插件运行最多 64 个目标、24 个活动任务、4096 条请求记录；核心自身的执行和文件额度继续生效。活动任务满时拒绝新任务，不另排执行队列。
- 证据不会自动删除，需自行管理磁盘空间。插件/SoDeck 重启后不扫描历史、恢复任务或接受旧 taskId；落地文件保留，缺少最终结果的元数据表示当时结果未知。
- 首版没有聊天、模型运行、诊断规则、上传/覆盖工具或插件间直接调用；服务器认证仍由核心管理。
