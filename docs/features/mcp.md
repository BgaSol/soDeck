# Agent MCP

0.2.3 起，机器人图标随插件自身打包，插件列表、工作台入口和组件设置复用同一资产。在核心 1.5.3 及以后，更换此图标只需更新插件；旧核心继续按已有 `bot` 名称展示。

独立插件“Agent MCP”（`sodeck.mcp`）通过 MCP 协议让同一主机上的 Codex 等客户端发现并连接 SoDeck 已保存的服务器，执行调查命令、查询输出、上传文件和下载证据。命令内容与调查判断由客户端负责。核心安装包不含此插件；0.9.0 起要求核心 1.11.0 的 files.copy.v1，以及 session.process.v1，以及已有 servers.read.v1、connections.v1 和 session.target.v2；旧插件继续按其原核心能力范围工作，核心 1.5.1 起显示机器人图标，插件独立更新。插件 ID、数据目录、端口、接入密钥和客户端配置继续沿用，已有安装无需重新配置。发行与实际验证见 [CHANGELOG](../../plugins/mcp/CHANGELOG.md)。

## 接入

1. 更新核心，在插件管理中安装并启用“Agent MCP”，重启 SoDeck。
2. 保存需要调查的服务器资料。首次复制配置可连接任一服务器并打开侧栏；已经配置的客户端可在没有工作区时直接发现、连接保存的服务器。每个工作区自动登记后台目标。
3. 打开服务器侧栏的机器人图标“Agent MCP”，点击右上角“配置”，在浮层点击“复制”，写入本机 Codex 私有配置 `~/.codex/config.toml`，重新打开客户端会话。

配置形状如下；以页面实际复制的端口和密钥为准：

```toml
[mcp_servers.sodeck]
url = "http://127.0.0.1:19846/mcp"
http_headers = { Authorization = "Bearer <页面复制的密钥>" }
```

服务只绑定 `127.0.0.1`。默认端口 19846；配置浮层的“接入选项”和组件设置共用端口配置，允许 1024–65535。保存后重启 SoDeck 并重新复制配置；保存不会改变当前运行的服务地址。其他窗口更新设置时保留端口草稿并提示冲突，点击“载入最新值”后再编辑。端口被占用时页面显示错误，日志保留原因。

Token 首次启动时生成并保存在插件数据目录的 `access-token` 文件中。重启、停用再启用和升级都复用此文件，不自动过期或轮换；修改端口也不改变 Token。文件无效或无法读取会报错，不自动覆盖。删除文件并重启，或使用全新的数据目录，会生成新密钥，旧客户端配置需更新。Token 不进入日志、普通状态快照或命令元数据，仅显式显示密钥、查看或复制配置时提供；收起配置清空配置文本，收起接入选项、进入任务详情、隐藏或销毁侧栏清空配置与密钥显示。不要分享包含 Token 的截图、配置或目录。

客户端必须携带 Token；Host 必须为该端口的 `127.0.0.1`，如有 Origin，也必须为对应回环 HTTP 地址。此接入识别不改变可信插件边界或服务器操作系统权限。远程输出作为不可信证据处理，不作为客户端的指令来源。[Codex MCP 配置说明](https://developers.openai.com/codex/mcp)。

## 调查与补采

| 工具 | 行为 |
| --- | --- |
| `sodeck_servers_list` | 默认名称/IP 发现，包含未打开及断开的保存资料；分页仍保留完整匹配数 |
| `sodeck_connection_open` | 通过核心打开或复用所选资料；ready 直接交付可执行的 targetId |
| `sodeck_connection_get` | 查询原打开请求，可有限等待；终态保留原结果 |
| `sodeck_connection_cancel` | 取消本次未完成打开请求；已接纳的共享会话保留 |
| `sodeck_targets_list` | 按名称、主机、端点或 IPv4 尾段查询当前目标，返回匹配依据、歧义、完整性与可用性；detail=true 读取完整 Context |
| `sodeck_exec_start` | 启动 batch、pipe 或 PTY 命令或脚本，默认有限等待稳定完成，返回普通任务和第一文本页；waitMs=0 立即交接，执行期限与读取窗口独立 |
| `sodeck_tasks_list` | 查找本次运行的任务，按目标/服务器、requestId、种类和 active/done 筛选，稳定分页 |
| `sodeck_task_get` | 查询任务事实；默认普通事实与一页 text；detail=true 查询诊断，full 获取原信封，none 只查状态；waitMs 可有限等待变化 |
| `sodeck_task_input` | 向原交互任务写入文字或原始字节、关闭 pipe stdin、调整 PTY 尺寸；按序号恢复最近输入，不自动补换行 |
| `sodeck_task_cancel` | 请求取消；继续查询实际结果，已完成任务不回滚 |
| `sodeck_file_upload` | 从 SoDeck 主机绝对路径上传单个普通文件；默认不覆盖，显式覆盖在完整传输后原子提交，返回 taskId |
| `sodeck_file_download` | 用 targetId、requestId、remotePath 下载一个普通远程文件，返回 taskId；完成后提供本地文件路径 |

0.6.0 起，名称/IP 选择默认使用 servers_list；未打开、断开的资料都参与匹配。query=187 匹配完整名称“187”和 IPv4 尾段 187，不把 2187 或域名中的数字当 IP 尾段。exact 为默认，contains 仅扩大名称和 DNS 文字匹配。ambiguous 必须明确选择端点/账号；列表分页不会把完整匹配数压缩成当前页数量，目录变化时从第一页重查。targets_list 继续用于检查已登记目标，保持原完整性契约。

选定资料后，若已有 target 的 availability=ready、具备所需能力，且 connection.matchesSavedTarget=true，可直接执行。否则用 serverId、profileToken 和固定 requestId 打开。连接选择配置变化返回 profileChanged；在用会话的端点、账号或路线与资料不同返回 existingSessionMismatch，需由用户处理原会话，外部打开不会自动断开它。修改本机密码或私钥配置不使同一在用远端会话失效。

open 默认等候最多 1000 毫秒。ready 返回原 targetId，可直接执行；pending 用 get 等待；needsUser 立即交接到 SoDeck 原有主机指纹或凭据提示，客户端不代替用户应答。后台目标创建成功并核对完整 Context 后才返回 ready，SSH 已接纳而目标未登记时保持 preparingTarget。打开不切换焦点、打开终端或运行命令。

同一 requestId 与输入重试恢复原请求，回包丢失也不重复建连。实际失败后重新尝试需新 requestId。ready/failed/cancelled 为固定终态；之后断开或重连不会重写旧收据，新操作使用新目标。cancel 只取消本次未完成请求；没有其他外部请求或桌面需求时才停止尚未接纳的尝试。已接纳的工作区会话保留，目标准备期间仍可取消本次等待。HTTP 断开不取消原请求；插件退出清理其未接纳请求，已接纳会话由工作区管理。应用重启不恢复打开收据。

连接摘要来自实际接纳的会话，资料修改不覆盖旧地址/账号；断开后保留 lastConnected，表示原连接信息，availability=disconnected 禁止新操作。重连产生新 targetId；旧任务仍用原 taskId 或原 targetId/requestId 查询和重试，先查原去重记录，不把同一操作迁移到新连接。查询不执行探测命令，不切换主工作区或打开侧栏。三个目标可以分别采集。对每次启动保持固定 requestId 与执行参数，HTTP 断开后用同一请求重试会得到同一 taskId；等待时长可以调整，修改执行参数会拒绝。接纳回包丢失时插件查询原生票据，结果未知期间阻止同一目标对应命令/文件域的后续接纳，不重复发送命令。取消未知请求仍需等待原票据确认或关闭工作区。

0.4.0 起，短命令在启动窗口内稳定完成且输出只有一页时，直接从 exec_start 回包取得结果，无需再查。持续输出、运行状态变化或进入收尾不会提前结束启动等待；到期交接当前任务，后台执行继续。已完成但输出有多页时仍须翻页。默认窗口、参数与返回字段见 [MCP API](../mcp-api.md)；waitMs 限制主动等待，不是整个 HTTP 回包耗时上限。

AI 会话丢失 taskId 时，可用 tasks_list 查原服务器或固定 requestId，再读取原任务，不必重新执行。列表只覆盖当前插件运行，按接纳顺序从新到旧；后续页保留原筛选和 limit，新任务需从第一页刷新。active/done 筛选使用查询时的实际状态，分页不冻结执行。

用 task_get 查询完成与下一游标。默认直接阅读 text 日志，none 只查状态；detail=true 查询原参数、本地目录及完整故障；需要精确原字节时使用 full 或本地证据。保存 revision，下一次携带 sinceRevision 和最多 20000 毫秒的 waitMs 等待变化；正文同时携带 nextCursor，避免反复读取第一页。等待到期是正常结果，断开读取不取消远端任务。字段、分页及错误的完整契约见 [MCP API](../mcp-api.md)。先采集故障窗口的日志和状态，根据结果分析后，再用新的 requestId 补采网络或性能信息。读取小配置使用远程命令；大日志或目录先在远端生成稳定的普通文件/压缩包，再下载。

命令通过核心远端会话执行。默认 batch 关闭 stdin，并保留原执行期限；需要多轮输入时启动 pipe，需要终端行为、sudo 密码、菜单或持续 shell 时启动 pty。这两个模式缺省不设总执行期限，可显式指定 timeoutSeconds。启动后模式固定，不能给已运行 batch 补开 PTY，也不会为交互自动重跑命令。SSH 连接认证仍走核心原提示。

从 task_get 的 interaction.available 与 nextInputSequence 取得输入状态，调用 task_input 向同一 taskId 发送输入，再继续读输出。text 原样按 UTF-8 发送，dataBase64 传任意字节；回车、换行、方向键和 Ctrl+C/D 由调用端明确传入。pipe EOF 是关闭 stdin 的独立动作；PTY 的 Ctrl+D 是终端字节，含义由远端终端模式决定。密码错误后的提示继续使用原任务。参数、回执与恢复示例统一见 [MCP API](../mcp-api.md#交互输入070)。

输入回执区分排队中、已发送、未发送失败和发送结果未知；已发送表示提交到原 SSH 通道，程序是否消费须核对输出。回包丢失时查询原任务或显式重试同一序号、同一内容，不能换序号猜测重发。核心只保留最近一次输入，推进后更旧序号明确过期。取消或收尾封闭新输入，已经发生的输入仍保留实际回执。通用命令可以修改、删除远端数据，工具如实声明这一行为。工具缺失、权限不足和非零退出码保留远端实际结果。取消、期限或断线仅尽力终止自己的远端通道，不证明脱离的子进程已经结束，也不撤销副作用。

## 上传文件

客户端先生成或选定 SoDeck 所在机器可读的稳定文件，再明确选择目标连接，调用 `sodeck_file_upload`，通过既有任务接口读取进度与提交结果。无需文件插件、文件选择框或另存 SSH 凭据。其他机器、云端沙箱或容器内路径需先放到 SoDeck 主机，不能将聊天附件编号作为来源。

一次上传一个普通文件，保留本地来源；正文流式复制，不进入 MCP JSON、模型上下文或另存的上传正文。零字节、二进制、大文件均支持。两个路径都按字面解释，远端必须是含文件名的完整路径，父目录需存在。目录、链接、特殊来源、相对路径、内联正文、自动建目录、断点续传和自动执行不在范围内；目录可先在本地打包。

默认遇到同名目标失败；`overwrite=true` 固定开始时的目标版本，提交前复核，再原子替换。开始时不存在、后来出现的目标仍按冲突处理；类型冲突与最终符号链接不覆盖。服务端不能提供所需提交能力时明确拒绝，不先删目标或直接截断目标。新上传文件以私有普通文件权限创建（POSIX 请求 0600，仍受服务端策略约束），不继承来源可执行位；覆盖保留可表达的目标普通权限位，不克隆 ACL、所有者或扩展属性。

100% 字节进度只说明临时文件写完；`file.commitState` 明确区分 pending、committed、notCommitted、unknown。取消在提交前保留目标；提交已发送后继续确认，成功不能撤销。丢失提交回执时不重发、不删除可能仍参与提交的临时文件；查询原请求，未知终态需核对远端实际内容。同请求重试恢复原任务，即使来源已删除也不重传。

来源固定打开句柄并在提交前检查身份、大小与版本，检测到变化则不提交；没有并发写入快照保证。目标版本检查与替换之间仍有外部写入竞争窗口，原子替换不等于跨进程版本锁，也不承诺远端断电持久化。参数和字段见[MCP API](../mcp-api.md#单文件上传090)。

## 证据与状态

每次运行在插件数据目录的 `evidence/<运行编号>/<任务编号>/` 保存 `metadata.json` 以及命令的 `output.jsonl` 或下载的 `download.bin`；上传只保存元数据，不复制本地来源。元数据 schemaVersion=3 保存目标端点/账号、完整 Context、原参数、最近原生事实、观察时间和本地保存结果。pipe 输出保持 v1 stdout/stderr，PTY 使用 v2 terminal 合并流，文本页提供 terminal，不复原屏幕状态。命令输出保存核心完整信封，包含原字节 Base64、来源、序号与接收时间；预览只是每页有损 UTF-8，跨页字符和二进制分析应读取原字节。

`phase` 区分 collecting、finalizing、done。最终元数据保存和清理完成后才发布稳定 `done=true`，之后事实与 revision 不再改变。最终元数据失败时发布保存失败的内存结果，磁盘保留最后有效元数据，可能仍为 finalizing。`done` 不能单独证明成功；检查 `native` 的退出/传输结果和 `evidence.complete`。非零退出码仍可有完整输出；取消、输出截断或保存失败不能标完整。`resourceReleased` 与 `cleanupError` 单独说明原生清理结果，各清理步骤失败分别保留，清理失败不抹去已经保存的证据。最终原生事实保存失败时保留回执到资源关闭，报告记录失败及资源未释放，不重传；已确认提交不被本地保存错误抹去。释放后 task_get 返回最后观察的快照和同一落地文件，不重新查询不存在的原生任务。

普通结果保留接纳目标、退出/保存/清理事实；detail=true 保留原 input、完整 Context、时间、本地目录与完整错误。runId、revision 和正文的 savedBytes 说明运行、有效变化版本和已保存水位；命令 none 模式使用 outputInfo.savedBytes。有正文时不重复水位。taskId 含运行身份，客户端按不透明字符串处理；旧短编号不作别名。target 尚未确认时为 null，界面不以当前页面目标替代历史归属。createdAt 不证明远端命令已经启动，finishedAt 不证明全部远端子进程已经退出。

普通下载用 file.remotePath 表示来源，file.localPath 仅稳定完成且证据完整时提供，其他为 null；诊断残留 evidence.path 不代表完整交付。

下载复用核心流式复制、源版本检查、独占新文件提交和取消。已有目标不覆盖，变化中的源文件不能标完整。没有下载总时间/大小期限；单次 SFTP 请求有期限，持续有进度的慢传输可以继续。保存失败或磁盘不足保留失败，未提交的临时文件按原复制流程清理。

## 侧栏实时监测

MCP 使用原有侧栏完成接入、监测、记录和详情，不提供中央操作页或中央新建入口。概览以双向任务气泡呈现客户端发起的操作：右侧显示实际命令或远程路径，左侧显示状态、限长输出预览、执行链和结果。插件名称由宿主标题显示一次；页头只保留服务器状态、刷新和“配置”。查看详情只切换侧栏内容，主工作区的页面、布局与输入保留。行为随 Agent MCP 版本更新，交付与实际验证见 [CHANGELOG](../../plugins/mcp/CHANGELOG.md)。

内容顶部显示服务器名称、真实连接状态和最后连接信息；观察失败在同一区域显示实际错误。配置在右上角浮层按需读取，提供复制和折叠的接入选项；收起、进入详情、隐藏或卸载时清空配置与密钥显示。刷新不会打开中央页面或改变主工作区。

每个任务只出现一组气泡，运行状态变化保持原任务位置；活动任务不另复制到单独监测区。概览最多显示后端允许的 50 条摘要及传输预算，超出范围提示使用 MCP 或本地证据查询。输出预览最多三行和约 1 KiB UTF-8；完整命令和日志进入详情。执行链只呈现接纳、远端执行/传输、保存与收尾等已有事实，不根据耗时猜测阶段。

## 侧栏记录与详情

每个服务器工作区使用一个后台侧栏视图。选择记录后切换到侧栏详情，从顶部阅读；返回恢复概览滚动位置和触发控件焦点，触发控件已隐藏时回到刷新按钮。上传详情显示本地来源、远端目标、覆盖策略、真实进度和提交结果；已提交但记录失败同时显示两种事实，不显示命令日志框。下载详情显示文件名、保存状态、远程路径和已交付的本地路径；不显示空的输出框。概览与详情不堆叠，不因详情过长自动扩大侧栏或覆盖主区域。

操作列表最多显示 50 条摘要，并受界面传输预算限制；后端优先选取活动任务及最近完成记录，侧栏将所选有限集合按提交时间从旧到新展示，状态改变不会跳位。首次定位到最近操作；阅读旧记录时新任务只显示提示，点击后才到末尾。超出显示范围时列出显示数和总数，更多记录通过 MCP 或证据目录查询。首次打开保持概览；点击记录读取完整详情，显示实际命令或远程路径、接纳时的服务器信息、提交时间、用时、请求/任务编号、原生状态与退出码、证据保存结果、本地路径及错误。返回后刷新不会重新进入详情。命令输出用上一页/下一页读取；查看历史或翻页时，新操作和定时刷新不会切换已选详情或输出页，并保留焦点与阅读位置。已展开的记录即使被新操作挤出范围，也保留到返回概览，不把它追加回最近列表；换到新的服务器连接后清除旧连接的选中记录和分页，回到新连接概览，不自动进入新记录。标准错误单独标注，显示为文本；跨页 UTF-8 与二进制分析仍应读取原字节证据。

页面约每 1.5 秒读取状态。概览只对可见且水位变化的命令串行读取最近页，单轮最多 4 个预览；详情打开后定时刷新改用内部无正文事实读取，不替换当前正文。详情阅读器每次读取一页文本，日志区域限高并独立滚动；上一页/下一页使用服务游标，“最新输出”读取最近页，失败时保留上一页并提供重试。新水位只显示“有新输出”，不改变页码或滚动位置。PTY 文本与 stdout/stderr 都按原输出来源显示，标准错误单独标注；跨页 UTF-8 与二进制分析使用原字节证据。一次观察失败与恢复保留详情和阅读状态；真正连接或插件运行换代才清空旧阅读，迟到回复不能写入新上下文。读取失败保留有效正文，不能显示假空输出；详情超出原传输预算时提示改用 MCP 或本地证据。取消只请求取消，收尾、已请求取消和结束时隐藏动作；无输出、证据完整与执行成功是不同事实，退出码、退出信号和保存/清理错误分别保留。

侧栏复用当前工作区的后台目标，不重复登记服务器。隐藏只暂停界面刷新与正文读取，后台任务继续，再显示可查看同一条记录。关闭工作区、停用插件或退出 SoDeck 按核心已有资源生命周期取消并清理。重连使旧目标不能接纳新任务，重新查询取得新目标。核心通用手动停靠能力仍由用户控制，MCP 不主动创建或迁移中央页面。

## 限制与恢复

- 同一主机、同一用户可访问本地证据；不提供远程 AI 网关或公开 HTTP 服务。
- 命令最长 16 KiB，每条捕获最多 16 MiB 编码后信封；超额停止采集。输出页最多约 16 KiB 原始 JSONL，使用 nextCursor 继续；更大的资料用下载。
- 十二个工具只返回一份 JSON 文本；MCP result 含外层转义最多 256 KiB，超限明确拒绝，可改读普通 text/none 或本地证据。0.2.x 客户端读取方式需按 [MCP API](../mcp-api.md)迁移。
- 服务器发现、目标采集、打开控制与输入共用最多 4 个短 IO/RPC 作业，不排队；HTTP 取消不能抢占已发出的同步只读 RPC，实际作业结束才释放位置。完整参数、错误与集合变化规则见 [MCP API](../mcp-api.md)。
- 单次插件运行最多 32 个未完成打开、4096 条打开记录；原任务仍最多 64 个目标、24 个活动任务、4096 条任务请求记录；核心自身的执行和文件额度继续生效。活动任务满时拒绝新任务，不另排执行队列。
- 正等待与正文读取分别受额度限制，完整数值见 [MCP API](../mcp-api.md)。新正等待启动在登记前预留位置，额度不足时明确拒绝；已有任务的等待/读取错误保留可查询身份。客户端可以显式零等待，不自动降级或排队扩展 worker。仅状态和列表不读取正文。
- 证据不会自动删除，需自行管理磁盘空间。插件/SoDeck 重启后不扫描历史、恢复任务或接受旧 taskId；落地文件保留，缺少最终结果的元数据表示当时结果未知。
- 首版没有聊天、模型运行、诊断规则、插件间直接调用；服务器认证仍由核心管理。
