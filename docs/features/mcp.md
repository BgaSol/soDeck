# 机器人接口

独立插件“机器人接口”（`sodeck.mcp`）通过 MCP 协议让同一主机上的 Codex 等客户端使用 SoDeck 已连接的服务器，执行调查命令、查询输出和下载证据。命令内容与调查判断由客户端负责。核心安装包不含此插件；最低核心版本为 1.5.0，核心 1.5.1 起显示机器人图标，插件独立更新。插件 ID、数据目录、端口、接入密钥和客户端配置继续沿用，已有安装无需重新配置。发行与实际验证见 [CHANGELOG](../../plugins/mcp/CHANGELOG.md)。

## 接入

1. 更新核心，在插件管理中安装并启用“机器人接口”，重启 SoDeck。
2. 连接需要调查的服务器。每个工作区自动登记后台目标，不需要打开终端或保持页面可见。
3. 打开服务器侧栏的机器人图标“机器人接口”，展开“接入设置”，点击“复制 Codex 配置”，写入本机 Codex 私有配置 `~/.codex/config.toml`，重新打开客户端会话。

配置形状如下；以页面实际复制的端口和密钥为准：

```toml
[mcp_servers.sodeck]
url = "http://127.0.0.1:19846/mcp"
http_headers = { Authorization = "Bearer <页面复制的密钥>" }
```

服务只绑定 `127.0.0.1`。默认端口 19846；侧栏的“接入设置”和组件设置共用端口配置，允许 1024–65535。保存后重启 SoDeck 并重新复制配置；保存不会改变当前运行的服务地址。其他窗口更新设置时保留端口草稿并提示冲突，点击“载入最新值”后再编辑。端口被占用时页面显示错误，日志保留原因。

Token 首次启动时生成并保存在插件数据目录的 `access-token` 文件中。重启、停用再启用和升级都复用此文件，不自动过期或轮换；修改端口也不改变 Token。文件无效或无法读取会报错，不自动覆盖。删除文件并重启，或使用全新的数据目录，会生成新密钥，旧客户端配置需更新。Token 不进入日志、普通状态快照或命令元数据，仅显式显示密钥、查看或复制配置时提供；收起配置清空配置文本，收起接入设置、进入任务详情、隐藏或销毁侧栏清空配置与密钥显示。不要分享包含 Token 的截图、配置或目录。

客户端必须携带 Token；Host 必须为该端口的 `127.0.0.1`，如有 Origin，也必须为对应回环 HTTP 地址。此接入识别不改变可信插件边界或服务器操作系统权限。远程输出作为不可信证据处理，不作为客户端的指令来源。[Codex MCP 配置说明](https://developers.openai.com/codex/mcp)。

## 调查与补采

| 工具 | 行为 |
| --- | --- |
| `sodeck_targets_list` | 查询当前后台目标、完整 Context、真实端点/账号摘要、连接状态与 closing |
| `sodeck_exec_start` | 用 targetId、requestId、command 启动非交互命令或多行脚本，立即返回 taskId；timeoutSeconds 默认 300，范围 1–3600 |
| `sodeck_tasks_list` | 查找本次运行的任务，按目标/服务器、requestId、种类和 active/done 筛选，稳定分页 |
| `sodeck_task_get` | 查询任务事实；outputMode 可选 full/text/none，默认立即 full，waitMs 可有限等待变化 |
| `sodeck_task_cancel` | 请求取消；继续查询实际结果，已完成任务不回滚 |
| `sodeck_file_download` | 用 targetId、requestId、remotePath 下载一个普通远程文件，返回 taskId；完成后提供本地文件路径 |

先列目标并明确选择服务器；三个目标可以分别采集。对每次启动保持固定 requestId 与参数，HTTP 断开后用同一请求重试会得到同一 taskId；相同身份修改参数会拒绝。接纳回包丢失时插件查询原生票据，结果未知期间阻止同一目标对应命令/文件域的后续接纳，不重复发送命令。取消未知请求仍需等待原票据确认或关闭工作区。

AI 会话丢失 taskId 时，可用 tasks_list 查原服务器或固定 requestId，再读取原任务，不必重新执行。列表只覆盖当前插件运行，按接纳顺序从新到旧；后续页保留原筛选和 limit，新任务需从第一页刷新。active/done 筛选使用查询时的实际状态，分页不冻结执行。

用 task_get 查询完成与下一游标。新客户端可用 text 阅读日志，none 只查状态；需要精确原字节时使用 full 或本地证据。保存 revision，下一次携带 sinceRevision 和最多 20000 毫秒的 waitMs 等待变化；正文同时携带 nextCursor，避免反复读取第一页。等待到期是正常结果，断开读取不取消远端任务。字段、分页及错误的完整契约见 [MCP API](../mcp-api.md)。先采集故障窗口的日志和状态，根据结果分析后，再用新的 requestId 补采网络或性能信息。读取小配置使用远程命令；大日志或目录先在远端生成稳定的普通文件/压缩包，再下载。

命令使用远端非交互 shell，不使用本机 PowerShell；没有 PTY、stdin 或交互认证。通用命令可以修改、删除远端数据，工具如实声明这一行为。工具缺失、权限不足和非零退出码保留远端实际结果。取消、期限或断线仅尽力终止自己的远端通道，不证明脱离的子进程已经结束，也不撤销副作用。

## 证据与状态

每次运行在插件数据目录的 `evidence/<运行编号>/<任务编号>/` 保存 `metadata.json` 以及命令的 `output.jsonl` 或下载的 `download.bin`。元数据保存目标端点/账号、完整 Context、原参数、最近原生事实、观察时间和本地保存结果。命令输出保存核心完整信封，包含原字节 Base64、来源、序号与接收时间；预览只是每页有损 UTF-8，跨页字符和二进制分析应读取原字节。

`phase` 区分 collecting、finalizing、done。最终元数据保存和清理完成后才发布稳定 `done=true`，之后事实与 revision 不再改变。最终元数据失败时发布保存失败的内存结果，磁盘保留最后有效元数据，可能仍为 finalizing。`done` 不能单独证明成功；检查 `native` 的退出/传输结果和 `evidence.complete`。非零退出码仍可有完整输出；取消、输出截断或保存失败不能标完整。`resourceReleased` 与 `cleanupError` 单独说明原生清理结果，各清理步骤失败分别保留，清理失败不抹去已经保存的证据。释放后 task_get 返回最后观察的快照和同一落地文件，不重新查询不存在的原生任务。

任务快照保留原 input、接纳目标和提交/结束时间；runId、revision 和 outputInfo.savedBytes 说明运行、有效变化版本和已保存正文水位。taskId 含运行身份，客户端按不透明字符串处理；旧短编号不作别名。target 尚未确认时为 null，界面不以当前页面目标替代历史归属。createdAt 不证明远端命令已经启动，finishedAt 不证明全部远端子进程已经退出。

下载复用核心流式复制、源版本检查、独占新文件提交和取消。已有目标不覆盖，变化中的源文件不能标完整。没有下载总时间/大小期限；单次 SFTP 请求有期限，持续有进度的慢传输可以继续。保存失败或磁盘不足保留失败，未提交的临时文件按原复制流程清理。

## 侧栏实时监测

MCP 使用原有侧栏完成接入、监测、记录和详情，不提供中央操作页或中央新建入口。侧栏默认显示当前服务器、折叠的接入设置、正在执行的操作和执行记录；查看详情只切换侧栏内容，主工作区的页面、布局与输入保留。此调整已在插件 0.2.1 发行，交付与实际验证见 [CHANGELOG](../../plugins/mcp/CHANGELOG.md)。

侧栏顶部显示当前服务器名称、端点、账号和本机接入状态。“正在执行”优先显示最新的活动操作、完整实际命令或远程路径、自提交起的用时和最近输出页；同时执行多个操作时显示数量，其余操作在下方记录中查看。点击“查看详情”在同一侧栏阅读当前任务。命令名称不根据脚本内容猜测调查意图。

## 侧栏记录与详情

每个服务器工作区使用一个后台侧栏视图。概览中的“接入设置”默认折叠，展开后提供运行地址、端口保存、配置复制/查看和密钥显示；页尾提供本地证据目录入口。选择记录后切换到侧栏详情，从顶部阅读；“返回记录”恢复概览的滚动位置和触发控件焦点，触发控件已隐藏时回到刷新按钮。概览与详情不堆叠，不因详情过长自动扩大侧栏或覆盖主区域。

操作列表最多显示 50 条摘要，并受界面传输预算限制；所有活动任务优先，其后按提交顺序从新到旧显示完成记录。超出显示范围时列出显示数和总数，更多记录通过 MCP 或证据目录查询。首次打开保持概览；点击记录读取完整详情，显示实际命令或远程路径、接纳时的服务器信息、提交时间、用时、请求/任务编号、原生状态与退出码、证据保存结果、本地路径及错误。返回后刷新不会重新进入详情。命令输出用上一页/下一页读取；查看历史或翻页时，新操作和定时刷新不会切换已选详情或输出页，并保留焦点与阅读位置。已展开的记录即使被新操作挤出范围，也保留到返回概览；换到新的服务器连接后清除旧连接的选中记录和分页，回到新连接概览，不自动进入新记录。标准错误单独标注，显示为文本；跨页 UTF-8 与二进制分析仍应读取原字节证据。

页面约每 1.5 秒读取状态和可见输出。实时区只读取约 16 KiB 的最近完整 JSONL 信封，不从头追赶大量输出；详情每次读取文本页，不把全部历史载入内存。刷新失败时标注状态可能已过期，输出读取失败在对应区域显示，可再次刷新。编码后详情超过界面传输预算时明确提示使用本地证据或 MCP，保留摘要与目录入口；不悄悄截断完整命令或显示空输出冒充成功。无输出与执行成功是不同事实。取消按钮只请求取消，正在收尾或已结束时不再提供新的取消动作；其他采集中的请求仍需查询原生实际结果，已发生的远端变化不会撤销。

侧栏复用当前工作区的后台目标，不重复登记服务器。隐藏只暂停界面刷新与正文读取，后台任务继续，再显示可查看同一条记录。关闭工作区、停用插件或退出 SoDeck 按核心已有资源生命周期取消并清理。重连使旧目标不能接纳新任务，重新查询取得新目标。核心通用手动停靠能力仍由用户控制，MCP 不主动创建或迁移中央页面。

## 限制与恢复

- 同一主机、同一用户可访问本地证据；不提供远程 AI 网关或公开 HTTP 服务。
- 命令最长 16 KiB，每条捕获最多 16 MiB 编码后信封；超额停止采集。输出页最多约 16 KiB 原始 JSONL，使用 nextCursor 继续；更大的资料用下载。
- 单次插件运行最多 64 个目标、24 个活动任务、4096 条请求记录；核心自身的执行和文件额度继续生效。活动任务满时拒绝新任务，不另排执行队列。
- 正等待全局最多 16、每任务最多 2；正文 IO 最多 4，忙时退避重读同一任务/游标，不排队扩展 worker。仅状态和列表不读取正文。
- 证据不会自动删除，需自行管理磁盘空间。插件/SoDeck 重启后不扫描历史、恢复任务或接受旧 taskId；落地文件保留，缺少最终结果的元数据表示当时结果未知。
- 首版没有聊天、模型运行、诊断规则、上传/覆盖工具或插件间直接调用；服务器认证仍由核心管理。
