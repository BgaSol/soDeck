# 文件管理与编辑

文件插件在侧栏浏览当前服务器的 SFTP 目录，在中央页面编辑小文本文件，并提供上传、下载和远端日常管理。远端路径按远程文件系统处理，本地路径由核心系统适配层处理。

## 目录与联动

支持多分支展开、路径定位、独立分页、隐藏项设置、刷新、键盘导航及右键菜单。单击选择，双击文件打开中央编辑器；同一远端规范路径复用已有页面。展开、选择和滚动属于显示状态，隐藏和移窗保留。

刷新按路径复用文件行，未变化的行及其内容保持挂载；变化条目局部更新，实际排序变化才移动节点，保留原滚动、菜单和逻辑选择。目录仍按已加载范围绘制，未引入虚拟化或预先遍历未展开目录。

多选和范围选择只作用于已加载可见条目。跨多个目录选择时，上传、粘贴和新建需要明确目标；拖到具体目录时使用该目录。异步粘贴期间焦点、目标或连接改变会使旧输入失效。

“跟随目录”默认开启，沿用原“跟随终端”开关值。文件插件接收当前工作区及连接中任意组件发布的位置，按核心接纳修订跟随最新目录，不根据插件类型选择来源。终端目录变化、用户重新激活终端，以及 Docker Compose 菜单“跟随”均可发布；发布者不查询文件插件是否存在或完成导航。

定位经核心文件服务核对路径、目录类型及适用的文件系统标记，不抢输入焦点、不自动展开隐藏面板。手动浏览后，重复通知、相同目录普通提示符和容量刷新不拉回；新的目录发布重新跟随。“定位到最近目录”主动重试，关闭后保留位置，重新开启按最近目标定位。

隐藏时只接收最近目标，显示时处理尚未完成的新发布；没有新发布则保留手动位置。冻结／移窗先取消在途定位并保存接收水位，恢复不重放已处理位置。来源结束、通知失效或定位失败时保留树位置，不回退其他来源的旧目录；重连清除旧连接目标。目录不存在、普通文件、无权限或文件系统无法对应时说明原因，可手动重试。协议见[通用目录位置](../plugin-api.md#通用目录位置)。

挂载容量由独立订阅消费系统状态快照，按远程路径匹配；不可用或过期不显示伪造的准确值，也不改变目录跟随。

## 上传、下载和管理

- 上传文件/文件夹，下载文件、多选或目录，保留顶层名称、空目录、隐藏项、零字节和二进制内容。大文件走流式数据，正文不放进控制 RPC。
- 本地文件选择、文件剪贴板和原生拖入共用上传流程，源文件保留。远端文件拖出到系统或复制后在系统粘贴尚不支持。
- 新建空文件/目录、递归删除和同服务器复制。当前 SFTP 后端无法保证原子无覆盖移动，移动、剪切和改名统一禁用，不以复制后删源替代。内部拖动仅支持 Windows/Linux Ctrl 或 macOS Option 复制；普通移动手势说明不支持。文件系统外部拖出不创建系统文件对象。
- 冲突可覆盖、跳过、保留两份、改名或取消；类型冲突禁止覆盖，目录合并。批量选择仅作用于当前批次。
- 递归遍历不跟随符号链接或特殊条目，跳过并报告；直接删除只操作链接本身。复制、上传、下载始终保留源；不会在传输完成后自动删除源。
- 操作影响已打开编辑器时先经过保存/放弃/取消，处理后关闭相应页面；运行中阻止再次打开冲突路径，不承诺移动后自动重开编辑器。

最多两个活跃批次、每工作区一个，等待队列为 64。隐藏或移窗不停止任务；取消等待实际在途操作结束，只有明确未提交且允许重试的失败项可以单独重试。变更请求的回执丢失时暂停批次并保留原身份；“确认并继续”只查询原操作，不再次执行。未决批次不能清除，也不能越过它启动同工作区的新批次。结果日志持久化成功后才释放核心回执，写盘失败同样暂停。记录保存在插件数据目录并分页读取，应用重启不恢复原批次，启动会清理旧运行记录。

任务行保留节点，速度按当前操作约每 500ms 采样，使用约 2 秒窗口；中间刷新保持显示，首次采样前显示“测速中”，无进度时收敛为 0。切文件、隐藏恢复和连接变化重新采样。字节进度走满后明确显示校验/保存阶段，任务完成以核心提交回执和插件结果记录为准，不预留虚构的百分比。失败明细保留阶段、系统错误码及提交事实；文件已保存但记录/释放待确认时，不重新下载。批次成功交付大小与包含失败部分的传输工作量分别计量。

新本地目标使用标准无覆盖提交，已有目标只有明确选择覆盖后才替换；不依赖文件系统必须支持硬链接。实际兼容范围按本次版本记录区分，网络盘和特殊文件系统仍可能拒绝安全提交，届时报告提交阶段原因。

传输使用独占临时文件，提交前核对源版本、目标 guard 和解析后的父目录。替换远端文件要求服务端支持原子替换；提交前取消不替换旧目标；提交已发送时继续确认真实结果。提交应答丢失标为结果未知，不自动重试或删除源，并保留临时路径供核对，避免清理仍可能参与服务端提交的文件。复制保留可支持的时间/模式，不承诺完整 ACL、所有者、扩展属性或目录元数据克隆。

## 文本编辑与保存

通过[通用文件编辑 SDK](file-editor.md)提供标准编辑、保存、搜索和草稿导出；编码、限制、失败及生命周期见该文档。下载与文件批次仍由文件插件负责。

JSON/JSONC 字符串中的 `$HOME`、`${HOME}` 和独立 `$` 按字面字符串着色。JSONC 保留行注释和跨行块注释着色，JSON 不提供注释着色。这项修正已由文件插件 0.10.2 发行，见[文件插件变更记录](../../plugins/files/CHANGELOG.md#0102)。

JSON/JSONC 支持字段名与冒号分行，浅色和深色主题继续区分字段名、字符串值与关键字；数组内字符串沿用值的颜色。这项完善已由文件插件 0.10.4 发行，见[0.10.4 变更](../../plugins/files/CHANGELOG.md#0104)。

## 操作反馈

主动展开、收起时衔接可见行，后台刷新保留文件行身份且不重播。文件任务按任务身份移动分组并保留进度节点，同轮多项任务结束合并提示。已知总量时仅衔接同一文件的真实字节进度；切换文件、未知总量或结果待核对时不模拟。明细按钮与 Esc 共用关闭路径，操作不等待视觉完成。节奏和减少动态效果规则见[界面规范](../../DESIGN.md#动效)。
