# 文件管理与编辑

文件插件在侧栏浏览当前服务器的 SFTP 目录，在中央页面编辑小文本文件，并提供上传、下载和远端日常管理。远端路径按远程文件系统处理，本地路径由核心系统适配层处理。

## 目录与联动

支持多分支展开、路径定位、独立分页、隐藏项设置、刷新、键盘导航及右键菜单。单击选择，双击文件打开中央编辑器；同一远端规范路径复用已有页面。展开、选择和滚动属于显示状态，隐藏和移窗保留。

多选和范围选择只作用于已加载可见条目。跨多个目录选择时，上传、粘贴和新建需要明确目标；拖到具体目录时使用该目录。异步粘贴期间焦点、目标或连接改变会使旧输入失效。

目录跟随使用当前服务器最近操作的终端位置，经核心共享状态和远端文件系统身份核对后导航。手动浏览与跟随状态分开，未知身份、失效路径或旧代次不强行跳转。挂载容量来自系统状态共享快照，按远程路径匹配；不可用或过期不显示伪造的准确值。

## 上传、下载和管理

- 上传文件/文件夹，下载文件、多选或目录，保留顶层名称、空目录、隐藏项、零字节和二进制内容。大文件走流式数据，正文不放进控制 RPC。
- 本地文件选择、文件剪贴板和原生拖入共用上传流程，源文件保留。远端文件拖出到系统或复制后在系统粘贴尚不支持。
- 新建空文件/目录、递归删除和同服务器复制。当前 SFTP 后端无法保证原子无覆盖移动，移动、剪切和改名统一禁用，不以复制后删源替代。内部拖动仅支持 Windows/Linux Ctrl 或 macOS Option 复制；普通移动手势说明不支持。文件系统外部拖出不创建系统文件对象。
- 冲突可覆盖、跳过、保留两份、改名或取消；类型冲突禁止覆盖，目录合并。批量选择仅作用于当前批次。
- 递归遍历不跟随符号链接或特殊条目，跳过并报告；直接删除只操作链接本身。复制、上传、下载始终保留源；不会在传输完成后自动删除源。
- 操作影响已打开编辑器时先经过保存/放弃/取消，处理后关闭相应页面；运行中阻止再次打开冲突路径，不承诺移动后自动重开编辑器。

最多两个活跃批次、每工作区一个，等待队列为 64。隐藏或移窗不停止任务；取消等待实际在途操作结束，只有明确未提交且允许重试的失败项可以单独重试。变更请求的回执丢失时暂停批次并保留原身份；“确认并继续”只查询原操作，不再次执行。未决批次不能清除，也不能越过它启动同工作区的新批次。结果日志持久化成功后才释放核心回执，写盘失败同样暂停。记录保存在插件数据目录并分页读取，应用重启不恢复原批次，启动会清理旧运行记录。

传输使用独占临时文件，提交前核对源版本、目标 guard 和解析后的父目录。替换远端文件要求服务端支持原子替换；提交前取消不替换旧目标；提交已发送时继续确认真实结果。提交应答丢失标为结果未知，不自动重试或删除源，并保留临时路径供核对，避免清理仍可能参与服务端提交的文件。复制保留可支持的时间/模式，不承诺完整 ACL、所有者、扩展属性或目录元数据克隆。

## 文本编辑与保存

编辑上限为 1 MiB（1,048,576 字节），同时约束远端打开及修改后的原始编码字节。仅编辑 UTF-8（可含 BOM）、一致的 LF/CRLF 文本；二进制、非法编码或混合换行可以下载。超限输入拒绝或撤销本次事务，不能截断正文。

Monaco 提供行号、撤销、选区、当前正文搜索、词法颜色和右侧彩色缩略图。搜索包含未保存内容，支持大小写、循环前后查找、Ctrl/Cmd+F、Enter/Shift+Enter、F3 和 Esc；最多显示 1000 个普通命中，更多显示“1,000+ 处”，导航仍搜索全文。查询最多 1024 个 UTF-16 单元。

根据文件名、后缀和有限 shebang 判断语言，可以手动更正；支持运维常见 YAML、JSON/JSONC、Shell、PowerShell、Nginx、INI/systemd、TOML、环境变量及 Dockerfile。这里只提供词法着色，不提供语言服务器、配置诊断、补全或格式化。长于 10,000 字符的单行可部分按纯文本呈现，正文与搜索不截断。缩略图可点击，窄编辑区退为位置标记；显示设置不产生正文修改。

JSON/JSONC 字符串中的 `$HOME`、`${HOME}` 和独立 `$` 按字面字符串着色。JSONC 保留行注释和跨行块注释着色，JSON 不提供注释着色。这项修正已由文件插件 0.10.2 发行，见[文件插件变更记录](../../plugins/files/CHANGELOG.md#0102)。

保存核对远端内容摘要、属性和链接目标，在同目录写临时文件并原子替换。已检测到的外部修改拒绝覆盖。属性/摘要检查与最终提交是分开的 SFTP 请求，不能阻止检查之后其他写入者的更新被覆盖；这是普通单写入者文件编辑，不提供原子版本比较或协同编辑。传输覆盖同样受此限制。

正文同步、元数据和光标通知分别处理。分片有上传身份、摘要和修订，失败可重试同一快照，末次提交丢回执可查询原结果。保存接受时固定修订 R，期间输入的 R+1 保持未保存。提交应答丢失标为未知，禁止直接重放保存；提交成功但后续属性读取失败仍显示已提交，同时禁止继续原位保存，须核对并重新打开。准备失败可能留下提示路径中的临时文件，不自动删除正式目标。

“下载远端”取得服务器当前版本。“导出草稿”在弹出本地对话框前固定本次正文，弹框期间的后续编辑不改变导出字节；同一请求不会重复弹框。导出不依赖远端连接、元数据或光标通知，断线后仍可使用。取消后迟到的路径选择不写入，原生对话框尚未结束时仍算在途任务。显示状态最多 8 KiB，含完整选区、逻辑滚动、搜索和语言覆盖；候选页面只读，交接先冻结输入再等待同步。撤销栈不跨 UI 重挂载持久化，进程崩溃不承诺草稿恢复，关闭释放编辑模型和 Worker。当前没有正则、替换、跨文件搜索或自动保存。
