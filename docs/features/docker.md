# Docker

Docker 是独立插件，默认固定在右侧工具栏、按需打开。通过核心短命令和非交互命令流复用当前连接；Docker 命令和业务规则全部留在插件，不直接依赖 SSH 实现或其他插件。

## 当前功能

- 读取 Engine 概况与容器列表，搜索名称、镜像、标签和完整 ID，筛选状态/健康；“按 Compose 项目排列”按项目名排序，相同项目的容器相邻显示，并展示项目/服务标签。
- 在中央页面查看容器配置、状态/健康、环境变量、端口、挂载、网络和标签。环境变量值默认隐藏。
- 在中央日志工作区连续阅读，跟随最新、固定当前位置、按时间补读、搜索/筛选、查看上下文和详情、复制原文及导出当前结果；右侧缩略支持定位和拖动。
- 在右侧栏选中容器后，当前行展开启动/停止、重启/恢复及“更多”操作。启动、恢复直接执行；停止、重启、暂停和删除在行内确认。只允许删除已停止容器，不使用 force 或删除挂载卷参数；详情页保留同样的快捷操作。
- 当前行提供日志、终端、详情入口；只有明确点击这些入口才在主区域打开页面。单击、双击和 Enter 都只选择容器，搜索、切换状态和维护不打开中央页面。已有手动停靠位置继续恢复，首次默认位于右侧。
- 运行中的容器可从侧栏或详情打开终端。容器 Shell 默认 /bin/sh；侧栏“更多 → 终端选项”可填写容器内的绝对可执行路径。通过核心 terminal.open.v1 命令请求终端插件，无需直接调用插件。
- 按需读取 CPU、内存、网络、块 IO 和进程数；累计字节不当作速率。列表按设置刷新，详情和指标手动读取。

Compose 分组只是读取标签和排序，没有独立分组标题或折叠操作，也不提供创建、部署或管理 Compose 项目的能力。当前不提供批量操作或镜像/网络/卷管理。

日志工作台从 Docker 0.4.1 提供，需配套核心 1.1.0 的 session.stream.v1/content.export.v1；启用中的插件升级在重启后生效。验证与未完成范围见[日志后续验收](../plans/docker-log-viewer.md)，对应插件记录见[CHANGELOG](../../plugins/docker/CHANGELOG.md)。

行内侧栏重构已在 Docker 0.3.0 发行，来源与验收范围见插件 [CHANGELOG](../../plugins/docker/CHANGELOG.md)。状态选择常驻，健康和 Compose 排列收在“更多筛选”，socket 编辑位于底部“连接设置”。操作结果显示在对应容器行；对象因筛选或删除而离开当前页时，仍显示带名称的结果。断线或数据待刷新时禁用维护，保留快照；不适用操作按容器状态隐藏，未运行容器的终端入口明确不可用。

后台刷新保留当前行菜单的展开状态、键盘焦点及 Shell 输入选区。Esc 关闭菜单或取消未提交确认，并返回可见触发入口；无需悬停或右键即可完成维护。

## 容器日志

打开日志默认选择“最新”，按Engine的当前时间先读取最近15分钟末尾最多2000行，初始捕获上限4MiB（含原始字节信封），随后持续接收。先启动跟随资源，再读固定的半开历史范围，交界时间的记录归入跟随流；Worker按原始RFC3339纳秒时间比较边界，保留真实重复记录。已停止容器从全部尚可用历史中读取最后的有限尾部，不受最近15分钟下界限制，不开无限跟随。预览结束后正文原字节最多2MiB。

正文占满主区域，身份只在页头显示；搜索、时间、筛选、显示和更多操作集中在工具条。没有日志分页、日志行数选择器或大尺寸统计卡。多巴胺和IDEA明暗主题复用核心公共颜色、控件与滚动条；具体日志布局属于Docker插件。

向上滚动、拖选、搜索、查看详情或点击“保持当前位置”会固定正在阅读的窗口。后台仍接收新输出，显示新增数量；“查看最新”回到近期窗口并恢复跟随。隐藏页面不停止采集，重新展示不重开命令；窗口尺寸变化也不退出跟随。关闭的是日志View时才清理它的采集资源。

搜索是当前已读窗口内的字面、不区分大小写匹配；数量按出现位置统计。默认保留周围日志并高亮，上一处/下一处、F3/Shift+F3导航。“只看匹配”缩小正文，每条命中可展开前后10条；级别仅解析明确前缀或JSON的level/severity，不从一句普通文字猜测错误。ERROR/WARN使用局部语义色，保留原文。已选筛选条件显示可清除的入口；跨日时在时间列标注日期。来源可选stdout/stderr；TTY容器只有combined来源。底部区分当前结果条数与已读窗口条数，时间范围属于当前结果并按本机时区显示；缺少源时间时标注接收时间，空结果不显示范围。

时间选择支持最近15分钟、1小时、24小时和自定义范围，默认仍是有限尾部预览；“完整读取时间范围”才读取所选范围全部可用输出，仍受容量和120秒期限约束。尾部预览期限30秒。达到容量、超时、日志驱动不支持或断线保留部分内容，明确显示未完成，不能当成全范围完成。顶部“查看更早日志”补读最早已请求历史范围前相邻15分钟，一次一个补读；当前捕获最多12段，窗口满时重新选择时间范围替换。

右侧缩略表示当前筛选投影的正文轮廓，保留ERROR/WARN和搜索标记、当前视口。点击标记定位真实记录，拖动保持按下时的记录身份；方向键、PageUp/Down、Home/End可操作，Esc、指针取消或失焦取消手势。缩略不查询未下载历史，也不隐式恢复跟随。显示菜单和插件设置可关闭缩略，窄窗口缩小导航轨，详情改为覆盖正文的可关闭面板。

固定阅读保留实际可见记录及行内偏移；普通重绘和宽度/系统缩放重排使用同一条定位路径，完成测量后按正文位置校准。状态、缺口提示或页面高度变化沿用已测折行高度。提示条可以改变正文区域的位置，但不会因此滚动到另一条记录。

点击时间打开详情，查看完整已保留记录或JSON结构化内容。正文长于8192字符先显示预览，可看全文；单个记录超过1MiB标为未完整保留，不伪装成全文。时间按本机时区显示，提示保留原源时间；没有源时间时明确使用接收时间。ANSI控制字符只作为安全文本显示，不执行终端控制序列，不猜测任意堆栈分组。

原生选区可直接复制；详情可复制原文。更多菜单导出当前筛选结果，或所选记录及前后10条；导出固定当时结果，不混入之后的新日志，附服务器/Engine/容器、范围、条件与覆盖说明。正文保留Docker原字节（含源时间戳，显示用UTF-8解码），分块写入核心的本机保存服务，支持进度与取消；含不完整长记录的范围拒绝导出并提示重新读取。原目标在成功提交前保留，保存失败不报告完成。导出进行中需完成或取消后移动页面。

重挂载从既有原捕获恢复查询、显示偏好和阅读窗口；候选仅重建索引，不提交业务事件或重新执行Docker命令。连接改变后保留旧捕获，重新读取需要确认当前Engine/容器，旧命令不自动重放。CLI没有稳定日志ID，时钟变化、日志轮转、驱动和同时间大量记录可能无法证明无缝衔接；尾部、缺口与未知来源不能用文本去重掩盖。

容器运行很久也不会一次下载全部历史：近期内容有界轮换，阅读时最多固定一个窗口，历史按需读取。搜索、缩略和导出始终只覆盖已保留内容，不提供永久归档或整个容器的远端全文索引。Docker的tail/since减少返回量，也不保证daemon完全不扫描历史。

## Endpoint 与操作语义

当前远端范围为 Linux Docker Engine，默认明确指定 `unix:///var/run/docker.sock`，可保存其他绝对 Unix socket。更改 endpoint 前需要关闭该服务器的详情/日志并等待请求完成；配置保存在插件数据目录的 `endpoints.json`。

命令清除 Docker host/context/TLS/API 环境覆盖并显式指定 socket，不自动安装 Docker、不修改用户组、不添加 sudo。每次采集核对 Context、Engine ID 和完整容器 ID；Engine 更换后旧详情页提示重新打开。

变更请求按操作 ID、序号和完整输入去重。发送前失败明确拒绝，发送后中断显示结果未确认；刷新不重发操作，取消本地等待不承诺撤销远端变更。停止/重启的宽限为 10 秒，命令沿用核心短任务期限和输出预算。

侧栏提交明确携带 Context、socket、Engine ID 和完整容器 ID，后台先检查已读列表身份，再在执行前重读远端对象。行内确认固定其创建时的目标；选择其他容器、改筛选、切换 Context 或关闭来源会取消尚未提交的确认。刷新导致身份改变时，旧确认会被后台拒绝，不作用于新对象。侧栏维护后更新对应行，删除成功使空闲的同身份详情/日志页面标为已删除。

## 容器终端

容器终端已在 Docker 0.2.0 发行，侧栏入口在 0.3.0 新增，来源与范围见 [CHANGELOG](../../plugins/docker/CHANGELOG.md)。

需启用支持 terminal.open.v1 的终端插件，Docker 插件初始化要求核心 commands.v1。请求固定当前 Context、socket、Engine ID、完整容器 ID 和 shell；后台在提交前重读 Engine/容器状态，终端启动命令在 exec 前再次核对 Engine。命令清除 Docker 环境覆盖并显式指定 socket，不自动换 socket、容器、shell 或提权。容器已经停止、暂停、更换 Engine 或 shell 不存在时明确失败；提交后的容器状态仍可能变化，实际结果以终端输出为准。

创建期间显示等待，重复点击不提交新意图；UI 重挂载从 Docker 后台继续查询原票据。回执完成只表示终端页面已登记，不保证容器 shell 已成功启动。通信超时保留原编号继续查询；已发送但结果未知时不自动补建。

同一终端请求编号不能更换容器、连接身份或 shell；完成后的同编号查询也不会补建页面。待确认票据查询优先于侧栏自动刷新，避免列表刷新推迟回执。请求失败或完成后可以用新的明确意图再次打开终端。

终端使用指定命令模式并关闭主机目录集成，容器 OSC 目录不会导航主机文件页。已创建终端独立于 Docker 详情页，关闭来源不结束终端；关闭终端才释放对应 PTY。命令及重开语义见[终端](terminal.md)，不是 Docker 对终端进程的直接调用。

## 有界数据与生命周期

| 内容 | 当前上限 |
| --- | --- |
| 逻辑视图与排队请求 | 64 个视图、16 个请求，worker 顺序执行 |
| 容器列表 | 1000 个、2 MiB 缓存，超限标明不完整 |
| 单容器 inspect | 输出 1 MiB，分区前 100 项，单值 4096 字节；截断明确标注 |
| 日志原始捕获 | 近期32MiB滚动；尾部4MiB/次，完整范围48MiB；核心View固定捕获与pin合计64MiB |
| 日志Worker窗口 | 近期最多50000行/估算16MiB，历史或固定窗口最多200000行/估算64MiB；正文仅渲染可见记录 |
| 全部视图数据 | 16 MiB |
| UI 分页 | 列表/详情每页最多20KiB、列表50项；日志独立正文通道每块最多16KiB |

断线保留已读内容并标为待刷新。UI v2候选只读，不轮询或提交业务操作；日志候选可恢复原捕获正文。交接等待在途交互，取消后恢复输入。关闭视图或退出插件清理资源，Context改变取消旧远端命令但保留日志捕获，旧结果不能覆盖新状态。

普通日志只记录动作、对象与结果，重要失败消息默认不弹出；不记录环境变量、inspect 或日志正文。参数、状态检查和远端操作系统权限继续生效，不引入插件授权步骤。
