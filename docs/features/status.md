# 状态总览

管理台的“状态”页汇总核心、远程连接、插件与本次运行的网络传输。首屏先呈现整体健康，再展示远程会话、运行插件、启动/停止任务和运行时间；网络按服务器分组，应用信息位于次级区域。

## 健康与异常

插件运行或更新失败、连接失败、日志/消息存储异常，以及网络计量读取失败会显示需要关注。插件与连接错误保留具体原因，并提供现有的插件详情或连接管理入口。正在连接、正常的插件启动/停止，以及未启用插件的“未加载”状态不自动算作故障。

“只看异常”筛选存在连接失败或关联插件失败/更新错误的服务器传输记录，不改变远程会话总数或插件统计。没有匹配项时可以返回全部服务器；只有插件或存储错误、尚无对应传输记录时，顶部错误仍保留。

## 网络与插件

每个服务器独立显示接收/发送速率及本次运行累计量。连接状态读取现有连接快照，历史累计记录在断线后继续显示，不能把有传输记录等同于在线；缺少连接快照时标为待更新。

展开“插件流量”查看该服务器的各插件累计量和当前速率。刷新保持已展开内容、键盘焦点与服务器身份。网络读取失败时保留已有累计记录，速率与连接状态标为待更新；读取恢复后继续更新。

连接传输包含 SSH/SOCKS 封装，插件只统计文件内容、PTY 和网络隧道有效载荷。两种计量口径不同，不直接相减计算核心/未归属流量；页面的“统计说明”保留核心提供的口径说明。

右侧插件运行列表显示实际生命周期状态、更新错误和待重启事实；点击进入对应插件详情。启停与升级规则仍由[插件管理](plugins.md)定义。

## 暂停与导航

“暂停刷新”只冻结状态页当前显示的快照，不停止核心采集、远程连接、插件或后台操作。切换其他管理页再返回仍保留暂停与异常筛选；“恢复刷新”读取当前状态。重开应用后恢复默认显示。

“复制状态”复制状态页当前显示的快照，暂停时仍复制冻结的内容。应用信息入口打开现有“应用与数据”设置；日志入口使用[日志与重要消息](logs-messages.md)约定的全部来源查询。

页面复用三主题和管理台导航。窄窗口按单列排列服务器、插件与应用信息，长服务器名、地址和错误正文允许换行。

实现见 [status.ts](../../src/status.ts)、[status.css](../../src/status.css) 和 [console.ts](../../src/console.ts)。正式前端回归位于 [test-production-ui.mjs](../../scripts/test-production-ui.mjs)。

## 操作反馈

插件流量详情立即展开并局部揭示。连接和健康状态通过即时文案与状态样式显示；后台速率、累计量、更新时间和数字稳定呈现真实读数，不播放淡化或数值滚动效果。节奏和减少动态效果规则见[界面规范](../../DESIGN.md#动效)。
