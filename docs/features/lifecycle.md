# 关闭、退出与重启

关闭页面、标签组、工作区、窗口、退出应用、普通重启和安装更新后重启，共用核心关闭协调器。目标是先确认用户输入与任务结果，再结束资源，最后执行窗口或进程动作。

## 当前流程

| 阶段 | 行为 |
| --- | --- |
| 准备 | 保留目标范围，同步相关窗口的最后输入，收集页面、服务器表单与设置草稿；阻止该范围创建新业务资源 |
| 决定 | 展示未保存或忙碌项，按实际项目提供保存、放弃、取消；保存失败或结果未知保持问题可见 |
| 清理 | 决定成立后取消/释放视图、后台任务、流和端口，确认实际结束；保留已完成步骤 |
| 收尾 | 根据目标销毁窗口、退出、重启或调用官方更新安装；只有实际结果或交接确认后完成 |
| 失败 | 保留失败阶段、已停止资源和未完成项；重试继续原步骤，不重新执行已经成功的远端副作用 |

准备与决定期间可以取消；已经接受的写入或 RPC 仍需核对，不能收到取消请求就宣布恢复。进入资源清理后失败不会假装回到完整运行状态，也不承诺撤销远端已经执行的命令。

## 宿主输入与草稿

服务器资料、组件设置、下载网络以及每个插件的更新来源都参加宿主输入收集，包含隐藏页面。未改变的值不算草稿。输入法仍在组合时先等待自然提交，再收集并冻结宿主；8 秒内未结束则报告错误，不能自动视为放弃。准备中的宿主输入确认不先打开模态框打断组合。

保存按各自业务执行：服务器表单仍要求返回表单保存；其他宿主设置可以由关闭协调器保存。保存中阻止重复决定；部分成功后只保留剩余草稿，失败/冲突阻止退出，取消恢复编辑。明确放弃只清理草稿，不写入配置。组件实际业务与资源仍由核心按下述阶段完成。

## 不同目标

- 关闭单页只释放该页所属资源，不结束其他页面共用的 SSH 连接。
- 关闭工作区、窗口或应用汇总其实际所属页面和后台逻辑视图，按范围处理连接及创建中的任务。
- 关闭独立窗口只处理该窗口范围；需要保留的单例工具按核心规则返回仍有效的工作台。存在不支持交接的 UI v1 页面时明确提示。
- 主窗口退出收集所有窗口和宿主草稿，停止全部受管插件，再完成应用退出。
- 窗口异常消失时移除失效 Surface，尝试把页面及已同步状态恢复到可用工作台，保留业务 Context 和任务；取消该窗口尚未完成的连接尝试。主窗口失联不自动发起应用退出，尚未进入资源清理的关闭会取消，已经开始清理的操作继续核对原范围。尚未同步的输入不保证恢复。
- 更新重启先按同一规则结束业务，再由主线程执行官方安装。安装尝试互斥，失败保留包和停止事实，提供后续重试。

## 必须保持的规则

1. **读取状态没有生命周期副作用。** 快照、刷新和绘制不能重新创建正在关闭的后台 view。
2. **范围保留持续到父对象和最终动作结束。** 删除页面列表不等于工作区、窗口或应用已关闭。
3. **开始与提交都检查归属。** 迟到的连接、RPC、后台初始化和跨窗 mount 不能重新登记到已结束的目标。
4. **请求接受与实际结束分开。** 取消、dispose 或端口关闭的 ACK 不代表线程、句柄和监听已释放。
5. **未知结果不自动重放。** `ui.save` 接受后查询原结果；dispose 超时继续跟踪原调用，明确失败后才允许重试。
6. **输入确认覆盖全部参与者。** 无页面的窗口、隐藏后台 view、服务器表单和设置草稿也需要正确结束，不能只处理当前 iframe。

文件编辑页交接先冻结输入，再确认最终正文、必要元数据和显示状态；失败恢复源页输入，失效的 flush 回执不能完成后来的交接。保存沿原请求查询结果，未知结果不触发另一次提交。导出对话框与写入也参与任务清理，取消不等于对话框已经退出。

同步输入的机器期限为 45 秒，状态/保存操作预算为 125 秒；用户阅读和决定没有自动同意期限。资源清理与连接结束分别有有界等待，超时显示未完成状态，不能把超时当作释放成功。具体协议参数由[插件 API](../plugin-api.md)维护。

## 实现与回归入口

关闭操作与 view/resource 接纳共享状态锁，使范围保留与登记提交原子一致。跨进程等待、文件 IO 和原生动作在释放登记锁后执行；closing 原子标记只是派生缓存。

- 核心：[lifecycle.rs](../../src-tauri/src/lifecycle.rs)、[close.rs](../../src-tauri/src/lifecycle/close.rs)、[host.rs](../../src-tauri/src/lifecycle/host.rs)、[资源任务](../../src-tauri/src/resource_tasks.rs)、[进程监督](../../src-tauri/src/plugins/process.rs)。
- 宿主：[close.ts](../../src/close.ts)、[components.ts](../../src/components.ts)、[main.rs](../../src-tauri/src/main.rs)。
- 回归：[close_lifecycle.rs](../../src-tauri/tests/close_lifecycle.rs)、[lifecycle.rs](../../src-tauri/tests/lifecycle.rs)、[component_ui.rs](../../src-tauri/tests/component_ui.rs)、[原生组合](../../scripts/test-close-native.mjs)。覆盖取消保留、空组关闭、迟到请求、主窗口失联、未知 dispose 与更新收尾。
- 可信插件自行脱离受管进程组的程序和远端不可撤销副作用不承诺强制回滚。实际包验证方法见[开发指南](../development.md)。
