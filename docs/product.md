# SoDeck 产品定义

SoDeck 是面向运维人员的远程服务器桌面工具，将服务器连接、终端、文件、网络隧道和运行信息组织在一个工作台中。用户可以在多个服务器、标签组和独立窗口之间工作，复用同一服务器会话。

## 用户与当前能力

主要服务管理多台服务器的运维人员、开发运维人员和小型团队管理员。

| 任务 | 当前功能说明 |
| --- | --- |
| 维护资料、核对主机、通过 SSH/混合跳板连接 | [服务器与连接](features/connections.md) |
| 组织多服务器、多页、分屏与独立窗口 | [工作台](features/workbench.md) |
| 安装、启停及更新外置能力 | [插件管理](features/plugins.md)、[在线更新](features/updates.md) |
| 执行远端交互命令、查找终端输出 | [终端](features/terminal.md) |
| 浏览、传输、管理文件与编辑小文本 | [文件](features/files.md) |
| 建立本机 TCP 转发和 SOCKS5 入口 | [网络隧道](features/network-proxy.md) |
| 读取服务器运行指标与 Docker 容器状态 | [系统状态](features/system-status.md)、[Docker](features/docker.md) |
| 保存偏好、处理关闭和排查问题 | [设置](features/settings.md)、[生命周期](features/lifecycle.md)、[日志与消息](features/logs-messages.md) |

## 产品边界

- 核心负责桌面壳、插件生命周期、连接认证与会话、通用网络/文件/命令能力、日志、重要消息和稳定性。具体业务由独立插件实现。
- 核心安装包不包含业务插件；核心和插件各自在线更新、独立版本与分发。插件启用、关闭及已加载插件升级在重启后生效。
- 插件是可信扩展，不实现权限声明、逐项授权、审批或角色权限系统。核心 API 版本、参数和资源归属检查，以及远端 SSH 和操作系统权限仍然必要。
- 使用标准安装器和 GitHub Actions/Releases，不建设插件市场、插件签名信任链、复杂发布状态机或全组件同步发版门禁。核心更新保留官方 updater 必需的签名。
- SSH 是当前连接实现；业务插件依赖核心能力接口。后续协议扩展不能要求产品插件直接调用具体传输库。
- 客户端正式支持 Windows x86_64/ARM64、Linux x86_64/ARM64 和 Apple Silicon macOS ARM64。客户端平台支持与远端系统/工具兼容分别验证。

NetBird、完整 Docker 资源管理与 Compose 部署尚未成为当前产品能力。后续需求进入临时计划，实际交付后再更新对应功能说明。平台限制和数据保护边界按功能文档描述，不从产品方向推定已经实现。

## 交付标准

功能交付包含代码、相关回归、与当前实现一致的正式文档和必要的验证证据。创建、使用、失败、取消和释放等适用路径需有明确结果；未知操作结果必须可辨，不把请求已发出显示成已经成功。

五个目标的正式发布保留原生编译、打包与实际程序启动/退出验证；交叉编译和浏览器模拟不能替代。源码检查、普通业务、原生界面和设备专项分别报告范围。发布证据在核心版本说明或插件 CHANGELOG 中，文档组织和收束规则见[开发约定](../AGENTS.md)。
