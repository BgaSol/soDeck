# 文件树与紧凑工作台实施记录

本次按 [文件树设计](plan-file-tree.md) 实现，参考 `docs/reference-v2/files-panel.png` 和 `workbench-light.png`，保留现有远程业务。

## 改动

- 文件插件 0.2.0 的 `ui/tree.js` 独立管理导航；`view.js` 保留编辑、草稿和下载流程。多分支展开、目录优先排序、路径定位、懒加载/分页/错误重试、单击选择与双击打开、键盘及右键菜单均使用真实文件接口。
- 同一视图的展开路径、分页数量、选择和滚动状态保存在插件进程，移窗前 flush，重挂载按已保存页数恢复。导航状态最多 128 个展开路径、约 12 KiB；目录内容不通过控制 RPC。应用重启结束连接工作区，不承诺恢复上次进程的远程会话。
- 核心 0.6.1 用可发现的 `files.directoryCursors.v1` 扩展独立目录分页，旧插件的 `list/next` 保持可用。未完成游标每资源最多 32 个，超出释放最早打开项，失效时在对应分支刷新重试。
- 核心向 iframe 传递语义配色和系统浅深色状态。多巴胺使用奶油树背景、粉色面板标题、黄色选中、薄荷绿状态栏；终端 0.1.1 将状态移到底部。默认侧栏宽度为 280，保留用户已存的宽度。
- 修复拖动侧栏时首选宽度与实际 iframe 宽度不同步的问题；新增松手前检查实际宽度的回归。
