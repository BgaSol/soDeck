# 跨平台 SSH 客户端：功能设计

状态：首版应用已进入实现与验证，目标平台为 Windows、macOS、Linux。

## 架构（已确定）

采用 Tauri + React + TypeScript + Rust 的桌面客户端。React 负责界面，Rust 负责 SQLite、SSH、SFTP 和 Docker 查询，通过 Tauri 命令及事件通信，无需部署独立 HTTP 后端。终端显示采用 xterm.js；SSH/SFTP 使用 ssh2（libssh2），本地数据库使用 rusqlite。

## 当前范围

完成服务器的新增、查看、编辑、删除，以及名称/地址搜索和标签筛选。服务器使用平铺列表，每台可以配置多个标签。

工作区包含服务器终端、远程文件、Docker 自动检测与资源树、运行中容器的独立终端窗口。配置存储与真实 SSH 功能在首版中实现。

## 界面

主界面采用三栏：左侧当前会话的远程文件，中间终端，右侧 Docker 服务树。三栏属于同一个 Tab 会话，切换 Tab 同步切换三栏，后台组件保持挂载。中间占剩余宽度，左右栏分别可调整。初始约 23% / 51% / 26%，受最小与最大宽度约束；窄窗口仍保持横向三栏。主页面右上角提供“终端历史”和“本地日志”，底部保留全局传输任务。

视觉采用 Apple 风格的桌面工具层次：系统字体、中性灰背景、轻磨砂工具栏、蓝色选中态，终端保持深色。会话标签与左右文件、服务面板使用圆角独立区域；空状态、编辑、认证和指纹弹窗沿用同一套间距与控件样式。窗口沿用操作系统原生标题栏。

分隔条拖动直接跟随指针并保留抓取位置；获得键盘焦点后，左右方向键移动对应分隔线，分别调整文件栏和服务栏宽度。面板尺寸为每个会话单独保留。界面响应系统深浅主题、减少动态效果、减少透明度和提高对比度的偏好。

服务器列表仅在点击 Tab 栏“＋”后以模态窗口展示：

1. 标题“服务器”和“新增”按钮。
2. 搜索框，按名称或地址搜索，不区分大小写。
3. 标签筛选下拉框，默认“全部标签”，可选一个标签；搜索和标签筛选同时生效。
4. 平铺服务器列表。每行依次显示名称、地址与端口、标签；选中行有清晰的高亮。
5. 底部显示当前匹配数和总数。

服务器新增、编辑使用弹窗，不占用终端和目录区域。选择窗口底部提供“编辑”入口。保存后选中新服务器；筛选条件不匹配时清除筛选，使新服务器可见。取消新增返回原选中项，取消编辑恢复已保存内容。

中间：终端窗口。顶部显示当前服务器名称、地址与用户名，主体用于真实 SSH 终端输出与输入。

文件、终端和服务分别独立滚动；两条竖向分隔线调整左右宽度。

- 左侧：以 `/` 为根的服务器文件树。首次只读取并展开登录目录的祖先链，各层显示直属文件和目录，其他分支按需读取。支持输入路径定位、上级定位、局部刷新和目录展开/收起；显示名称和大小，通过 SFTP 获取真实内容。
- 右侧：服务树，当前只提供 Docker。Docker 根节点展示检测状态；可访问时提供“镜像”和“容器”两个可展开的子节点。

单击服务器只选中配置；双击或点击“连接”创建独立会话，不断开其他会话。服务器选择窗口的选中项与活动 Tab 分别管理。连接中保留选择窗口；认证/指纹窗口优先显示，完成后返回进度。成功后关闭选择窗口并聚焦新终端；失败显示原因并复用待连接 Tab 重试。取消未成功连接移除待连接 Tab 并返回原会话，忽略取消或旧尝试的迟到结果。没有会话或配置时不自动打开服务器窗口。

## 多 SSH 会话

- 一个 Tab 对应一个独立主 SSH 会话，以会话标识隔离终端、目录查询、Docker 查询与连接状态。
- Tab 栏“＋”只打开服务器选择窗口；双击列表或点击“连接”均创建新会话，同一服务器以 `服务器 · 2` 等编号区分。通过已有 Tab 切换会话。
- 所有会话组件在切换后保持挂载，后台 SSH 继续接收输出。每页保留终端输出/滚动位置、目录路径/选中文件、Docker 节点展开状态及左右栏宽度。
- 只有活动页自动刷新 Docker，切回时更新；已发出的异步查询结果仍回到原页，关闭或重新连接后丢弃旧结果。
- Tab 标记连接中、已连接、已断开和连接失败。断开后保留输出与页面，可手动重新连接。关闭 Tab 只结束对应主 SSH 会话，容器独立窗口不受影响。
- 新增、编辑和删除配置不关闭已有 Tab。已有连接继续使用原配置；手动重新连接使用最新保存的配置，配置已删除时说明原因。
- 会话 Tab、输出、浏览状态不写入 SQLite，不在重启后自动恢复连接。退出整个应用关闭所有连接。

### 标签排序与独立窗口

- 在主窗口拖动标签可调整顺序；拖到主窗口外可拆成独立 Tauri 窗口。将独立窗口标签拖到主窗口标签栏可按落点插入。右键菜单也提供拆出与移回操作，键盘可用 Alt+左右方向键排序。
- 移动的是原会话的窗口归属。Rust 持有 SSH PTY 与连接，在目标窗口准备好后交接输出；终端快照恢复历史、滚动位置和尺寸。文件目录、选中项、Docker 展开状态及左右栏宽度同时转移。新快照保存 `layout.fileWidth/serviceWidth`；旧快照的 `resourceWidth` 用作文件栏初始宽度，服务栏采用默认值，旧 `fileRatio` 不再使用。
- 移动失败或目标窗口未准备好时，恢复源窗口与输出。连接中、认证弹窗或指纹确认期间暂不移动。独立窗口关闭只结束其中的会话；主窗口仍可操作。

### 远程文件编辑与下载

- 文件树按逻辑路径缓存目录，另存软链接的真实路径。收起保留缓存，节点单独显示加载与读取错误；同目录请求去重，快速定位以最新目标为准。多会话隔离缓存，拆出/移回窗口保留展开、选中、当前目录和滚动位置。
- 主终端通过会话级 shell 集成上报实际工作目录，Rust 解析为结构化事件；提示符返回后文件树自动展开路径、加载目标内容并滚动定位，键盘焦点留在终端。失败的 `cd` 不改变目录，普通相对/绝对路径、`cd ..`、`cd ~`、`cd -` 均按实际结果处理。组合命令在整条命令返回提示符时同步；嵌套 SSH/容器及未适配的 shell 不映射到当前登录账号的 SFTP。
- 路径链批量读取共用一次 SSH/SFTP 连接，仅读取缺少的祖先和目标。可穿过但不可列出的祖先显示读取错误，仍尝试已知目标目录。手动文件树浏览与终端目录分别记录，下一次终端目录变化继续跟随。

- 文件列表双击或点击编辑按钮打开非模态原生编辑窗口。只允许不超过 1 MB 的 UTF-8 文本，拒绝二进制及无效编码。编辑器提供行号、语法高亮、查找、撤销重做和快捷保存。
- 使用独立 SFTP 连接读取与保存。保存时比较远端版本，发生冲突时可重新加载或明确覆盖；先写临时文件，再使用服务器支持的安全重命名替换原文件。保留文件权限、BOM 和换行格式。未保存内容关闭窗口或退出应用时给出提示。
- 文件或文件夹下载先选择本地目录，再选择同名处理方式：自动改名、覆盖或跳过。文件夹递归保留层级、隐藏文件和空目录；符号链接及特殊文件跳过并计数。任务显示扫描、传输、完成或失败状态，支持进度、取消和重试。下载任务在后台运行，不阻塞 SSH 终端。

## 服务器字段

| 字段         | 规则                                                    |
| ------------ | ------------------------------------------------------- |
| 名称         | 必填，用于识别服务器                                    |
| 地址         | 必填，支持 IPv4、IPv6 或域名；端口单独填写              |
| 端口         | 默认 22，整数，范围 1–65535                             |
| 用户名       | 可选，本步骤只保存配置                                  |
| 认证方式     | SSH Agent、密码或私钥文件                               |
| 密码         | 密码认证时可填写，直接存入本地 SQLite；清空后连接时输入 |
| 连接方式     | 直接连接或通过一台已有直连服务器；禁止自身引用及多层跳板 |
| 真实地址     | 可选，供其他服务器直连本机使用；作为直传目标时必填，支持 IP 或域名 |
| 直连端口     | 默认 22，范围 1–65535；独立于普通 SSH 连接端口 |
| 本地私钥路径 | 私钥认证时填写，私钥口令在连接时输入                    |
| 标签         | 可选、多个，例如“生产”“Web”“上海”                       |

标签输入支持选择已有标签，或输入新名称后按回车/点击添加。去除首尾空格，空标签不能添加，同一服务器的标签不重复；标签名称匹配不区分大小写。删除标签仅解除与当前服务器的关联。

## 交互细节

- 单击服务器只选中配置，双击创建独立会话 Tab；点击“编辑”打开配置弹窗，编辑后点击“保存”。
- 搜索无匹配时显示“没有匹配的服务器”，可清除搜索与标签筛选。
- 没有任何数据时显示“还没有服务器”，提供新增入口。
- 表单错误显示在对应字段附近；保存失败保留输入，提示原因。
- 有未保存修改时，切换服务器或新增之前提示保存、放弃或继续编辑。
- 删除前显示服务器名称与地址，明确确认。删除成功后选择下一条；没有剩余服务器时显示空状态。
- 修改服务器不改变其标识；名称排序，相同名称按地址、端口和标识稳定排序。
- 同一名称或地址可以对应不同连接配置，本步骤不限制为唯一。

## 本地文件数据库

使用 SQLite，数据库文件名 `servers.db`，存放于应用在各平台的用户数据目录。无需安装独立数据库服务。

| 表          | 内容                                                                                     |
| ----------- | ---------------------------------------------------------------------------------------- |
| servers     | id、name、host、port、username、auth_type、private_key、password、jump_server_id、created_at、updated_at |
| host_keys   | scope、host、port、fingerprint；前三列为联合主键，区分跳板网络 |
| tags        | id、name、normalized_name；normalized_name 唯一                                          |
| server_tags | server_id、tag_id；联合主键，防止重复关联                                                |

开启外键约束，删除服务器时级联删除标签关联。保存服务器和标签关联在同一个事务里完成。保留全局标签，列表筛选只展示仍被服务器使用的标签。

SSH 密码直接以明文保存在本地 SQLite；私钥文件不复制到数据库，私钥口令只在内存中使用。当前数据库结构直接包含密码字段。

保存密码后，新建 Tab 与重新连接自动使用。没有保存密码时先核对主机指纹、再输入密码，认证成功后保存到对应服务器；存储失败结束该次连接并提示原因。认证失败在同一次连接中允许两次更正。配置并发编辑时不覆盖新的密码或连接地址。前端只获得 hasSavedPassword；编辑提交 keep/set/clear，空输入默认保留已保存密码，清空需明确点击。清空或替换不影响既有连接快照。

## Docker 自动检测与树

首期按 Linux 远程服务器设计 Docker 检测，客户端仍跨平台。

1. SSH 连接成功后，在后台独立执行只读检测，检查当前用户能否找到 Docker CLI 和访问 Docker 引擎。检测不向主终端发送输入。
2. 用引擎实际响应判断是否可用，不依赖 systemctl，兼顾 rootless Docker 等运行方式。检测到的是当前账号可访问的引擎；Docker context 指向外部引擎时明确显示目标，避免误当成本机 Docker。
3. 状态区分未连接、检测中、运行中、未找到 Docker 命令、服务不可达、权限不足和检测失败。超时不能直接判断为“Docker 已停止”。
4. 可用时显示以下层级，展开节点加载列表：

```text
Docker · 运行中
├─ 镜像
│  ├─ mysql:8.0
│  └─ redis:7.2
└─ 容器
   ├─ mysql-prod · 运行中   [日志] [终端]
   ├─ redis-cache · 运行中  [日志] [终端]
   └─ backup-job · 已停止  [日志]
```

镜像显示仓库名与 tag，详情或提示展示镜像 ID；无 tag 的镜像以 ID 区分。容器显示名称和实际状态，包括运行、停止、暂停、重启等，按运行中优先排序。

连接时自动检测，提供手动刷新；当前活动 Tab 的服务树可见时，每 15 秒刷新状态与已展开列表。刷新不并发重叠，单次查询有超时。切换 Tab 后旧查询结果仍归属于原页，关闭或重新连接后丢弃旧结果。查询失败时说明原因，保留的旧列表标记为过期，并禁止依靠旧状态直接进入终端。

不自动启动 Docker 或容器，不自动 sudo，也不修改服务器权限。本阶段提供资源浏览与进入终端。

## 容器终端独立窗口

- 只有确实处于 running 且未暂停的容器提供“终端”入口；打开前再次核对容器状态。
- 点击后创建独立 Tauri 原生窗口，非模态，无主窗口遮罩。主终端、服务器切换、文件浏览继续可用，允许同时打开不同容器的窗口。
- 同一服务器、同一引擎、同一容器重复打开时，聚焦已有窗口。
- 窗口标题显示“服务器 / 容器名称”，内部会话绑定服务器 ID、引擎目标及完整容器 ID，不依赖当前主窗口选中项。容器同名重建后不会自动连接到新容器。
- 每个容器窗口使用独立 SSH 连接和 PTY，通过 Docker exec 进入容器。窗口输入、输出、尺寸变化和关闭都按会话 ID 隔离；主终端不被占用。
- 优先使用 /bin/bash，明确发现其不存在时尝试 /bin/sh。没有可用 shell 的镜像显示原因；权限、网络或容器状态错误不以切换 shell 掩盖。
- 关闭窗口只关闭对应 exec 会话及 SSH 连接，不停止、重启或删除容器。主窗口切换服务器、关闭该服务器的主终端，不主动关闭已打开的容器窗口。
- 容器停止、Docker 不可达或连接中断时保留已有输出，并显示会话结束或失败原因。重新进入需要用户操作和状态核对。
- 退出整个应用时关闭所有窗口与连接，并提示仍在使用的会话数量。

SQLite 保存服务器与标签配置；Docker 状态、镜像/容器清单属于运行时数据。服务器和容器终端输出保存在独立的 `terminal-history/` 本地档案，不作为服务器配置写入数据库。

### 终端历史

- 两类终端共用 Rust PTY 采集，位于应用目录协议解析之后、前端派发之前；迁移 attach/rollback 重放不再次入档。记录任务属于连接生命周期，不依赖历史界面是否打开。
- 来源由已验证连接身份区分，容器再绑定 Docker endpoint 和完整容器 ID。会话 ID 跨窗口迁移保持不变，重连新建；名称快照不包含认证凭据。历史记录位置使用会话 ID、事件序号和包内字节偏移，前端序号使用字符串。
- 原始输出、尺寸、目录、清理显示、记录缺口与会话结束事件先写分片 SQLite WAL；被动 vt100 解析器生成不可变文本版本、分隔与屏幕交互记录，FTS5 trigram 加速搜索。索引进度独立保存，可从原始事件恢复；短关键词可以取消扫描。原始字节是保真依据，阅读视图是终端语义的文本投影。
- 历史在同面板覆盖显示，保留实时 xterm 的尺寸和挂载状态；历史键盘焦点独立，不向远端发送搜索或复制输入。分隔不写入 PTY。“清理显示”作为有序事件执行，保留当前提示符行；备用屏幕期间跳过本地清理。
- 全局窗口可离线搜索所有保存会话，固定各会话的索引快照；支持上下文定位和独立只读屏幕回放。复制使用后端记录范围，文本与原始 JSONL 导出采用流式读取。
- 全局历史使用按日期分组的会话导航，正文突出来源、连接时间和记录状态；窄窗口及终端内使用会话选择器。搜索范围常驻，时间和大小写位于筛选浮层，导出格式集中在菜单。选中记录后显示复制、范围导出与“查看当时屏幕”；时间始终可见，正文保留原生文本选择。历史屏幕显示所属来源，返回时保留阅读位置并恢复触发按钮焦点。搜索结果用“查看前后记录”定位会话，新的输出只提示，不强制跳转。
- 默认保存全部收到的历史，不自动删除分片。前端分页与缓存有界，后台队列满或写盘失败时优先保持终端功能，明确提示记录不完整。正常退出等原始记录提交，异常退出只恢复已提交部分；未收到及未提交的数据不能声称完整。

## 文件语法高亮与容器日志

- 远端小文件使用 CodeMirror，按特殊文件名、扩展名和 shebang 自动识别语言；底部语言选择器可覆盖自动识别。语言包按需加载，切换仅重新配置语法解析，保留文本、光标、撤销记录和未保存状态。支持 Java、JS/TS/JSX/TSX、Python、Go、Rust、C/C++、JSON/JSONC、YAML、TOML、INI/Properties/.env、Shell、PowerShell、HTML/CSS/XML、SQL、Markdown、Dockerfile 和 Nginx。
- 日志为独立非模态窗口，以服务器地址、端口、用户、已确认主机指纹、引擎地址及完整容器 ID 标识来源，重复打开聚焦已有窗口。使用独立 SSH 连接，不申请 PTY；首次自动读取远端全部可用历史，成功后记录同步完成并衔接实时采集；旧存档自动补齐可用历史，失败或关闭后继续补取。运行中持续跟随，停止时每 5 秒检查并在启动后接续。
- Rust 按完整日志的时间戳、输出流和原始字节在落盘前去重，再原子持久化原文、解析记录和全文索引并通知前端。按每次采集的出现次数匹配，保留真实重复；没有有效时间戳的内容保守保存。网络拆包、长行和未完成尾部使用持久化暂存区，半行重开后续写，异常退出的暂存内容在离线打开时也可恢复。日志独立保存在应用数据目录 `logs/`，采用 SQLite WAL、FULL 同步和约 256 MiB 分片。分片轮换、关闭、退出及删除服务器配置都不删除存档。服务器配置数据库保持独立。
- 展示使用分页虚拟列表，缓存最多 5000 条或约 16 MiB，历史可反复读盘。移除显示行数、刷新视图、恢复/停止采集和全历史补取按钮；默认定位最新，向上/下滚动自动加载本地历史。向上滚动或搜索暂停自动滚动，保存继续；可跳到最新。换行支持动态高度，稳定序号保留阅读位置。
- 搜索覆盖全部本地存档，支持中文子串、大小写、时间范围及输出流筛选，FTS5 trigram 加速长关键词，短关键词分段扫描并可取消。结果范围固定在查询开始的序号，有新日志时显示“更新搜索结果”，支持查看上下文。
- 默认高亮等级、时间戳、JSON、异常及安全 ANSI 颜色；搜索命中优先显示。复杂解析在 Worker 中执行并缓存，日志始终按文本呈现。显示设置不改变原文；跨包 UTF-8 和未换行内容可持久化，超长行分片并折叠展示。
- 原文支持按序号范围复制及流式导出。主界面提供“本地日志”入口，服务器离线、容器删除或配置删除后仍可搜索、复制、导出。TTY 元数据随存档保存，非 TTY stderr 独立标记。
- 关闭日志窗口停止采集并提交已接收内容；退出应用等待采集结束。重新打开保留本地历史，重连使用最后时间戳回退一秒尝试补采，停采区间的覆盖不作完整保证；确认匹配的重放直接跳过，不再显示重放标记。临时断线按有上限的退避重试，认证、指纹、Docker 权限/驱动和写盘错误显示原因及“重试”。暂无日志、历史结束、驱动不支持、权限和写盘失败均显示对应状态。

## 验收

1. 能新增、修改、删除服务器，重新打开应用后已保存的数据仍存在。
2. 同一服务器能添加多个标签、选择已有标签、删除关联，且没有重复标签。
3. 搜索与标签筛选能组合使用，结果数正确。
4. 列表始终为平铺布局；活动 Tab 的终端、文件和 Docker 面板始终属于同一会话，右侧选中配置不改变活动会话。
5. 新增取消、编辑取消、删除确认和未保存修改提示行为正确。
6. SQLite 保存失败时不显示保存成功，输入内容不丢失。

7. 编辑弹窗可保存、取消和关闭；关闭有未保存内容的弹窗时提供明确选择。
8. 真实 SFTP 目录可进入子目录、返回上级、输入路径和刷新；每个新会话从起始目录加载，切回已有 Tab 保留其路径。

9. Docker 可用时，镜像和容器节点能展开；命令缺失、引擎不可达、权限不足和查询超时均有清晰状态。
10. 快速切换服务器时，不会把上一台服务器的 Docker 查询结果显示到当前树中。
11. 运行中容器可打开独立终端；停止、暂停或正在重启的容器不提供可用入口。
12. 容器窗口打开后主界面仍可操作，主界面切换服务器时窗口目标不变；同时打开的容器输入输出互不干扰。
13. 重复进入同一容器聚焦已有窗口，关闭容器窗口不停止容器，不关闭主终端。
14. 容器停止或没有可用 shell 时能说明原因，不无限重试，也不自动提权。

15. 多个主 SSH 连接可同时存在；同一服务器的额外连接输入输出独立，切换 Tab 不断开会话。
16. 后台输出持续接收，目录/文件选中项和 Docker 展开状态能恢复；异步结果不串页，后台页停止 Docker 定时刷新。
17. 关闭活动或后台 Tab、认证失败、远端退出和重新连接只影响相应会话；连接中关闭的页不会遗留 SSH 连接。
18. 标签拖动排序、拆出及拖回主窗口后，原 SSH 连接仍可交互，已有输出、目录、Docker 展开和面板尺寸保留；失败迁移恢复源会话。
19. 远端 UTF-8 小文件可在独立窗口读取、修改和保存；超限、二进制、冲突与未保存关闭均有明确处理。
20. 单文件与目录下载保留远端字节和目录结构；同名策略、进度、取消、失败重试及符号链接跳过均可验证。
21. Java、JSON、Shell 等语言自动高亮；手动切换语言不丢失内容、光标和撤销历史，保存到服务器的字节不受高亮影响。
22. 日志关闭后停止采集、存档永久保留，应用重启可离线阅读；大量历史可分页搜索，虚拟列表的 DOM 和内存有界；高亮、复制、导出、重连、UTF-8 及原始字节保真正常，主终端保持可操作。

交互原型独立保留用于设计参考。应用源码已接入 SQLite、SSH、SFTP、Docker CLI 查询及 Tauri 独立窗口；运行方式、当前范围和联调方法见项目 README。Windows 本机验证与其他平台 CI 验证应分别记录，不以跨平台架构代替实际平台测试。

## 单层跳板连接实现

- `servers.jump_server_id` 引用一条直连配置；数据库外键限制删除，保存校验同时检查当前记录及其引用方。新数据库直接采用此结构，不迁移旧库；旧开发库仅提供明确的备份并重建入口。
- 后端解析 `[B]` 或 `[A,B]` 不可变计划，`open_connection` 在网络工作前登记连接 ID，`answer_connection` 按窗口归属、challenge ID 与回复类型验收，`close_connection` 可随时取消。Ready 在目标 PTY 就绪后发出，随后才允许终端输入及业务请求。
- `connection.rs` 负责逐跳握手、指纹和认证，产生只留在 Rust 的已验证上下文；`ssh_transport.rs` 持有真实 socket、SSH Session 与转发线程；`terminal.rs` 负责 PTY、目录协议及迁移时输出冻结/回放。错误带失败跳点与阶段。
- A 上的 `direct-tcpip` 通道承载 B 的 SSH 数据；Unix 使用本地 socket pair，Windows 使用校验对端地址的临时回环连接，建立配对后关闭监听。B 的域名和端口原样交给 A。双向缓冲有上限，EAGAIN 重试保留同一份待写数据，关闭连接会停止并等待转发线程。
- 指纹 scope 由前置已验证路径生成，直连使用独立 scope。同一私网地址经不同 A 访问时不会共用指纹。业务上下文包含整条路径的凭据与指纹，SFTP、Docker、下载、文件编辑和日志各自创建完整连接并复核两端指纹。
- 资源身份由服务器配置 ID、地址、端口、用户和已验证主机指纹生成；名称、标签或密码变化不改变身份。文件编辑再绑定路径，容器和日志再绑定引擎地址及容器 ID。
- 取消会关闭关联 socket，覆盖 DNS 等待、SSH 握手、认证提示、转发和下载。系统 DNS 调用在独立线程中，迟到结果被丢弃。退出阻止新的会话与后台任务登记，取消活跃连接与下载，等待清理及日志刷新后退出。


## 跳板连接界面

按 apple-design skill 的分组、反馈和可取消原则整理连接界面。配置窗口分为服务器信息、连接路径、登录认证与标签；直连/跳板使用原生 radio 的分段选择，支持键盘方向键，切换回来保留已选跳板。跳板选择下展示本机 → 跳板 → 目标的路径预览。表单内容独立滚动，底部操作和保存错误始终可见。

认证及指纹弹窗统一显示服务器名称、地址、角色和跳点；密码输入打开后聚焦，指纹确认默认聚焦取消。指纹变化单独提示新旧记录，按钮明确标记更新。等待认证回复期间仍可取消或按 Esc 退出。已保存密码显示状态，清空和替换明确标记保存后生效。配置未保存时使用窗口内“继续编辑 / 放弃修改”，不依赖系统确认框。

界面使用现有系统字体、颜色和材质变量；支持深浅色、提高对比度、减少透明度与减少动态效果，未增加动画依赖。

## 文件写入与跨窗口服务器直传

交互保留新建文件/文件夹、选择文件上传、本地文件/目录拖入、两个服务器窗口之间拖动复制，并新增工具栏/右键的“复制到另一台服务器…”作为键盘入口。来源、目标目录、真实地址/端口、目标账号与已验证公钥在 Rust 草稿中固定。缺少真实地址时可在确认框填写，保存后替换草稿并再次确认；修改地址与启动同用草稿锁，重复启动返回原任务 ID。只更新服务器的直连字段，并通知主窗口刷新配置列表。

真实地址 `directHost` / `directPort` 只用于 A 发起的直连，不回退普通地址。客户端管理连接仍沿用现有跳板路径。直传使用 rsync over SSH，密码通过 sshpass 的私有输入描述符，或指定 A 上的私钥；严格校验已验证的 B 主机密钥。

实现分工：

- `desktop_drag.rs` 保留已修复的原生拖放入口和固定草稿，继续使用现有真实地址字段。
- 草稿由 Rust 判定 `upload / direct / serverCopy / serverMove`，前端使用返回的类型。只有 `direct` 读取真实地址及直传认证；原生拖拽在落下时读取 Shift 意图，跨服务器移动拒绝。
- `desktop_drag/clipboard.rs` 独立持有跨窗口内存剪贴板、版本与剪切任务预留。任务完成只更新相同版本，保留失败／跳过项目，旧任务不清空新剪贴板。
- `transfers/same_server.rs` 实现本机 SSH 路由上的 `cp`、同盘文件／完整目录改名和跨盘移动。目标提交与来源删除分开落盘，删除前核对来源设备号、inode、纳秒时间和摘要；仅删除完成文件及空目录。目录改名回复丢失后检查原位置、目标目录 inode，拒绝仅凭目录存在认定成功。
- `scheduler.rs` 一次性取得来源读／写与目标写路径，避免相反方向移动互等。独立目标文件可并行，动态改名扩展到冲突路径时失败并提示重试。编辑器保存、新建项目使用相同协调；正在打开或已打开的编辑文件阻止移动，移动期间阻止打开相关编辑器。
- `transfers/pipeline.rs` 统一扫描、同名映射、按目标文件系统暂存、校验和逐文件提交。源文件前后检查，覆盖前复查目标版本，合并目录保持原属性。
- `transfers/direct/` 检查 Linux、rsync/ssh/sshpass 等工具，从 A 验证 B 的身份与共享临时路径，以 NUL 分隔清单传入 rsync。短命令只记录工具退出结果，不再使用 supervisor、心跳或租约。
- `remote_write.rs` 提供非覆盖重命名与 OpenSSH 原子覆盖；`PendingCommit` 在提交前落盘。回复不确定时保留确切路径和可选摘要，不能凭文件大小认定成功。
- `transfers/task_store.rs` 使用独立 SQLite 保存任务、尝试和逐文件结果；`scheduler.rs` 协调重叠的最终路径。全局三项传输名额，不再有服务器级隔离队列。
- `transfers/recovery.rs` 分开核对执行、核对提交与清理。只清理已登记且已确认停止的私有目录。重试保留已提交结果，直传复用仅限已确认停止的暂存数据。
- `TransferPanel.tsx` 展示阶段、逻辑进度、提交计数、速度、预计时间、具体错误和临时位置；支持重新输入认证、重试未完成项、核对及独立清理。`FileOperationDialog.tsx` 显示本次真实地址、认证边界和可选摘要校验。

完整功能规则、限制与验收场景见 [文件传输设计 v2](file-transfer-design-v2.md)。测试使用隔离 OpenSSH/rsync 容器和浏览器 IPC 回归，不连接业务服务器。
