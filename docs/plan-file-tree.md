# 紧凑文件工作台

沿用旧版文件侧栏：路径栏、图标工具栏、名称/大小表头、目录树、简短状态栏。奶油底、粉色侧栏、黄色选中和薄荷绿状态区域从核心主题传入；浅色和深色同样可用。编辑器仍占中央 Tab。

## 本次可验收行为

- 目录箭头展开/折叠，多分支同时保留；单击选中，双击普通文件在中央打开。目录优先，同类按名称稳定排序，显示隐藏文件和符号链接。
- 路径输入定位文件或目录，展开父目录并滚动到目标。目录按需加载，各分支有独立的加载、错误重试和每页 100 项的“加载更多”。折叠、再次展开已加载分支不重复读目录。
- 上下键移动选择，左右键展开/折叠或选父子，Home/End、Enter 和 F5 可用。右键菜单及工具栏提供打开、下载、复制路径、刷新；下载期间才出现取消按钮。
- 同一工作区隐藏、切换服务器、重挂载和移窗保留展开路径、选中项、滚动位置。仅向插件进程保存导航元数据，不传输目录内容；展开状态有界。
- UTF-8 小文件编辑、BOM/换行保留、保存冲突检查、草稿恢复与下载继续可用。
- 侧栏窄宽度无横向溢出，长文件名省略，完整路径可查看；主题切换同步到插件。工作台面板标题与中央 Tab 统一密度。

## 边界

核心只扩展通用目录枚举：增加可选的独立游标及关闭游标操作，保留旧版 `list/next`。每个资源最多 32 个未完成的独立游标，超出时释放最早打开的游标；结束、刷新、关闭页面或会话失效时释放。不提前递归扫描服务器。

文件树、排序、路径定位、图标、菜单、导航状态由文件插件实现。挂载容量、跟随终端目录、上传/删除/重命名不属于本次。

验证覆盖真实 OpenSSH 的交错分页、目录树浏览和状态恢复，以及编辑/冲突/下载回归；用实际界面截图检查三种主题和窄侧栏。
