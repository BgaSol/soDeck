# 文件管理实施记录

2026-11-06。本次按核心 0.8.4、文件插件 0.3.0 独立发行，五目标原生包验证结果在发行流程结束后补记。功能范围见 [需求](plan-file-management.md)，分层及目标验收见 [编码方案](plan-file-management-coding.md)，发行说明见 [v0.8.4](releases/v0.8.4.md)。

## 已进入源码的行为

- 文件侧栏提供文件、文件夹上传，文件或多选下载；目录保留顶层名称、空目录、隐藏项、零字节和二进制内容。大文件正文使用 64 KiB 缓冲，不经过 iframe 或控制 RPC。
- 本地文件剪贴板读取、Tauri 原生拖入共用上传批次。Windows 为 CF_HDROP，macOS 为 NSPasteboard 文件 URL，Linux 为 GTK uri-list/gnome-copied-files。源始终保留。远程复制后系统粘贴、远程拖出到系统目录均没有实现。
- 多选、范围选择、已加载可见条目全选、Ctrl/Cmd+C/X/V、右键复制和剪切记录；同服务器内部指针拖动默认移动，Windows/Linux Ctrl、macOS Option 切换复制。拖出 iframe 不创建系统文件对象。
- 跨多个目标目录的多选状态下，上传、粘贴和新建会先确认目标目录；明确拖放到某个目录时使用该目录。异步粘贴期间焦点、连接或目标变化时拒绝继续。
- 新建空文件、文件夹、重命名、递归删除、同服务器复制与移动。移动优先 rename，明确失败时逐文件复制后校验、删除对应源；未知提交不自动重试或删除源。递归链接和特殊条目跳过并报告，直接删除或 rename 仅处理链接本身。
- 冲突提供覆盖、跳过、保留两份、改名、取消；类型冲突禁止覆盖。目录合并。非法本地名称可以改名或跳过。同类批量选择只保存在当前批次。
- 任务进程独立于页面轮询，最多两个活跃批次、每工作区一个，等待队列 64；结果写插件数据目录 JSONL，删除目录偏移写固定宽度索引，按逆序处理。有分页结果、取消、失败项重试、清理记录、字节进度和当前文件速率/剩余估计。
- 修改影响已打开编辑器时先走宿主保存/放弃/取消，处理后关闭编辑器；运行期间阻止再打开受影响路径。编辑器按钮和快捷键保存经插件协调。此轮采用关闭页面策略，未实现移动后自动重开新位置。
- 关闭等待通过短轮询进行；遇到待处理同名时明确要求返回处理，放弃关闭先请求取消并等待核心在途操作结束。隐藏或移窗继续保留批次。

## 实际接口与资源

核心增加 `files.operations.v1` / `files.localInputs.v1`，保持 API 主版本 1 和旧文件接口。文件插件缺能力时拒绝初始化并提示升级核心。没有新增生产依赖；仅为已有 windows-sys 增加系统剪贴板和 Shell feature。

本地入口实际使用既有文件 data 桥的 `input.chooseUpload/chooseDownload/clipboard/revision/drop/release/reveal`，没有单独引入设计示例中的 localFiles request 方法。选择器立即返回 waitingInput 操作票据，完成后 poll 取得 inputId。引用保存原生 PathBuf，绑定实例、view 和 Context；未领取 60 秒过期，下载引用允许在原选择父目录内改名。input.reveal 只打开登记的下载目标目录。已领取来源保留到任务记录释放；用户明确重试失败项时，可在同一工作区重新连接后将保留的本地来源绑定到新 Context，不恢复旧远程操作。

插件调用 files.request 的 `batch.begin/end` 和 `op.start/poll/result/lookup/cancel/release`。操作种类为 inspect/list/next/closeCursor/mkdir/createEmpty/copyFile/rename/removeFile/removeDirectory。每资源 16 个未释放操作、核心全局 128 个；单目录页最多 100 项、16 KiB，每资源最多 4 个批量遍历游标、闲置 120 秒过期。

复制使用同目录独占 .part 临时文件，提交前重新检查可观察源版本、目标 guard、解析后父目录。替换远程已有文件要求 posix-rename 扩展；本地不存在目标用同目录硬链接独占安装。取消、流式失败不截断原目标；提交应答丢失标为 unknown。回退到复制再删除的移动保存已提交目标 stamp，删除源和清理重试前同时核对源与目标，发现变化时保留源并报告失败。复制尝试保留普通文件修改时间及已有目标 POSIX 模式，不承诺所有者、ACL、扩展属性、目录时间及完整元数据克隆。

新选择集合使用 selection.begin/append/release 分帧最多 4096 项，不把所有路径塞进一条 UI 事件。任务快照和结果也分页。旧浏览目录游标与新任务游标独立。当前进程结果不承诺应用重启恢复，下次启动清理本插件生成的旧运行记录。

## 验证记录

本机为 Windows x86_64。已运行的源码检查覆盖 TypeScript、Rust 格式、核心及测试夹具编译、核心测试、文件插件单元、脚本测试和终端文本剪贴板回归。真实 OpenSSH 集成覆盖目录上传下载、空目录/隐藏/零字节/2 MiB 二进制、目标 guard、非法相对路径、重复请求、过期序号、创建/改名、同名保留两份、215 项目录复制及递归删除、失败项单独重试，以及 32 MiB 覆盖传输中取消后原件保留、临时文件清理。

## 未完成的交付验证与已知边界

- macOS ARM64、Linux x86_64/ARM64、Windows ARM64 原生编译和实际包互操作尚未执行。Windows 本地系统文件管理器复制后粘贴、原生拖入主/独立窗口、混合 DPI、页签拖动共存也仍需真实桌面验收；浏览器夹具不能替代。
- Linux 尚未明确验收 GNOME/KDE、X11/Wayland 组合；GTK 原生适配不能据此宣称所有 Linux 文件管理器兼容。
- 普通 SFTP 没有文件系统级条件替换/CAS。版本和父目录检查能发现可观察变化，不能消除检查与提交之间的全部外部竞态；同大小同秒修改可能不被 SFTP 属性 stamp 区分。源码未承诺事务目录复制。
- 断网后清理 .part 可能失败，任务显示归属名称及清理原因；没有远程后台垃圾回收器。底层本地网络文件系统卡住时也不能承诺即时取消。
- 尚未完整注入空间不足、权限拒绝、提交确认丢失、目录枚举中断、文件系统大小写/Unicode 规范化冲突等全部故障组合；不把当前通过场景扩大为这些已验证。
- 当前不提供暂停、断点续传、跨服务器复制、重启恢复或远程到系统剪贴板/拖出的功能。

五目标正式包验收完成前，本记录状态保持“源码实施，尚未发行”。
