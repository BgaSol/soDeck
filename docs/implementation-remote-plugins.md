# 真实终端与文件实施

本轮继续既有方案，交付真实业务插件，保留 `ui-example` 作为宿主测试。验收以隔离服务器上的实际 PTY、SFTP 读写和下载为准。

## 实施契约

- 核心持有会话、PTY、远端文件与本地文件。插件通过 API v1 的能力扩展调用，不取得凭据或 SSH 库对象。
- 每个资源绑定真实插件实例、逻辑 viewId 和创建时 Context。读取本地屏幕/草稿与连接在线检查分开；写入拒绝旧连接和旧 surface。关闭页面、插件退出、会话关闭时取消相关资源。
- 控制 RPC 保留 64 KiB 上限。正文和终端输出使用单独的有界视图数据桥；每块最多 16 KiB，序号确认后继续发送，慢消费者暂停读取。终端显示快照是插件生成的有界不透明数据，核心不解析 VT 内容。
- 终端先贯通 `terminal.open/close`、视图订阅、输入、尺寸、快照和结束。一个逻辑终端只打开一次 shell；跨窗重新挂载恢复快照和后续输出。
- 文件随后补齐 SFTP、目录与属性、UTF-8 小文本、保存冲突与提交状态、流式单文件下载。流量计量位于远程 IO，不计本地重放。
- 真实插件各自声明所需能力。缺少能力时提示升级，不用 API 主版本相同代替能力检查。

## 依赖

终端使用 `@xterm/xterm` 6.0.0、`@xterm/addon-fit` 0.11.0、`@xterm/addon-serialize` 0.14.0，均为 xterm.js 上游维护的 MIT 包；2026-11-05 查询稳定版本与近期发布。分别用于 VT 渲染、尺寸和显示快照，固定版本并提交锁文件。替代方案是自行维护 VT 解析器或使用较重的整套终端框架，当前不采用。运行资源全部在独立插件包内，不访问 CDN、不需要 Node 运行时。

SFTP 使用 `russh-sftp` 3.0.1（Apache-2.0，AspectUnk 上游维护，2026-11-05 核对源码与发布）。通过 AsyncRead/AsyncWrite 复用 russh 通道，不另起系统 ssh；采用原始分页 API，不一次性收集整个目录。协议包限制 256 KiB，正文每次 16 KiB。替代自写协议维护成本高，libssh2 会引入 C 依赖。锁文件固定解析结果。

## 实际代码与契约

| 落点 | 职责 |
| --- | --- |
| terminal.rs / streams.rs | PTY、所有权、有界重放与显示快照 |
| remote_files.rs | SFTP 句柄、分页目录、文件缓冲、版本校验、提交与流式下载 |
| network_metrics.rs | socket 运行累计和插件业务量、约 3 秒速率、十进制 u64 字符串 |
| component-data.ts | surface 独立原生正文桥，不进入普通 ui.event |
| crates/plugin-client | 连续接收及有界请求，避免嵌套 RPC 死锁 |
| plugins/terminal / plugins/files | 独立进程、版本、UI；终端渲染、文本规则、导航及视图元数据 |

控制使用 terminal.open/close 和 files.request 的 open/close/status/save，只传 ID、版本和状态。插件 iframe 直接经宿主 data bridge 调用原语；核心绑定真实 surface、view、实例和 Context。正文 staging 完成才替换之前完整的缓冲，断线仍可读取本地缓冲。插件解释 UTF-8、BOM 与换行，核心保存有界原始字节和远端版本。保存抓取当时完整的缓冲版本，后续输入继续保留，不误标已保存。

本轮没有加入原方案中的 localhost 插件数据管道：两个真实插件均由 iframe 消费正文，原生进程只持有元数据，核心与 iframe 的正文桥即可完成真实用例。将来原生插件确需处理正文时再增加对应传输，避免当前多出一个端口和正文副本。控制帧和普通 UI 事件上限保持不变。

移窗/关闭先请求声明 flush 的页面同步草稿。插件只保留一个在途快照和最新输入，避免为每次按键排队整份文档。断线/重连保留 iframe；旧 PTY 不能将输入发送到新会话。新会话保存文件仍校验原始摘要和目标。

保存需要 posix-rename@openssh.com；不支持时拒绝修改原文件。先校验原文，独占创建同目录临时文件，写入并恢复权限，再次校验，再原子替换。任意外部并发写入没有强 CAS；提交阶段失联提示结果未知。失联可能留下 .sodeck-*.tmp，清理尽力执行。

下载逐块写入本地同目录 .part 文件，校验并 flush 后替换，取消/失败不提前截断原件。关闭可等待保存完成或明确放弃取消，不做断点续传。

网络区分 socket 传输与插件有效载荷，在真实 IO 处累计，包含失败前已传字节；不计本地草稿、快照和重放。跨重连/插件退出保留本次运行累计。目录、协议封装和各跳网卡流量当前不能准确归属，allocationQuality=unavailable，不生成虚假的精确分摊。
