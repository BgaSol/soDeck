## 1. 目标和范围

用户已确认统一 AI 窗口，并明确“不需要本机执行命令”。继续设计聊天以外的能力及核心调用、远端命令执行；具体自动执行程度、模型服务、数据外发及首期实施范围尚未确认。

建议围绕问题建立对话与任务，选择单台服务器、分组、多台服务器或App为对象，通过公共证据分析原因、编排工具、验证结果。分组只帮助选择对象和整理历史，不为每组部署AI实例。

AI插件负责对话、模型适配、上下文、工具选择和任务编排；核心负责公开能力、身份/连接/凭据、资源执行生命周期与审计。保持P-13插件不互调；保持P-14不建立插件能力权限表或安装授权弹窗。AI任务执行策略约束模型发起的步骤，不改变其他插件调用核心的规则。

当前核实：T-016已提供观测查询、trace、快照、指标与证据；`remote.exec.v1`及`exec.start/read/cancel/close`支持远端通用执行，不是只读沙箱。T-020正在实施API5，未来AI插件基线以其实际交付核对。本轮不新增本机进程、PowerShell、cmd或本地shell执行能力，也不借远端工具绕过该排除项。

## 3. 窗口与设置建议

App作用域的统一非模态窗口，可调整大小，内部管理多对话；具体视图ID、尺寸、单例路由和多主窗口行为待细化。核心承载窗口，插件拥有内容。初步布局为对话列表、对话/执行步骤、按需展开的证据与结果详情。

使用已读取的apple-design技能：分析对象始终清楚、运行持续反馈、操作可中断，支持边看结论边操作终端；复用公共主题/组件和Windows键盘习惯，不因流式回答抢焦点。当前无视觉原型。

按P-62，模型服务/模型选择、上下文、保存偏好由AI插件声明设置；核心统一设置窗口提供接入，不硬编码AI业务。当前统一设置方案仍设计中，不将其承载接口描述为已实现。

## 4. 技术与交付

插件只经公开SDK读取和执行，不访问核心数据库或终端等插件私有状态。模型HTTP/流式传输、API key安全保存、App级插件窗口承载的实际缺口在代码方案阶段核实。不通过本机命令启动或管理模型；若用户配置已经运行的本地模型服务，仅连接其API。

尚无manifest、签名包、构建入口、模型请求或测试结果。包独立更新、最低核心版本和资源预算由后续代码方案确定；具体进度统一见T-022。
