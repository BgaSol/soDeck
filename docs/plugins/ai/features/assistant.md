## 1. 已确定与本稿建议

已确定：统一AI窗口；不需要本机命令执行。用户要求继续功能设计、讨论核心与系统指令调用，不代表已授权AI自动执行、模型外发或编码。

建议目标为问题→选范围→读取证据→分析/计划→调用工具→验证→报告。保留纯聊天方式。以下执行策略、模型设置、存储和关闭行为均为待讨论建议。

## 2. 对话之外的功能

| 功能 | 可观察行为 | 关键边界 |
| --- | --- | --- |
| 对话与任务管理 | 新建、命名、搜索、归档，查看执行中任务和历史报告 | 身份独立于服务器Tab；重启不自动续跑命令 |
| 对象范围 | 单服务器、分组、显式多服务器或App，显示名称与数量 | 任务开始解析为明确ID/修订，Tab切换/分组成员变化不静默扩展执行对象 |
| 证据与上下文 | 选择时间段、事件/trace、快照/指标及用户选定材料，结论链接证据 | 区分历史、过期和实时状态，明确缺项/截断，不默认全库发送给模型 |
| 计划与执行步骤 | 显示拟检查/修改的对象、工具/命令、输入、影响、状态和输出 | 计划、受理、实际完成分开；真实回执决定结果 |
| 停止与结果核对 | 停止生成、停止后续步骤、取消当前工具，分别展示状态 | 取消请求不等于远端已停止；部分执行/结果不明保留，写操作不盲目重试 |
| 验证与报告 | 再查实际状态、前后对比、证据引用、剩余问题 | 有可靠逆操作才提供恢复，不承诺任意命令可撤销 |
| 模型设置与用量 | 服务地址、模型、连接测试、当前模型/用量和任务预算 | 由AI插件声明设置，核心承载；价格未知不伪造精确费用 |
| 环境说明与常用流程 | 用户主动保存的环境说明、常用排查步骤 | 可查看/修改/删除，不默认静默建立长期记忆 |

窗口建议不遮罩主工作台；从服务器发起新对话可预填对象，已有对话保持原对象。采用apple-design的清楚范围、持续反馈、可中断与并行工作原则，工具详情紧邻步骤。键盘/输入法、缩放、主题、焦点和减少动态效果纳入原生验证。

## 3. 核心调用与远端执行

| 工具类型 | 示例 | 建议行为 |
| --- | --- | --- |
| 核心查询 | 服务器/连接状态、事件、操作链、快照和指标 | 在用户选定分析范围内自动查询，不逐项弹确认 |
| 核心操作 | 建立/结束AI自己的连接和执行任务；修改服务器配置、停止共享资源 | 已明确授权的任务步骤连续推进；改变配置或影响其他使用者的操作先呈现实际影响 |
| 远端诊断工具 | 进程、磁盘、服务状态、指定日志片段 | 预定义且输入/输出边界明确的诊断工具可按任务策略自动运行 |
| 远端变更工具 | 修改配置、重启服务、安装软件、批量变更 | 展示准确目标、命令/差异和影响；可一次接受一组具体步骤，超出原范围再决定 |
| 本机命令 | PowerShell、cmd、本机shell及本机进程启动 | 用户已明确排除，不设计此入口或绕行路径 |

建议“对话 / 分析 / 执行”三种任务方式：对话不主动获取环境数据；分析读取核心与运行选定的远端诊断工具；执行完成明确授权的操作计划。模式与默认值仍待用户决定，非既定产品规则。

AI通过有名称、参数结构、对象范围和效果说明的工具使用核心；不把任意模型文本直接转成任意RPC。核心继续现有身份/参数/代次/资源检查及逐次留痕，不引入插件权限管理。AI自己的任务范围约束必须实际执行，不能仅靠提示词；若后续方案要改变P-14，需单列确认。

远端通用exec可以产生副作用，不能仅凭模型声称“只读”或命令黑名单判断。预定义诊断工具与任意shell命令分开处理。每步明确远端服务器、账号和shell，不默认提升权限；优先使用独立非交互exec，不向用户当前PTY注入输入。交互式执行若需要，另定会话所有权。

多服务器任务展示准确列表与逐台结果；查询可有界并行，变更按计划逐步或分批。AI通过自己的核心租约/句柄执行，执行与输出预算、超时、取消及释放由核心管理，不自行建立SSH旁路。

## 4. 数据与任务生命周期

- 区分插件可读取的数据与发给模型的数据。配置模型服务后按任务最少取证，可查看所用服务和上下文范围。SSH密码/私钥/API key不进入模型上下文或公共日志；命令输出与选定材料须有长度与脱敏处理。
- 对话及工具输出可能包含正文，不能整体写入T-016日志。建议独立AI会话存储，并单独确定保存开关、期限、删除/加密；公共审计记录安全摘要、目标引用、操作ID、阶段和结果。完整命令展示必须与实际执行一致，哈希不能代替用户可读内容。
- 日志/文件/远端输出中的“执行命令”等文本作为数据，不能改变执行策略、增加目标或读取凭据；AI判断保留证据和不确定性，不改写核心事实。
- conversation/task/step关联核心trace/operation；模型响应、工具受理、实际结果、取消与复核分别记录。远端变更超时或断网先核对结果，不仅因缺回执重新执行。
- 建议收起窗口保持同次运行任务；明确关闭有活动任务时提供停止或显式保留，保留必须有重新进入和停止入口。App退出按P-11停止模型请求和自有资源；重启仅显示历史/中断，不自动重放。关闭行为、历史存储方案须在编码前最终确定。

## 5. 首期建议及待决项

建议首期包含统一窗口、多对话、对象范围、模型配置、核心观测查询、远端诊断工具、可查看/停止的步骤及证据报告，形成完整排查流程。明确授权的核心操作/远端变更是否同期纳入由最终执行策略决定。

待决：远端变更的自动执行程度、首期工具、模型服务与数据发送范围、会话保存/删除/加密、关闭任务语义。定时巡检、持续后台自动修复、通知和跨插件业务调用不默认纳入；本机执行已排除。

## 6. 初步验收与测试流程

这是需求讨论阶段候选流程，尚无测试入口，全部未运行。代码设计前按首期范围补齐精确契约、预算及异常矩阵。

环境：临时App数据与专门测试服务器；模型协议先由受控夹具验证，真实模型按最终配置和数据范围另测；窗口在Windows原生验证。

| 编号 | 准备与步骤 | 预期 |
| --- | --- | --- |
| AI-01 窗口/归属 | 两服务器/两个App窗口，开AI、切Tab、重复打开、收起恢复 | 统一窗口可定位，对话/任务对象不随焦点改变，终端仍可操作 |
| AI-02 固定范围 | 从分组启动后调整组成员或目标配置，再继续步骤 | 对象/修订变化可见，不静默扩展执行范围 |
| AI-03 证据解释 | 准备无关相邻故障、过期快照、partial证据，停止生产者后分析 | 证据有引用，缺口可见，无虚构根因或完整覆盖 |
| AI-04 工具/模式 | 各模式运行请求，返回未知工具、坏参数、范围外目标、本机命令 | 按最终策略调用；不提供本机执行，非法步骤无副作用，允许查询不重复打断 |
| AI-05 执行一致 | 展示变更计划，接受/取消；展示后更换目标/命令 | 未授权步骤不执行，实际内容与接受步骤一致，变化重新确定，正常步骤不重复 |
| AI-06 异常/停止 | 真实远端成功/非零退出/超时，派发后断网，再停止或恢复 | 终态真实，未知结果不写成功、不盲重试；取消可核对，资源释放 |
| AI-07 数据边界 | 参数/输出含测试秘密及指令样本，检查模型请求/持久介质 | 秘密不进模型/公共观测；证据不能触发范围外工具；正文按独立会话策略处理 |
| AI-08 并行/预算 | 多服务器、部分失败、大输出、慢模型及预算耗尽 | 逐台结果/截断/用量明确，其他插件和停止路径继续可用 |
| AI-09 生命周期 | 运行中收起/关闭/明确退出/强杀再启动 | 按最终策略保留或停止，无孤儿资源，重启不重放变更 |

清理：停止测试模型请求/任务、释放远端连接和流，恢复夹具注入，清除临时凭据与材料，仅保存脱敏结果。当前仅编辑文档，未请求模型或运行业务命令。
