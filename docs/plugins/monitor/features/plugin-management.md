## 1. 本次边界

覆盖Linux资源采样、短期趋势、后台定时器与连接观察。完整性、签名状态、启用存储和加载门禁由核心负责；本插件不实现自己的启用开关、签名审批或核心管理页。启停完整重启生效，停用不执行任何插件代码、保留包与业务配置；原功能与资源归属不改。

核对文件：plugins/monitor/src/worker.ts及采集/视图模块、manifest.json。预计不改业务实现、不提升manifest要求、不重编译现有有效包；用当前API6.1原包验证新核心兼容。如发现确有需要修复的生命周期缺陷，先记录落点及其属于已确认结果的依据，再改代码。新核心API6.2不意味着每个插件必须重编译。

## 2. 本插件测试流程

适用r1，关联公共AC-03/04/06/07。使用.qa/t028下的独立App数据与插件副本，已有隔离SSH/Linux环境；协议夹具与真实服务证据分别记录，不接触日常服务器。三项均在Windows原生宿主验证，必要计数用测试入口，不把UI按钮消失当成worker已停证据。

| 用例 | 准备与步骤 | 预期 |
| --- | --- | --- |
| MON-PM-01 | 隔离Linux监控正在采样；取消启用应用后观察，再退出重启 | 应用后当次采样继续；重启无监控worker/定时器/采集exec/面板，终端与文件正常 |
| MON-PM-02 | 监控保持启用，终端/文件停用；重启打开服务器并检查既有连接状态行为 | 监控按自身契约独立运行，无插件互调或为展示而重启终端；待连接/登录状态准确 |
| MON-PM-03 | 重新启用监控并重启，对Linux采样、断线、关闭工作区 | 保留设置，CPU/内存/磁盘/网络流程恢复；退出释放观察/采样；不增加Windows采集范围或长压测 |

共同清理：停止测试业务、关闭工作区并完整退出，核对本插件进程/核心租约/监听/订阅释放；恢复隔离副本启用状态，保留日志/版本/包哈希。不得通过清空用户配置模拟停用。实际结果统一写T-028实施记录，当前均未运行。
