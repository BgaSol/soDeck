## 1. 目标与范围

终端用自己的包声明“插件 › 终端”页面，核心不硬编码终端字段/校验/生效逻辑。打开设置不需要存在终端会话，不申请 SSH/PTY。沿用原数据与默认值；首期只有以下两个已存在的偏好，不顺便新增字体族、回滚行数等产品设置。

| 项目 | 声明、规则与生效 |
| --- | --- |
| 终端字号 | 整数 10–24，默认14；插件校验并保存。应用后同步本次运行所有终端视图，新终端用相同值；xterm 按实际可见尺寸 fit，必要时发送合法 resize，不重建 PTY。隐藏视图显示后再 fit，不发送0尺寸。这是对当前各视图局部字号更新的明确增量建议 |
| Shell 目录集成 | 布尔，默认开启；说明可能额外读取一次非交互 `.bashrc`。只影响后续新建/用户明确重连的会话；应用不热改当前 Shell、不发命令、不自动重连，保留既有支持矩阵 |

保留现有右键字号及状态栏集成快捷入口，立即保存语义继续有效；它们和设置页共用一份 provider/校验/修订/变更通知，不能出现两份权威值。恢复默认字号只改字号；设置页“恢复本页默认”同时改两项草稿。

## 2. 接口、数据及恢复

manifest 可选声明、快照/校验/提交/结果查询与feed接入按 F-CORE-028 §4。provider 在 worker 内持有权威值，设置中心/终端视图仅持有快照。继续使用原 `fontSize` / `shellIntegration` 存储数据；现有合法值不能因接入重置；缺失值用声明默认，非法旧值按原合法回退并显示修复说明，保存时再写入有效值。未知 key 保留。

两项提交需原子落盘并递增修订，持久化成功后才更新内存/发布通知；失败保留旧值。同一操作 ID 防重复提交；写成功后投递失败区分为同步未完成，可重新读取快照，不二次写盘。正常视图取消订阅/移窗重新订阅时取得最新修订；旧订阅迟到结果不能跨会话代次应用。记录仅含字段名/修订/结果。

只新增设置组需要的兼容数据元信息；不迁移终端会话、不恢复跨启动现场、不自动重建业务数据库，插件整体dataSchemaVersion仍为1。降级/升级保护按公共规格；独立更新测试用A包先接入字号、B包再接入已有Shell目录集成，实际验证新建/明确重连效果，不新增第三个产品偏好。

新版快捷入口改经公开settings.commit，由worker provider和原子偏好存储统一处理。移窗恢复屏幕/选择/滚动后以最新设置字号为准，旧Snapshot.fontSize不能覆盖新值；集成偏好在会话创建开始时捕获，创建途中不改变该次启动方式。删除focus补读轮询，使用有代次/修订的feed和补读恢复。

## 3. 验收与测试

- AC-01：无终端时也可读取/保存两项，原合法偏好保留；只读设置不发起 SSH。
- AC-02：字号跨视图/窗口同步且保持原 PTY；Shell 偏好只影响新建/明确重连。
- AC-03：快捷入口与设置草稿通过修订冲突协调；独立插件更新无需核心终端特判。

适用 r2。与 SET-01～10 共用独立 v2 数据/Windows 原生目录包；真实 Shell 行为用隔离 Bash/OpenSSH 测试服务。实际分层结果归 T-023，代码级验证补充见SCODE-02/03/07/09。每条清理关闭测试视图并退出，核对 PTY/worker/订阅释放；测试使用独立偏好和插件副本，证据保留在任务目录。
