## 2. 操作矩阵

| 操作 | 目标行为 |
| --- | --- |
| 鼠标拖动、双击、三击 | 沿用终端选择文本/词/行；选中不写剪贴板、不发远端输入 |
| Ctrl+C，有选区 | 只复制选区，不向 PTY 发送 `ETX`；成功后清除选区，随后无选区的 Ctrl+C 可中断；复制失败保留选区并提示 |
| Ctrl+C，无选区 | 活动终端收到一次 `ETX`，按远端程序处理；退出/断线态不发送 |
| Ctrl+Shift+C | 明确复制；有选区时与上条复制一致，无选区时不操作且不退化为中断 |
| Ctrl+V / Ctrl+Shift+V / Shift+Insert | 从核心剪贴板读取一次，将纯文本交给 xterm 的粘贴路径一次；不同时触发浏览器默认粘贴和自定义粘贴 |
| 终端正文右键 | 打开复制/粘贴及字号菜单，不自动写剪贴板或向远端粘贴；打开菜单不能提前清除选区 |
| 复制菜单项 | 无选区时禁用，有选区时执行上述同一复制动作；剪贴板写失败不谎报成功 |
| 粘贴菜单项 | 仅当前绑定可输入时可用；用户执行后才读取剪贴板，不在打开菜单时读取正文；空文本无操作，失败可重试 |
| Shift+F10 / 菜单键 | 聚焦终端时打开本地菜单，关闭后回到终端；Esc 只关闭菜单，不再发远端 Esc |
| 远端程序启用鼠标报告 | 保留远端普通鼠标/右键事件；Shift+右键或键盘菜单键打开本地菜单，Shift+拖动可本地选择；菜单已打开后事件不透传 |

仅处理精确的快捷键组合；IME 组合中不抢键，AltGr、普通 Ctrl+其他键、远端编辑器控制键继续走原路径。按住复制/粘贴组合键的自动重复不重复提交剪贴板操作；无选区中断保留终端自身行为。

粘贴保留 xterm 的换行及 bracketed paste 协议处理，不额外附加 Enter、不裁掉正文、不绕过原有输入队列。若剪贴板本身含换行，未开启 bracketed paste 的远端程序可能执行这些行；界面不声称“多行粘贴一定不会执行”。本次不新增多行确认、自动执行、敏感命令检测或命令历史功能。

## 3. 焦点、异步和失败

- 输入只属于发起时聚焦的终端。粘贴开始记录窗口、viewId、挂载代次和 PTY 代次；剪贴板返回时，若已切页/失焦/移窗/重连/关闭或进入不可输入状态，丢弃结果，绝不把旧正文送到新活动终端。回到原终端也不自动补发。
- 菜单粘贴先关闭菜单，再将焦点交还原终端，确认原绑定仍有效才提交。共享菜单的打开/关闭规则引用 F-CORE-008，不因终端是子 WebView 而遗漏外部点击/窗口失焦。
- 同一终端一次仅处理一个在途剪贴板读取；相同手势的重复事件合并/忽略。完成后下一次明确粘贴可正常执行；其他终端的显式操作独立，但各自仍需满足焦点检查。
- 复制在触发时获取选区快照；异步成功不能清除用户后来选出的另一段文本。读取/写入剪贴板失败在所属终端就地报告，可关闭；重试只由用户明确操作触发。
- 断线、结束、输入暂停时仍可选择并复制已显示内容，粘贴禁用并说明原因。已有结束占位无可恢复正文时不伪造文本。迁移冻结期间禁用新的剪贴板操作，旧结果失效。
- 沿用 256 KiB 输入队列上限及现有分块/背压；超限在提交前明确拒绝整次新输入。已经部分发送后遇到错误，显示“部分输入可能已发送，请核对远端状态”，不自动重放，也不把全部标为成功。
- 剪贴板数据不写入布局、迁移持久数据、调用日志或调试输出；核心保留调用来源、结果及长度摘要。此功能不引入插件授权弹窗。

## 4. apple-design 与界面

采用熟悉、即时反馈和用户可控的原则：常用键位可用，右键菜单列出快捷键，复制不弹阻塞成功框；仅失败需要明确提示。字号通过右键的缩小/增大/恢复默认沿用 10–24、默认 14；字号状态可见，改动后立即 fit，窗口移动不重置设置。主题/浮层/焦点及终端配色全部引用[独立主题定义](../../../standards/theme.md)，遵循 UI r8，不由终端另写一套颜色；颜色替换回归见 F-CORE-008 UX-10。

## 5. 验收与本功能测试流程

验收：IN-AC-01 复制与中断不混淆；IN-AC-02 粘贴一次、内容正确且不串目标；IN-AC-03 本地/远端菜单与 IME 不冲突；IN-AC-04 失败可处理、日志不泄露正文。

准备：Windows 原生宿主、隔离 Linux/OpenSSH、A/B 两终端及一独立终端，系统记事本作为外部剪贴板来源/目标；测试 ASCII、中文、emoji、CRLF/LF、多行、空文本和队列超限文本。使用测试输入接收器记录字节/次数，支持切换 bracketed paste 和鼠标报告；已建立的原生/浏览器/loopback 入口与环境缺口统一见 T-006 实施结果。仅使用无害标记，不对业务 shell 粘贴测试命令。

| 用例 | 步骤 | 预期及关联 |
| --- | --- | --- |
| IN-01 复制与中断 | 有选区 Ctrl+C 后粘到记事本；无选区 Ctrl+C；分别试 Ctrl+Shift+C 与菜单复制；空选区/复制失败 | 内容一致；复制不发 ETX，清除选区后中断只发一次；失败保留选区，无选区显式复制不发输入；IN-AC-01、04 |
| IN-02 四种粘贴路径 | 从记事本复制各类文本，分别用三种键位和菜单粘贴；观察字节/次数，测试 bracketed paste 开/关 | 同一手势一份内容；遵循终端协议换行，不额外回车；无双发、乱码；IN-AC-02 |
| IN-03 本地选择与菜单 | 拖选/双击/三击、右键、复制/禁用项；外部点击与 Esc；远端鼠标报告开启后普通/Shift 右键及 Shift 拖动 | 右键不直接粘贴、不丢选区；本地菜单不透传，远端鼠标按模式接收；IN-AC-01、03 |
| IN-04 异步与目标变化 | 延迟剪贴板读取，再切 A/B、焦点移到表单/其他 App、弹出/返回、重连、关闭源；随后放行旧读取 | 旧内容不进入任何新目标，未偷偷缓存待回焦再发送；下一次明确粘贴正常；IN-AC-02 |
| IN-05 重复与错误 | 快速重复/长按粘贴；空剪贴板、原生读写失败、队列满、发送部分失败 | 一个在途读取不双发；空文本无输入；超限不截断新提交；部分失败说明不确定范围且不重发；IN-AC-02、04 |
| IN-06 IME、失联与表单 | 中文组合中按键；输入远端控制键；断线/结束/冻结时复制粘贴；服务器表单 Ctrl+C/V | IME 一次提交，控制键不被全局抢走；断线可复制屏幕、不可粘贴；普通表单仍标准编辑；IN-AC-01、03 |
| IN-07 多窗与日志 | 主窗/工作区窗/独立窗重复 IN-01/02/04；菜单字号变更；检查日志与调用记录 | 焦点目标一致，字号/fit 正确；有调用归因和错误摘要，无正文；IN-AC-02、04 |

每项结束清空测试剪贴板和选区，停止输入接收器、还原鼠标/bracketed paste/故障设置，核对队列与 PTY。全组结束退出 App 并清理远端受控进程及临时数据；保留脱敏计数和截图。浏览器事件测试、loopback 字节验证、Windows 原生和 Linux shell 各记结果；不能互相代替。实际覆盖与未运行项见 [T-006 实施结果](../../../tasks/T-006-results.md)。
