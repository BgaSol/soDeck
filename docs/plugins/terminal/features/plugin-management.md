## 1. 本次边界

覆盖终端会话/PTY、工作区初始化、终端设置provider与目录上报。完整性、签名状态、启用存储和加载门禁由核心负责；本插件不实现自己的启用开关、签名审批或核心管理页。启停完整重启生效，停用不执行任何插件代码、保留包与业务配置；原功能与资源归属不改。

核对文件：plugins/terminal/src/worker.ts、terminal-view.tsx、settings.ts、manifest.json。预计不改业务实现、不提升manifest要求、不重编译现有有效包；用当前API6.1原包验证新核心兼容。如发现确有需要修复的生命周期缺陷，先记录落点及其属于已确认结果的依据，再改代码。新核心API6.2不意味着每个插件必须重编译。

## 2. 本插件测试流程

适用r1，关联公共AC-03/04/06/07。使用.qa/t028下的独立App数据与插件副本，已有隔离SSH/Linux环境；协议夹具与真实服务证据分别记录，不接触日常服务器。三项均在Windows原生宿主验证，必要计数用测试入口，不把UI按钮消失当成worker已停证据。

| 用例 | 准备与步骤 | 预期 |
| --- | --- | --- |
| TERM-PM-01 | 隔离SSH连接已有终端；取消启用并应用，继续输入，再完整退出重启并打开服务器 | 保存后当次PTY继续；重启无终端worker/Tab创建/PTY/目录上报；其他插件可用 |
| TERM-PM-02 | 停用后打开终端设置页，再勾选启用并重启，打开真实终端 | 停用页明确不可编辑，不调用provider；重新启用保留字号/Shell偏好、真实PTY可用，沿用Windows普通Shell规则 |
| TERM-PM-03 | 固定新核心哈希，用当前签名原包A及无签名测试新版B准备更新，重启后检查UI版本/worker行为 | 仅终端包更新，签名提示反映B；其余插件包不变；连接/关闭和资源释放正常 |

共同清理：停止测试业务、关闭工作区并完整退出，核对本插件进程/核心租约/监听/订阅释放；恢复隔离副本启用状态，保留日志/版本/包哈希。不得通过清空用户配置模拟停用。实际结果统一写T-028实施记录，当前均未运行。
