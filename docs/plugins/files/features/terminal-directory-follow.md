## 1. 目标与范围

让每服务器的一份文件树展示当前终端所在目录。一个服务器的多个终端分别维护 cwd；文件树无需为每个终端复制实例。支持终端选择改变和 shell 实际目录改变两类触发。

仅增加自动定位，不增加文件写入、反向 `cd`、命令注入、容器/二级 SSH 文件浏览。文件大小、挂载判断、字节路径和读权限继续遵循 F-FILES-001。

F-FILES-001 r4 的“切换终端 Tab 时目录树不变”在本功能的跟随模式下被覆盖；关闭跟随时保持原规则。新工作区尚未收到有效报告时，仍从 `/` 开始，不猜 home 或上一会话目录。

## 2. 操作与界面

| 用户操作 / 事件 | 推荐可观察行为 |
| --- | --- |
| 新建工作区 | 跟随默认开启；首终端正常创建。报告未到时显示“等待终端目录”，文件原有浏览可用 |
| 选中终端 A，再选 B | 立即切换来源标签；分别定位 A/B 的最新有效 cwd。B 未知时保留树，明确“尚未获取 B 的目录”，不借用 A 的值 |
| 当前终端 cwd 真正改变 | 取消过时自动定位，仅应用最新有效位置；展开祖先、选中目录、展开一层、保证可见。保留根 `/` 和其他已展开分支 |
| 当前 cwd 相同的重复报告 | 更新观测状态但不重选、不滚动、不重复刷新目录或挂载 |
| 后台终端 cwd 改变 | 只更新该终端的核心快照；切回时再定位，不改变当前树 |
| 手动浏览/输入路径 | 跟随仍开启；保持手动结果直到下一次实际 cwd 改变或明确切换终端。查看文件属性不会立刻被相同 cwd 报告拉回 |
| 关闭“跟随终端” | 停止自动定位、取消所属未完成自动读取；当前路径/选择保持。之后终端切换和 cd 均不移动树 |
| 点击“定位到终端目录” | 根据当前来源的一份有效报告定位一次；不改变跟随开关，不向终端注入命令 |
| 重新开启跟随 | 有有效来源时立即定位一次；没有时显示等待/不可用 |

工具栏提供可聚焦的“跟随终端”切换按钮（可访问名称和按下状态）及“定位到终端目录”按钮。靠近路径栏显示简短来源，例如“跟随：终端 2”，加载/手动浏览/不可用状态有文字表达；完整路径继续用已有路径框和详情，不增加重复的整行长路径。沿用主题令牌和线性图标，不用颜色单独传达状态。

应用 apple-design：触发后先更新来源和加载反馈，内容完成后再提交定位；同步不切换键盘焦点，保留用户输入。自动定位采用即时必要滚动，避免大幅平滑滚动；减少动态时仍可操作。Tab/Space 可操作开关，按钮有明确名称，不增加全局快捷键拦截。

正在编辑路径文本时，不覆盖草稿或光标；只记录最新待跟随目标。Enter 提交手动路径优先于此前积压的自动事件，下一次新目录变化/终端选择才跟随；取消编辑或未提交离开输入框时可应用最新目标。菜单/拖动进行中同样延后布局改变，操作结束合并一次，不能重复排队跳转。

## 3. 来源与生命周期

“当前终端”由核心的目录来源定义，不等同于每一刻的 DOM 焦点。点击文件侧栏、菜单、设置不会清空来源；选择同工作区另一个终端或进入它的独立窗口才改变来源。切换服务器仅使用该工作区上下文，不定位或展开后台服务器的树。

完整工作区移窗保持来源/开关/路径；单终端弹窗仍使用原工作区的一份文件树，来源标签明确弹窗终端名称，不新建文件面板。关闭来源终端后，若工作台明确激活另一终端则跟随它；否则保留树并显示无可跟随终端，不从后台随机选一个。

收起文件面板或工作区不可见时只保留最新目标，不发起文件读取；恢复可见且跟随开启时定位一次。关闭文件视图释放文件请求，终端报告继续属于其会话；重开视图恢复同工作区跟随开关并读取最新上下文。关闭工作区清空全部跟随现场；重启空台，新工作区默认开启，不恢复旧 cwd/来源/暂停状态。

开关是本工作区本次创建期间的操作状态，不作为首版跨启动偏好。已有隐藏文件等明确偏好保持原规则。

## 4. 异常、身份和异步

- 无报告/不支持 shell/执行中的命令：展示明确状态或“上次确认目录”；不把旧值写成已确认的当前值，不轮询终端执行 `pwd`。
- 路径与文件服务不在同一服务器/账号可见根/命名空间，或证据不足：停止自动定位并说明“终端目录无法映射到文件浏览”，保留手动浏览。
- 目录不存在/已删除/无权限：保留原选择、路径及内容，显示目标失败并提供重新定位；不把错误当空目录，不自动提权或改用终端身份。
- 逻辑路径经过符号链接时，优先定位已验证的实际目录，保留 shell 逻辑路径供查看；不修改原链接的挂载身份，不自动展开链接环。字节路径仍是操作身份，非 UTF-8 不经显示文本往返。
- 断线/重连/服务器配置改变：撤销旧报告，旧内容可标过期；等待新会话报告，不能因重新选中 Tab 复活旧 cwd。
- 自动跟随不触发认证；只使用现存可用连接及文件自己的租约。取消文件读取后暂停自动跟随，直至用户重新开启或明确单次定位，不用后续 prompt 绕过取消。
- 每次定位绑定工作区、来源会话代次、上下文修订和本地定位代次。A→B 快速切换后 A 的迟到结果不得覆盖 B；自动失败不撤销用户较新的手动选择。
- 默认隐藏文件过滤若挡住 cwd 路径中的节点，临时显示必要路径并标记隐藏，保持用户偏好不变；离开此路径后按原过滤显示。

不递归扫描、不每次 prompt 重取挂载表、不为自动跟随额外创建 SSH 连接；复用 F-FILES-001 / F-CORE-009 的分页、缓存、超时和取消预算。[代码方案 r1](../../../technical/terminal-directory-follow-implementation.md) §7/9 固定 worker FollowController、至多一个在途和一个最新目标、隐藏时退订/恢复重取及分段延迟测量。共享来源通过[通用状态通信](../../../technical/component-communication.md)获得，UI 不直接监听终端组件。

## 5. 验收与测试流程

AC-01：不同终端目录独立，选中哪个终端就跟随哪个；后台报告不抢树。
AC-02：成功目录变化自动定位，失败或相同目录报告不误跳；单向且不抢焦点。
AC-03：手动浏览、开关、单次定位、编辑文本规则一致，来源和未知状态可辨。
AC-04：隐藏/窗口移动/关闭/重连/重启按作用域隔离，迟到结果不串用。
AC-05：特殊路径与不可映射场景诚实降级，不改变认证、权限或既有文件/挂载语义。

适用 r2；实际脚本与分层结果见 T-010 结果记录。准备 Windows 原生双插件、隔离 Linux 的同服务器两个终端及第二服务器；真实 shell 测目录语义，模拟延迟/故障测竞态，浏览器仅测交互，结果统一写 T-010。原生 UI 覆盖两主题及 100/150/200% 系统 DPI，按 apple-design 核查即时反馈、可中断与焦点保持。

| DF-04 输入/可访问性 | 路径编辑、菜单或拖动中到达目录报告；键盘操作开关；原生两主题、减少动态及缩放 | 不覆盖草稿、不抢焦点；提交手动路径优先，状态不用颜色独自表达，控件可达。AC-02/03 |

每例关闭新建会话/工作区，核对新增监听、请求、句柄已释放，恢复故障和临时偏好；隔离目录/挂载按 T-008 环境规则先卸载再清理。既有真实文件树、终端输入及移窗作为回归，不能只测模拟目录事件。
