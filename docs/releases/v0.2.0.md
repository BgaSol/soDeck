# SoDeck v0.2.0

- 插件启用状态保存到本地，启用、关闭在重启后生效；启动自动加载已启用插件。
- 设置中的插件管理可检查独立 Release、下载新版，重启后切换；新版初始化失败恢复旧程序。
- 新增应用更新页：检查、下载和安装后重启；保留设置、插件记录、消息、日志与插件数据。
- 核心与插件使用独立标签和更新清单。新增 Linux AppImage 用于应用内升级，DEB 继续使用系统包管理器。

v0.1.1 需要手动安装一次本版本。旧插件记录默认关闭，启用并重启后开始自动加载；旧 Hello 可配置仓库 `BgaSol/soDeck`、标签前缀 `plugin-hello-v` 后获取更新。插件程序回退不回退数据迁移。Windows 和 macOS 的操作系统代码签名状态与之前一致。

核心与 Hello 独立发布，下载入口为 [SoDeck v0.2.0](https://github.com/BgaSol/soDeck/releases/tag/v0.2.0) 和 [Hello 0.1.1](https://github.com/BgaSol/soDeck/releases/tag/plugin-hello-v0.1.1)。

## 本机验证

Windows x86_64 已通过类型、Rust 格式、6 项发布脚本测试、17 项 Rust 测试、前端构建、Hello 独立打包及带更新签名的 NSIS 打包。release 程序烟测覆盖签名验证、篡改拒绝、插件初始化/停止/重载、日志消息保存，以及再次启动按启用配置自动加载。原生窗口检查了插件管理与应用更新页。

本机与 macOS 测试复现连接中断，原因是测试 HTTP 服务的已接受连接可能继承非阻塞模式，导致读取或大包写入不完整；已显式切回阻塞模式并设置超时。正式发行信息 GET 保留有限重试。另补充回归测试，覆盖待更新和回退程序保留用户修改的更新来源、AppImage 启动后工作目录变化，以及 macOS 更新附件命名。

已核对两份更新清单的组件、版本、五目标地址与实际 Release 附件匹配，核心签名和插件哈希齐全。上述 CI 验证不等价于五种系统上的交互式跨版本在线安装升级；v0.2.0 是首个带核心更新器的版本，仍需对后续正式版本继续执行该回归。核心更新包仅保存在当前进程内存中，退出后需重新下载；旧插件程序目录保留，不自动清理。
