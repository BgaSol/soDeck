# SoDeck 2.2.3

修复正式构建中右键菜单动画几乎看不出来的问题：CSS 压缩将 `160ms/100ms` 转成 `.16s/.1s` 后，原读取器把数值直接当毫秒，导致动画仅播放 `0.16ms/0.1ms`。共享读取入口现在兼容秒与毫秒，并在应用原有时长上限、默认值和减少动态效果规则前完成单位换算；入场恢复为 160ms、普通退出恢复为 100ms。

修复适用于核心内所有使用共享 Web Animations 的效果。独立插件下次使用本源码打包时包含相同修复，本次核心更新不会替换已有插件归档。没有修改菜单内容、连接/认证、路径继承、RPC、数据格式、依赖或动效幅度。行为见[服务器与连接](../features/connections.md#节点右键操作与经节点新增)，验收规则见[界面规范](../../DESIGN.md#动效)。

## 验证与发行

包来源为 [`43f5540`](https://github.com/BgaSol/soDeck/commit/43f554044721f3e1860407334833b45853325115)，[原始打包与独立验包](https://github.com/BgaSol/soDeck/actions/runs/45226783451)，[同源 Check](https://github.com/BgaSol/soDeck/actions/runs/45226734053)。
