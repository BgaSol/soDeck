# SoDeck 2.12.1

- 修复终端偶发保持拖拽预览色的问题。服务器标签、页面/组、面板和工具排序使用同一个手势生命周期；在插件正文内松手后，普通悬停不会误启动拖拽。
- 松手或取消立即停止预览、浮动标签和指针屏蔽，异步启动、页面同步及移动完成不再延长拖拽画面。准备失败清理核心记录，迟到预览和上一轮结束不会覆盖新操作。
- 固定松手位置后再确认目标几何；等待时移动鼠标不会改变落点。保留原会话、页面草稿、分屏与跨窗交接，不新增生产依赖或插件 API。

使用边界见[工作台](../features/workbench.md)，内部职责见[架构](../architecture.md)。

## 验证与发行

本地 Windows x86_64 通过类型/格式、234 项脚本、核心完整测试及新增 4 项拖拽状态单测、44 项交互、24 项真实核心工作区、布局与 21 项正式前端产物检查；`npm run build` 生成 MSI/NSIS。没有新增生产依赖。

[本地原生结果](v2.12.1-native.json)使用本轮 release 程序、WebView2、150% 缩放与系统注入指针，在隔离 OpenSSH 上验证 iframe 边缘松手/悬停、固定落点排序、重复取消、实际拖出/返回、原 PTY 继续输入、文件草稿、工具停靠、TCP 数据、后台恢复及关闭退出。夹具初次在布局动画和固定翻页按钮覆盖处误取命中位置；修正为动画后测量和标签可见交集，再完成整轮。该结果是本机 release 程序专项，不等于五平台安装包或物理输入设备验收。

包来源 [4340d1e](https://github.com/BgaSol/soDeck/commit/4340d1e8282452dfcb65eb712007ce0f56d1d3e4)。[源码 Check](https://github.com/BgaSol/soDeck/actions/runs/46028874961)的五平台核心/共享客户端、浏览器、Windows SSH、Linux 两架构网络及业务集成全部通过，netem 明确跳过。

[原始打包及实际包验收](https://github.com/BgaSol/soDeck/actions/runs/46028913009)一次通过 Windows x86_64/ARM64、Linux x86_64/ARM64 和 macOS ARM64 的原生构建、签名/资源、实际安装或解包启动、持久化重开及退出。五平台均使用原生架构程序；macOS bundle 与登录服务专项、Windows 两种安装范围检查也通过。[永久附件与原包验收报告](v2.12.1-assets.json)。

[五平台远程组合](https://github.com/BgaSol/soDeck/actions/runs/46031227899)固定上述核心原包和终端 0.12.1、文件 0.14.1、网络隧道 0.7.0 正式包，在原生 WebView/Channel 下验证 PTY、文件读写下载、TCP 转发、移窗、重开与退出；[固定输入与实际结果](v2.12.1-remote.json)。系统状态不在此组合入口，本机原生专项单独列明其版本。

正式版本 [SoDeck 2.12.1](https://github.com/BgaSol/soDeck/releases/tag/v2.12.1)使用同一批原包，共 16 个附件，设为仓库 Latest。草稿阶段仅更新发布说明及更新清单中的说明文字，程序、签名与已验收包的摘要保持一致，不重复打包。

发布后匿名读取全部 16 个公开附件，大小与 SHA-256 全部匹配；更新清单五平台 URL/签名与原候选一致，Latest 仍为 2.12.1。本机大文件下载先遇到超时及 ARM64 AppImage 连接中断，改为校验 Content-Range 的分段下载并按顺序计算完整摘要后通过；未修改或替换任何已发布附件。

本轮不执行 netem、真实注销登录、物理 IME/触控板/读屏和全部混合 DPI 多屏组合。其他平台的深度拖拽交互与设备范围继续保留在[原生验收计划](../plans/native-verification.md)，不能以基本包启动退出推定通过。业务插件沿用独立版本，不重新联动发行。
