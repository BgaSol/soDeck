# SoDeck 0.20.0

## 本机系统能力复用库绑定

文件剪贴板、本地目录与网页打开、Windows 窗口命中及 macOS 标题栏验证改用 windows-sys、objc2 Foundation/AppKit 和与 Tauri 匹配的 GTK3 绑定，删除手写系统函数声明、Objective-C 消息签名和鼠标测试的 P/Invoke。

保留现有用户入口、原生路径、来源变化检查和插件 API。修正 Linux 文件读取超时后可能突破底层请求上限的问题；过期请求保持槽位直到回调结束，应用退出前清理订阅和等待者。目录与 HTTP/HTTPS 网页通过系统默认应用打开，不再维护分平台启动命令。

增加独立原生文件剪贴板提供者和实际包验收，分别记录文件格式、来源变化与退出。测试工具不发行，核心安装包继续不包含业务插件。终端 0.7.0、文件 0.8.0、网络隧道 0.3.0、系统状态 0.4.0 沿用已发布版本。

## 验证与发行来源

五平台原生源码、构建、签名和实际包启动/退出均通过。独立提供者验证真实系统文件格式、中文/空格/特殊字符路径、文件→文本 revision 变化与退出；Linux 同时覆盖 URI-list 和 GNOME copied-files。实际包与终端 0.7.0、文件 0.8.0、网络隧道 0.3.0 的 SSH、PTY、SFTP 和网络组合验收均通过。本机另验证真实鼠标拖出/返回、PTY 接续、关闭取消及四插件资源释放。

## 限制

平台绑定不提供同步系统调用的硬取消；Linux 来源不响应时保持四个未返回请求的上限并返回忙，直到回调或退出收尾。Wayland 跨窗口拖动仍通过既有菜单操作替代。

本次不执行混合 DPI、多显示器、原生 Wayland、真实文件管理器人工复制、默认浏览器实际页面显示、netem 或历史版本升级专项。五平台原生包启动/退出和合成系统文件格式验收分别以本次结果为准。
