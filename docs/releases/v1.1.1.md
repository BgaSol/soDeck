# SoDeck 1.1.1

- 七个管理页统一移除重复的“管理台 / 页面名称”路径栏，内容直接从工具栏或页面内容开始；有活动工作区时，“返回工作台”位于管理导航底部。
- 顶部 SoDeck 恢复当前窗口最近访问的管理页；主窗口“＋”以“连接服务器”标明用途，进入完整服务器连接页。
- “查看插件”直接定位来源插件详情，“打开插件管理”进入插件列表。普通切页保留已选插件详情、原设置分区、日志筛选及暂停状态；返回工作台继续保留会话和草稿。
- 消息未读数和更新提示分别显示在对应管理导航入口，设置快捷入口专用于设置。

未新增生产依赖，插件版本与归档不变。操作规则见[工作台](../features/workbench.md#管理台导航)、[插件管理](../features/plugins.md)及[日志与重要消息](../features/logs-messages.md)。

## 验证与发行

待发布：本次源码提交、原始五平台打包运行、Release 与实际验收结果将在验证完成后记录于此。

本机 Windows x86_64 的界面改动已通过类型与核心格式检查、181 项工程脚本测试、七管理页和三窗口宽度的导航回归、三主题 token 校验，以及正式前端的 16 组集成验证。集成覆盖插件详情定位、设置分区恢复、日志暂停保持、来源草稿、消息选择、连接定位与工作台返回。变更后的本地 1.1.0 NSIS 包内程序通过启动、资料保存、重开和退出；这不代替本版 1.1.1 的五平台正式包验收。

本版范围为管理台界面与导航，不修改 SSH、插件业务或远程资源协议。真实系统 IME、读屏、触控板、多屏和混合 DPI 未做本轮新增专项；其他已有专项的历史通过不计入本次验证。
