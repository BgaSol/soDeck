# SoDeck 1.1.1

- 七个管理页统一移除重复的“管理台 / 页面名称”路径栏，内容直接从工具栏或页面内容开始；有活动工作区时，“返回工作台”位于管理导航底部。
- 顶部 SoDeck 恢复当前窗口最近访问的管理页；主窗口“＋”以“连接服务器”标明用途，进入完整服务器连接页。
- “查看插件”直接定位来源插件详情，“打开插件管理”进入插件列表。普通切页保留已选插件详情、原设置分区、日志筛选及暂停状态；返回工作台继续保留会话和草稿。
- 消息未读数和更新提示分别显示在对应管理导航入口，设置快捷入口专用于设置。

未新增生产依赖，插件版本与归档不变。操作规则见[工作台](../features/workbench.md#管理台导航)、[插件管理](../features/plugins.md)及[日志与重要消息](../features/logs-messages.md)。

## 验证与发行

发行：[SoDeck 1.1.1](https://github.com/BgaSol/soDeck/releases/tag/v1.1.1)，核心使用 GitHub Latest。包来源为 [db1f0dd0278a2dd5cfe282c49c7be19b113e7711](https://github.com/BgaSol/soDeck/commit/db1f0dd0278a2dd5cfe282c49c7be19b113e7711)，原始核心打包为 [43678657331](https://github.com/BgaSol/soDeck/actions/runs/43678657331)。Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 全部原生构建、签名和打包；实际 NSIS、DEB/AppImage、DMG/updater tar 内程序的启动、资料保存、重开和退出通过。沿用该次已验证包，不以版本标签重复构建；附件摘要、签名及五平台报告保存在[本版证据](v1.1.1-assets.json)。

发布后通过匿名 GitHub API 确认 Latest 指向 v1.1.1，并匿名下载全部 16 个公开附件，大小与 SHA-256 均与本轮已验证包及清单一致。公开更新清单的五平台地址、签名和发行说明与草稿核对结果一致。

[来源 Check 43678632171](https://github.com/BgaSol/soDeck/actions/runs/43678632171) 的全部选中检查通过，包含五平台核心/插件源码、类型与格式、181 项工程脚本、Linux 完整 UI/正式前端与终端输入/历史、Windows SSH 及普通文件、终端、网络、系统状态、Docker 和组件通信回归。netem 与 Windows 完整 UI 对照 skipped，不计为通过。发行记录的后续文档提交不改变包内程序，不替代原始包来源检查。

本机 Windows x86_64 的界面改动已通过类型与核心格式检查、181 项工程脚本测试、七管理页和三窗口宽度的导航回归、三主题 token 校验，以及正式前端的 16 组集成验证。集成覆盖插件详情定位、设置分区恢复、日志暂停保持、来源草稿、消息选择、连接定位与工作台返回。变更后的本地 1.1.0 NSIS 包内程序通过启动、资料保存、重开和退出；这不代替本版 1.1.1 的五平台正式包验收。

本版范围为管理台界面与导航，不修改 SSH、插件业务或远程资源协议。真实系统 IME、读屏、触控板、多屏和混合 DPI 未做本轮新增专项；其他已有专项的历史通过不计入本次验证。

仓库仍有 GLib 0.18.5 的 `VariantStrIter` 中危告警 [GHSA-wrw7-89jp-8q8g](https://github.com/advisories/GHSA-wrw7-89jp-8q8g)，修复版本为 0.20.0。本次管理台发行未升级这项既有传递依赖；五平台测试通过不代表该告警已消除。
