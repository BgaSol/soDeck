# SoDeck 2.11.0

- 核心新增通用用户激活页面通知，明确选中与界面恢复分别处理；键盘切换标签继续保留标签焦点。
- 终端 0.12.0、文件 0.14.0 与 Docker 0.13.1 独立提供通用目录发布与跟随，复用现有共享状态，不新增消息总线、核心 RPC、生产依赖或插件授权。

用户行为见[文件](../features/files.md)、[终端](../features/terminal.md)及 [Docker](../features/docker.md#compose-工作目录)，字段见[插件 API](../plugin-api.md#通用目录位置)。建议先更新核心，再更新所需插件并重启。文件插件保留原跟随开关值；旧终端不发布通用位置，新终端保留旧位置投影。

## 验证与发行

[包来源 Check](https://github.com/BgaSol/soDeck/actions/runs/45962067702) 的五平台核心/插件源码、浏览器、桌面和网络任务通过；原业务任务在新增 Compose 联调中使用了不匹配的终端 iframe 标题，聚合结果保留失败。[测试修正 d2e21e3](https://github.com/BgaSol/soDeck/commit/d2e21e3267bb18346cd3f2db92664a3cfcc57f79) 改为实际 View ID；[中间 Check](https://github.com/BgaSol/soDeck/actions/runs/45965057074)发现菜单中的完整索引保护生效。[完整索引等待 Check](https://github.com/BgaSol/soDeck/actions/runs/45968553391)进一步复现 Docker 后台索引已完成但树投影仍为加载中的缺陷。[修正 4e2db02](https://github.com/BgaSol/soDeck/commit/4e2db0284d200a93483d5166fd5db926fe7210ab)区分读取中检查与同代次完成接纳，补齐索引/对象失效及实际插件无导航投影回归，Docker 独立重新打包为 0.13.1；原 0.13.0 草稿未发布。[Docker 源码 Check](https://github.com/BgaSol/soDeck/actions/runs/45971753955) 的五平台 Docker 测试通过；该次业务在紧凑窗口的第二次菜单操作中移出视口。[测试 d2920d8](https://github.com/BgaSol/soDeck/commit/d2920d80a2d8d675ba4b401f844e7561dad885b8)固定双侧栏窗口与减少动画；[最终 Check](https://github.com/BgaSol/soDeck/actions/runs/45972978512) 的类型/格式/233 项脚本、完整浏览器和真实业务全部通过，原生源码、桌面、netem 未重新选择。核心、终端与文件产品源码和原包来源无差异。

本次仅重跑失败任务：包来源的 Linux ARM64 既有插件生命周期测试曾因卸载时响应超时失败，重跑通过；修正后业务任务首次在既有文件批量复制的 120 秒等待上超时，当时已完成 161 项、失败 0 项，文件复制步骤原样重跑通过，该次后续 Compose 等待条件失败见上段。未放宽断言或改动无关传输逻辑。原始失败与成功结果均保留在[附件证据](v2.11.0-assets.json)。
