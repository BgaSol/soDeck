# SoDeck 0.12.2

修复 macOS 左上角红、黄、绿原生窗口按钮在一体化标题栏中偏上的问题。按钮在 44px 标题栏中垂直居中，主窗口与拆出的工作区窗口复用同一份原生定位配置。

原因是原先只在网页中给系统按钮留出左侧空间，Overlay 原生标题栏仍采用默认按钮位置。原生定位参数经实际包坐标测量校准为 Y=20，目标按钮中心距顶部 22pt。

新增 macOS 配置回归与实际包 AppKit 几何检查，验证主窗口、拆出窗口、调整大小和持久资料重开后的按钮中心及横向留位。检查在包烟测入口运行，不增加生产依赖。

本次只发布核心 **0.12.2**，业务插件保持独立版本与分发。

真实设备的全屏动画、混合 DPI 桌面手势和交互式在线升级仍需专项验收。

## 验证与交付

本机通过 TypeScript/Rust 格式、正式前端构建、78 项脚本回归、常规核心测试和窗口配置回归。包来源提交的 Check 通过五平台原生核心测试、前端/脚本检查和完整 Windows 界面回归。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 的原生构建、updater 签名、实际包启动、持久资料重开和退出全部通过。Windows 检查系统安装登记，x86_64 另执行包内 OpenSSH 烟测；Linux 分别运行 DEB 解包程序和 AppImage；macOS 挂载 DMG 后运行实际程序。

macOS 实际包直接读取 AppKit 坐标：主窗口与拆出窗口的三个按钮中心均为 **22.00pt**，横向位置为 12/32/52pt，均在 86px 左侧留位内；调整到 900×650 逻辑尺寸及持久资料重开后重复检查通过。

本次未重复插件包组合、真实远端业务、netem、历史版本对的在线升级，以及真实设备的全屏动画和混合 DPI 手势专项。业务插件没有源码或版本变化，这些跳过项不计为本次通过。
