# SoDeck 2.1.0

每次启动时插件登记可正常读取且数量为 0，主窗口自动进入插件管理并按目录安装全部适用官方插件，完成后统一重启开始使用。关闭、运行失败、目录缺失和旧 API 的登记仍算已安装；损坏/不可读配置保留原文件与错误，不触发自动安装。

官方整轮与手动单项安装统一进入应用服务，复用原下载、校验、登记和重启机制。名单在本轮固定，首项成功后继续，单项失败保留原因并继续其他项；部分成功可先重启使用，重启后不自动补齐。切页/前端重载只读取状态，安装阶段不能穿插重启、更新或插件登记修改。启动加载先于默认安装，新登记在重启后加载。

核心安装包继续不含业务插件，核心与插件独立在线分发；不新增生产依赖、首次使用标记、插件权限或插件 API 变化。行为见[插件管理](../features/plugins.md)，实现职责见[架构](../architecture.md)。
