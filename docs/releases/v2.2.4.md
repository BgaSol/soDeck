# SoDeck 2.2.4

中央工作页面标签条改用中性面板背景，保留各主题当前页选中底；多巴胺绿色收束到创建按钮的悬停反馈。当前分屏复用已有底部分隔线显示焦点色，移除叠加的阴影线。标签顺序、关闭、创建、列表、拖动、分屏和移窗行为保持原样，不影响插件内部布局或数据。

终端顶部与阅读区域整理由终端 0.11.1 独立提供，详见[终端 CHANGELOG](../../plugins/terminal/CHANGELOG.md)；仅更新核心不会替换已安装插件。功能见[工作台](../features/workbench.md#多标签与查找)和[界面规范](../../DESIGN.md#workspace-tabs)。
