# SoDeck v0.7.0

新增独立“网络隧道”插件：固定 TCP 端口转发与 SOCKS5 CONNECT 代理，复用当前服务器的完整 SSH/SOCKS5 混合跳板路径，目标域名由最终远端服务器解析。规则按服务器保存，支持编辑、删除、立即启停、复制实际入口、连通性检查、连接数和本次运行带宽统计。侧栏默认右侧收起，编辑使用可滚动的宿主弹窗。

收起侧栏、切换工作区和移窗保持同一监听；断线、关闭工作区、插件退出及应用退出释放端口，重开后手动启动规则。本版不包含 HTTP 代理、UDP、反向转发和系统代理接管。

统一多巴胺、浅色与深色主题的页签、侧栏、菜单、描边和底栏。终端新增原生剪贴板及 Windows/Linux/macOS 快捷键处理：Windows 有选区时 Ctrl+C 复制、无选区时保留中断；Linux 使用 Ctrl+Shift+C/V，macOS 使用 Cmd+C/V；防止重复粘贴及切页、失焦、断线后的异步输入串到其他终端。文件路径与网络入口复制复用核心原生剪贴板。

核心安装包仍不包含业务插件。**先更新核心至 0.7.0，再在设置中安装或更新以下独立插件，并统一重启：**

- 终端 `0.1.2`：`plugin-terminal-v0.1.2`。
- 文件 `0.2.1`：`plugin-files-v0.2.1`。
- 网络隧道 `0.1.0`：`plugin-network-proxy-v0.1.0`。

核心通过兼容 API v1 的 capability 增加 `net.tcp.v1` 和 `ui.dialog.v1`；旧插件继续使用已有能力。插件启用、关闭及升级仍在重启后生效；单条网络规则启停立即生效。

本机 Windows x86_64 已通过类型/格式、11 项脚本测试、60 项 Rust 回归、实际 xterm 输入与剪贴板回归、网络协议和持久化测试，以及真实混合跳板、OpenSSH、终端与文件页面流程。实际核心 NSIS 包加载三个独立插件，验证原生 WebView、PTY、SFTP、TCP/SOCKS5、移窗、断线清理、重开和退出。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 五目标原生发行包构建与包内启动均已通过：[核心](https://github.com/BgaSol/soDeck/actions/runs/42024096338)、[终端](https://github.com/BgaSol/soDeck/actions/runs/42024104116)、[文件](https://github.com/BgaSol/soDeck/actions/runs/42024113121)、[网络隧道](https://github.com/BgaSol/soDeck/actions/runs/42024120130)。同一提交 `edb4284` 的 [实际包组合验收](https://github.com/BgaSol/soDeck/actions/runs/42026635490) 五目标全部通过，覆盖真实终端、SFTP、TCP/SOCKS5、移窗、断线清理、重开和退出。34 个发行附件的 SHA-256、四份更新清单的版本与五目标映射、插件归档清单与公共界面资源均已核对；核心五个更新包另已用仓库公钥验证 Ed25519 签名。

详细范围、验证和已知边界见 [网络实施记录](https://github.com/BgaSol/soDeck/blob/8115fdcd5bed4108021a729da605fbde77afc2af/docs/implementation-network.md) 与 [工作台实施记录](https://github.com/BgaSol/soDeck/blob/8115fdcd5bed4108021a729da605fbde77afc2af/docs/implementation-workbench-design.md)。Windows 重复验收曾发生一次插件初始化超时，相同产物串行重试通过，未修改产品超时来掩盖；仍待稳定复现定位。原生 CI 不替代真实设备上的复杂输入法、混合 DPI 手势和人工升级验收。

核心 [v0.7.0](https://github.com/BgaSol/soDeck/releases/tag/v0.7.0) 已于 2026-11-05 正式发布并设为 Latest；终端 0.1.2、文件 0.2.1、网络隧道 0.1.0 分别独立正式发布，保持非 Latest。四个标签均指向 `edb4284`。请先升级核心，再更新所用插件并重启。

发布后已匿名核对 Latest、四份更新清单及核心/三个插件的 Windows x86_64 下载附件，SHA-256 与发布前验证的附件一致。
