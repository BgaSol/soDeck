# SoDeck 1.2.3

状态页重构为总览台：整体健康优先，服务器网络改为接收/发送卡片，插件流量按需展开，插件运行与应用信息分别分组。新增异常筛选和暂停显示，页面切换保留暂停状态，刷新保持明细和焦点。历史传输记录明确显示实际连接状态；网络读取失败保留累计记录并标明速率待更新。

当前功能与操作见[状态总览](../features/status.md)。核心使用既有网络与连接接口。同期独立发布的 [Docker 0.5.1](https://github.com/BgaSol/soDeck/releases/tag/plugin-docker-v0.5.1) 简化侧栏标题和加载反馈，通过插件更新获取，启用中的升级在重启后生效；验收记录见其 [CHANGELOG](../../plugins/docker/CHANGELOG.md)。

## 发布与验证

本机 Windows x86_64 已通过类型与格式检查、183 项工程脚本、核心 Rust 测试、前端生产构建和 17 组正式前端集成验证。状态页回归覆盖健康与异常、历史断线标识、展开与焦点跨刷新、暂停期间继续采集、切页保留暂停、恢复当前速率、异常筛选、网络读取失败、空连接/插件，以及三主题和 390/736/1180px 布局；已查看实际截图。需要 SSH、插件发行包或公开下载的 ignored 核心用例未执行，不计为通过。

错误提示消失后曾稳定复现总览列错位：未固定身份的错误容器被复用为主布局，保留了旧的带身份操作。现固定错误与布局容器身份，并按区域区分重复操作；正式前端回归确认空状态仍只包含网络与次级两列，旧错误操作已移除。

独立复审还复现了暂停时应用读取失败、网络读取成功导致冻结流量变化的问题：暂停引用了壳层仍可能更新的同一份快照。现暂停时复制独立快照，集成回归覆盖该失败组合。

浅色主题的异常说明文字原对比度为 3.99:1。局部调整文字颜色后，浅色/深色/多巴胺主题分别达到 5.03:1、6.69:1 和 7.10:1；正式前端回归检查实际级联颜色均达到 4.5:1。独立复审确认冻结快照与对比度修复通过，最终 UI 可交付。
