# SoDeck 2.0.1

更新检查由应用级服务随核心启动，不再依赖插件/更新页、服务器目录或前端首次读取成功。主窗口服务器工作区可从顶部更新数量/待重启入口进入现有更新页。关闭的已安装插件仍按来源检查，官方目录继续按需加载。

自动、手动和逐项检查统一接纳与执行；缓存恢复先于用户操作。本轮结果明确决定每日检查或至少 15 分钟失败重试，初始化失败与中断不再误等一天，单项检查不推迟其他组件，取消关闭后继续调度。宿主一次读取更新条目和概览，统一显示规则，保留已有草稿、下载与重启流程。

不新增生产依赖，不改变插件 API 2.0、业务插件、更新清单、官方签名或安装方式。功能与职责见[在线更新](../features/updates.md)和[架构](../architecture.md)。

[固定提交 Check all](https://github.com/BgaSol/soDeck/actions/runs/45122228540)所有选中任务通过，涵盖五平台核心与六插件源码、格式/类型、211 项工程脚本、完整浏览器、Windows 桌面与 SSH、两架构网络及终端/文件/状态/Docker/MCP 普通业务集成。netem skipped。检查提交 [`f6bf202`](https://github.com/BgaSol/soDeck/commit/f6bf2027a25384784b180bf15375e8af9a75bc4b)相对原包只修正 `cfg(test)` 内的等待：原 Windows x64 回归在看到版本后固定等待 40ms，尚未确认批次收尾；改为等待真实批次完成。本轮原始 Check 因该测试失败且后续提交而取消，不计为通过；最终验证已固定提交，发布程序代码与原包一致，不重复构建。

本机按锁文件重装依赖后，类型/格式、211 项脚本、核心完整测试、新增服务故障回归、25 项交互测试、完整正式前端 18 组回归、Windows release 构建及隔离启动/资料重开/退出均通过。更新专项使用真实核心和回环发行服务，在初次快照与服务器目录读取失败、不访问插件或更新页的情况下，自动发现版本并从顶部进入已有结果；关闭取消后继续、禁用/手动检查、客户端初始化失败重试、部分失败、单项不推迟全量和缓存恢复均有回归。
