# SoDeck 2.5.2

- 修复 macOS 进入“设置 → 应用与数据”时可能崩溃的问题。
- macOS 登录项状态读取和修改统一回到 Tauri 主线程执行，避免 AppKit、NSBundle 与 Service Management 在后台线程调用。
- 其他平台的登录启动行为不变。

行为见[设置](../features/settings.md#登录后自动启动)，实现职责见[架构](../architecture.md)。

## 验证与发行

源码并入[2.6.0](v2.6.0.md)，此版本不另行发行。本机类型/格式、核心 Rust 回归和 218 项脚本测试通过；macOS 原生包专项将验证进入设置页的登录项读取回执。发布时补齐包来源、五平台原生验收、Release 与公开下载摘要。
