# SoDeck v0.9.2

修复工作台按钮在后台刷新时点击丢失、菜单焦点和迟到组件响应抢焦点的问题。更新说明支持 Markdown 标题、列表、引用、代码和表格，网页链接在系统默认浏览器打开。

核心菜单在缩窗和滚动时自动定位。文件剪贴板按标准文件 URL 处理路径和文件名，增加只读 `hasFiles` 状态供新版文件插件判断粘贴可用性。SSH/SOCKS5 协商使用固定版本协议库，保留已有认证、连接期限和正文转发行为。

终端 0.2.1、文件 0.4.1、网络隧道 0.2.1 各自独立更新菜单资源与业务修复；请先升级核心，再升级插件并重启。核心安装包仍不包含业务插件，API/UI 主版本保持 1。

发布流程记录版本、源码、平台和包摘要，支持复用已验证产物恢复草稿、按精确版本选择独立组件和重放固定验收输入。修复实际包终端验收的输入序号竞争，不改变普通输入的序号检查。

## 验证与交付边界

本版通过现有独立工作流生成五目标原生包，最新四组件的实际包组合验收全部通过。实际构建、公开分发与旧版升级结果统一记录在 [打包实施记录](https://github.com/BgaSol/soDeck/blob/8115fdcd5bed4108021a729da605fbde77afc2af/docs/implementation-packaging-workflows.md)。包内启动与真实跨版本升级分别记录；混合 DPI、首次聚焦点击及系统剪贴板互操作继续按对应专题验收。
