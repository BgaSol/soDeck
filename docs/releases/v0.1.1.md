# SoDeck v0.1.1

无独立标题栏的工作台与外置插件基础。核心安装包不包含插件，两个组件独立版本、独立构建与下载。

- 右上角查看应用状态、消息和设置；插件管理统一放在设置中。
- 从目录加载、卸载及重新加载插件；核心保存生命周期日志，接收插件日志与重要消息，保留消息已读状态。
- 支持跟随系统、浅色和深色主题。示例 Hello 插件无需额外语言运行时，Windows 运行库静态链接。

本机 Windows x86_64 另实际检查无独立标题栏、设置中的目录选择、Hello 运行、日志和消息界面；已安装核心的注册信息与界面版本为 v0.1.1。9 项 Rust 测试在五个原生目标通过，覆盖初始化超时、崩溃、忽略退出、进程树清理、输出洪水、日志限额/轮转和存储故障。

## 边界

SSH、终端、文件、Docker、NetBird、代理和插件业务视图在后续版本实现。v0.1.0 无插件和消息数据，本次升级不能证明业务数据跨版本迁移。Linux/macOS 尚无真实设备人工界面和系统覆盖升级验收。

Windows 安装包未配置商业代码签名，macOS 使用 ad-hoc 签名，系统可能提示来源。当前仓库为私有仓库，下载需要有访问权限的 GitHub 账号。
