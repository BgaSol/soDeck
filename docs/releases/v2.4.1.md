# SoDeck 2.4.1

- macOS 关闭主窗口后，没有其他工作窗口或必要交互时仅保留菜单栏入口，撤去 Dock 运行身份与 Cmd+Tab；从菜单栏或必要交互恢复窗口时重新回到普通应用身份。独立窗口及普通最小化、Cmd+H 保留正常系统入口。
- 统一菜单栏、连接聚焦、页面定位、布局恢复、必要对话框与异常重建的呈现链。跨窗迁移仍先显示再提交，失败只恢复本次未被新意图替代的显示；真正退出和重启继续使用现有关闭协调器。
- macOS 实际包验收读取系统激活策略，覆盖快速收起/恢复、迁移显示回滚、旧回执、模态保护和最后独立窗口结束，不以窗口隐藏或本地标记推定 Dock 策略成功。

功能与限制见[桌面行为](../features/settings.md#托盘与后台运行)。用户固定或系统最近使用的 Dock 快捷方式由 macOS 管理，应用不删除它们；后台会话仍受休眠、网络及系统结束会话影响。未新增依赖包，读取系统策略只启用现有 AppKit 依赖的声明能力。
