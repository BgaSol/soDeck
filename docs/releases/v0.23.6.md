# SoDeck 0.23.6

- 核心和插件检查更新先读取各自的轻量版本标签，再按需确认对应 Release，只读取最新公开正式发行的更新清单；历史 Release 数量和说明大小不再拖累更新检查。
- 标签没有公开 Release 时按版本顺序继续查下一标签。已找到正式 Release 后，缺清单、清单损坏或不兼容会明确报错，不继续选择旧版。
- 只有原始 GitHub API 确认的 404 才表示 Release 缺席；镜像 404、网络故障和其他 HTTP 错误保留重试与失败处理。

沿用现有仓库、组件版本、下载线路、官方核心签名、插件哈希及重启机制；未新增生产依赖。核心独立发行，插件由新版核心发现与更新，无需联动重发。

## 本地验证

类型与格式、142 项工程脚本、核心完整 Rust 套件、Windows x86_64 NSIS 构建及 14 项正式界面回归通过。历史 Release 响应超过 2 MiB 的缺陷在修复前稳定复现，修复后仅请求标签、单个 Release 与清单；28 项更新集成及 13 项网络集成覆盖顺延、错误边界、原站/镜像、取消和已有下载/重启流程。

未固定候选、无 GitHub token 的真实发现预检已在 Windows x86_64 核对当时公开的 0.23.5 清单，完整说明与本机包来源保留。
