未公开的草稿与其标签已清理；[永久候选证据](v1.8.0-assets.json)保留五份实际包报告、来源与附件摘要。Docker 0.6.0 保留其独立源码和原始包，配套正式核心 1.8.1；没有复用本候选核心程序或覆盖正式附件。
