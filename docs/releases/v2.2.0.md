# SoDeck 2.2.0

连接树支持节点右键快捷操作，以及“经此节点新增服务器”：直接带入从本机到所点位置的完整中转路径，只填写新目标资料即可保存。SSH 目标按连接状态显示连接、重连、前往工作台、取消或继续确认；中转 SSH、SOCKS5 与本机提供各自适用的操作。展开、折叠继续使用树箭头和键盘，不进入菜单。

连接目录统一完整节点身份、操作规则、执行入口和菜单生命周期。筛选只改变可见性，不再把共享前缀上的服务器目标改成仅中转；同一资料在不同位置新增时继承对应分支，不递归展开引用资料自己的路径，也不复制中转凭据。编辑、复制、草稿冲突、取消与保存沿用既有核心能力。

核心原子拒绝删除正在建连或取消收尾的目标，不再由删除间接取消连接。保留资料引用与工作区检查，不新增依赖、目录格式、插件 API 或权限流程。完整操作与限制见[服务器与连接](../features/connections.md#节点右键操作与经节点新增)。
