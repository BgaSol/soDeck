# SoDeck 1.4.0

- 服务器详情可“复制服务器…”：打开已预填的新增表单，地址自动全选，改 IP、名称等信息后再保存；取消不会留下副本。
- 登录密码和私钥口令默认沿用，持久/本次运行状态随原资料预填，也可替换或不沿用。秘密由核心在保存时复制，新旧服务器资料独立。
- 标签、端口、账号与多层中转引用沿用；目录冲突刷新保留输入，保存失败可修正重试。

功能与限制见[服务器与连接](https://github.com/BgaSol/soDeck/blob/main/docs/features/connections.md)，内部凭据来源约束见[架构](https://github.com/BgaSol/soDeck/blob/main/docs/architecture.md#连接与资源归属)。SOCKS5 独立复制保持原有行为；未新增生产依赖、目录迁移或插件 API 变化。

## 发布与验证

Windows x86_64 本机类型/格式、289 项核心测试（13 项专项忽略）、186 项工程脚本、18 组目录界面集成、17 组正式构建界面及 NSIS 安装包构建通过。新增回归覆盖持久与临时密码/私钥口令、目标保存状态、独立凭据、非法来源、版本冲突及写入失败；目录界面验证取消不落盘、地址全选、显式停止沿用、失败保留输入和多层路径。独立 OpenSSH 验证原连接及复制的私钥资料可执行命令；完整 SFTP 与文件界面复测通过。三主题/系统主题在 1100×720 与 720×480 的表单及认证状态实画面已检查，200 连续字符来源名称能够换行且保留关闭/保存操作。

包来源：[ae69369da286c154ca19b4ab3ce8c9dc638dc71d](https://github.com/BgaSol/soDeck/commit/ae69369da286c154ca19b4ab3ce8c9dc638dc71d)；[来源完整 Check](https://github.com/BgaSol/soDeck/actions/runs/44019053483)；[原始打包与实际包验收](https://github.com/BgaSol/soDeck/actions/runs/44019047296)。同一最终提交完整 Check（all，不含 netem）通过，覆盖五平台核心/插件源码、工程脚本、Linux 完整浏览器、Windows SSH、真实 SFTP/PTY、网络、系统状态、Docker 和组件通信。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 五平台原生构建、签名和实际包启动/资料保存/重开/退出通过。安装或解包 NSIS、DEB、DMG 后运行包内程序，AppImage 与 macOS updater tar 另验启动退出；更新包使用官方 updater 签名。正式附件沿用上述原始 run 生成的同一份草稿归档，15 个程序包/签名摘要与原生报告逐一匹配。

首次候选 [64d8149](https://github.com/BgaSol/soDeck/commit/64d814923571214f4b76cfe195dcfac28d4663b9) 的 [Check](https://github.com/BgaSol/soDeck/actions/runs/44016337063) 触发新增目录测试的异步删除竞态：trace 确认点击发生在删除回调返回前，被忙碌状态拦下。最终提交只补齐测试等待删除完成并注入 150 ms 延迟，生产代码与首次候选相同；18 组本机目录回归通过。此前还记录了既有 SFTP 215 文件批次超时与终端搜索夹具未取得未完成批次，本机完整 SFTP/文件界面、终端搜索/历史/基准复测均通过。旧候选虽已通过五平台包验收，仍在正式发布前删除草稿及标签，改用最终提交重新构建和完整验收，不覆盖任何正式版本。
