# SoDeck 1.4.0

- 服务器详情可“复制服务器…”：打开已预填的新增表单，地址自动全选，改 IP、名称等信息后再保存；取消不会留下副本。
- 登录密码和私钥口令默认沿用，持久/本次运行状态随原资料预填，也可替换或不沿用。秘密由核心在保存时复制，新旧服务器资料独立。
- 标签、端口、账号与多层中转引用沿用；目录冲突刷新保留输入，保存失败可修正重试。

功能与限制见[服务器与连接](../features/connections.md)，内部凭据来源约束见[架构](../architecture.md#连接与资源归属)。SOCKS5 独立复制保持原有行为；未新增生产依赖、目录迁移或插件 API 变化。

## 发布与验证

Windows x86_64 本机类型/格式、完整核心测试、186 项工程脚本和 18 组目录界面集成通过。新增回归覆盖持久与临时密码/私钥口令、目标保存状态、独立凭据、非法来源、版本冲突及写入失败；目录界面验证取消不落盘、地址全选、显式停止沿用、失败保留输入和多层路径。独立 OpenSSH 验证原连接及复制的私钥资料可执行命令。三主题/系统主题在 1100×720 与 720×480 的表单及认证状态实画面已检查，200 连续字符来源名称能够换行且保留关闭/保存操作。

五平台原生构建、签名及实际包启动/资料重开/退出由本次 Package SoDeck 运行验证；本文件在发布后补齐原始包来源、相关源码检查和永久附件证据，不以历史运行代替本次结果。

未执行 netem、正式旧版到本版线上升级及额外原生 IME/DPI/读屏/多屏设备专项；本轮界面截图和浏览器回归不替代这些专项。
