# SoDeck 0.22.1

核心新增 `terminal.history.v1`，配合终端插件 0.8.0 的 10 万行历史、正文搜索和常驻彩色预览。核心负责原始输出的临时恢复日志、分片显示检查点、小界面状态和资源清理；检索、颜色和预览仍由终端插件实现。

输出 ACK 与全量快照解耦，正常输出不再等待历史序列化。移窗继续复用原 PTY，恢复查询、阅读位置和有效当前命中；自然退出的终端输出保留到用户关闭。关闭终端或应用重启后不提供可检索档案。

每流恢复日志与显示检查点分别最多 128 MiB，日志及全部在途、已提交检查点共用 1 GiB 额度。写盘或额度失败保留实时输出并报告恢复状态；出现恢复缺口时明确失败，不重新执行命令补历史。核心 API 主版本保持 1，旧插件继续使用原有接口；终端 0.8.0 需要先升级核心。

本版也包含 main 中既有的标准 Base64 和 Tauri 官方 opener 接入，详细变更及历史候选来源见 [0.21.1 候选记录](v0.21.1.md)。核心不包含业务插件，文件插件 0.9.0 已独立发行。

Windows 默认应用不存在时，系统打开调用使用原生 Shell API 的禁止错误弹窗标志，及时把失败返回界面，避免系统修复提示阻塞调用。保留默认应用、完整路径、目标校验和正常目标的可见窗口；其他系统继续使用官方 opener，没有新增生产依赖。

## 发行与验证

正式发行：[SoDeck 0.22.1](https://github.com/BgaSol/soDeck/releases/tag/v0.22.1)，设为仓库 Latest。包来源：[`b44b15d72b738c01732e37643911b54e6764c48c`](https://github.com/BgaSol/soDeck/commit/b44b15d72b738c01732e37643911b54e6764c48c)；原始打包：[Package SoDeck #42812281189](https://github.com/BgaSol/soDeck/actions/runs/42812281189)。Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 五个原生目标的正式打包、updater 签名、实际程序启动、重开和退出均通过。

源码：[Check #42812275591](https://github.com/BgaSol/soDeck/actions/runs/42812275591) 验证同一提交的核心五平台源码、公共脚本和 Linux 完整 UI；未选择普通业务、Windows desktop 或 netem。新增终端能力及其他插件的源码与真实业务由 [Check #42807748154](https://github.com/BgaSol/soDeck/actions/runs/42807748154) 验证，五平台核心/插件源码、Windows 完整 UI/SSH、Linux 普通业务全部通过，netem 跳过。之后的 Windows 修复只修改核心，插件运行源码保持原包版本。

实际包组合：[Verify native remote plugins #42814180548，attempt 2](https://github.com/BgaSol/soDeck/actions/runs/42814180548/attempts/2)。使用本次核心、终端 0.8.0、正式文件 0.9.0 和网络隧道 0.3.1 的固定原包，五平台实际 SSH/PTY、SFTP 读写与下载、TCP/SOCKS5、原生移窗、资料重开及正常退出全部通过。首轮在核心打包结束前选择输入而失败，未启动业务；第二轮重跑同一输入，没有重建程序。

本次直接发布原草稿的 16 个核心附件；核对五平台更新地址及签名，并将上述五平台实际安装包和三个插件归档共 20 份包的大小、SHA-256 与对应 Release 附件逐项比对。终端和网络隧道另下载全部归档，核对实际字节、包清单与十份原生二进制架构。本机额外下载 Linux AppImage 时超时，没有把该额外下载计为通过；原始打包工作流的 AppImage 实际包验证继续保留。

本轮全部组件均已正式发行：终端 [0.8.0](https://github.com/BgaSol/soDeck/releases/tag/plugin-terminal-v0.8.0)、文件 [0.9.0](https://github.com/BgaSol/soDeck/releases/tag/plugin-files-v0.9.0)、网络隧道 [0.3.1](https://github.com/BgaSol/soDeck/releases/tag/plugin-network-proxy-v0.3.1)、Docker [0.1.2](https://github.com/BgaSol/soDeck/releases/tag/plugin-docker-v0.1.2)、系统状态 [0.4.1](https://github.com/BgaSol/soDeck/releases/tag/plugin-system-status-v0.4.1)。各插件原始来源与独立验证维护在自身 CHANGELOG；核心包不包含插件。

没有重复历史版本在线升级、系统 IME、多屏混合 DPI、长时间压力或用户生产服务器专项。五平台基本实际包流程不能替代这些专项；终端深度搜索/性能和文件编辑器深度界面的现有证据边界见下述实施记录。

首次核心候选 [42807875463](https://github.com/BgaSol/soDeck/actions/runs/42807875463) 在 Windows ARM64 的坏默认应用关联专项超时，metadata 失败；其他四个平台成功，不计为完整核心发行。原终端包仍来自功能提交，Windows 打开错误处理修复后，以 0.22.1 从新程序源码生成正式候选；0.22.0 的失败草稿保留原来源。

终端实现、性能样本、系统 IME、DPI、并行终端与原生交互的验证边界统一见 [终端实施记录](../implementation-terminal-search.md)。Windows 文件编辑器深度界面 CI 的调试端口限制见 [文件编辑器实施记录](../implementation-file-editor-search.md)。
