# SoDeck v0.8.2（候选撤回，未发布）

2026-11-05，按用户要求回退两级 Tab 加号方案并停止发行。GitHub Release 草稿已删除，公开 Latest 仍为 [v0.7.1](https://github.com/BgaSol/soDeck/releases/tag/v0.7.1)。版本标签保留作为候选构建记录，不移动或覆盖。

下列为已撤回候选的原计划。两级 Tab 新建交互已从当前代码撤销；底栏简化、凭据重试、公共主题、剪贴板和插件清理保留，未发布部分不因本记录成为正式发行。新的交互仅作为 [重新规划提案](../plan-tab-creation.md) 评审。

- 一级加号打开可搜索的服务器列表，按名称、账号、地址或分组查找；选择已有连接前往工作区，其他服务器使用原连接与认证流程。底部“新建服务器”打开资料表单，独立窗口也可唤起主窗口表单。连接成功后才创建工作区。
- 二级加号直接新建默认组件，初始优先终端。旁边下拉选择类型并立即创建，同时记为之后的默认类型；跨窗口与重启保留。默认插件不可用时回退，没有可创建页面时禁用。右侧列表按钮只负责切换已打开页面。
- 两级按钮沿用公共主题、图标和无常驻边框工具样式，标签溢出时加号仍可见。多巴胺继续使用统一粗结构线，菜单复用公共描边。
- 移除左下角连接弹出菜单及底栏“更多”入口，连接状态与地址仅作展示；断线后的“重新连接”保留。
- SSH 密码或私钥口令错误可重新补填。补填默认记住，只有整条路径认证成功后才保存勾选的各节点凭据；取消勾选仅用于本次连接。失败、取消、拒绝指纹、并发修改或写入失败不覆盖原凭据。密码和口令仍按既有规则明文保存在本机文件。

原候选计划只升级核心；终端 0.1.2、文件 0.2.1、网络隧道 0.1.0 继续独立分发，无需重新安装。Hello 和组件交互示例继续保持退役状态。

本机 Windows x86_64 已通过类型与格式检查、12 项脚本测试、70 项 Rust 回归、完整目录/工作区/连接/正式前端界面回归、独立 OpenSSH 互操作、NSIS 构建，以及实际安装程序的启动/退出、移窗、重开、原生 SSH、终端/SFTP/TCP/SOCKS5 组合验收。Rust 常规测试另有 5 项需独立 OpenSSH/实际插件环境的场景，由专用验收入口执行。发行前修复了原生移窗检查早于标签位置上报的时序，以及正式前端测试桥遗漏异步连接事件的问题；前两次候选版本均未正式发布。

候选历史：源码 `feeb60cdbe67e0fba1df2a7de3b9dd4adc06466a` 的 [核心打包](https://github.com/BgaSol/soDeck/actions/runs/42045149822) 五目标原生构建、实际包启动退出通过，16 个附件的大小、SHA-256、五目标更新地址及 Tauri updater 签名核对通过。[组合验收](https://github.com/BgaSol/soDeck/actions/runs/42050593985) 中 Linux x86_64/ARM64 与 Windows ARM64 通过；macOS ARM64 烟测出现重复回复问题，Windows x86_64 包内 SSH 超过 10 秒。组合验收没有全部通过，本轮不再修复或重试发行。上述结果不作为回退后代码的验收证明。

更新包使用 Tauri updater 签名；Windows 未配置商业代码签名，macOS 使用 ad-hoc 签名。原生 CI 不替代真实设备的复杂输入法、混合 DPI 手势和人工升级验收。
