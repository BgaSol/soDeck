# SoDeck 0.23.0

核心新增文件操作、编辑草稿与网络监听的结果确认能力，配合文件插件 0.10.0 和网络隧道插件 0.4.0 使用。核心 API 主版本保持 1，新增能力分别为 `files.operations.v2`、`files.editor.v1` 与 `net.listenerLifecycle.v1`。旧插件仍可加载，但其旧业务决策不属于新协议保证；新插件遇到缺少能力的核心会明确拒绝初始化。

- 文件批次保留原操作身份。回执丢失时暂停并查询原请求，结果记录持久化后再释放回执，避免把通信错误变成重复操作。
- 编辑器按接纳时的固定修订保存和导出。旧保存不清除后续输入，分片失败可恢复；提交回包丢失标为未知，成功提交后属性查询失败仍保留成功事实并阻止继续覆盖。
- 网络监听分开记录实际资源状态与查询错误。停止请求不是清理完成；监听、流和后台任务全部退出后才允许重新启动或删除规则。
- 关闭与跨窗交接检查原 Surface 身份，迟到的输入同步回执不能完成后来的交接。导出对话框和写入也参与资源清理。

## 功能边界与升级

文件插件 0.10.0 在当前后端禁用移动、剪切和改名，删除复制后删源的回退。复制、上传和下载保留源；提交未知时保留原身份和临时路径供核对，不自动重放或回滚。保存与明确覆盖仍面向没有其他写入者的普通文件操作，不提供原子版本比较或协同编辑。

网络隧道插件 0.4.0 将保存、启动、停止和删除分成独立动作。保存新规则不替换正在运行的监听；先停止并确认清理完成，再启动应用配置。

先升级核心并重启，再升级上述插件并重启。核心安装包仍不包含业务插件，各组件独立版本和更新。没有新增生产依赖、插件授权体系或发布状态机。

详细行为统一维护在[文件](../features/files.md)、[网络隧道](../features/network-proxy.md)、[生命周期](../features/lifecycle.md)与[插件 API](../plugin-api.md)。本轮也收敛了文档职责，完成的设计归入功能文档，临时计划仅保留未完成项，旧设计历史通过 Git 查询。

2026-11-11 正式发行：[SoDeck 0.23.0](https://github.com/BgaSol/soDeck/releases/tag/v0.23.0)，设为仓库 Latest。插件各自保留最新正式版本和更新清单；GitHub 同仓库只有一个 Latest 标记，核心包仍不包含插件。

包来源提交：[`fcf4f44`](https://github.com/BgaSol/soDeck/commit/fcf4f446d0e588c16da2187473c2c22a63d31f7c)。原始五平台打包：[Package SoDeck #42883684922](https://github.com/BgaSol/soDeck/actions/runs/42883684922)。Windows x86_64/ARM64、Linux x86_64/ARM64 和 macOS ARM64 均使用原生产物，构建、更新签名、实际包启动、资料重开与退出通过；Linux 分别验证 DEB 内程序和 AppImage，Windows 实际安装 NSIS 并核对系统安装登记，x86_64 另验包内 SSH。首轮 metadata 因新草稿查询暂时不可见失败，仅重跑该任务后完成同一草稿的 16 个附件，没有重建五个平台或改换来源。

首轮 [Check #42883621108](https://github.com/BgaSol/soDeck/actions/runs/42883621108) 的 Windows 流测试与旧文件菜单预期失败。补充提交 [`9519499`](https://github.com/BgaSol/soDeck/commit/9519499b9053cd613d566ebf23d2572636650b91) 仅修改这两个测试：用独立序号避免并行测试时间戳目录撞名，并检查当前不支持的剪切/改名入口保持禁用。其复验完成五平台核心/插件源码、完整 Linux 界面与正式前端、脚本、Windows SSH、普通网络及文件/终端/状态业务。Docker Engine/OpenSSH 通过，但 Docker UI 又暴露异步筛选未完成就断言旧行的测试竞态；[`1ec534d`](https://github.com/BgaSol/soDeck/commit/1ec534d085222033711096fe50313700d3c06d34) 只将测试改为等待目标行，80 ms 受控延迟复现与修正后回归通过。[Check #42885519869](https://github.com/BgaSol/soDeck/actions/runs/42885519869) 与 [Docker 补测 #42887442456](https://github.com/BgaSol/soDeck/actions/runs/42887442456) 合计完成上述范围及 Docker Engine/UI/归档补测；发行程序及其构建输入始终未变，仍使用原始打包来源。netem 按规则跳过。

[Verify native remote plugins #42885589898](https://github.com/BgaSol/soDeck/actions/runs/42885589898) 使用上述原始核心包、终端 0.8.1、文件 0.10.0 与网络隧道 0.4.0 的独立原包，五平台 PTY/原生显示、SFTP 读写下载、TCP/SOCKS5、移窗、工作区恢复、端口释放与退出全部通过。系统状态和 Docker 不在该组合入口内，它们的独立包证据见各自 CHANGELOG。

另下载五个插件的 25 份原归档，核对 GitHub/更新清单 SHA-256、包内版本、更新来源、UI 入口和原生二进制架构；下载的 Windows 文件、网络及 Docker 程序通过实际进程回归。核心五平台更新 URL、签名附件字节和清单一致，直接发布已验证草稿的同一份附件。

Windows 与 Linux 的默认应用专项确认 URL/目录各到达一次、非法目标拒绝和启动器失败。macOS 默认关联受保护，目标收据及 handler-only 部分明确 skipped；实际包交付、非法目标拒绝和退出通过，不将系统 open 成功算作目标收据通过。

未重复历史版本在线升级、netem、用户生产服务器、系统文件剪贴板、Windows 深度编辑器自动化与 IME/DPI 等设备专项。容量/写盘失败、提交期间取消或切换、原生长时间导出对话框等剩余组合继续见[剩余验收](../plans/operation-outcomes.md)，本次发布不代表该专项整体完成。
