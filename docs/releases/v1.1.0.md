# SoDeck 1.1.0

- 核心增加非交互命令流：复用已认证会话，分别捕获 stdout/stderr 原字节；支持有界尾部、固定阅读窗口、逐包确认和取消。关闭日志来源不会中断独立终端。
- 核心增加本机内容导出：用户在系统保存框选择目标，完整接收后才替换文件；取消、目标变化或提交失败保留原文件。迟到的保存框回调不恢复已超时任务，写入失败保留临时文件清理错误。
- 新能力按可选 API 声明，旧插件继续使用已有接口。Docker 日志界面、时间范围、搜索及缩略属于独立 Docker 插件；核心安装包仍不包含业务插件。
- 正文桥为每次原生调用使用独立 Channel，同一 Surface 的多条流、重新订阅和确认请求不再互相丢弃消息。

未新增生产依赖。接口与配额见[插件 API](../plugin-api.md)，业务行为见[Docker](../features/docker.md)。
