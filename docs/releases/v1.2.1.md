# SoDeck 1.2.1

- 管理台侧栏改为中性底色与轻分隔线，当前项用主题色和适度字重标明，移除常驻粗框；多巴胺的粉色集中于当前项。
- 统一图标、行高和留白。服务器连接、插件位于上方，消息、日志和状态另成一组，设置、更新靠底部；消息和更新数量采用紧凑角标。
- 保留图标与文字、可见键盘焦点，以及窄窗口横向导航。键盘顺序与显示顺序一致，悬停当前项仍保留选中底色。
- 连接树、会话、插件页面和草稿继续保留，返回工作台和最近管理页恢复行为沿用原有逻辑。

操作说明见[工作台](../features/workbench.md#管理台导航)。未新增生产依赖；插件版本与发行包不变。
