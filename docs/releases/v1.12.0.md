# SoDeck 1.12.0

- 核心新增 servers.write.v1：可信插件通过版本化接口新增、部分修改和删除保存的 SSH 节点，复用目录修订、校验、原子保存、工作区与路线引用检查。
- 目录修改集中为同一个提交入口，完整表单与 patch 共用 SSH 保存逻辑。keep 保留兼容凭据，更换地址、端口或账号不再隐式清除密码；认证类型或私钥路径变化仍按兼容性处理。SOCKS5、磁盘格式和凭据存储方式不变。
- Agent MCP 0.11.0 独立使用此能力，增加三个节点写工具；查询、连接、远程执行与证据流程保持原契约。无新增生产依赖。

行为见[服务器与连接](../features/connections.md)、[Agent MCP](../features/mcp.md#管理服务器节点)，字段见[插件 API](../plugin-api.md#服务器资料与连接)。
