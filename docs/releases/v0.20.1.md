# SoDeck 0.20.1

## Docker 图标与推荐位置

宿主支持标准 Docker 鲸鱼标志和容器图标，修正 Docker 入口、插件列表、组件设置及容器详情显示通用信息图标的问题。图标跟随工作台主题，无需额外图片下载。

配套独立发布 Docker 0.1.1，默认固定在右侧工具栏，点击才展开；日志页使用现有日志图标。已有布局偏好保留，在 Docker 面板菜单选择“恢复推荐布局”可将入口和面板返回右侧。核心安装包继续不包含业务插件。

## 本地添加插件的焦点恢复

修正本地添加插件与后台刷新重叠时详情出现后焦点留在页面空白的问题，恢复键盘操作入口。此修正此前已进入 main，本版首次随核心安装包交付。

## 验证与发行来源

本机类型/格式、正式前端构建、95 项脚本测试、211 项核心测试（13 项外部环境专项 ignored）、Windows x86_64 Docker 独立包及包内进程退出、Docker UI 和真实核心工作台右侧/推荐恢复通过。核心测试首次有一项夹具初始化超时，串行全量复跑通过。

本次提交的 GitHub Check 全部通过：五平台核心与插件源码、公共前端/脚本、Windows 完整界面与 SSH、Linux 普通网络，以及 x86_64 文件、终端、系统状态、真实 Docker Engine/OpenSSH 与组件协作。netem 按范围跳过。

五平台核心分别原生构建、签名，安装或解包实际程序并验证启动、资料重开和退出；Linux 同时验证 DEB 与 AppImage，Windows x86_64 另验证包内 SSH。Docker 使用自身独立版本、工作流和更新清单，其五平台归档与包内进程全部通过。
