# SoDeck v0.9.1

修复工作台按钮在后台刷新时点击丢失、菜单焦点和迟到组件响应抢焦点的问题。更新说明支持 Markdown 标题、列表、引用、代码和表格，网页链接在系统默认浏览器打开。

核心文件剪贴板接口增加只读 `hasFiles` 状态，供新版文件插件判断粘贴可用性。文件菜单改进由文件插件独立更新提供；核心安装包仍不包含业务插件。核心 API/UI 主版本保持 1。

核心打包先检查版本、标签与发布说明，五目标原生构建及实际包验证通过后才收集产物，再集中准备更新清单和 Release 草稿。产物记录提交、版本、平台及 SHA-256；发布收尾可复用同次运行的已验证 Artifact 重试。

## 验证与边界

本版用于打包工作流第一批验证，目前只准备草稿，尚未正式发布。实际命令、原生工作流结果、产物核对及未完成项目统一记录在 [打包实施记录](../implementation-packaging-workflows.md)。原生包启动和签名验证不等同于五平台从旧版到新版的实际安装升级；混合 DPI、首次聚焦点击与系统文件剪贴板互操作仍需设备验收。
