# SoDeck v0.5.0 — 混合跳板连接与插件组件宿主

本版把服务器档案接入真实 SSH 会话，并提供外置插件的组件 UI 基础。核心安装包仍不包含业务插件；终端、文件读写、下载和网络转发业务尚未提供。

## 功能变化

- 服务器详情可建立真实连接，支持按保存顺序串联任意混合的 SSH / SOCKS5 跳板；引用节点不递归展开自己的路径。只有第一站由本机解析，后续域名交给紧邻跳板解析。
- 支持 SSH 密码、普通或加密的 Ed25519/RSA 私钥，以及 SOCKS5 无认证和用户名/密码认证。缺失凭据通过弹窗补填，仅本次尝试有效。
- 每站 SSH 认证前确认主机身份；首次指纹和密钥变化分别提示，信任记录按访问路径保存，不修改系统 known_hosts。
- 支持分阶段连接进度、取消、超时、断开和原位重连。成功后才创建工作台，拖出或移回窗口继续复用原会话；关闭工作台、窗口或退出应用会回收连接。
- 核心记录每次连接的累计 socket 传输字节，包含握手和代理封装且不重复计数。速率、跨重连累计和按插件划分的带宽统计留待业务插件实现。
- 外置插件可声明左右侧栏与中央页面，宿主统一管理混合 Tab、布局、关闭确认及跨窗口重挂载。仓库中的 UI 示例插件需独立打包，只验证交互，不执行远程操作。
- 重整插件 RPC，支持有界并发、乱序响应、超时、停止取消和异常退出，修复插件与核心相互请求时阻塞的问题。

## 验证与范围

发布准备阶段，本机 Windows x86_64 已通过类型/格式、52 项 Rust 测试、6 项脚本测试、服务器及工作台 UI 回归和新增连接 UI 检查。独立临时 OpenSSH 验证通过，实际安装包已验证真实连接、多窗口移动、外置插件和退出重开；数据及服务均与用户生产环境隔离。

正式发行由 GitHub Actions 在 Windows x86_64/ARM64、Linux x86_64/ARM64 和 macOS ARM64 五个原生 runner 上构建，验证实际包启动退出并生成签名更新清单；最终结果以本次工作流记录为准。Windows x86_64 额外运行独立 OpenSSH 源码与包内互操作验证。

尚未支持 PTY、SFTP、正式终端/文件插件、SSH agent、系统 SSH config、交互式 MFA、主机证书和自动重连。跨显示器混合 DPI 的实际拖窗手势仍需人工验收。Windows 未配置商业代码签名，macOS 使用 ad-hoc 签名；应用内更新使用 Tauri updater 签名。

## 更新

已安装带更新模块的版本可从 **设置 → 应用更新** 检查本版；Linux 应用内升级使用 AppImage，DEB 通过包管理器更新。服务器资料、主题和插件配置保存在应用数据目录，核心升级继续沿用。插件独立维护与发行，不随核心安装。
