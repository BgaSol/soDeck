# SoDeck 0.24.0

- 核心新增 commands.v1，插件通过版本化命令协作；单一处理者路由、稳定请求去重与回执查询复用现有双向 RPC。
- 核心新建、默认创建、终端重开及 Docker 容器终端统一提交 terminal.open.v1；旧 UI actions 适配同一服务，移除原独立执行表。
- 命令绑定连接代次、来源及目标 Host/Group；关闭、断线和进程停止撤销迟到创建资格，未知结果不自动重放，实际调用结束前保留在途额度。
- 页面登记与命令关联原子提交，重复请求不复活已关闭页面；迟到创建保留用户后续焦点，关闭 Docker 来源页不关闭已登记终端。

核心不包含业务插件。完整契约见[插件 API](../plugin-api.md#命令默认行为与进程主动创建页面)，操作与失败行为见[终端](../features/terminal.md)、[Docker](../features/docker.md)及[生命周期](../features/lifecycle.md)。未新增生产依赖。

## 验证与发行

2026-11-13 本机 Windows x86_64 的核心、SDK、终端与 Docker 测试，以及 160 项工程脚本、相关类型/格式和界面回归通过。工作台进程回归覆盖去重、来源隔离、重入、关闭取消、未知结果、真实在途额度、移窗、焦点及参数边界。真实 OpenSSH/PTY、组件通信和隔离 Docker Engine 24.0.9 联调通过，验证进入容器及关闭来源页后继续输入。

版本调整前的本地核心 MSI/NSIS 构建和构建目录程序 smoke、终端及 Docker 独立归档验收通过；这些开发工作树产物不是本版正式附件，也不替代五平台实际包验收。

本版准备发布，包来源提交、原始 Actions 打包运行、五平台实际包与新旧组合验收将按本次固定输入记录。尚未完成部分见[通信增强待验收范围](../plans/component-communication.md)。不把历史版本或本机开发包结果当作本版实际包通过。
