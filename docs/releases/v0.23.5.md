# SoDeck 0.23.5

- 同一表单刷新保留密码框、文本输入与多行输入的焦点、选区和方向；控件定位限定在当前表单内，输入仍来自当前草稿。
- 核心与插件客户端使用标准库有界逐行读取，保留换行计数、合法 EOF 尾帧及各调用方超长处理；Interrupted 自动重试，极限上限在读取前拒绝。
- 测试 CLI 在工具启动前拒绝无效参数，保留启动器原样透传；状态与 Docker 测试读取真实 CSS 主题，升级验证使用带期限的流式下载与完整摘要校验。

未新增或升级生产依赖，核心安装包继续不包含业务插件。编辑器菜单与偏好恢复由文件插件 0.10.3 独立交付；终端 0.8.4、网络隧道 0.4.2、系统状态 0.4.4、Docker 0.1.4 独立更新共享客户端读取实现。
