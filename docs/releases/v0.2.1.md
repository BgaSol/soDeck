# SoDeck v0.2.1

- 设置 → 外观新增「多巴胺」，沿用旧版奶油底、粉色导航、黄色选中、薄荷绿点缀和深色粗描边，无装饰阴影。
- 工作台、设置、插件管理、应用更新、状态、消息与日志统一应用主题；即选即保存，重启后保留。
- 保留已有浅色、深色和跟随系统偏好。核心独立发布，Hello 插件继续使用 0.1.1。

## 验收行为

1. 在外观中选择多巴胺，当前窗口立即改变；关闭重开后仍为多巴胺，切回其他主题正常。
2. 粉色导航、黄色选中和主按钮、奶油内容区、薄荷绿品牌区域、2px 深色轮廓与旧版色板一致；文字、禁用状态、键盘焦点可辨，无投影。
3. 外观四个选项在最小窗口下均可访问；主题切换不丢失插件状态、消息、日志或设置草稿。
4. 五目标原生打包，实际包启动退出及更新签名检查通过后发布。v0.2.0 在设置 → 应用更新发现 0.2.1、下载并安装后重启，原有数据保留。

## 本机验证

Windows x86_64 已通过类型与格式检查、17 项 Rust 测试、6 项发布脚本测试、前端构建和带更新签名的 NSIS 打包。v0.2.1 实际安装包通过插件启动退出、重开自动加载、日志消息和偏好保留检查，并通过同版本更新包签名及篡改拒绝检查；尚未在用户环境执行从 v0.2.0 到 v0.2.1 的安装升级。

独立数据目录脚本确认四种主题均能保存并在重开核心后恢复，未知主题不会覆盖已有设置。后台以正式界面组件和 CSS 预览，确认多巴胺配色及无投影；720×480 下四选项自动换行、可滚动访问且无横向溢出。未新增生产依赖。

## 五目标发行验证

[GitHub 原生构建与实际包检查](https://github.com/BgaSol/soDeck/actions/runs/41924152004)全部通过：

| 系统与架构 | 实际发行包启动退出、架构及更新签名 |
| --- | --- |
| Windows x86_64 | NSIS 通过 |
| Windows ARM64 | 原生 ARM64 NSIS 通过 |
| Linux x86_64 | DEB 与 AppImage 通过 |
| Linux ARM64 | 原生 ARM64 DEB 与 AppImage 通过 |
| macOS ARM64 | DMG 包内程序与 app 更新归档通过 |

各目标均通过类型与格式检查、17 项 Rust 测试和 6 项发布脚本测试；更新签名检查同时拒绝篡改包。核心更新代码和签名公钥保持不变，Hello 插件无需重新安装。

发行入口为 [SoDeck v0.2.1](https://github.com/BgaSol/soDeck/releases/tag/v0.2.1)。从 v0.2.0 的设置 → 应用更新检查、下载、安装并重启；升级后可在设置 → 外观选择多巴胺，原有偏好不会自动改变。未在用户环境执行跨版本安装，留给本次在线升级测试。

正式发布后，匿名读取更新清单及仓库 latest 均通过，五目标更新地址与正式 Release 附件逐一匹配。Windows x86_64 使用程序实际的 `ReleaseClient::github().discover`，以当前版本 `0.2.0` 成功发现 `0.2.1` 及对应 NSIS 下载地址；此检查未执行安装。

Linux 应用内更新仍使用 AppImage，DEB 通过系统包管理器升级；Windows/macOS 的操作系统代码签名状态沿用上一版。
