# SoDeck 2.5.1

- macOS 13+ 使用系统主应用登录项，让开机启动关联到完整 SoDeck.app 的名称和图标；保留旧 macOS 的兼容路径。
- 已启用旧登记的用户可在原开关旁选择“更新登录项”。状态读取保持只读，系统禁用不会被升级或刷新重新开启；迁移失败保留旧项并说明原因。
- 原生登录 Apple Event 与现有启动意图合并；登录后台、手动显示、第二实例、普通重启和当前运行会话继续沿统一链路处理。
- 合入已通过评审的 Tauri API/CLI、tauri-build、SSH 与归档依赖更新；Agent MCP 的独立依赖更新由插件自行升版发行。

行为与限制见[设置](../features/settings.md#登录后自动启动)，实现职责见[架构](../architecture.md)。
