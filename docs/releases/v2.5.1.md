# SoDeck 2.5.1

- macOS 13+ 使用系统主应用登录项，让开机启动关联到完整 SoDeck.app 的名称和图标；保留旧 macOS 的兼容路径。
- 已启用旧登记的用户可在原开关旁选择“更新登录项”。状态读取保持只读，系统禁用不会被升级或刷新重新开启；迁移失败保留旧项并说明原因。
- 原生登录 Apple Event 与现有启动意图合并；登录后台、手动显示、第二实例、普通重启和当前运行会话继续沿统一链路处理。
- 合入已通过评审的 Tauri API/CLI、tauri-build、SSH 与归档依赖更新；Agent MCP 的独立依赖更新由插件自行升版发行。

行为与限制见[设置](../features/settings.md#登录后自动启动)，实现职责见[架构](../architecture.md)。

## 验证与发行

正式发行：[SoDeck v2.5.1](https://github.com/BgaSol/soDeck/releases/tag/v2.5.1)，设为仓库 Latest。附件来自 [a2a13db](https://github.com/BgaSol/soDeck/commit/a2a13db93ab6d82ffe503652867ea6c97328214c) 的[原始五平台打包 run](https://github.com/BgaSol/soDeck/actions/runs/45707456360)；[最终恢复验收](https://github.com/BgaSol/soDeck/actions/runs/45710948218)跳过所有 package，五平台 verify 和 metadata 全部通过，直接发布同一草稿原包。签名、架构、实际包启动/退出、登录后台、第二实例、连续数据锁和替换重启通过；Windows 两种安装范围均通过。

[包来源完整 Check](https://github.com/BgaSol/soDeck/actions/runs/45707453525)的五平台原生核心/插件源码、浏览器、Windows SSH、Linux 两架构网络及业务均通过，netem 按配置跳过，见[源码检查收据](v2.5.1-checks.json)。本机类型/格式、218 项脚本、完整设置 UI/浏览器与启动交接回归通过；合入依赖前的本机完整核心为 350 项通过、17 项 ignored，依赖更新后以包来源五平台完整 Check 为准。Agent MCP 单独发行 [0.12.1](https://github.com/BgaSol/soDeck/releases/tag/plugin-mcp-v0.12.1)，保持非 Latest；其他插件未消费本次变更的 Tauri 依赖，无需升版。

原生 ARM64 Mac 的正式包验证主应用登记/取消、旧 plist 迁移、重复开关及当前进程继续运行；通过 NSWorkspace 传递的登录 Apple Event 在 setup 识别，后台启动、恢复、图标渲染和退出通过。系统设置的“Open at Login”显示 SoDeck、类型 Application，图标与仓库正式绿色终端显示器一致；系统记录指向完整 SoDeck.app。[截图](v2.5.1-login-items.png)与[登记/展示收据](v2.5.1-macos-login.json)永久保存，原包与五份报告、公开附件摘要见[发行证据](v2.5.1-assets.json)。

真实注销登录、macOS 11/12、系统设置外部禁用/允许、完整原地升级、多副本/移动位置、真实 IME/DPI/读屏及用户机器系统策略未验证。合成事件和当前 runner 截图不能替代这些结果，未完成范围继续维护在[专项计划](../plans/login-startup.md)。
