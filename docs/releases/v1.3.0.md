# SoDeck 1.3.0

工作台、管理台和插件操作采用统一的轻快动效：侧栏实际宽度与插件窗口逐帧同步，标签、菜单、对话框、连接及维护状态自然衔接。快速反复操作可改向，拖动直接跟手；终端和编辑器正文不缩放。

动效尊重系统减少动态效果，隐藏和卸载停止展示。业务结果、凭据、草稿、Surface 身份及资源释放沿用现有机制；没有新增生产依赖。操作与限制见[工作台](../features/workbench.md)及[界面规范](../../DESIGN.md#动效)。

本轮源码、五平台原生打包、实际包与远程组合验收及正式发布尚未全部完成；包来源、原始运行与 Release 链接将在同轮收尾补齐。
