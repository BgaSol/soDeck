# SoDeck 1.3.0

工作台、管理台和插件操作采用统一的轻快动效：侧栏实际宽度与插件窗口逐帧同步，标签、菜单、对话框、连接及维护状态自然衔接。快速反复操作可改向，拖动直接跟手；终端和编辑器正文不缩放。

动效尊重系统减少动态效果，隐藏和卸载停止展示。业务结果、凭据、草稿、Surface 身份及资源释放沿用现有机制；没有新增生产依赖。操作与限制见[工作台](../features/workbench.md)及[界面规范](../../DESIGN.md#动效)。

## 发布与验证

本机 Windows x86_64 的类型/格式、20 项交互、完整工作台布局、17 组正式构建界面、桌面输入/终端输入、设置与真实网络 UI 验收通过；检查了三主题及窄窗实际截图。修正详情展开时 Tab 跳过字段，以及跨侧停靠时旧侧栏收起状态影响活动 Surface。来源 Check 全部选中项通过，覆盖工程脚本、五平台核心/五插件源码、Linux 完整 UI、Windows SSH 和相关真实业务。

包来源：[33f001452488c7d57f8014a98fee587599a46478](https://github.com/BgaSol/soDeck/commit/33f001452488c7d57f8014a98fee587599a46478)；[来源 Check](https://github.com/BgaSol/soDeck/actions/runs/43847374906)；[原始打包与实际包验收](https://github.com/BgaSol/soDeck/actions/runs/43847481981)。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 五平台原生构建、实际包启动/资料保存/重开/退出全部通过。NSIS、DEB、DMG 安装或解包后运行包内程序，AppImage 与 macOS updater tar 另验启动退出，更新包使用官方 updater 签名。
