# SoDeck 2.6.0

- 配置使用同目录独占临时文件提交；失败保留原目标，核心保留已有文件模式，改进 Windows 长路径兼容。登录项短时文件写入复用同一机制，流式导出/更新包保留原生命周期。
- Windows 数据目录安全简化，长路径和特殊名称保留扩展形式；本地来源支持相应普通文件，仍拒绝设备、数据流和重解析文件。
- SFTP 扩展参数统一使用 SSH 协议库编码，保留保存/复制的确认与未知结果边界。
- 修复 macOS 保留旧版登录项时，进入“设置 → 应用与数据”触发原生崩溃：旧项状态查询改用系统实际的 Objective-C 方法 `statusForLegacyURL:`。页面读取不迁移、删除或重新启用登录项。

边界见[架构](../architecture.md)，依赖与基准入口见[开发指南](../development.md#解析依赖与性能基准)。MCP、Docker、文件和网络插件独立发行，核心包不含这些插件。

## 验证与发行

已发布为 [SoDeck 2.6.0](https://github.com/BgaSol/soDeck/releases/tag/v2.6.0)，并作为仓库 Latest。包来源提交为 [`d41930a`](https://github.com/BgaSol/soDeck/commit/d41930acfd80c4df2e357964d301e0d2c664f24b)。[原始五平台打包与实际包验收](https://github.com/BgaSol/soDeck/actions/runs/45725690757)的 package、verify、metadata 全部通过；[同一来源 Check](https://github.com/BgaSol/soDeck/actions/runs/45725688747)的核心格式、类型、脚本、UI、五平台核心测试和相关业务检查通过。Release 含 16 个公开附件及 `core-update.json`。

原生 macOS [修复前回归](https://github.com/BgaSol/soDeck/actions/runs/45724980642/job/139592556440)直接执行旧项状态查询，验证错误的方法名会导致原生调用失败。2.5.2 的线程假设未得到证实，其隔离探针未执行系统查询；本版撤回该调度，保留原有后台系统 IO。新的 macOS 包验收在迁移前用真实登录启动服务读取旧项，并核对读取不修改原文件或主应用登记；随后验证迁移、重复开关和关闭后进程继续运行。macOS ARM64 的[验收收据](https://github.com/BgaSol/soDeck/actions/runs/45725690757)记录 `legacyRead=unknown`（旧 plist 未被系统登记时的可读结果）、迁移成功、关闭成功及当前进程继续运行。

## 性能范围

文件树优化已加载节点重复刷新；核心日志保留 500 条和完整正文；Docker 保留现有可变行高虚拟布局，仅调整分页预算。局部浏览器与真实插件 RPC 数据保存在本目录 JSON，不代表原生 WebView、远端 IO、磁盘扫描、持续吞吐或长期内存专项。
