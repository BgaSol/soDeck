# SoDeck 2.6.0

- 配置使用同目录独占临时文件提交；失败保留原目标，核心保留已有文件模式，改进 Windows 长路径兼容。登录项短时文件写入复用同一机制，流式导出/更新包保留原生命周期。
- Windows 数据目录安全简化，长路径和特殊名称保留扩展形式；本地来源支持相应普通文件，仍拒绝设备、数据流和重解析文件。
- SFTP 扩展参数统一使用 SSH 协议库编码，保留保存/复制的确认与未知结果边界。
- 包含尚未单独发行的 2.5.2 macOS 登录项主线程修复。

边界见[架构](../architecture.md)，依赖与基准入口见[开发指南](../development.md#解析依赖与性能基准)。MCP、Docker、文件和网络插件独立发行，核心包不含这些插件。
