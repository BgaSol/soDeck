# SoDeck 2.9.0

状态：连接分享与导入已实现，源码和实际包验收进行中，尚未正式发行。

- 单台及全部服务器生成完整 Base64 分享码，自动携带实际中转、标签、可用凭据和私钥。
- 粘贴预览后整批新增独立资料，同名自动调整，不覆盖原连接。
- 核心管理导入私钥，写入失败回滚，启动清理保留有效备份引用。
- 原生分享剪贴板支持 8 MiB，插件剪贴板预算保持原样。

功能行为见[服务器与连接](../features/connections.md#连接分享与导入)。

## 当前验证

本地 Windows x86_64：格式与类型检查、220 项脚本测试、完整核心测试（364 项通过、17 项按既有专项约定跳过）、OpenSSH 实际导入私钥认证、22 组服务器 UI、连接 UI、壳导航和桌面关闭回归通过。服务器分享界面检查了三主题和 1100/420px，提交忙状态纳入关闭流程。

`npm run build` 完成 Windows 本机安装器构建；由 Tauri 正式构建入口产生的程序在隔离数据目录完成两次启动、分享码按钮复制、超过 256 KiB 的原生文本菜单粘贴预览、受管私钥重开读取及退出。原生回执为 `{ok:true,export:true,managedKey:true,reopen:true,copy:true,textMenuPaste:true,over256KiB:true}`。

五目标源码和实际发行包验证尚待 GitHub Actions。尚无 Release；后续在此记录原始打包 run、包来源提交、验证及跳过范围，不将本机构建程序等同五平台安装包验收。
