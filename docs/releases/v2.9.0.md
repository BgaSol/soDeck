# SoDeck 2.9.0

- 单台及全部服务器生成完整 Base64 分享码，自动携带实际中转、标签、可用凭据和私钥。
- 粘贴预览后整批新增独立资料，同名自动调整，不覆盖原连接。
- 核心管理导入私钥，写入失败回滚，启动清理保留有效备份引用。
- 原生分享剪贴板支持 8 MiB，插件剪贴板预算保持原样。
- 修复主题和关闭行为保存后焦点丢失；完成时恢复原控件，用户已经转移焦点时不抢回。

功能行为见[服务器与连接](../features/connections.md#连接分享与导入)。

## 发行与验证

发行：[SoDeck 2.9.0](https://github.com/BgaSol/soDeck/releases/tag/v2.9.0)，作为仓库 Latest。包来源 [3f3be9c89ba28022ecb89197a6067f90689e6bac](https://github.com/BgaSol/soDeck/commit/3f3be9c89ba28022ecb89197a6067f90689e6bac)；[原始打包与实际包验收](https://github.com/BgaSol/soDeck/actions/runs/45842842689)；[来源 Check](https://github.com/BgaSol/soDeck/actions/runs/45842167835)。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 五平台原生构建、签名与实际包验收通过。各平台报告均确认 `serverSharingNative`：分享按钮、原生剪贴板、大码文本菜单粘贴预览、受管私钥及重开；同时验证包内程序启动、资料重开、桌面生命周期与退出。发布原始运行的同一份草稿附件，未重新构建程序包；来源、原生报告、附件摘要和匿名公开下载核对见[永久发行证据](v2.9.0-assets.json)。

本地 Windows x86_64：格式与类型检查、220 项脚本测试、完整核心测试（364 项通过、17 项按既有专项约定跳过）、OpenSSH 实际导入私钥认证、22 组服务器 UI、连接 UI、壳导航和桌面关闭回归通过。服务器分享界面检查了三主题和 1100/420px，提交忙状态纳入关闭流程。

`npm run build` 完成 Windows 本机安装器构建；由 Tauri 正式构建入口产生的程序在隔离数据目录完成两次启动、分享码按钮复制、超过 256 KiB 的原生文本菜单粘贴预览、受管私钥重开读取及退出。原生回执为 `{ok:true,export:true,managedKey:true,reopen:true,copy:true,textMenuPaste:true,over256KiB:true}`。

最终来源 Check 的格式、类型、脚本、Linux 完整浏览器 UI（含设置焦点和连接分享）、系统状态真实 SSH 业务及三插件通信通过；五平台原生源码任务执行的是系统状态插件测试，不记作五平台核心 Rust 套件。此前本地核心与分享回归和本次五平台实际核心包验收分别记录。

本次未执行 netem、Windows 完整 desktop 套件、旧版到本版的线上升级、全部生产网络与外部聊天工具组合，以及人工 IME/DPI/读屏等设备专项。原生剪贴板及合成私钥回归不代表所有生产服务器连接均已验证。

系统状态插件 0.6.0 在本轮独立发布，补齐 macOS 指标和采集链路；核心安装包继续不包含业务插件。其版本、包来源与验收见[插件 CHANGELOG](../../plugins/system-status/CHANGELOG.md)。
