# SoDeck 0.23.2

- 将核心前端的独立 TypeScript 检查从打包链移到 Check，`web:build` 只构建资源；类型检查继续作为发布前源码质量门槛。
- 增加故障回归：同一份只有类型错误的夹具必须在源码检查中失败、在资源构建中成功，确保两条入口互不调用。
- 不改变业务功能、插件 API、安装格式、更新清单或 Tauri updater 密钥。五个插件保持各自已发布版本。

包来源：[b613b900bca2afa36ad143c234bec04cc4b6a86e](https://github.com/BgaSol/soDeck/commit/b613b900bca2afa36ad143c234bec04cc4b6a86e)。原始打包、独立验收和草稿：[42922366666](https://github.com/BgaSol/soDeck/actions/runs/42922366666)，五个平台均一次通过。

[本次 Check](https://github.com/BgaSol/soDeck/actions/runs/42922340598) 全部通过，包含独立前端类型检查、边界故障回归、五平台源码与共享客户端、相关浏览器/SSH/SFTP/终端/网络/Docker/通信检查。Windows 本地 118 项脚本测试通过；其他平台跳过 Windows 文件锁专用回归。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 的实际 EXE、DEB/AppImage、DMG/updater tar 均验证原生程序、更新签名、隔离资料保存/重开和退出。最终 Release 16 个附件的大小、摘要与实际验收报告一致，更新清单与 .sig 对应。

发行：[SoDeck 0.23.2](https://github.com/BgaSol/soDeck/releases/tag/v0.23.2)。0.23.1 的原附件保持不变。五个插件无需跟随升版，仍使用 terminal 0.8.2、files 0.10.1、network-proxy 0.4.1、system-status 0.4.3、docker 0.1.3。

[核心 0.23.1 → 0.23.2 正式版升级](https://github.com/BgaSol/soDeck/actions/runs/42924551156) 五平台全部通过：固定正式 Release 与附件摘要，官方 updater 验签/安装，核对替换字节、新程序启动、设置与服务器资料保留，且临时目录清理成功；Linux 另验 DEB 系统升级。升级由测试夹具驱动生产服务，不等于完整旧客户端更新页面/UAC 人工点击流程。

本版业务代码未变，未重复上一版五平台原生桌面/远程组合；实际覆盖、macOS 默认关联目标收据跳过、未运行的 netem/深度编辑器和设备范围见[上一版记录](v0.23.1.md)。
