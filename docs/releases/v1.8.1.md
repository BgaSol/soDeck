# SoDeck 1.8.1

- 新增 session.program.v1：当前会话有界环境探测，POSIX/Windows 程序参数编码，复用原 exec/stream/PTY 的归属、票据、期限和回收。
- 非交互模式以明确启用的启动前导区分身份检查失败、程序未启动与原始业务输出；Windows 保留字节和实际退出码，兼容 cmd/PowerShell 默认 shell。
- 探测原始输出与 JSON 转义后的结果均受同一 16 KiB 预算限制；超限直接失败，不继续尝试其他平台方案。
- 原 command 接口、插件 API 主版本和现有插件保持兼容；Docker 0.6.0 独立提供自动/手动端点发现及 Windows CLI/npipe。无新增生产依赖。

契约见[插件 API](../plugin-api.md#sessionprogramv1核心-181)，业务边界见[Docker](../features/docker.md)。[1.8.0 候选](v1.8.0.md)因环境结果预算遗漏而放弃，没有正式发布；本版使用新的固定源码打包。

## 发布与验证

状态：待本次源码、五平台原生打包与实际包验收后发行。包来源提交、Check、原始打包 run、Release 与永久附件证据在交付后补齐。

本机 Windows 类型/格式、190 项工程脚本及完整核心测试（306 通过、14 项真实环境专项 ignored）通过。已稳定复现 JSON 转义膨胀：探测原始数据不到 16 KiB，序列化后超过预算。新增解析回归验证恰好 16 KiB 成功与多一字节失败；SSH/RPC 集成回归验证超限结果不提交，且只尝试一次探测。

真实回环 OpenSSH/Docker Desktop 4.96.3（CLI/Engine 29.9.2，Windows amd64 客户端、WSL2 Linux amd64 Engine，desktop-linux/npipe、Root /var/lib/docker）完整流程通过：四类资源、详情/指标、中文历史日志、容器 PTY、来源关闭后独立终端、维护/删除/拉取及断线捕获保留。隔离 OpenSSH/Linux Docker Engine 24.0.9 的同一完整业务流程通过，保留自定义 Root 与挂载卷。Windows Server Engine 的进程模拟不计为真实 Engine 验收。

未执行 Windows Server Engine、ARM64 Docker 远端、五平台实际包 SSH 组合、旧版安装升级、netem 或新增物理 IME/DPI/读屏专项，剩余要求见[待验收计划](../plans/docker-windows.md)。
