# SoDeck v0.5.1 — 恢复表单滚动与多巴胺主题

修复 v0.5.0 在线升级后，服务器表单布局错位、内容无法正常滚动以及多巴胺配色只有部分生效的问题。已有服务器资料和主题设置继续沿用，无需重新设置。

- 统一样式入口，在载入样式前固定 base / components / themes 的优先顺序，防止正式打包后基础规则覆盖组件和主题。
- 由独立容器滚动服务器和代理表单，fieldset 仅负责保存期间禁用输入。长连接路径仍可滚到名称和分组，标题与保存/取消按钮保持可见。
- 新增直接加载正式 HTML/JS/CSS 的回归检查，覆盖保存主题后重开、三种主题、服务器与代理表单、滚轮、末尾字段及 720×480 小窗口。该检查纳入原有 UI 验收和 GitHub 原生打包流程。

## 验证

使用 v0.5.0 正式前端产物稳定复现：已保存多巴胺设置，但计算色板回落为浅色、字段标签居中；长路径会使弹窗标题与页脚移出窗口。修复后的正式前端产物通过三种主题、两种尺寸、服务器与代理表单共 12 组检查，滚轮可到达底部字段且标题/页脚保持固定。

本版只修复样式和表单滚动，不增加终端、文件或其他远程业务。五目标原生安装包、签名更新清单和实际包验收由本次 GitHub Actions 执行。
