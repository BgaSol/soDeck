# SoDeck 0.9.4

修复标题栏加号的位置：没有服务器标签时紧跟“服务器管理”，已有标签时紧跟最后一个可见标签，并与标签垂直居中。窄窗口和长标签溢出时，加号继续保持可点击，服务器选择浮层和键盘焦点正常。

原因是空标签容器仍保留 60px 最小宽度，加号则按整条标题栏居中，产生 62px 间隔和 4px 向上偏差。空主窗口改用现有标题栏空白区接收拖回的服务器标签，并在窗口调整大小时更新原生命中区域，避免可见留白缩小后拖回困难。本次不更改插件版本、连接行为或生产依赖。

## 验证与交付边界

- 正式前端产物已稳定复现原问题，并增加回归，覆盖空标签、单标签、八个长标签溢出、拆出窗口、三种主题、1100/720 窗口宽度及 macOS 窗口按钮留位。
- 本机类型与格式检查、65 项脚本测试、107 项核心测试、工作区界面回归及正式前端回归通过。工作区回归额外核对空窗口、空窗口缩小和已有标签的原生命中区域；核心测试按既有规则跳过 8 项需要 OpenSSH/外置插件或 Linux namespace 的专项验收。
- 本机 Windows x86_64 NSIS 安装包构建通过；五目标原生包验收结果在完成后补充。
- macOS 留位的浏览器布局检查不替代真实设备操作；五目标安装包的交互式窗口拖动、混合 DPI 和 macOS 原生按钮仍需设备验收。
