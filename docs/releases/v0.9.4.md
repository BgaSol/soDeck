# SoDeck 0.9.4

修复标题栏加号的位置：没有服务器标签时紧跟“服务器管理”，已有标签时紧跟最后一个可见标签，并与标签垂直居中。窄窗口和长标签溢出时，加号继续保持可点击，服务器选择浮层和键盘焦点正常。

原因是空标签容器仍保留 60px 最小宽度，加号则按整条标题栏居中，产生 62px 间隔和 4px 向上偏差。空主窗口改用现有标题栏空白区接收拖回的服务器标签，并在窗口调整大小时更新原生命中区域，避免可见留白缩小后拖回困难。本次不更改插件版本、连接行为或生产依赖。
