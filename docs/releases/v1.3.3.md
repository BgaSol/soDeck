# SoDeck 1.3.3

管理台一次导航只播放一层过渡，返回已打开的工作台页面直接恢复；搜索计数、连接、更新与状态文字稳定显示。修复浮层在入场中关闭的透明度跳变与菜单边框丢失，隐藏或卸载后阻止迟到动效，并清除退出投影。

主动树操作、任务和消息按实体衔接，树快速反向展开从当前位移继续；文件树和任务刷新保留滚动位置及正在使用的菜单。通知队列和更新辅助区域局部调整，关闭、输入与资源释放不等待视觉完成。继续使用现有 DOM、CSS 与 WAAPI，未新增生产依赖、后端能力或插件 API。

## 发布与验证

本机 Windows x86_64 的类型/格式、工程脚本、Rust、25 项交互、完整工作区/布局、17 组正式构建界面、桌面/终端输入、设置、编辑器搜索、终端历史、系统状态与 Docker 界面回归通过，完整核心安装包构建通过。文件修正后，真实 SFTP 文件界面通过，覆盖上传/下载、冲突、指针复制、跨窗草稿和保存。检查三主题、常规与紧凑窗口的实际截图及退出中间帧；关闭从当前透明度和位置开始，菜单保留主题边框。

[同机测量](https://github.com/BgaSol/soDeck/blob/main/docs/releases/v1.3.3-motion-measurements.json)使用实际 FileTree 1000 行和共享位置采集夹具。FileTree 行身份保留；中位耗时由 26.3 ms 到 24.6 ms，p95 由 34.9 ms 到 29.8 ms，不宣称稳定帧率改善。默认行高下可见项不足 40 时仍会检查其余候选；减少动态效果时零几何采集。六 iframe 夹具只测共享采集，不代表原生终端/编辑器渲染性能。本轮没有增加缓存、调度器或虚拟化框架。
