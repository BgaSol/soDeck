# SoDeck 1.9.1

- 访问路径的本机、SSH 跳板、SOCKS5 代理和目标节点统一使用圆形图标，编辑步骤同步移除数字标记。
- 连线按真实连接阶段向下流动；等待确认时暂停，失败标出节点，取消或断开后静止。已连接慢速流动，后台、屏外和减少动态效果时暂停或静态显示。
- 本次同时交付 main 已实现的 Windows 标准安装器范围选择与安装向导品牌图；首次安装可选择当前用户或所有用户。

行为见[服务器与连接](../features/connections.md#操作反馈)，Windows 安装范围见[分发文档](../distribution.md#windows-安装范围与图标)。无新增生产依赖或后端 API 变化。

## 发布与验证

本机 Windows 类型/格式、191 项工程脚本（含验收清理回归）、19 组目录界面回归、真实连接界面、正式前端构建和核心套件（307 通过、15 项独立专项 ignored）通过。三主题访问路径截图检查通过，回归包含直连、混合中转、凭据/主机确认、转发阶段、实际取消/失败、重复快照连续性、后台/屏外及减少动态效果。

发行：[SoDeck 1.9.1](https://github.com/BgaSol/soDeck/releases/tag/v1.9.1)，已设为仓库 Latest。包来源 [491bf709f673461b6eb7b302961ef64e97dcc490](https://github.com/BgaSol/soDeck/commit/491bf709f673461b6eb7b302961ef64e97dcc490)；[来源 Check](https://github.com/BgaSol/soDeck/actions/runs/44707270848)通过。五平台原生安装包、更新归档、官方签名、包内启动/资料重开/退出通过，Windows x86_64/ARM64 的当前用户和所有用户安装、登记与卸载均通过。

[原始打包运行](https://github.com/BgaSol/soDeck/actions/runs/44707345735)的五平台构建成功，首次 Windows 验收在卸载后的清理阶段重复删除已经不存在的空目录而失败；程序启动、资料重开和退出已通过。清理现接受目录已移除，仍拒绝非空目录，并增加回归。按原始 run [复用同一批包验收与草稿收尾](https://github.com/BgaSol/soDeck/actions/runs/44709260228)，五平台全部通过；验收工具来源 [d1dc640](https://github.com/BgaSol/soDeck/commit/d1dc640e284a43a5ad740bfd331119fc40032159)及[修正提交 Check](https://github.com/BgaSol/soDeck/actions/runs/44709215075)通过，全部选中的源码、界面、Windows SSH、两架构网络及普通业务回归通过，netem skipped。

直接发布同一草稿附件，未重新构建或覆盖同版本正式包。公开 16 个附件的匿名下载大小、SHA-256 与原包报告/清单一致，公开 Latest API 确认为 v1.9.1。[永久发行证据](v1.9.1-assets.json)保存原始包来源、五平台报告、修正与复验运行、签名清单、Release 附件及匿名校验结果。

本次未独立发行插件，未执行五平台已安装核心与插件的真实 SSH 组合、旧版升级、netem 或新增物理 IME/DPI/读屏专项。
