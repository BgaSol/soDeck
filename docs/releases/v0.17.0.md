# SoDeck 0.17.0

发行日期：2026-11-09。

## 工作台分屏与独立窗口

中央支持嵌套左右/上下分屏，每组独立切换、排序、移组、合并和临时放大。窗口过小时显示焦点组与其他组的未保存/错误提示，扩大后恢复原树和比例。工具可停靠中央、左右侧栏或独立窗口。

页面、整组与本窗口中的整份服务器工作台都可拆出独立窗口或移入已有窗口。同一服务器上下文可分布在多个窗口；跨窗交接保留逻辑实例、终端 PTY、输出与文件草稿。返回来源优先还原原组、相邻标签或工具侧栏；“此窗口全部返回主窗口”共同准备并原子提交全部工作台，失败保留来源，成功回收空窗口。

关闭页面、组、当前工作台、窗口、服务器全部工作台和应用使用统一范围。关闭一个显示部分保留其他窗口任务；最后关闭时等待实际资源结束。布局记忆保存结构、比例、工具位置和窗口尺寸，不重放命令、重连服务器或恢复运行任务。

## 插件与升级顺序

本次独立发布终端 0.7.0、文件 0.8.0、网络隧道 0.3.0、系统状态 0.4.0，全部声明 UI v2。请先升级核心 0.17.0，再升级插件并重启。核心包不包含业务插件，组件仍独立版本、独立分发，核心 RPC API 主版本保持 1。

新核心兼容旧 UI v1 的基础显示和同窗布局；跨窗页面/组/工作台迁移需要 UI v2，含旧插件时提示升级。新插件包会被旧核心的 UI 主版本检查拒绝，旧程序保留；旧核心可能在下载后才提示通用清单错误。

## 验证与限制

实施阶段的类型、格式、脚本、Rust、浏览器与真实 SSH 业务回归通过，细节见[工作台实施记录](../implementation-workbench-layout.md)。Windows x86_64 本机 release 程序在单屏 175% 原生 DPI 下，实际鼠标拖出终端、PTY 接续输入、返回来源组和空窗口回收通过；草稿取消、转发保留、端口释放及四插件退出通过。

最终核心来源的五平台原生源码、类型、格式、前端和完整 Windows 浏览器检查通过。核心五平台原生构建、updater 签名、实际安装/解包、启动、原生工作台移窗、资料重开和退出通过。四插件分别通过五平台原生构建与包内进程生命周期验收；核心安装包不包含这些插件。

包烟测使用窗口作用域检查原生坐标；Windows 使用系统 `ScreenToClient`，不要求云 runner 接收桌面前台焦点。Windows ARM64 云 runner 拒绝普通及系统前台切换，先前候选的屏幕全局命中检查失败；增加等待和前台切换仍未通过，最终将包内几何与交互式系统遮挡验收分开。产品拖拽的 `WindowFromPoint` 遮挡判断保持原样；云包烟测通过不代表 ARM64 真机指针或遮挡已经验证。失败核心候选的本轮草稿已替换，未覆盖正式版本附件。

发布检查还发现终端输入测试只等待第一个字符、终端进程测试仍使用旧 `ui.mount`，以及 Linux 联动测试重连后未操作新终端就等待“最近操作”的目录。分别改为等待完整输入、验证 UI v2 创建/读取契约，以及先真实点击新终端；业务源码和插件归档保持不变。修正后的 Linux 自动目录、重连和三插件联动通过。一次 CI 插件详情焦点超时没有在本机完整生产界面测试和后续两轮 CI 复现，不能描述为已经修复产品缺陷。

本次五平台实际包远程组合通过：Windows x86_64、Linux x86_64/ARM64 与 macOS ARM64 来自 [Verify native remote plugins #42578953749](https://github.com/BgaSol/soDeck/actions/runs/42578953749) 的四个成功任务；该运行整体因 Windows ARM64 下载 Microsoft OpenSSH 返回 HTTP 504 而失败，重试同一平台仍未进入应用测试。改用固定资产 API 并保留大小/SHA-256 检查后，重放同一输入、只补 Windows ARM64 的 [#42580417042](https://github.com/BgaSol/soDeck/actions/runs/42580417042) 成功。两次报告的核心与插件原始 run、来源及实际包摘要完全一致，验证了 SSH、PTY、SFTP 读写/下载、网络转发、移窗、资料重开和退出。系统状态不在这项五平台组合内。

从本轮草稿下载 Windows 核心及四插件，校验摘要与原生架构后，实际 WebView2/隔离 OpenSSH 的关闭交互验收通过；报告为 `artifacts/workbench-release/native-close-release.json`。首次返回来源遇到交接未确认超时，后续两次返回均通过，未确认可复现的产品原因。另一次验收提前读取隧道“尚未监听”占位文字，改为等待真实监听地址后完整复验通过；产品包未改变。验收脚本改动来自 [`365f635`](https://github.com/BgaSol/soDeck/commit/365f635)，单平台补测脚本来自 [`e845f11`](https://github.com/BgaSol/soDeck/commit/e845f11)，与包来源分别记录。

最终附件沿用原始打包的五平台包及成功 metadata 的逐文件大小/SHA-256 核对；本机再次核对 16 个核心附件、四插件各 6 个附件、五目标更新 URL、插件包摘要与核心 updater 签名。更新清单只同步版本说明，不改变 URL、哈希或签名。没有重复 netem、历史版本升级、混合 DPI 副屏、macOS Spaces/全屏或真实 X11/Wayland 手势专项。Wayland 跨窗使用菜单；macOS/X11 遮挡仍使用应用窗口最近焦点顺序，尚未以实际 OS 遮挡顺序验收。除 Windows x86_64 单屏 175% DPI 外，其他目标的真实拖拽、系统遮挡与副屏专项仍待真机验收。
