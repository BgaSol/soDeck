# SoDeck 2.10.0

- 核心复制完整报告准备、传输、校验、提交与完成阶段，失败保留 IO/校验位置和系统错误码；满字节不等同下载成功。
- 本地新文件使用现有 tempfile 的安全无覆盖提交，明确覆盖继续保留原目标直到替换成功；保留源版本检查、取消与未知提交边界。
- 唯一当前核心 API 更新为 2.1，文件、Agent MCP 及其余插件共享 SDK 和清单同步升级。插件独立打包与分发。

先更新核心，再更新所需插件并重启。用户行为见[文件](../features/files.md)与[MCP](../features/mcp.md)，接口见[插件 API](../plugin-api.md)。

## 验证与发行

包来源 [e2b0a10](https://github.com/BgaSol/soDeck/commit/e2b0a108941387969c30357ce7a014c8387959f4)；[原始核心打包](https://github.com/BgaSol/soDeck/actions/runs/45951470548) 的五平台 package/verify/metadata 全部成功。Windows x86_64/ARM64、Linux x86_64/ARM64 与 macOS ARM64 均使用原生产物，验收实际包内程序、资料重开、退出和更新签名。公开 Release 为 [2.10.0](https://github.com/BgaSol/soDeck/releases/tag/v2.10.0)，附件 16 个；直接发布同一份通过附件，不重复标签构建。

[本次来源 Check](https://github.com/BgaSol/soDeck/actions/runs/45951435357) 完成五平台核心/共享 SDK/六插件源码和相关普通业务、UI/脚本验收。首次 Linux x86_64 的两个更新加载测试因插件读取核心响应超时失败；只重跑失败任务后通过，其余平台未重跑。Windows 本地完整核心、223 项脚本、38 项浏览器交互、文件/MCP 与 SDK 单元、文件真实进程/UI/OpenSSH、MCP 真实进程/UI/OpenSSH 均通过；1 GiB MCP 上传逐字节校验通过。

[五平台原生远程组合](https://github.com/BgaSol/soDeck/actions/runs/45952930618) 使用本次原始核心、终端 0.11.2、文件 0.13.0 和网络隧道 0.6.2 五平台候选包，验证原生 WebView 的 SSH/PTY、文件读写下载、网络转发、移窗和退出。固定输入与五份结果保存在[永久组合证据](v2.10.0-remote.json)，公开附件摘要见[附件证据](v2.10.0-assets.json)。MCP、Docker 与系统状态另有独立包和普通业务验收，不计作本组合已覆盖。

本轮复现并回归“源文件传输中改变，全部字节传完后校验失败且不提交”，以及假核心注入的刷盘失败与结果诊断；不把它们当作已确认对方那次事故的原因。未执行 FAT32/exFAT 实卷/镜像、全部网络文件系统、真实磁盘耗尽、完整收尾故障交错、netem、实际旧版升级及物理 IME/DPI/读屏专项。剩余专项见[传输验收](../plans/file-transfer-reliability.md)，不将本次发行写成所有故障与文件系统已覆盖。
