# SoDeck 0.10.0

新增外置「系统状态」插件的官方下载安装入口。安装系统状态 0.1.0 并重启后，服务器工作区默认在右侧固定展开设备信息与运行指标，隐藏、切换服务器和移窗继续采集。动态指标默认 5 秒、拓扑 30 秒、容量与运行时间校准 60 秒，支持暂停、刷新和最近五分钟趋势。

核心提供可选后台工作区实例和有界短命令任务，复用当前认证连接；取消单个任务保留共享会话，关闭工作区和插件退出会清理资源。只读插件查询只在元数据变化时广播工作台。旧插件 API 主版本保持 1，核心安装包继续不包含业务插件。

系统状态需要本版的 `session.exec.v1` 和 `ui.background.v1`；核心 0.9.4 尚未提供，升级核心后再安装新插件。终端 0.2.2、文件 0.4.2 和网络隧道 0.2.2 保持原版本与独立分发。

## 验证边界

本机完成格式、类型、脚本、核心与插件测试、完整工作台和插件界面回归；隔离 Windows OpenSSH 验证新插件采集、隐藏、暂停/恢复、关闭以及已有终端、文件、网络隧道流程。GNU sh 与 BusyBox 的 Linux 容器采集脚本通过。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 五个客户端原生发行包均完成正式构建、updater 签名及实际安装/解包后的架构、启动、持久资料重开和退出验证；Linux 同时验证 DEB 与 AppImage，Windows x86_64 另通过包内 OpenSSH 烟测。发布前核对五平台更新清单、16 个附件及清单签名与实际 `.sig` 附件一致。

远端真实 OpenWrt/Dropbear、Windows Server 与不同默认 SSH shell、macOS/BSD/其他 Unix 仍待设备验收；macOS/BSD 总内存百分比与部分磁盘 I/O 暂不可用，Windows 网络按性能计数器实例展示，尚未映射物理网卡。慢查询可能延迟采样，界面保留实际观察窗口。未执行本次旧正式核心到新版的在线安装切换专项、netem、真实设备的交互式安装/升级和一小时远端运行统计。

实现及本机证据见[系统状态实施记录](https://github.com/BgaSol/soDeck/blob/8115fdcd5bed4108021a729da605fbde77afc2af/docs/implementation-system-status.md)。
