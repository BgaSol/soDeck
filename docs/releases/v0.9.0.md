# SoDeck v0.9.0

统一桌面交互、组件设置与在线更新体验。核心为 0.9.0，终端 0.2.0、文件 0.4.0、网络隧道 0.2.0 分别独立分发。请先升级核心，再升级三个插件并重启；核心安装包继续不包含业务插件。

## 桌面交互

核心和官方插件使用同一套三主题窄圆角滚动条，终端同步适配 xterm 滑块。主窗口、拆出窗口和插件 iframe 统一取消浏览器右键、刷新、查找、打印、页面缩放、导航及开发者工具的默认动作。文本编辑、终端控制键、Shift+Tab、业务右键和终端鼠标模式继续有效；输入框、编辑器和日志选区提供应用文本菜单。

## 组件设置

在现有设置页面配置终端、文件列表、文件编辑器和网络隧道，同类组件跨服务器和窗口共享偏好。终端支持字体、字号、行高、底部留白及光标；文件设置只影响显示，网络默认值用于之后新建的规则。插件关闭时也可配置，保存失败或冲突保留草稿；设置随插件版本切换，并保留兼容值。

终端和文件插件携带 JetBrains Mono、Source Code Pro、IBM Plex Mono 的 Regular/Bold、来源校验元数据和许可证，安装后无需联网下载字体。终端默认 14px、1.2 倍行高和 24px 底部留白；应用外观设置保留 PTY。

## 在线更新

设置 → 更新集中管理核心和已安装插件，默认每日检查，支持选择、批量下载、逐项重试及准备完成后的统一重启。插件安装入口移入“添加插件”，来源与技术信息收进详情。核心完整下载包在重开后可通过官方 updater 离线验签恢复，插件下载期间继续运行，重启后切换版本。

## 验证与边界

发布前本机 Windows x86_64 的类型/格式、18 项脚本测试、89 项常规 Rust 测试和完整 UI 回归通过；终端、文件和网络真实插件集成与实际核心包启动退出验证通过。5 项真实远端专项按入口设计从常规 Rust 测试中忽略，已由插件专项入口独立执行相关场景。

首次 CI 暴露 Git 换行转换使许可证摘要失配；现已对预置字体和许可证禁用换行转换，保留固定上游的原始字节，并增加两种 Git 换行策略下的回归。macOS 的新增 Git 摘要回归曾停滞，现改为直接读取文件并设置执行超时；重新构建的结果才作为本版验收。

macOS 实际包组合验收发现编辑器读取旧描述后接收新草稿数据块的竞争。已增加逐块修订与长度检查和有界重读，首次文档读入后才应用编辑设置；原生验收等待当前界面的设置回报后保存。回归覆盖长度改变、同长度修订变化、持续变化及不完整数据块，真实 OpenSSH 文件与完整界面回归通过。
