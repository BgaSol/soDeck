# SoDeck 1.7.0

- 设置分类合入管理台同一列侧栏，父项显示展开状态，子项标明当前页面；离开设置再返回仍保留最近分区和组件草稿。
- 设置正文限宽，控件与标题靠近；短表单的操作区紧随字段，长表单滚动时保持提交和反馈可达。布尔设置支持键盘开关和高对比模式。
- 设置、插件管理和更新分别组合页面，删除旧双侧栏/弹窗布局与分区状态混用，保留输入节点、冲突、字体预览和关闭协调机制。

行为见[设置](https://github.com/BgaSol/soDeck/blob/main/docs/features/settings.md)，布局与职责见[界面规范](https://github.com/BgaSol/soDeck/blob/main/DESIGN.md)和[架构](https://github.com/BgaSol/soDeck/blob/main/docs/architecture.md)。无新增生产依赖，插件协议与独立发行保持原有边界。
