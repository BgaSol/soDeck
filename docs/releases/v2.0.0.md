# SoDeck 2.0.0

- 核心与六个插件统一为 API 2.0。共享协议定义版本、Context、请求、稳定回执和错误；进程 SDK 负责初始化与有界 RPC，页面 SDK 随每个插件独立打包。
- 移除 API 1、历史能力协商、UI v1、旧行为执行、session.state、session.stream、旧文件控制与监听入口、重复页面桥及旧样式。Docker 日志迁移到 process，文件与 MCP 使用当前文件批次、草稿和提交回执。
- 保留已安装登记、启用意图、设置、用户数据和更新来源。旧插件在新核心中不执行，管理页提供明确原因和升级入口；失败仅回退到实际启动成功的兼容包。
- 统一页面错误传递和插件自有图标。保留超时结果未知、远端退出、正文完整性和资源清理的独立事实；修复多个工作台并发开页的焦点、空编辑器首次描述及终端 shell 探测的票据/序号问题。

对应插件独立升版：终端 0.11.0、文件 0.12.0、网络隧道 0.6.0、系统状态 0.5.0、Docker 0.9.0、Agent MCP 0.12.0。核心安装包仍不包含业务插件。升级插件和核心后重启生效；API 2 插件不能用于旧核心。

契约见[插件 API](../plugin-api.md)，用户行为见[插件管理](../features/plugins.md)、[在线更新](../features/updates.md)、[工作台](../features/workbench.md)及[通用文件编辑](../features/file-editor.md)。

本轮不自动覆盖既有计划中的全部故障矩阵、netem、物理设备 IME/DPI/读屏、用户服务器或已认证 Codex CLI 专项。实际执行与跳过范围分别记录，包启动不能代替真实远程业务验收。
