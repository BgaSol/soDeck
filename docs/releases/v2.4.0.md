# SoDeck 2.4.0

- 增加系统托盘：显示主窗口、消息未读数、设置和明确退出。默认关闭主窗口后继续后台运行，可在应用与数据中改为退出；首次收起前解释一次。
- Windows/macOS 隐藏到托盘；Linux 采用最小化并保留系统窗口入口。独立窗口关闭继续处理自己的页面，主窗口收起保留连接、任务和草稿。
- 统一原生窗口显示、应用退出/重启、必要认证与文件对话框保护。窗口可见性接入现有插件显示链，连接成功的旧意图不打断后台状态；消息成功提交独立更新托盘未读数。

功能与限制见[设置与桌面行为](../features/settings.md#托盘与后台运行)及[生命周期](../features/lifecycle.md)。插件 RPC 与资源清理状态机保持原契约，启用固定 Tauri 的托盘能力，未新增直接生产依赖。

待本次源码检查、原生打包与实际包验收后补充来源提交、原始打包运行、Release 和实际验证/跳过范围。当前尚未正式发布。

Windows 本机类型/格式、脚本 217 项及核心完整回归通过；浏览器回归覆盖原有导航、连接、工作区、设置、正式前端和新增桌面交接，设置已按三主题、1100/720 宽复核。原生托盘/窗口烟测通过，首次后台说明已实际核对取消、重试、确认隐藏与持久化。真实 SSH、终端、编辑草稿、隧道收起/恢复以及取消后再次退出、四插件停止和端口释放通过。

本轮 Windows 后台专项使用 `SODECK_TEST_TRAY_ONLY=1`；已有系统指针拆窗专项在当前混合 DPI 下未命中目标页签，未计入通过。Linux 真桌面有/无托盘、macOS 菜单栏与 Dock 的实际鼠标操作、全平台 IME/读屏/DPI/系统注销、原生显示故障注入和并发压力尚未覆盖；五平台包烟测仅证明其实际断言，不替代这些专项。剩余范围见[托盘专项](../plans/system-tray.md)。
