# SoDeck 2.4.0

- 增加系统托盘：显示主窗口、消息未读数、设置和明确退出。默认关闭主窗口后继续后台运行，可在应用与数据中改为退出；首次收起前解释一次。
- Windows/macOS 隐藏到托盘；Linux 采用最小化并保留系统窗口入口。独立窗口关闭继续处理自己的页面，主窗口收起保留连接、任务和草稿。
- 统一原生窗口显示、应用退出/重启、必要认证与文件对话框保护。窗口可见性接入现有插件显示链，连接成功的旧意图不打断后台状态；消息成功提交独立更新托盘未读数。

功能与限制见[设置与桌面行为](../features/settings.md#托盘与后台运行)及[生命周期](../features/lifecycle.md)。插件 RPC 与资源清理状态机保持原契约，启用固定 Tauri 的托盘能力，未新增直接生产依赖。
