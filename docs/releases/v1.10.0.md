# SoDeck 1.10.0

新增 session.process.v1，插件可在原远端进程中继续写入字节、关闭 pipe stdin 或调整 PTY。短命令、命令捕获和终端统一使用同一执行器，旧 API 保持适配；启动请求、本地排队和服务器接受分别报告，输入与退出结果不互相冒充成功。没有新增生产依赖。

Agent MCP 0.7.0 独立发行，要求本核心；默认 batch 沿用旧行为，pipe/pty 支持密码、连续确认、控制字节与持续 shell。契约见[插件 API](../plugin-api.md)、[MCP API](../mcp-api.md)，行为见[功能说明](../features/mcp.md)。

本版尚待固定来源的检查与五平台实际包验收。正式发行前回写来源提交、原始打包运行、Release 和实际验证/跳过范围。
