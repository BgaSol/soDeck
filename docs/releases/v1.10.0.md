# SoDeck 1.10.0

新增 session.process.v1，插件可在原远端进程中继续写入字节、关闭 pipe stdin 或调整 PTY。短命令、命令捕获和终端统一使用同一执行器，旧 API 保持适配；启动请求、本地排队和服务器接受分别报告，输入、排空屏障与退出结果保留实际失败或未知状态。没有新增生产依赖。

Agent MCP 0.7.0 独立发行，要求本核心；默认 batch 沿用旧行为，pipe/pty 支持密码、连续确认、控制字节与持续 shell。契约见[插件 API](../plugin-api.md)、[MCP API](../mcp-api.md)，行为见[功能说明](../features/mcp.md)。

## 发布与验证

发行：[SoDeck 1.10.0](https://github.com/BgaSol/soDeck/releases/tag/v1.10.0)，设为仓库 Latest。核心包来源 [afc8948b8823d2f03f0ecc45498e869723472eca](https://github.com/BgaSol/soDeck/commit/afc8948b8823d2f03f0ecc45498e869723472eca)；[来源 Check](https://github.com/BgaSol/soDeck/actions/runs/44746430788)通过。[原始打包与实际包验收](https://github.com/BgaSol/soDeck/actions/runs/44746571290)第 2 次尝试通过，五个平台均使用原生构建，ARM64 未使用 x86_64 程序代替。

五平台安装包、更新归档与官方签名、包内程序启动、资料重开和退出通过。Windows x86_64/ARM64 分别验证当前用户与所有用户的默认目录、安装登记、启动和卸载；Linux 分别验证 DEB 与 AppImage，macOS 验证 DMG 与 updater tar 内程序。原始报告、各附件大小和 SHA-256 保存在[永久发行证据](v1.10.0-assets.json)。

后续仅修正隔离 OpenSSH 验收夹具：[最终 Check](https://github.com/BgaSol/soDeck/actions/runs/44751914413)对应 [ba8f86a](https://github.com/BgaSol/soDeck/commit/ba8f86a198e278c39367f9d24c1158af2e078ddf)，核心和 MCP 生产输入保持原包来源。五平台核心、共享客户端和插件源码，工程脚本、完整界面、Windows SSH、两架构网络，以及文件、终端、系统状态、Docker、MCP 和组件通信等选中回归全部通过；netem 未选择。本机 191 项工程脚本通过，新增终端排空回归保留 sent/failed/unknown，受控 SSH 与 5000 轮输入检查覆盖原进程、顺序和记录边界。

Windows x86_64 使用 MCP 0.7.0 的 Actions 原始归档与本次核心夹具联调，两个真实 OpenSSH 流程在 16.49 秒通过，覆盖 9000 字节 pipe 输入、多轮问答、EOF、PTY 输入与 resize。Linux x86_64 的最终业务回归另覆盖无回显原始控制字节、持续 shell、Ctrl+C/Ctrl+D，以及真实 sudo 错误密码后在同一任务输入正确密码，确认 root 文件副作用、退出码和完整输出。使用临时账号、独立回环服务和应用数据；没有在用户服务器安装软件。MCP 五平台包内输入控制使用受控宿主，不等于五平台已安装应用的真实 SSH 组合。

早期 [c59f478 候选](https://github.com/BgaSol/soDeck/actions/runs/44740803286)完成打包后，发现终端排空屏障误把失败或未知回执当成功，故在正式发布前替换。最终打包第 1 次尝试因旧草稿遗留标签仍指向该提交而停在预检，没有构建；清理尚未发布版本的遗留标签后，第 2 次尝试从 afc8948 构建并验收。首次夹具修正的 [Check](https://github.com/BgaSol/soDeck/actions/runs/44749401506)已通过真实 MCP/sudo，但删除账号时发现残留 PAM 会话；最终夹具按实际 sshd PID 退出并清理临时用户进程，完整回归和隔离容器的活跃会话清理均通过。

发布复用同一草稿的安装包、归档与签名，不重新构建同版本。仅同步 Release 说明与更新清单 notes；公开 16 个附件的匿名下载大小及 SHA-256 与报告/清单一致，Latest API 返回 v1.10.0。MCP [0.7.0](https://github.com/BgaSol/soDeck/releases/tag/plugin-mcp-v0.7.0)独立发行；更新核心和已启用插件后重启 SoDeck 生效。

未执行五平台已安装核心与插件的真实 SSH 组合、旧版实际安装升级、netem、新的已认证 Codex CLI 调用、真实超过 300 秒的持续等待或新增物理 IME/DPI/读屏专项。期限默认与长等待策略由受控测试验证，不把它当作真实长时间运行结果。
