# SoDeck 2.3.0

- 插件页面增加有界只读查询，迁移候选页可恢复插件持有的数据，不取得业务输入权；查询不刷新整个工作台，过期回复按挂载身份拒绝。
- 支持视图各自声明包内页面入口，安装登记及重开保留入口，未声明时沿用插件默认页。
- 插件 IPC 完成回复和写入队列即时唤醒，临时恢复存储复用有界文件句柄，避免小块日志读取中的固定轮询延迟与反复开文件。执行、捕获配额和关闭清理契约保持原样。

Docker 日志重构由 Docker 0.10.0 独立交付；用户先更新核心并重启，再更新插件并重启。相关契约见[插件 API](../plugin-api.md)，业务行为见[Docker](../features/docker.md)。未新增生产依赖。

## 验证与发行

已正式发布 [SoDeck v2.3.0](https://github.com/BgaSol/soDeck/releases/tag/v2.3.0)，设为仓库 Latest。包来源 [cf3aaae](https://github.com/BgaSol/soDeck/commit/cf3aaae8e8e0392a314d322fe5ba012eb5059b34)；[原始打包](https://github.com/BgaSol/soDeck/actions/runs/45377720945)的 Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 原生构建、更新签名及实际包启动/退出全部通过。直接发布同一草稿，16 个公开附件匿名下载的大小与 SHA-256 均和原包核对，永久证据见[附件与五平台报告](v2.3.0-assets.json)。

[包来源检查](https://github.com/BgaSol/soDeck/actions/runs/45377712290)的五平台原生核心与 Docker 源码、相关六插件业务、网络及桌面回归通过；Linux 总 UI 在设置夹具缺少新页面时失败。本机复现后仅修正设置夹具的页面文件和已删除开关断言，[补验](https://github.com/BgaSol/soDeck/actions/runs/45380033066)的 207 项脚本和完整 Linux UI 通过，生产源码未变。来源、执行/跳过和失败事实见[检查收据](v2.3.0-checks.json)。

Windows 本机类型/格式、核心完整测试和 Docker 34 项 Rust、真实 SSH/Engine 24.0.9、三主题浏览器日志与原生 WebView 通过。最终原生日志持续接收 60 秒，固定阅读和新增计数保持稳定，20 次打开/固定/关闭及进程退出通过；核算数据约 9.1 MiB，首正文至绘制单次约 4.8 ms。实际核心/插件 IPC 接收 240 MiB，约 30.008 秒、7.998 MiB/s。样本、早期失败与修复保留在[本机记录](v2.3.0-local.json)；单次首屏和运输吞吐不代替分位数或端到端日志性能。

本轮没有完成 8 MiB/s 解析/绘制及多页压力、30 次延迟分位数、一小时无外部调试连接内存对照、其他系统 Docker 日志 WebView/IME/DPI/读屏、全部日志驱动/源边界与系统写入故障组合；netem 未执行。既有未完成要求继续维护在[日志专项计划](../plans/docker-log-viewer.md)，不由五平台包启动推定通过。
