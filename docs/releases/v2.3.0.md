# SoDeck 2.3.0

- 插件页面增加有界只读查询，迁移候选页可恢复插件持有的数据，不取得业务输入权；查询不刷新整个工作台，过期回复按挂载身份拒绝。
- 支持视图各自声明包内页面入口，安装登记及重开保留入口，未声明时沿用插件默认页。
- 插件 IPC 完成回复和写入队列即时唤醒，临时恢复存储复用有界文件句柄，避免小块日志读取中的固定轮询延迟与反复开文件。执行、捕获配额和关闭清理契约保持原样。

Docker 日志重构由 Docker 0.10.0 独立交付；用户先更新核心并重启，再更新插件并重启。相关契约见[插件 API](../plugin-api.md)，业务行为见[Docker](../features/docker.md)。未新增生产依赖。

## 验证与发行

发行准备中。Windows x86_64 本机类型/格式、207 项工程脚本、核心完整测试、只读候选/卸载迟到回复、视图入口和临时捕获回归通过。日志原生读通道的并发上限已由 Docker 页面串行读取回归覆盖，核心的既有上限保持不变。实际核心与插件 IPC 在 release 编译下接收 240 MiB，耗时约 30.008 秒、7.998 MiB/s；此前固定轮询/重复文件打开下只有约 6 MiB/s，保留失败探针与后续结果。

包来源、原始五平台打包与实际包验证、Check 及正式 Release 链接在完成后回写。原生 WebView、长时资源及未执行专项以本轮实际结果为准，不沿用历史通过作为本版验收。
