# SoDeck v0.6.0

增加独立终端与文件插件所需的真实核心能力：复用混合 SSH/SOCKS 会话的 PTY、SFTP、有界正文桥和资源清理。终端插件提供多 Tab xterm；文件插件提供分页目录、UTF-8 小文件编辑、冲突检测、原子保存及单文件流式下载。两插件保持独立安装与升级，核心包不包含业务插件。

右上角状态和工作台底部展示网络传输与插件业务量，跨重连保留本次运行累计。无法准确归属的协议流量不伪造精确估算。修复后注册插件丢失推荐固定/默认展开的布局问题；已有用户偏好继续保留。

设置中的官方插件列表提供真实终端与文件的独立来源。升级核心后，在“设置 → 插件管理 → 官方插件”下载并启用终端和文件，重启后加载。两插件各为 0.1.0，独立发行和升级，核心包仍不包含业务插件；旧的组件交互示例可关闭后统一重启。

五个原生目标均已通过核心/插件独立打包及实际包组合验收，见 [运行 41995021265](https://github.com/BgaSol/soDeck/actions/runs/41995021265)。本地 60 项 Rust 回归、6 项脚本测试、真实 OpenSSH/插件 UI 及正式前端回归通过。文件另覆盖保存并关闭、1 MiB 边界、取消下载后重试、冲突与离线草稿导出。

中文输入法、全屏终端及复杂 VT 状态持续移窗仍待人工验证；编辑限 UTF-8 小文件，保存要求 OpenSSH 原子替换扩展，不提供上传、批量文件管理和逐跳流量分摊。完整结果及约束见 [实施记录](../implementation-remote-plugins.md)。
