# SoDeck 0.12.0

修复点击右上角关闭后程序无法退出的问题。关闭页面、工作区、窗口，以及应用退出、重启和更新安装统一由核心生命周期协调器处理。工作台快照改为只读，后台组件不会在关闭过程中重新创建；关闭范围持续保留到对应父对象结束。

关闭前同步各窗口当前输入，集中处理文件和宿主设置的未保存内容。取消后保留原页面、草稿、终端和网络转发，再次关闭可以继续。新页面请求在决定期间挂起，取消后核对身份并恢复，避免插件轮询留下关闭错误。子窗口最后一个工作区关闭时，一并处理窗口草稿与原生窗口销毁。

核心等待在途 RPC、连接、终端、文件和网络任务实际结束，再停止插件并执行原生收尾。超时保留原请求与已完成事实，不重复保存或释放；清理失败允许继续未完成步骤。窗口意外失联按实际归属接管，主窗口失联收尾全部应用资源。

核心包仍不包含业务插件，插件 API 主版本保持 1。终端 **0.2.2**、文件 **0.4.2**、网络隧道 **0.2.2**、系统状态 **0.1.0** 保持各自版本与独立分发，本次无需更新插件。

## 验证与交付

本机完成 TypeScript/Rust 格式、正式前端构建、78 项脚本测试、131 项常规核心测试、完整界面回归，以及隔离 OpenSSH 下 SSH、PTY、SFTP、TCP 转发、SOCKS 和系统状态业务验证。Windows x86_64 本机再次下载本次正式 NSIS 草稿包，核对 GitHub SHA-256 后仅解包运行，不覆盖用户安装。两种关闭入口均先取消保留同一页面、草稿和真实转发，再放弃关闭；程序退出码为 0，四个插件进程结束，连接断开且端口可以重新绑定。实现与前期本机证据见 [实施记录](https://github.com/BgaSol/soDeck/blob/8115fdcd5bed4108021a729da605fbde77afc2af/docs/implementation-close-lifecycle.md)。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 五个目标的原生构建、updater 签名、实际包启动、持久资料重开和退出均通过。Windows 验证系统安装登记，Linux 验证 DEB 与 AppImage，macOS 挂载 DMG 后运行实际程序；Windows x86_64 另通过包内 OpenSSH 烟测。核心包不包含业务插件。

同一源码 Check 的五平台核心与四插件原生源码测试、三类原生宿主脚本、格式、前端、脚本和交互回归全部通过。Windows 完整 UI 与 SSH、Linux 两架构网络/SOCKS/curl，以及 Linux x86_64 文件/SFTP、终端/PTY、系统状态业务全部通过。临时文件锁回归在 Windows 实际持有排他文件句柄，验证包退出后的有界清理重试；Linux/macOS 跳过该 Windows 专项。插件安装焦点断言等待异步操作完成后再检查。

独立的原生组合验收从明确的核心打包 run 和正式插件 Release 取包，五平台均通过终端 0.2.2、文件 0.4.2、网络隧道 0.2.2 的实际界面、远程业务、跨窗移动与重开退出。本机四插件关闭组合另包含系统状态 0.1.0 的后台 view，没有将三插件矩阵结果扩写为五平台四插件关闭交互验收。

未重复历史版本对的在线升级专项、netem 或真实设备的交互式安装升级。本机包验收与原生 runner 包烟测不能替代这些验收。可信插件自行脱离受管进程组的程序、远端命令已执行的副作用不承诺回滚。
