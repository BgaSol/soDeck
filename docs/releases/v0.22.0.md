# SoDeck 0.22.0

核心新增 `terminal.history.v1`，配合终端插件 0.8.0 的 10 万行历史、正文搜索和常驻彩色预览。核心负责原始输出的临时恢复日志、分片显示检查点、小界面状态和资源清理；检索、颜色和预览仍由终端插件实现。

输出 ACK 与全量快照解耦，正常输出不再等待历史序列化。移窗继续复用原 PTY，恢复查询、阅读位置和有效当前命中；自然退出的终端输出保留到用户关闭。关闭终端或应用重启后不提供可检索档案。

每流恢复日志与显示检查点分别最多 128 MiB，日志及全部在途、已提交检查点共用 1 GiB 额度。写盘或额度失败保留实时输出并报告恢复状态；出现恢复缺口时明确失败，不重新执行命令补历史。核心 API 主版本保持 1，旧插件继续使用原有接口；终端 0.8.0 需要先升级核心。

本版也包含 main 中既有的标准 Base64 和 Tauri 官方 opener 接入，详细变更及历史候选来源见 [0.21.1 候选记录](v0.21.1.md)。核心不包含业务插件，文件插件 0.9.0 已独立发行。
