## 验证与发行

本地核心类型与格式、149 项工程脚本、完整 Rust 默认并行测试、正式前端构建和界面回归通过。界面检查覆盖独立窗口隐藏入口、零宽工具栏、正文宽度、服务器标签与“＋”、连接状态以及标题栏最大化/还原；主题与不同窗口宽度通过。Windows x86_64 本地实际包烟测的渲染、移窗、关闭子窗口、资料保存与重开退出通过。

发行准备中：本次五平台正式包来源、原始打包 run、实际包验收与 Release 链接将在发布前补齐，历史版本验收不代表本次通过。
