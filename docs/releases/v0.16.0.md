# SoDeck 0.16.0

工作台二级“＋”执行插件声明的默认新建行为，按钮名称来自声明。插件自行处理事件并申请自己的页面，核心负责通用页面登记、请求回执和生命周期；不再固定打开某个终端插件。等待超时后继续查询原回执，关闭、断线和插件停止会使旧请求失效。

本次独立发行终端 **0.6.0**。创建时可携带标题、登录 shell 或指定命令、目录集成策略；指定命令直接启动独立 PTY，关闭主机目录集成，不探测主机 shell。命令退出后“重新打开终端”沿用原配置、新建页面和 PTY。同页重挂载复用原状态，初始化失败不自动重复启动。

请同时更新核心与终端插件并重启。文件、网络隧道和系统状态沿用正式版本。核心与插件 API 主版本仍为 1，旧页面协议保留；旧插件未声明默认行为时不会获得新“＋”入口。核心安装包仍不包含业务插件，没有新增生产依赖。接口和兼容边界见[插件 API](https://github.com/BgaSol/soDeck/blob/8115fdcd5bed4108021a729da605fbde77afc2af/docs/plugin-api.md#默认行为与进程主动创建页面)，实施细节见[实施记录](https://github.com/BgaSol/soDeck/blob/8115fdcd5bed4108021a729da605fbde77afc2af/docs/implementation-default-behavior-terminal.md)。

## 验证与交付

整改阶段本机 Windows x86_64 类型、格式、90 项脚本回归、核心全量 175 项测试及新增预算单测、24 项组件 UI 回归、终端 8 项单元/实际插件进程测试、21 项工作台 UI 回归通过。真实 xterm 输入、独立终端包与隔离 OpenSSH 指定命令交互、结束与再次打开，以及三插件目录联动、隐藏、移窗和重连通过。最终生产前端、核心 MSI/NSIS 和终端独立包构建及核心原生启动、资料重开、退出通过；10 项原有 ignored 不计为普通套件通过。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 的核心与四个现有插件原生源码检查、公共格式/前端/脚本/输入检查、Windows 完整 UI/SSH，以及 Linux 两架构普通网络、x86_64 文件/终端/系统状态与三插件联动通过。核心五平台原生构建、updater 签名、实际包安装/解包、启动、资料重开和退出通过；终端五平台独立包与包内进程验收通过。

五平台实际包远程组合固定使用本次核心 0.16.0、终端 0.6.0，以及正式文件 0.6.0、网络隧道 0.2.2，验证原生程序、SSH、PTY、指定命令、文件、网络、移窗和退出。核心首次草稿汇总遇到 GitHub 草稿状态变化，仅重跑失败 metadata 后完成，五份原始平台包保持不变。

macOS 首次实际包组合在资料重开后的原生窗口按钮坐标检查测到 14pt，目标为 22pt；同一包在打包验收和该组合前面的窗口检查测到 22pt。仅重跑 macOS 与汇总后全部通过，没有修改源码或重建包。该瞬时坐标差异的原因尚未证实，不能将重试描述为已修复缺陷。

默认行为选择界面尚未新增；极长期 Context 达到请求记录预算时需关闭并重开工作区。命令终端首版只允许 directoryIntegration=off。Docker 插件、容器命令生成和容器 TTY 清理不在本次范围。用户业务服务器、全部自定义 shell 配置、真实设备 DPI/多屏、netem 与历史版本对在线升级未在本次验证。
