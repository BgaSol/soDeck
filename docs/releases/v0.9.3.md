# SoDeck 0.9.3

修复设置弹窗的键盘顺序、切页和切换主题后的焦点丢失，以及浅色选中文字的对比度。服务器详情把连接操作前置，最小窗口仍可见；目录展示已有会话状态，首次使用和筛选无结果分别提供明确入口。

组件偏好的保存操作固定在内容底部，终端与文件编辑器的字体样本反映草稿字号和行高。小窗口设置导航独立滚动，标题和字段不会因聚焦底部导航被裁切；短窗口仍可直接调整字体与字号。连接失败持续显示站次、阶段和原因，主机指纹可以分别复制核对。终端不可用时可直接进入插件管理，插件异常提供日志与重启入口。

日志可一次清除全部筛选，保留暂停状态并拒绝迟到查询结果；应用与数据页面提供固定使用帮助。现有工作台、主题、认证和重启生效规则保持。

嵌套新建代理的字段标签正确关联各自表单。目录切换、窄窗返回、添加跳板及进入插件详情保持键盘焦点；消息筛选向辅助技术提供选中状态。多巴胺导航与黄色选中背景上的辅助文字满足小字对比度要求。

终端 0.2.2、文件 0.4.2、网络隧道 0.2.2 各自独立发行，提供退出恢复、字号与任务展示、刷新交互稳定性修复。核心安装包不包含业务插件，API/UI 主版本保持 1，没有新增生产依赖。
