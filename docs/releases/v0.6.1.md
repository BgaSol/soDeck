# SoDeck v0.6.1

恢复旧版紧凑工作台风格：文件侧栏使用真正的多分支目录树，提供目录按需展开、路径定位、独立分页、键盘和右键操作。单击选中、双击文件进入中央编辑器；重挂载和移窗恢复展开、分页、选中及滚动状态。

统一多巴胺、浅色和深色的组件配色。多巴胺使用奶油底、粉色面板标题、黄色选中与薄荷绿状态栏。终端状态移到底部，修复拖动侧栏时实际内容宽度未即时更新的问题。保留已有主题和布局偏好。

核心新增向后兼容的独立目录游标能力。文件插件 **0.2.0 需要核心 0.6.1**；请先更新核心，再在“设置 → 插件管理”更新文件插件和终端插件，重启后生效。终端版本为 0.1.1。核心安装包仍不包含业务插件，插件单独发行。

本机 Windows x86_64 已通过格式/类型检查、6 项脚本测试、60 项 Rust 回归、既有工作台与正式前端测试，以及实际 OpenSSH 终端/文件流程。真实文件界面覆盖双目录交错分页、路径定位、失败重试、刷新选择、键盘菜单/复制、三主题、窄侧栏和跨窗恢复；实际 NSIS 包完成隔离安装、真实 WebView 终端及文件读写下载、移窗、重开与退出。

Windows x86_64 / ARM64、Linux x86_64 / ARM64、Apple Silicon macOS ARM64 五目标均已完成原生发行包构建和启动验收：[核心](https://github.com/BgaSol/soDeck/actions/runs/42008315667)、[终端](https://github.com/BgaSol/soDeck/actions/runs/42008315509)、[文件](https://github.com/BgaSol/soDeck/actions/runs/42008315198)。使用这三个独立产物的 [实际包组合验收](https://github.com/BgaSol/soDeck/actions/runs/42009725924) 五目标也全部通过，覆盖真实 WebView/Channel/xterm、SFTP 读写下载、移窗、重开和退出。

核心 [v0.6.1](https://github.com/BgaSol/soDeck/releases/tag/v0.6.1) 已正式发布并设为 Latest；[终端 0.1.1](https://github.com/BgaSol/soDeck/releases/tag/plugin-terminal-v0.1.1) 和 [文件 0.2.0](https://github.com/BgaSol/soDeck/releases/tag/plugin-files-v0.2.0) 独立发布并保持非 Latest。三个更新清单已核对五目标、版本、附件、插件 SHA-256/核心签名，并验证匿名下载与发布前内容一致。标签均指向 `bfea180`。

范围和限制见 [实施记录](https://github.com/BgaSol/soDeck/blob/8115fdcd5bed4108021a729da605fbde77afc2af/docs/implementation-file-tree.md)：编辑限 UTF-8 小文件，挂载容量、跟随终端目录及上传/删除/重命名不在本版；大目录跨窗恢复会重新读取之前已展开的分页，目录变化后滚动位置可能偏移。原生 CI 验证不替代真实设备的复杂输入法、混合 DPI 手势和人工升级测试。
