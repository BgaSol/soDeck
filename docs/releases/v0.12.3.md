# SoDeck 0.12.3

修复工作台左右面板拖动时被后台刷新拉回旧宽度、空间不足突然隐藏、取消后残留拖动状态的问题。手势预览、等待保存和核心确认统一归并；新调整不会被旧快照或旧响应覆盖，松手保留最终位置。

集中处理左右空间约束，以及松手、Esc、失焦、指针取消、捕获丢失、切换、关闭和销毁的结束路径。拖动复用原插件 iframe 与终端会话；核心只提交请求侧宽度，保存失败不改变内存或偏好文件。

本次同时独立发布终端 **0.2.3**：本地适配与远程尺寸通知分离，尺寸任务有界合并；修正测量容器和完整行高度，消除裁切及底部黑条。完整体验建议同时更新核心与终端插件并重启。插件版本、分发、UI v1 和配置格式继续独立兼容，没有新增生产依赖。

设计与本机证据见[方案](../plan-panel-resize.md)及[实施记录](../implementation-panel-resize.md)。

## 验证与交付

本机 TypeScript/Rust 格式、81 项脚本回归、核心测试、工作台及正式 UI、真实 xterm、隔离 OpenSSH 和 Windows x86_64 构建通过。实际 NSIS 包内程序与独立终端包的 WebView2 检查覆盖左右拖动、捕获时刷新、Esc、宽度落盘、iframe 保留、完整行高度，以及取消关闭后继续使用与最终退出释放资源。

本次 GitHub 检查、五平台正式打包和实际包组合结果将在正式发布前补齐。当前本机证据不能代替其他目标的原生验证。

实际跨显示器、100%／150%／200% DPI 切换和长时间拖动帧率仍需设备专项验收；本次不执行 netem 或历史版本对的在线升级。正常终端重排与远端程序自身重绘不等同于旧状态回弹。
