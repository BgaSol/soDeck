# SoDeck 0.19.0

发行日期：2026-11-09。

## 标签与分屏更简单

一级服务器标签和二级页面标签删除三个点，右键提供少量常用操作，也可聚焦后按 Shift+F10/菜单键打开。右键非活动标签保持当前内容；Esc/Tab 收起菜单并返回入口焦点。

服务器标签提供移到新窗口、适用时返回主窗口及关闭。普通页面提供移到右侧/下方分屏、移到新窗口、适用时单一返回入口及关闭；中央工具提供停靠到侧栏和隐藏。

右键分屏标签栏空白处可左右/上下分屏或取消此分屏。取消会合并页面并保留草稿、终端会话及后台工具。唯一页面分屏保留空的原区域；小窗口通过“其他分屏”访问隐藏页面，扩大窗口恢复布局。

修复关闭空标签组时一直等待输入同步的问题。移窗和关闭继续复用既有核心生命周期、会话与请求回执，没有新增生产依赖。业务插件版本保持不变。

## 验证与发行来源

本机类型、格式、正式前端构建、91 项脚本、209 项核心测试（12 项远端用例按标记跳过）、9 项交互以及完整工作台/布局/正式前端 UI 通过。三主题、窄/宽窗口截图和错误局部重试已验证，页面错误为空。详细范围见[实施记录](../implementation-tab-interactions.md)。

本版本正在完成 GitHub 源码检查与五平台原生打包，完成后补齐包来源、原始打包和正式 Release 链接。

## 限制

常规菜单不再提供整组移窗、任意已有窗口列表、批量返回、手动放大及恢复额外历史窗口。任意已有窗口移动沿用平台支持的拖拽；Wayland 菜单仍可新建窗口与返回。

本轮不修改插件业务或重建插件，不执行历史版本升级、netem 或混合 DPI 专项；原生包启动/退出与所选界面和会话流程分别按实际结果记录。
