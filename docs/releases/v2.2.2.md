# SoDeck 2.2.2

连接树右键菜单从实际操作位置轻轻浮出，避让窗口边缘后保持自然方向；入场 160ms，普通关闭 100ms，高菜单取消缩放。连续右键立即让位于最新菜单，Tab、命令与焦点交接不等待动画，表单接管、来源失效、切页或销毁直接撤下。系统减少动态效果时直接显示与关闭。

定位与目录呈现分别管理，保留其他菜单及独立插件的原定位入口。共享退出快照保存当前缩放、透明度及内部滚动内容，并支持立即取消，避免缩放跳变、关闭时闪回列表顶部和旧画面堆积。菜单项复用既有颜色反馈，不改变菜单内容、目录业务、认证、路径继承、RPC 或生产依赖。行为见[服务器与连接](../features/connections.md#节点右键操作与经节点新增)，参数见[界面规范](../../DESIGN.md#动效)。

## 验证与发行

当前尚未发行。本机类型与格式、215 项工程脚本、36 项完整交互回归和完整 `ui:test` 已通过，Windows x86_64 MSI/NSIS 构建通过。新增六组长期回归覆盖缩放与滚动快照、同步取消、快速替换/销毁、退出尾部让位、实际原点、中断、纯定位兼容、高菜单及刷新不重播；真实目录和正式前端产物另检查模态与切页接管。三主题的入场、退出中间帧及减少动态效果画面已核对。

一次并行启动的额外交互检查遇到 Vite 动态模块读取失败；完整 UI 中的同套件及无并行 Vite 服务的独立重跑均为 36/36 通过，没有修改业务代码规避。共享消费者 CI、五平台原生包验收与最终原生 WebView2 检查尚待完成，最终来源、结果和跳过范围在发布时回写。
