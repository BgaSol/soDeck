# SoDeck 1.5.2

- 核心将页面寿命的终端历史与一次 PTY Run 分开：shell 退出或连接断开后保留同一历史资源，每次运行使用独立身份、输入队列和取消状态。
- 新增可选 `terminal.runs.v1` 与 `session.connection.v1`，为终端插件的原标签恢复提供运行接纳和既有连接流程。只有远端明确接受 PTY 与 shell/exec 后才启用输入，迟到输入和旧请求按身份拒绝。
- Context 变化重挂载时沿用通用焦点交接；用户切走后恢复成功不抢焦点。

配合独立的终端 0.9.4，登录 shell 退出后在原标签正文按普通回车即可启动新 shell；真断线使用既有凭据、主机身份与目标变更确认，保留标签、布局和可检索历史。指定命令终端继续显式重开。恢复不还原旧进程、变量或目录，不修改远端登录策略。核心 API 主版本保持 1，旧插件与旧创建协议继续兼容，核心未新增生产依赖。

完整行为与限制见[终端功能](https://github.com/BgaSol/soDeck/blob/main/docs/features/terminal.md)，接口见[插件 API](https://github.com/BgaSol/soDeck/blob/main/docs/plugin-api.md)，终端版本与独立发行证据见[CHANGELOG](https://github.com/BgaSol/soDeck/blob/main/plugins/terminal/CHANGELOG.md)。

## 发布与验证

本机格式/类型、核心测试、187 项工程脚本、终端进程与输入/十万行历史、真实 Windows OpenSSH 同页退出恢复/断线/移窗/焦点及三插件联动通过；隔离 Linux Bash/Zsh 登录脚本与 TMOUT 空闲退出、新 shell 和清理通过。工作树 Windows 本地包通过原生 WebView/Channel 的远程输入、历史检查点、文件读写、移窗、重开和退出。

本次准确提交的源码检查、五平台核心原生构建/签名/实际包验收及配合终端 0.9.4、文件插件的原生远程组合由 Actions 执行；结果、原始包来源和 Release 链接在收尾时回写。Linux 原生组合新增 TMOUT 退出后的同页新 Run、新目录 token 与历史保留验收。
