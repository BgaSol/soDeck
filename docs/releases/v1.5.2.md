# SoDeck 1.5.2

- 插件可以声明并携带自己的 SVG 图标，列表、更新、侧栏、标签和设置入口统一读取当前插件包。
- 插件关闭、未启动或启动失败时仍可显示自有图标；缺失或损坏图标回退为通用图标，不影响业务。
- 官方目录预览读取同源配置和 SVG 并缓存，已安装插件展示不依赖官方目录。旧插件和已有图标名称继续兼容。

Agent MCP 0.2.3 首先接入自有机器人图标。核心 API/UI 主版本不变，未新增生产依赖，核心与各插件独立更新。完整行为和限制见[插件管理](../features/plugins.md)及[插件 API](../plugin-api.md#插件图标核心-152)。
