# SoDeck 1.9.0

- 新增 servers.read.v1 与 connections.v1，提供非敏感保存资料、共享连接打开、原请求读取和取消。外部与桌面共用认证、主机密钥、SSH/SOCKS5 路线及工作区接纳。
- 原请求与当前 Attempt 在同一注册表管理；已接纳收据固定原 Context，取消不误断其他需求或已接纳会话，取消占位阻止迟到首次派发。
- 后台 UI v2 创建状态支持非阻塞观察并复核换代身份；session.target.v1/v2 共用事实且保留原契约。无新增生产依赖、插件权限列表或 API 主版本升级。

契约见[插件 API](../plugin-api.md#serversreadv1-与-connectionsv1核心-190)，行为见[服务器与连接](../features/connections.md)；Agent MCP 0.6.0 独立发行并使用新增能力。

## 发布与验证

本机 Windows 类型/格式、190 项工程脚本、完整核心套件（307 通过、15 项独立专项 ignored）、MCP 21 项单元、进程与侧栏回归通过。真实三服务器 OpenSSH 从零工作区发现、打开、执行/下载、重连与旧收据验证通过；双外部请求只认证一次、取消占位与凭据编辑复用也通过。Windows x64 核心 NSIS 构建及 MCP 独立归档启动/挂载/销毁/十工具/打开进程回归/退出通过。

待固定来源的 Check、五平台原生包与公开附件验收；发行后在本文保存来源、原始 run、Release 及永久报告。Codex CLI 未登录，新的已认证客户端调用未执行；未执行五平台已安装核心与 MCP 的真实 SSH 组合、旧版升级、netem 或新增物理 IME/DPI/读屏专项。剩余交付见[当前计划](../plans/mcp-connections.md)。
