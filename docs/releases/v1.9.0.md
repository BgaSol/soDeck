# SoDeck 1.9.0

- 新增 servers.read.v1 与 connections.v1，提供非敏感保存资料、共享连接打开、原请求读取和取消。外部与桌面共用认证、主机密钥、SSH/SOCKS5 路线及工作区接纳。
- 原请求与当前 Attempt 在同一注册表管理；已接纳收据固定原 Context，取消不误断其他需求或已接纳会话，取消占位阻止迟到首次派发。
- 后台 UI v2 创建状态支持非阻塞观察并复核换代身份；session.target.v1/v2 共用事实且保留原契约。无新增生产依赖、插件权限列表或 API 主版本升级。

契约见[插件 API](../plugin-api.md#serversreadv1-与-connectionsv1核心-190)，行为见[服务器与连接](../features/connections.md)；Agent MCP 0.6.0 独立发行并使用新增能力。
