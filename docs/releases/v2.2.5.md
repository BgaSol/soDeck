# SoDeck 2.2.5

恢复 2.2.4 之前的核心工作页面标签条样式：各主题继续使用原有标签条配色，多巴胺保留绿色工具与标签区域，分屏焦点恢复原有阴影线表达。上一轮整理的需求范围仅限终端插件，2.2.4 对核心样式的修改超出了该范围，本版完整撤回这部分修改。

终端插件 0.11.1 的工具带分组、空状态、标记留白和缩略预览保持原样，无需重新更新插件。核心菜单及其动画等已有行为保留。当前规则见[界面规范](../../DESIGN.md#workspace-tabs)和[工作台](../features/workbench.md)。

## 验证与发行

包来源为 [`d648399c4f8710ade089b7333a17ca6ca89a6f5c`](https://github.com/BgaSol/soDeck/commit/d648399c4f8710ade089b7333a17ca6ca89a6f5c)；[原始核心打包与独立验包](https://github.com/BgaSol/soDeck/actions/runs/45255524084)第一轮全部通过。[同源 Check](https://github.com/BgaSol/soDeck/actions/runs/45255450750)的类型/格式、215 项脚本、完整 Linux 浏览器和 Windows/Linux 四原生目标核心测试通过。

Check 的 macOS ARM64 源码测试首次未获得 hosted runner 而取消，GitHub 注明 ARM64 容量不足；仅重跑失败/取消任务后仍未获得机器。发行时该源码测试尚未执行，Check 汇总尚未通过，不记为五平台源码通过。此次产品变更为 CSS 原样恢复，相关本机与云端 UI 已验证；按已通过的五平台实际包验收发布，保留该项未执行范围。普通业务、Windows desktop/SSH 与 netem 未选中，不计为通过。

核心前端、共享组件与原生代码逐项比较，除应用版本外，与 [2.2.3 来源](https://github.com/BgaSol/soDeck/commit/43f554044721f3e1860407334833b45853325115)一致；相关工作台断言和正式设计说明恢复原样，保留终端插件说明。没有修改终端插件源码或重新打包其归档。

本次本机格式/类型、215 项工程脚本、38 项交互回归、完整 `ui:test` 和 Windows x86_64 NSIS 构建均第一轮通过。实际 release-build WebView2 结合已有终端 0.11.1 独立包与隔离回环 SSH，验证三主题原有标签条配色与焦点阴影、终端单行工具带、34px 留白、64px 预览、键盘详情、真实输入、手动标记/定位、搜索、窄窗口和模拟 1.5 倍设备缩放；核心与插件干净退出。隔离资料保存、重开和退出另验通过。实际画面：[浅色](v2.2.5/light.png)、[深色](v2.2.5/dark.png)、[多巴胺](v2.2.5/dopamine.png)。

五平台原生构建、官方 updater 签名和实际包验收全部通过：Windows x86_64/ARM64 验证当前用户与所有用户安装；Linux x86_64/ARM64 的 DEB/AppImage、macOS ARM64 的 DMG/updater tar 验证实际程序启动、资料保存、重开与退出。该验收与上述尚未运行的 macOS 源码测试分别记录。

发行：[SoDeck 2.2.5](https://github.com/BgaSol/soDeck/releases/tag/v2.2.5)，设为核心 Latest。直接发布同一原始 run 的草稿和十五份程序/签名附件，发布前仅同步说明与清单 notes；平台 URL、签名和包摘要不变。[永久证据](v2.2.5-assets.json)保存实际检查结果、基础设施未执行范围、五份实际包报告、本机原生结果、画面摘要、标签和公开下载核对。

本次只发行核心恢复样式，终端 0.11.1 保持既有独立发行。物理指针/IME/DPI/多屏/读屏、Linux/macOS 交互界面、五平台原生远程发行包组合、历史版本升级和 netem 专项未执行；模拟缩放、源码/浏览器或包内生命周期不能代替这些专项。
