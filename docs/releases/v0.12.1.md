# SoDeck 0.12.1 未发行候选

本候选尝试修复 macOS 原生窗口按钮在 44px 标题栏中的垂直位置，并增加实际包 AppKit 坐标验收。原生定位参数 Y=22 实测得到按钮中心 24pt，偏离目标 22pt，macOS 实际包验收失败。

Windows x86_64/ARM64 与 Linux x86_64/ARM64 的打包任务通过，但不构成五目标完整交付。汇总创建了部分草稿和指向候选源码的标签；该版本没有正式发布。

- 候选来源：[`97b29d14c7f257b9ebcd2d0dace593058b8caed6`](https://github.com/BgaSol/soDeck/commit/97b29d14c7f257b9ebcd2d0dace593058b8caed6)。
- 原始打包：[Package SoDeck #42479226015](https://github.com/BgaSol/soDeck/actions/runs/42479226015)。
- 校准源码后的同版本尝试：[Package SoDeck #42479680307](https://github.com/BgaSol/soDeck/actions/runs/42479680307)，前置检查因版本标签指向另一源码而拒绝，未构建或替换附件。

修正后的原生参数为 Y=20，采用新核心版本 [0.12.2](v0.12.2.md) 重新打包与验收。0.12.1 的源码测试和部分包结果不能作为 0.12.2 的验收证明。
