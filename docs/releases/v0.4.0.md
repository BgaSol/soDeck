# SoDeck v0.4.0 — 服务器工作区与原生多窗口

[正式发布 v0.4.0](https://github.com/BgaSol/soDeck/releases/tag/v0.4.0) 已设为 Latest，五目标安装包及更新清单共 16 项附件。

此版本实现工作区壳，SSH 连接与文件、终端等组件业务留到下一步。普通发行界面仍从服务器管理开始；成功的核心会话才能打开工作区，不把目录档案当成已连接服务器。

- 顶部服务器 Tab 绑定稳定工作区与会话；同档案重复打开会定位原窗口。服务器管理固定留在主窗口。
- 左工具栏、文件空槽、中央组件区域、网络空槽和右工具栏延用旧版布局。每台服务器保留自己的侧栏开关和宽度，多巴胺及现有主题继续可用。
- 支持顶部排序、拖出原生窗口、向其他窗口顶部 Tab 条合入，以及菜单“移至新窗口 / 返回主窗口”。目标就绪后才交接，失败或取消保留源；Context 和布局不变。
- 内容区与系统按钮不是拖放目标；8px 门槛、抓取偏移、插入反馈和 Esc 取消已实现。原生命中按各窗位置与缩放转换屏幕物理坐标。
- 关闭 Tab 不删除服务器档案；打开工作区时禁止删除对应档案。修改档案名称会更新 Tab，当前会话地址不被修改。
- 子窗口关闭只释放它自己的工作区；移走最后一个 Tab 后回收空子窗。主窗口关闭仍退出整个应用，升级/重启统一经过主窗口的未保存表单检查。
- 没有增加生产依赖、布局持久化、托盘或权限流程。插件初始化的 5 秒期限包含进程启动，避免启动耗时叠加到协议等待后撞上外层超时。

## 验证记录

本地 Windows x86_64 通过类型与格式、31 项 Rust 测试、6 项发布脚本测试及前端构建。包含 7 项核心工作区回归测试、9 组工作区界面检查及原有 12 组服务器表单检查。签名 NSIS 已构建，从包中解出实际程序验证原生架构、多窗口生命周期、目录重开、更新签名和篡改拒绝；未覆盖用户的安装目录。五目标结果见下表。界面测试调用真实 Rust 归属服务；原生拖放调用由浏览器替身提供，不能当作系统指针拖窗验收。

包内烟测使用显式测试入口与隔离数据，创建实际原生 WebView，验证两台服务器合窗、返回、窗口关闭、最后一个 Tab 回收、会话及布局保持，以及真实窗口几何的有效/无效区域命中；不移动用户指针。退出再启动验证服务器资料保留，而工作区不恢复。

跨原生窗口的实际指针手势、混合 DPI 多显示器仍需要真实桌面交互验收。Wayland 缺少可靠全局窗口坐标时提示使用 Tab 菜单，不声称已支持原生拖动。当前没有 SSH 连接，也没有终端或文件组件。

Windows x86_64 初次界面检查因旧脚本在删除分组回调结束前点击关闭而失败，重跑已通过界面及实际包检查。主分支增加了延迟回调的稳定复现与等待界面完成的修正，Chrome 与 Playwright Chromium 的 21 组检查均通过；此修正只影响验收脚本，产品代码未变。类型、格式及前端构建的 [Check](https://github.com/BgaSol/soDeck/actions/runs/41944116568)已通过。
