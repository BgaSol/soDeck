# SoDeck 0.23.7

- 核心资料的 UTC 日期换算与 RFC 3339 格式化使用 Rust time，继续保存秒精度的创建与修改时间；编辑保留创建时间，复制生成新时间，时间无法格式化时保存失败并保留原资料。
- 宿主日期显示和日志本地时间筛选使用 date-fns，修复零毫秒时间戳被当成空筛选的问题；刷新保留有效边界，清空移除边界，时区与夏令时沿用本机规则。
- 原生包来源复验使用 Node 标准库深比较，避免仅因 JSON 对象键顺序变化误报来源改变；字段值、类型和数组顺序继续严格检查。

时间库直接依赖固定为 date-fns 4.4.0 与 time 0.3.55；time 已在核心锁文件中作为间接依赖。两库持续维护，替代选择为 Day.js 与 Chrono。接入范围限于日期换算、格式化和时间输入，超时与耗时继续使用标准运行时。
