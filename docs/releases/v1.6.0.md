# SoDeck 1.6.0

- 新增 session.target.v2：插件按完整 Context 查询真实会话主机/端口/账号，断开后保留最近成功连接摘要，重连成功才替换，关闭工作区释放。
- v1 session.state 保持断开 target=null 和原字段；连接接纳先完成可能失败的共享状态登记，再提交工作区与会话身份。
- 核心不增加目录搜索、自动连接、插件授权或业务 UI。Agent MCP 0.5.0 独立使用此能力。

契约见[插件 API](../plugin-api.md#sessiontargetv2核心-160)，客户端行为见[Agent MCP](../features/mcp.md)。核心与插件独立更新，无新增生产依赖。

## 发布与验证

发行：[SoDeck 1.6.0](https://github.com/BgaSol/soDeck/releases/tag/v1.6.0)。包来源：[50062c22566eaf8d9b4378e14a82115a4416064b](https://github.com/BgaSol/soDeck/commit/50062c22566eaf8d9b4378e14a82115a4416064b)；[来源完整 Check](https://github.com/BgaSol/soDeck/actions/runs/44349827850) 在第 2 次尝试通过；[原始打包与实际包验收](https://github.com/BgaSol/soDeck/actions/runs/44349921667) 首次通过。使用同一草稿的原始附件发布，不推同版本标签再次构建。按用户要求先发布核心，再将独立 Agent MCP 0.5.0 标为仓库 Latest；各组件更新继续按自身标签前缀发现版本。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 五平台原生构建、签名及实际包启动/保存资料/重开/退出通过。安装或解包 NSIS、DEB、DMG 后启动包内程序，AppImage 和 macOS updater tar 另验启动退出；15 个程序与签名附件逐项核对五份原生报告的版本、来源、大小与 SHA-256。[永久核心发行证据](v1.6.0-assets.json)保存报告、原始运行、公开附件和实际范围。

Windows 本机类型/格式、190 项脚本、完整核心测试、正式安装包构建通过。真实 SSH 回归覆盖资料修改后旧摘要、断开保留、拒绝变更保持原事实、成功重新认证后身份换代、v1 兼容及错误归属；活动工作区的目录删除按既有约束拒绝。来源 Check 的五平台核心/相关插件源码、Linux 浏览器、SSH/文件/终端/Docker/网络、MCP 三目标调查及共享状态回归通过。

来源 Check 首次终端密集批次与 Docker 阅读位置断言失败；不修改发行程序或放宽断言，同源码只重跑失败任务后通过。macOS 来源任务首次在队列中被取消，没有执行检查，单任务重跑后通过。两项 CI 首次失败的确切调度未完全复现；随后[测试夹具提交](https://github.com/BgaSol/soDeck/commit/f6817b7cede66f138f3e72cf9641d12814fddfe3)让终端回包按当前 queryRevision/requestId 关联，让 Docker 等待挂载及当前查询结果后再操作，本机完整界面与脚本回归通过。该提交只改变两个测试文件，核心与插件原包字节保持固定。

未执行正式旧版安装升级、五平台实际包 SSH 组合、netem 或物理 IME/DPI/读屏专项。现有 remote-integration 入口只验终端/文件/网络，不把它说成 Agent MCP 包组合验证。
