# SoDeck 1.2.2

- 连接树的展开箭头改为收起向右、展开向下，使用独立操作栏；叶节点保留同宽占位，图标和名称统一对齐。
- 连线从本机图标或父节点的操作栏引出，避开卡片，转角轻微圆滑。当前完整路线叠在普通连线上方，兄弟分支继续显示且不覆盖高亮。
- 修复动态切换主题后连线错位的问题，树的实际尺寸变化时重新计算连线。展开控件固定尺寸，筛选状态下仍保持清晰。
- 保留连接树、紧凑两行节点、折叠、筛选、选择和键盘操作；服务器单击查看、双击连接以及 SOCKS5 不直接建连的行为继续沿用。

操作说明见[服务器与连接](../features/connections.md#连接树与标签)。未新增生产依赖；插件版本与发行包不变。

## 验证与发行

本机 Windows x86_64 已通过类型与核心格式检查、183 项工程脚本、16 组目录 UI 回归、16 组正式前端集成验证、连接 UI 回归和核心生产构建。覆盖三主题与 1100/880/720px、展开方向、操作栏尺寸、父子锚点、卡片边缘与连线对齐、路线高亮顺序、动态主题切换、折叠/筛选/刷新保留，以及单双击连接和原有失败恢复；已查看实际界面截图。

动态切换多巴胺主题时曾稳定复现连线与节点相差 6.5px：原实现只观察宿主尺寸，节点高度变化没有触发重绘。现同时观察实际树尺寸，并以同一回归验证切换后误差不超过 1px。
