## 发行与验证

本机 Windows x86_64 的格式、类型、220 项工程脚本、23 组服务器 UI 回归及三主题 1100/720/420px 工具栏检查通过。核心完整套件 364 项通过、17 项按原专项约定跳过；补齐包夹具后重新执行 9 项分享测试，含首次启动与重开后复制全部的新增回归，全部通过。

`npm run build -- --bundles nsis -- --locked` 及实际构建程序的隔离数据启动、单台与全部分享原生剪贴板、超过 256 KiB 的粘贴预览、受管私钥重开与退出通过。首次原生验收暴露旧夹具引用不存在的私钥，已改用现有公开合成测试密钥；尚未验包的首轮打包取消，没有发布。

五平台原生打包和实际包验收待完成；正式发行前在此记录包来源提交、原始打包运行、Release 和实际验证及跳过范围。
