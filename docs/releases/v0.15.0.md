# SoDeck 0.15.0

终端重构为核心 PTY 会话、插件目标/准备策略、共同显示和可选目录模块。保留多终端页、剪贴板、字体主题、跨窗接续及 Bash/Zsh 自动目录识别。打开页面可先显示准备状态，核心分别确认 PTY 和启动请求；旧页面在重载、移窗及重连后保留历史输出，不自动再次执行命令。

本次独立发行终端 **0.5.0** 与文件 **0.7.0**。请一起更新核心与这两个插件并重启。新终端要求核心 `terminal.session.v1` 能力，文件按会话的位置能力识别提供方；现有文件系统标记校验和旧终端兼容保持。核心独立打包，不包含业务插件，没有新增生产依赖。Docker 留到后续。

## 验证与交付

本机类型与格式、核心普通测试、92 项脚本、真实 xterm 输入/剪贴板/尺寸/主题、OpenSSH 终端与 Windows 三插件联动通过。新增契约回归验证明确启动、冲突拒绝、取消中的未知结果、尾部输出、终态历史与重连后旧输入限制。实际五平台包验收及发布来源正在完成，结果完成后补入本记录；不能视为已发布。
