# SoDeck v0.3.0 — 服务器资料管理

源码和五目标实际包均已通过验收。[正式发布 v0.3.0](https://github.com/BgaSol/soDeck/releases/tag/v0.3.0)提供五目标安装包及签名更新清单，设为仓库 latest。v0.2.0/v0.2.1 可从设置 → 应用更新检查、下载并安装。

- 核心工作台新增服务器和 SOCKS5 代理目录，支持新增、编辑、复制、删除、搜索及服务器单层分组。
- 配置任意有限层数的 SSH/SOCKS5 混合路径，支持排序、移除和内联创建代理；引用节点只取地址与认证，不递归展开其路径。中转解析下一站地址的语义固定。
- 记住的密码和私钥口令按用户选择明文保存在本机文件；未记住的秘密仅当前核心进程有效。复制不携带秘密，公开目录不返回密码。
- 被引用资料禁止直接删除，删除分组保留服务器。保存失败保留草稿，关闭/退出/重启前确认未保存修改。
- `servers.json` 使用修订检查、串行提交、临时文件同步与替换，保留上一份有效备份。损坏目录禁止覆盖，恢复时另存原文件。
- 保留现有四种外观、外置插件和在线升级流程；核心安装包仍不携带业务插件。本版不发起 SSH、SOCKS 或连通性探测，不提供终端。

## 验证

本机 Windows x86_64 已通过类型与格式检查、24 项 Rust 测试（含 7 项目录测试）、6 项发布脚本测试和前端构建。12 组无头浏览器检查调用真实 Rust 目录服务与隔离文件，覆盖 CRUD、分组、路径、秘密、保存失败、旧修订、重开、恢复及四主题最小窗口。只增加 Playwright 开发依赖，无新增生产依赖。

本机带更新签名的 NSIS 已构建；解包其中的实际程序后，验证 x86_64 架构、渲染页面、目录保存重开、签名有效及篡改拒绝。测试使用独立数据目录，未覆盖用户已安装程序。

[五目标原生打包及实际包检查](https://github.com/BgaSol/soDeck/actions/runs/41935523475)全部通过（源码 `cc9b98f`）：

| 系统与架构 | 实际包验证 |
| --- | --- |
| Windows x86_64 | 安装 NSIS，检查包内原生程序、目录保存重开、启动退出和更新签名；真实核心表单自动检查通过 |
| Windows ARM64 | 原生 ARM64 NSIS，同上包内检查 |
| Linux x86_64 | DEB 解包程序及 AppImage 分别保存重开、启动退出与签名检查通过 |
| Linux ARM64 | 原生 ARM64 DEB 及 AppImage，同上包内检查 |
| macOS ARM64 | 挂载 DMG 后运行包内程序，保存重开、启动退出及 app 更新归档签名通过 |

所有目标均在对应系统架构的原生 Runner 运行 24 项 Rust 测试及 6 项发布脚本测试。包内目录检查会保存一个分组、两台服务器、一条代理与 SSH/SOCKS5/SOCKS5 三层路径，复制后删除副本，再重开验证记住的口令保留、临时密码清除。常规 [Check 工作流](https://github.com/BgaSol/soDeck/actions/runs/41935519309)也已通过。

本次直接复用已通过五目标实际包检查的 GitHub Actions 产物，发布标签指向对应源码 `cc9b98f`；更新清单使用仓库现有脚本从产物生成。未重新构建同一套已验证产物。当前未在用户安装目录执行跨版本升级，也未迁移旧版服务器数据。

正式发布后，匿名请求 GitHub `releases/latest` 返回 `v0.3.0`，16 项附件完整，公开更新清单中的五目标地址与 Release 附件逐一匹配。下载产物及上传附件的 SHA-256/大小均匹配。Windows x86_64 使用程序实际的 `ReleaseClient::github().discover`，分别以当前版本 `0.2.0`、`0.2.1` 成功发现 `0.3.0` 及对应 NSIS 下载地址。该检查只发现更新，不安装。发布时新标签触发的重复构建已取消，保持已验证产物不变。

备份可能保留清除前的旧密码。私钥只保存文件路径，跨设备不会自动复制私钥。操作系统签名方式沿用上一版。
