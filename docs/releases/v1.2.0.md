# SoDeck 1.2.0

- 服务器和 SOCKS5 统一放入连接树，保留本机根、路径层级、前缀合并、重复位置、折叠与祖先高亮；未使用的代理也能直接查看和维护。
- 移除目录分类页签、密度切换和独立标签管理。仅保留紧凑布局，标签直接点选筛选，搜索可匹配中转节点；“全部”保留搜索。
- 新增服务器一键进入表单，箭头提供 SOCKS5 新增；刷新放在工具栏外显。详情优先呈现连接状态、连接和编辑，再显示路线与资料。
- 标签随服务器一次保存，取消不留下新标签。刷新、筛选、失败恢复与过期响应保留有效树、选择、折叠和草稿；代理及 SSH 上下文不能直接建连。

操作和兼容说明见[服务器与连接](../features/connections.md)。未新增生产依赖，目录仍为 schemaVersion 2，旧目录、标签 ID 与旧保存调用兼容；插件版本与发行包不变。
