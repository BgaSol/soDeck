# SoDeck 1.2.0

- 服务器和 SOCKS5 统一放入连接树，保留本机根、路径层级、前缀合并、重复位置、折叠与祖先高亮；未使用的代理也能直接查看和维护。
- 移除目录分类页签、密度切换和独立标签管理。仅保留紧凑布局，标签直接点选筛选，搜索可匹配中转节点；“全部”保留搜索。
- 新增服务器一键进入表单，箭头提供 SOCKS5 新增；刷新放在工具栏外显。详情优先呈现连接状态、连接和编辑，再显示路线与资料。
- 标签随服务器一次保存，取消不留下新标签。刷新、筛选、失败恢复与过期响应保留有效树、选择、折叠和草稿；代理及 SSH 上下文不能直接建连。

操作和兼容说明见[服务器与连接](../features/connections.md)。未新增生产依赖，目录仍为 schemaVersion 2，旧目录、标签 ID 与旧保存调用兼容；插件版本与发行包不变。

## 验证与发行

本机 Windows x86_64 已通过类型与核心格式检查、183 项工程脚本、完整 Rust 核心测试（285 项通过，13 项既有专项 ignored）、16 组目录 UI 回归、连接 UI、管理台导航和16 组正式前端集成验证，以及核心生产构建。目录覆盖原子标签保存、取消、重复路径、直接标签 AND、中转搜索、上下文禁止建连、折叠/选择保留、刷新失败、隐藏资料恢复和过期读取隔离。正式产物检查三主题、1100/880/720px、深层路线、长标签换行、菜单位置与键盘、表单滚动和固定页脚，并已查看实际截图。

本版等待同一源码的 GitHub Check、五平台原生核心打包、更新包签名与实际包验证；完成后在本记录补充来源提交、原始打包运行、Release 和附件证据。

本轮没有新增真实系统 IME、读屏、触控板、多屏和混合 DPI 专项；Chromium 组合输入与正式前端回归不替代这些设备验证。生产服务器与全部外部 SSH 配置也不从夹具通过推定。
