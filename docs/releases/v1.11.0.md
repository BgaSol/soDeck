# SoDeck 1.11.0

- 核心新增 files.copy.v1：后台只读本机路径来源、固定普通文件句柄、准备时固定目标版本，以及仅传内容的属性策略；不需要打开文件选择器或安装文件插件。
- 单文件复制整理为共用流水线，上传、下载和原生文件输入复用；进度、提交尝试、已提交/未提交/未知结果独立保留到终态，不以附属查询或清理失败抹去已确认提交。
- Agent MCP 0.9.0 独立新增文件上传，要求本版核心能力；核心与插件各自分发，更新启用中的插件后重启生效。无新增生产依赖。

行为见 [Agent MCP](../features/mcp.md#上传文件)，核心契约见[插件 API](../plugin-api.md#filescopyv1核心-1110)，客户端字段见[MCP API](../mcp-api.md#单文件上传090)。目标版本检查与原子替换之间仍有其他进程写入的竞争窗口；不提供文件快照、跨进程 CAS、完整 ACL 克隆或断电持久化保证。

## 发布与验证

待本次固定源码的五平台原生打包、官方签名、实际包启动/资料重开/退出和来源 Check 完成后发布；原始 run、提交、Release 及附件摘要在本节与永久证据中保留。

本机 Windows x86_64 已完成核心完整测试、MCP 进程/连接与真实三服务器 OpenSSH：空文件、二进制、默认冲突、显式覆盖、删除来源后同请求恢复，以及 1 GiB 上传和逐字节比对通过。核心提交原语的受控回包覆盖新建/替换 ACK、明确拒绝与丢回包，不重复提交。最终验证结果随发行补齐。

五平台已安装核心与 MCP 的真实 SSH 组合、旧版实际升级、netem、新的已认证 Codex CLI 调用和物理 IME/DPI/读屏专项未执行；不把源码、浏览器或包启动验收计为这些专项通过。
