# SoDeck 0.23.10

- 修复原生 Tab 移窗验收的 macOS 区域误判：窗口按钮在左侧，右侧标题栏空白仍按有效落点处理。
- 移窗提交后等待前端上报匹配最新标签顺序的可用区域，避免读取旧区域造成偶发失败；超时保留窗口与区域诊断。

## 验证与发行

待本次源码检查、五平台原生打包和实际包验收完成后发布；原生远程组合使用本次核心包复验。此前核心 0.23.9 的 macOS 组合验收在 [43356799617](https://github.com/BgaSol/soDeck/actions/runs/43356799617) 稳定报“内容区或窗口按钮错误地接受了 Tab 拖放”，此次修正该验收判断。

发行目标：[SoDeck 0.23.10](https://github.com/BgaSol/soDeck/releases/tag/v0.23.10)。本次不联动重发插件；多屏、混合 DPI、真实触控板、IME/读屏和 Wayland 跨窗设备专项不计入常规包验收。
