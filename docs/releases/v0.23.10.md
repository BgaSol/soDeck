# SoDeck 0.23.10

- 修复原生 Tab 移窗验收的 macOS 区域误判：窗口按钮在左侧，右侧标题栏空白仍按有效落点处理。
- 移窗提交后等待前端上报匹配最新标签顺序的可用区域，避免读取旧区域造成偶发失败；超时保留窗口与区域诊断。

## 验证与发行

此前核心 0.23.9 的 macOS 组合验收在 [43356799617](https://github.com/BgaSol/soDeck/actions/runs/43356799617) 报“内容区或窗口按钮错误地接受了 Tab 拖放”。原因是验收将右侧标题栏空白按其他系统的窗口按钮位置检查，且移窗提交后未等待新的区域上报；此次修正验收，不更改正常拖放与页面交接协议。

本地类型、Rust 格式、文档检查、158 项工程脚本及完整核心测试通过（253 项通过，13 项需专项环境的测试保持 ignored）。新增回归验证区域必须匹配已提交标签顺序且未被阻挡、尺寸有效。Windows x86_64 的正式前端、核心 release 编译及 NSIS 构建通过。

包来源：[5d939315e4b8caa182ae1437b4760bb919afa3b7](https://github.com/BgaSol/soDeck/commit/5d939315e4b8caa182ae1437b4760bb919afa3b7)；[来源提交 Check](https://github.com/BgaSol/soDeck/actions/runs/43364144677) 全部通过，包括五平台原生核心测试、格式/类型/工程脚本和 Linux 完整界面回归。独立插件源码、普通业务 integration、Windows 完整浏览器/SSH 专项和 netem 未被本次 Check 选择，skipped 不计为通过。

原始打包与独立实包验收：[43364158591](https://github.com/BgaSol/soDeck/actions/runs/43364158591)。Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 全部原生构建、签名和打包，一次通过实际安装器/归档内程序的启动、资料保存与重开、退出；Linux DEB/AppImage 与 macOS DMG/updater tar 分别验证。五份通过报告与来源、版本及原包摘要绑定通过。

[原包远程组合](https://github.com/BgaSol/soDeck/actions/runs/43365284661) 固定本次核心、terminal 0.8.5、files 0.11.1，在五平台验证原生工作台移窗、SSH、终端、文件、重开和退出，全部通过。macOS 原区域误判消除。Linux ARM64 首轮已通过几何检查，但后续返回主窗口出现“目标窗口未就绪，工作区保留在原窗口”；仅重跑失败平台和汇总后使用同一输入、同一原包通过，未调整生产超时或重编译。此单次就绪超时的进一步原因尚未确认，保留首轮失败记录。

发行：[SoDeck 0.23.10](https://github.com/BgaSol/soDeck/releases/tag/v0.23.10)，设为 Latest。16 个附件沿用原始打包 run，发布前核对大小、SHA-256、五平台更新目标和签名；只同步发布说明及更新清单中的说明，不改变安装器、归档和签名字节。来源与附件记录见[发行附件记录](v0.23.10-assets.json)。

本次不联动重发插件；未执行生产服务器、网络插件组合、Windows 深度编辑器、系统文件剪贴板/默认应用、正式版实际升级、netem、多屏/混合 DPI、真实触控板、IME/读屏和 Wayland 跨窗设备专项。
