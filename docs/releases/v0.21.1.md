# SoDeck 0.21.1（未发布候选）

本轮最终按要求交付远端 main，不发布 Latest；截至本轮核对，正式 Latest 仍为 [v0.21.0](https://github.com/BgaSol/soDeck/releases/tag/v0.21.0)。下面保留改动、既有候选和验证边界，不代表 0.21.1 已正式发行。

核心命令输出改用固定 Base64 库，保持 8192 原始字节分页、偏移和控制帧限制。Docker 独立新版严格拒绝非法 Base64 输出，失败后仍释放任务且不重发操作。

网页、Release/帮助链接及下载目标目录改用 Tauri 官方 opener 的 Rust 自由函数。保留 HTTP/HTTPS、页面/资源归属校验，增加绝对目录、NUL、失效路径和普通文件检查；目录仍直接进入目标目录。没有新增前端 opener 包、链接注入或插件权限流程。

核心固定 tauri-plugin-opener 2.7.2、open 5.4.5 和 base64 0.23.1；五个插件同步共享客户端锁文件并独立升补丁版本：terminal 0.7.3、files 0.8.1、network-proxy 0.3.1、system-status 0.4.1、docker 0.1.2。核心安装包不包含业务插件，升级已启用插件在重启后生效。

方案、依赖维护/许可、错误语义和源码验证见[接入记录](../implementation-base64-opener-adoption.md)。同期已有的 CI 分层、诊断、终端交接等待和 macOS 按钮验收等待一并合入 main，见[CI 实施记录](../implementation-ci-optimization.md)及已合并的 [PR #10](https://github.com/BgaSol/soDeck/pull/10)。

随后补布局测试的页面就绪等待、800ms 延迟挂载及失败 trace，保留右键不选中页面、跨窗返回和草稿断言。[Check #42792471502](https://github.com/BgaSol/soDeck/actions/runs/42792471502) 在更早的窗口缩放宽度断言失败；诊断证实固定等两帧仍可能读到旧窄窗口的几何数据，后续改为等待实际恢复宽度。

最终测试源码为 [`9ef08b5ca7845a3db89b9163bf11a445a77b0776`](https://github.com/BgaSol/soDeck/commit/9ef08b5ca7845a3db89b9163bf11a445a77b0776)。对应 [Check #42793876847](https://github.com/BgaSol/soDeck/actions/runs/42793876847) 按末两次浏览器测试改动复验 Linux 完整 UI/正式构建和脚本，首次 attempt 全部选中检查及汇总通过；未选中的平台/业务和 netem 明确 skipped，后续文档提交不改变这些源码。

本机 Windows x86_64 类型/格式、前端构建、100 项脚本测试、actionlint 1.7.12、完整 Windows UI 对照、实际终端与文件独立包/OpenSSH/UI 回归通过。先前 Base64 专项的共享客户端、五插件、实际 Docker 包进程与核心源码回归通过。五平台核心与插件源码及普通远程业务的结果按上述确切源码运行记录，不使用历史候选包结果代替。

## 未完成与验证边界

macOS runner 保留受保护的默认关联，最新夹具明确报告默认应用目标收据未验证；`--handler-only` 仅编译并记录 skipped。实际核心包模式中的系统 handoff、非法目标拒绝与退出不等于完整 URL/目录收据通过。Windows ARM64 的最近包验收超时也没有通过最终源码的实际包复验。

最终源码五平台核心实际包、核心与新插件实际包组合、历史版本在线升级未完成。系统接口成功不能确认目标应用后续状态；受控 handler 不代替真实浏览器/文件管理器可见窗口、UNC、Wayland 和多屏/DPI 人工验收。netem、用户生产服务器和其他远端系统不是本次专项。
