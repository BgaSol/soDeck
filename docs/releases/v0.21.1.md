# SoDeck 0.21.1

核心命令输出改用固定 Base64 库，保持 8192 原始字节分页、偏移和控制帧限制。Docker 独立新版严格拒绝非法 Base64 输出，失败后仍释放任务且不重发操作。

网页、Release/帮助链接及下载目标目录改用 Tauri 官方 opener 的 Rust 自由函数。保留 HTTP/HTTPS、页面/资源归属校验，增加绝对目录、NUL、失效路径和普通文件检查；目录仍直接进入目标目录。没有新增前端 opener 包、链接注入或插件权限流程。

核心固定 tauri-plugin-opener 2.7.2、open 5.4.5 和 base64 0.23.1；五个插件同步共享客户端锁文件并独立升补丁版本：terminal 0.7.3、files 0.8.1、network-proxy 0.3.1、system-status 0.4.1、docker 0.1.2。核心安装包不包含业务插件，升级已启用插件在重启后生效。

方案、依赖维护/许可、错误语义和验证设计见[接入记录](../implementation-base64-opener-adoption.md)。正式包来源、原始运行、Release 与实际验证结果在本轮验收后补齐。

验证边界：系统接口成功代表已交付默认应用，不能确认目标应用后续状态。受控 handler 不代替真实浏览器/文件管理器可见窗口、UNC、Wayland 和多屏/DPI 人工验收；netem、生产服务器和旧版升级不是本次改动专项。
