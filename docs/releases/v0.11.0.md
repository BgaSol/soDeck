# SoDeck 0.11.0

官方插件名单改为从仓库 main 分支的 `plugins/<目录>/release.json` 自动发现。新增插件只需提交自身配置并独立发布，不再要求修改核心名单或发布新版核心。进入插件管理后异步获取，成功结果缓存一小时；支持手动刷新，网络或配置错误保留上次完整列表，首次无缓存时提供重试。

插件管理常驻“已安装 / 官方插件”切换，空安装直接展示官方列表。安装后留在列表，可连续添加插件并统一重启；本地添加、启停和详情继续可用。设置按“偏好设置 / 应用管理”分组，软件更新集中处理应用和已安装插件的升级，插件页快捷入口定位到对应更新项。修复切换设置分区后组件菜单仍高亮的问题。

核心安装包继续不包含业务插件，插件 API 主版本保持 1。终端 0.2.2、文件 0.4.2、网络隧道 0.2.2 和系统状态 0.1.0 保持原版本与独立分发；本次仅为各插件发行配置补充列表展示元数据。旧用户升级本版一次后，即可自动发现后续新增官方插件；安装仍要求正式包兼容核心 API 和本机平台。

## 验证与交付

本机完成 TypeScript/Rust 格式、77 项脚本测试、115 项常规核心测试、完整界面回归及 Windows x86_64 核心开发构建。通过实际 GitHub Trees/Blobs 接口读取现有官方插件；隔离 HTTP 回归验证运行中新增/移除插件、缓存、部分失败保留名单以及核心代码中不存在的新 ID 下载和安装。三主题和 720×480 小窗口下的刷新、连续安装、更新及重启入口通过。

本次源码提交后由 `Package SoDeck` 进行五个目标的原生正式构建、updater 签名和实际包验收，相关 Check 与原始打包 run 的最终结果在发布收尾时补记。既有源码验证详见[更新体验实施记录](../implementation-update-experience.md)。

不重复执行历史版本对的正式在线升级专项、netem 或真实设备交互式安装升级；包内自动化烟测不等价于这些验收。
