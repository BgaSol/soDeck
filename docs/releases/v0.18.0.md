# SoDeck 0.18.0

## 更新与插件下载加速

更新检查、官方插件目录、发行清单、核心更新包、插件首次安装和升级共用下载线路。GitHub 直连失败后自动切换启用的备用地址；内置 7 个地址，文件专用线路只参与文件下载，近期成功线路优先。单个节点失败不会阻止后续下载尝试。

设置 → 软件更新 → 下载与网络支持添加最多 10 个自定义 HTTPS 转发前缀，以及编辑、排序、启用/停用和删除地址。单地址测试检查 API、目录、清单和包首段，结果只代表该地址当前的连通情况，不代替完整包校验。保存冲突时保留输入。

下载失败清理临时文件后重新尝试，不拼接不同节点的内容；核心继续使用 Tauri 官方签名验证和安装，插件继续使用 SHA-256、解包与清单检查。缓存保留原始 GitHub URL，已准备包继续支持离线恢复。未新增生产依赖，业务插件版本与独立分发保持不变。

## 升级与限制

已安装客户端可按原更新流程升级核心。旧客户端需要先能够访问 GitHub 或手动下载安装本版本，升级后才具有备用地址功能。

公共代理可能限流、失效或缓存旧资源，多个域名也可能共享上游；本轮没有覆盖大陆不同运营商网络。核心签名保护核心包，插件哈希保证包与清单一致，代理仍参与元数据传输。

## 验证与发行来源

功能实施阶段在 Windows x86_64 完成类型、格式、90 项脚本与 219 项 Rust 测试、正式前端更新专项及实际 NSIS 包程序启动/重开/退出。公网验证完成真实核心 0.16.0 下载和官方验签、终端 0.6.0 下载/哈希/解包/登记；这些历史结果不代替本版本的合并后和五平台发行验收，详见[实施记录](../implementation-update-acceleration.md)。

整合最新 main 并升至 0.18.0 后，本机重新完成类型/格式、文档、91 项脚本、207 项 Rust 测试（12 项远端用例按标记跳过），以及正式前端更新专项（8 类验收、无页面错误）。

本版本正在准备五平台原生源码检查和正式打包。最终包来源提交、原始打包 run、Release 链接和实际验证范围在发布收尾时记录；当前文档不声明这些检查已通过。
