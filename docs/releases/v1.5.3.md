# SoDeck 1.5.3

- 插件可以声明并携带自己的 SVG 图标，列表、更新、侧栏、标签和设置入口统一读取当前插件包。
- 插件关闭、未启动或启动失败时仍可显示自有图标；缺失或损坏图标回退为通用图标，不影响业务。
- 官方目录预览读取同源配置和 SVG 并缓存，已安装插件展示不依赖官方目录。旧插件和已有图标名称继续兼容。

Agent MCP 0.2.3 首先接入自有机器人图标。核心 API/UI 主版本不变，未新增生产依赖，核心与各插件独立更新。完整行为和限制见[插件管理](../features/plugins.md)及[插件 API](../plugin-api.md#插件图标)。

Windows 本机类型/格式、189 项工程脚本、完整核心测试、正式前端构建及真实产物界面、SVG 图片遮罩回归和原生图标 smoke 通过。回归覆盖任意插件 ID/图标名、旧清单兼容、关闭及未启动的图标读取、无官方缓存、版本切换与回退、路径穿越/包外链接/缺失/超限、官方同源 Git 树缓存和单项失败。来源完整 Check 的五平台核心及插件源码、Linux 浏览器、SSH/文件/终端/Docker/网络和三服务器业务回归通过。
