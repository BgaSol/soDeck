# SoDeck v0.5.2 — 官方插件在线安装

补齐客户端首次安装官方插件的入口。此前只能添加本地目录，在线更新只针对已登记插件，空白安装无法直接取得插件。

- **设置 → 插件管理 → 官方插件** 可查看 Hello 和组件交互示例，点击“下载并启用”自动选择本机平台的正式发行包、下载、解压并登记。核心包仍不包含插件程序。
- 显示查找版本、下载进度和失败原因，支持重试；安装完成后统一重启启用。打开设置不会自动在后台下载或启动插件。
- 已有记录显示“管理”，不重复安装、不覆盖原目录或修改已配置来源；之后继续在详情中独立更新。
- 组件交互示例独立以 `plugin-ui-example-v0.1.0` 发行，提供侧栏和中央多 Tab 的交互占位，不执行远程终端、文件或转发业务。

## 验证

Rust 集成覆盖从空记录下载安装、重启加载、重复安装拒绝、API/平台不匹配、损坏归档、错误 ID、登记失败清理和重试。正式前端产物配合真实隔离核心验证官方列表、尚未发行与下载失败重试、安装后待重启和页面重开保留记录；原有主题与表单滚动回归继续执行。

核心和插件均沿用五目标原生 GitHub 构建、独立 Release 与现有更新清单；更新包从 GitHub 下载，网络不通时界面保留失败原因。没有新增生产依赖、插件权限系统或插件市场。
