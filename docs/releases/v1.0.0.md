# SoDeck 1.0.0

- 顶部 SoDeck 打开完整管理台，连接、插件、设置、消息、日志、状态和更新在主区域内导航；主窗口“＋”进入同一个服务器连接页。
- 工作台两侧窄入口栏仅展示插件工具，终端通过新建和标签使用；管理台隐藏插件页面，返回时保留会话、布局和草稿。
- 服务器目录改为紧凑连接路径树，共享显式路线前缀并高亮完整路径；多标签采用 AND，保留非命中祖先作为上下文。
- 旧分组资料在内存中迁移为标签，首次保存保留 servers.v1.json.bak；旧核心无法读取 v2，降级需恢复备份，备份不包含迁移后新增资料。
- 公共样式和三主题集中维护于 packages/ui，明暗使用 IDEA 配色，多巴胺保持原色彩角色；旧插件 token 和几何语义保持兼容。
- 连接成功的会话接纳与页面定位分开，等待期间切页或改选服务器后，迟到成功不抢走当前页面。

文件、终端、Docker、网络和系统状态插件内部的操作与展示逻辑保持原实现，核心包仍不包含业务插件。未新增生产依赖。行为及维护边界见[连接](../features/connections.md)、[工作台](../features/workbench.md)、[设置](../features/settings.md)和[架构](../architecture.md)。

## 验证与发行

包来源：[d78f5406d77fc108ef6f949210d9756525c15633](https://github.com/BgaSol/soDeck/commit/d78f5406d77fc108ef6f949210d9756525c15633)；[来源 Check](https://github.com/BgaSol/soDeck/actions/runs/43578281356) 的全部选中检查通过，包含五平台核心、共享客户端与五插件源码测试，类型/格式、工程脚本、完整浏览器 UI 与生产前端回归、Windows SSH，以及真实 SFTP、PTY、网络、系统状态、Docker 和组件通信。netem 未选择，skipped 不计为通过。本机另通过 165 项脚本、三主题 token/插件几何契约、11 项目录回归、核心完整测试、NSIS 构建及原生 WebView 远程组合。

原始打包与独立实际包验收：[43578304833](https://github.com/BgaSol/soDeck/actions/runs/43578304833)。Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 五平台全部原生构建、签名和打包；实际 NSIS、DEB/AppImage、DMG/updater tar 内程序的启动、保存资料、重开及退出全部通过。

固定原包兼容验收：[43579046341](https://github.com/BgaSol/soDeck/actions/runs/43579046341)，配套独立正式插件 terminal 0.9.0、files 0.11.1、network-proxy 0.4.3。五平台均通过原生工作台、SSH/PTY、文件读写下载、网络转发、移窗、保存重开及退出。核心与插件分别固定来源及摘要，未重新发行插件；此组合不包含 Docker 和系统状态插件。

发行：[SoDeck 1.0.0](https://github.com/BgaSol/soDeck/releases/tag/v1.0.0)，设为 Latest。16 个附件沿用原始打包 run；发行收尾仅同步说明及 core-update.json 的 notes，安装器、更新程序归档及签名字节不变。[附件与验收记录](v1.0.0-assets.json)保留来源、SHA-256、五平台实际包报告和固定远程输入，必要证据不只依赖临时 Artifact。

早期候选未采用：文档链接大小写、浏览器测试套件归属、旧夹具的隐式工作区激活及分组操作已修正；旧 Check 失败和取消的打包不计为验收结果。目录实际包保存/重开新增回归，最终所有结果均来自上面的确切来源。

未执行正式旧版实际安装升级、生产服务器、netem、原生文件剪贴板/默认应用及深度编辑器专项、设备 IME/读屏、多屏/混合 DPI、Wayland 指针，也未覆盖全部 Docker Engine/远端系统。旧核心无法读取 v2 目录，降级需恢复 servers.v1.json.bak，迁移后新增资料不在该备份中。既有 [glib 0.18.5 中危告警 GHSA-wrw7-89jp-8q8g](https://github.com/BgaSol/soDeck/security/dependabot/5)仍保留；本次未调整 GTK/Tauri 依赖链，不宣称修复该告警。
