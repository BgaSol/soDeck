# SoDeck v0.8.3

一级 Tab 的加号展开服务器选择层，可按名称、地址、账号或分组搜索；选择后复用现有连接和认证流程。已打开的服务器定位已有工作区，新连接创建在发起窗口，重连保留原窗口和页面。列表支持键盘选择、Esc、再次点击加号或点击外部关闭，并提供连接状态、读取失败重试和连接进度。

二级 Tab 的加号直接追加、选中并聚焦一个官方终端。在文件编辑器中点击同样新建终端，原页面和草稿保留。创建中防重复，失败可重试；终端不可用或服务器断线时显示原因。没有默认类型菜单或上次插件记忆。两个入口复用公共主题，多巴胺浮层使用完整的 2px 描边。

工作台左下角仅展示连接状态和地址，移除连接弹出菜单和断开入口；断线时保留直接重连。SSH 密码或私钥口令错误可重新补填，默认勾选记住；整条路径认证成功后才保存，取消勾选仅用于本次连接。失败、取消、拒绝指纹、并发修改或写入失败不覆盖原凭据。密码和口令按现有规则明文保存在本机文件。

本次仅升级核心。终端 0.1.2、文件 0.2.1、网络隧道 0.1.0 继续独立分发，无需重新安装。Hello 与组件交互示例继续保持退役状态。v0.8.0～v0.8.2 是已撤回的候选，本次使用新的版本标签。

本机 Windows x86_64 已通过类型与格式检查、71 项 Rust 常规测试、12 项脚本测试、目录/工作区/连接/正式前端界面回归及正式前端构建。另有 5 项需 OpenSSH 与实际插件包的用例由专用验收入口执行。功能与验证边界见 [Tab 新建实施记录](https://github.com/BgaSol/soDeck/blob/8115fdcd5bed4108021a729da605fbde77afc2af/docs/implementation-tab-creation.md)。

发行准备修复了原生 SSH 烟测可能对同一指纹问题重复回复的竞态；连接超时时补充最后状态与阶段，未延长超时或增加重试。本次 Windows x86_64 包内 SSH 在既有时限内通过，之前单次超时未再复现。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 的原生构建、安装包启动/退出和更新签名验证均通过：[核心构建](https://github.com/BgaSol/soDeck/actions/runs/42159047061)。同一提交 `363ded9576367e46453891c71489762f2ef01c8b` 的三个插件独立构建通过：[终端](https://github.com/BgaSol/soDeck/actions/runs/42159076004)、[文件](https://github.com/BgaSol/soDeck/actions/runs/42159083849)、[网络隧道](https://github.com/BgaSol/soDeck/actions/runs/42159090730)。[实际包组合验收](https://github.com/BgaSol/soDeck/actions/runs/42160685410) 五目标全部通过，覆盖真实终端、SFTP 读写与下载、TCP/SOCKS5、移窗、断线清理、重开和退出。

16 个发行附件的大小和 SHA-256 已核对，核心更新清单覆盖全部五个正式目标，更新地址和签名与实际包一致。核心作为 Latest 发布，三个插件的既有正式 Release 保持不变。

更新包使用 Tauri updater 签名；Windows 未配置商业代码签名，macOS 使用 ad-hoc 签名。原生 CI 不替代真实设备的复杂输入法、混合 DPI 手势和人工升级验收。
