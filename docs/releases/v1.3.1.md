# SoDeck 1.3.1

- 修复插件刚打开时的白色闪烁：主题与挂载握手完成前显示宿主主题底色，保留 iframe 的真实布局尺寸；挂载后显示页面，失败沿用重试和日志入口。
- 修复旧版全局侧栏默认值一直覆盖插件推荐位置：Docker 在没有服务器保存布局的新工作台默认位于右侧。已保存的实际停靠位置不变；显式设置的新默认侧栏继续保留，恢复推荐后跟随插件声明。

未新增生产依赖或改变插件 UI API 主版本。旧 `ui-layout.json` 缺少位置覆盖标记时按历史缓存默认值迁移，其他固定、启动和顺序偏好保持。功能行为见[工作台](../features/workbench.md)，本地布局兼容规则见[插件 API](../plugin-api.md)。本次只更新核心；Docker 插件现有发行声明已为右侧，无需重新发行插件。
