# SoDeck 1.3.1

- 修复插件刚打开时的白色闪烁：主题与挂载握手完成前显示宿主主题底色，保留 iframe 的真实布局尺寸；挂载后显示页面，失败沿用重试和日志入口。
- 修复旧版全局侧栏默认值一直覆盖插件推荐位置：Docker 在没有服务器保存布局的新工作台默认位于右侧。已保存的实际停靠位置不变；显式设置的新默认侧栏继续保留，恢复推荐后跟随插件声明。

未新增生产依赖或改变插件 UI API 主版本。旧 `ui-layout.json` 缺少位置覆盖标记时按历史缓存默认值迁移，其他固定、启动和顺序偏好保持。功能行为见[工作台](../features/workbench.md)，本地布局兼容规则见[插件 API](../plugin-api.md)。本次只更新核心；Docker 插件现有发行声明已为右侧，无需重新发行插件。

## 发布与验证

本机 Windows x86_64 的类型/格式、286 项核心测试、183 项工程脚本和真实文件/SFTP 界面、完整工作台布局与 17 组正式构建界面回归通过。新增回归先复现旧全局默认覆盖 Docker 右侧推荐值，再验证默认值更新、显式默认和已存停靠保留；插件挂载测试分别在浅色、深色和多巴胺主题下阻止挂载，确认 iframe 隐藏、保持真实尺寸并由宿主显示当前主题底色，挂载后正常显示。

包来源：[d7ebe07f963743d39bd347a0cd552010a821ce67](https://github.com/BgaSol/soDeck/commit/d7ebe07f963743d39bd347a0cd552010a821ce67)；[来源 Check](https://github.com/BgaSol/soDeck/actions/runs/43864040294)；[原始打包与实际包验收](https://github.com/BgaSol/soDeck/actions/runs/43864053144)。来源 Check 的全部选中项通过，覆盖脚本及修正后的真实文件/SFTP 界面；[同提交五平台核心源码检查](https://github.com/BgaSol/soDeck/actions/runs/43864056275)通过。完整浏览器界面、共享客户端、Windows SSH 与网络测试在[产品代码相同的前序提交](https://github.com/BgaSol/soDeck/actions/runs/43860559760)通过；该轮文件界面测试因暂停加载时等待可见而失败，最终提交改为检查加载节点与隐藏状态，真实文件/SFTP 界面重新验收通过。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 五平台原生构建、签名和实际包验收全部通过。安装或解包后运行包内程序，验证启动、资料保存、重开和退出；AppImage 与 macOS updater tar 另验启动退出。

[五平台原生远程组合](https://github.com/BgaSol/soDeck/actions/runs/43865957608)通过，使用本次原始核心 1.3.1 候选及已发布终端 0.9.1、文件 0.11.2、网络 0.4.4 包，验证原生 WebView/Channel 下的 PTY、文件读写/下载、网络转发、移窗、重开和退出。该组合入口不包含 Docker 或系统状态；Docker 推荐位置由本次核心回归使用其实际发行声明验证。
