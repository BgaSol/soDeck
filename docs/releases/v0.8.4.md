# SoDeck v0.8.4

文件与文件夹统一使用批量任务上传、下载，保留空目录、隐藏文件和二进制内容。文件侧栏支持多选、范围选择、远程复制/剪切/粘贴、内部拖动复制或移动，以及新建、重命名和递归删除。任务提供进度、冲突处理、取消和失败项重试；覆盖传输先写临时文件，移动回退为复制时确认目标后再删除源，未知提交结果要求用户核对。

本地系统文件剪贴板与原生拖入接入同一上传流程。远程复制后在系统粘贴、远程拖到系统目录继续不实现；远程到本地使用明确的下载入口。跨目录多选时先确认目标，涉及未保存编辑页的修改先走保存/放弃/取消流程。实际接口与限制见 [文件管理实施记录](../implementation-file-management.md)。

核心与业务插件继续独立分发。此轮核心为 0.8.4，文件插件为 0.3.0；请先升级核心，再升级文件插件并重启。终端 0.1.2、网络隧道 0.1.0 保持原版本。核心安装包不包含业务插件，旧文件插件仍可使用原接口。

服务器首页单击查看详情，双击连接或切回已有工作台，连接中防止重复发起。修复工作区、服务器页签菜单位置和短菜单双向滚动，长组件列表仅纵向滚动，搜索后重新贴近入口。主窗口与拆出窗口顶部空白统一使用原生拖动和双击最大化/还原；修复 macOS 顶部重复留白。

本机 Windows x86_64 已通过类型与格式检查、74 项核心测试、3 项文件插件测试、12 项脚本测试、真实 OpenSSH 文件集成、完整文件界面回归、服务器/工作区/连接/正式前端界面回归、EXE/NSIS 构建和原生包启动退出、终端与 SFTP 组合烟测。

发行提交 `430fc3530acdd333962bc886cb6ed5615011ac02` 的 [核心构建](https://github.com/BgaSol/soDeck/actions/runs/42178755288) 在 Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 全部通过，包含原生架构校验、安装/解包后的程序启动退出和更新签名验证。[文件插件](https://github.com/BgaSol/soDeck/actions/runs/42178756002)、[终端](https://github.com/BgaSol/soDeck/actions/runs/42178794268) 与 [网络隧道](https://github.com/BgaSol/soDeck/actions/runs/42178800419) 独立构建全部通过。[实际包组合验收](https://github.com/BgaSol/soDeck/actions/runs/42180281189) 五目标全部通过，覆盖真实 PTY、SFTP 保存下载、TCP/SOCKS5、移窗、断线清理、重开与退出。

核心 16 个附件与文件插件 6 个附件的大小、SHA-256 均已下载核对；两个更新清单均覆盖五个正式目标，核心清单签名与独立签名附件一致，插件清单哈希与归档一致。核心作为仓库 Latest，文件插件使用独立正式 Release，终端与网络插件保留既有正式版本。

系统文件管理器的真实复制/拖入、混合 DPI、Linux GNOME/KDE 与 X11/Wayland 组合仍需设备验收。普通 SFTP 的属性检查无法消除全部外部并发竞态；断线时临时文件清理可能失败并报告名称。不提供暂停、断点续传、跨服务器复制或重启恢复。

更新包使用 Tauri updater 签名；Windows 未配置商业代码签名，macOS 使用 ad-hoc 签名。
