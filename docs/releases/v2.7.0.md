# SoDeck 2.7.0

- “设置 → 通用”集中提供外观、登录启动和关闭窗口行为；各组件页面与应用信息继续独立。
- 普通设置入口恢复当前窗口最近位置，托盘设置直接打开通用，状态页的应用信息继续打开应用与数据。
- 各项保存状态与错误独立显示；后台重绘保持保存中的控件状态，登录项读取不会清除关闭行为的错误。
- 系统登录项读取跟随通用页实际显示，切到工作台、其他页面或隐藏窗口时停止主动读取，返回后核对实际状态。

操作与失败规则见[设置](../features/settings.md)。核心 API、偏好数据和插件设置协议保持兼容，未增加生产依赖，业务插件不随本次核心重建或发行。
