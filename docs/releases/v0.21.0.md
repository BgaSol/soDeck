# SoDeck 0.21.0

## 工具按钮与面板共同停靠

侧边只提供工具入口，终端保留中央标签和「＋」新建。工具按钮支持左右拖动及同侧排序，按钮与面板保持同侧；也可通过右键或 Shift+F10 菜单移侧、排序和置顶。

展开工具移动后继续展开，目标侧原工具收起并保留实例；收起或尚未打开的工具保持收起，不因移动创建业务。Esc、失焦、切换服务器或布局修订变化取消手势，同窗移动保留原 iframe、Surface 和业务资源。

两侧更多清单提供全部工具及实际位置，中央工具可显式停靠，其他窗口的工具定位到原窗口。每台服务器和工作台分别保存位置及顺序；兼容旧布局，损坏和未知版本文件保留。保存失败时布局仍有效，重试只保存最新状态。

停靠、布局与持久化由核心管理，插件继续负责业务。配套终端 0.7.2 只清理侧边入口推荐，旧终端清单在新核心上也不再产生侧边按钮；没有新增插件 API 或生产依赖。核心与终端独立版本、独立打包，核心安装包不包含业务插件。

## 验证与发行来源

本机 Windows x86_64 类型/格式、95 项脚本、217 项核心测试及完整 UI 回归通过；默认 13 项环境专项跳过，另显式完成真实 OpenSSH PTY、SFTP、三插件协作及网络 UI/转发。MSI 包内实际程序配合独立终端包验证 SSH、原生移窗、资料重开与退出；四插件原生交互的 8 项检查验证系统鼠标拖动、草稿、原 iframe、运行中转发、取消关闭和最终端口释放。本机系统 DPI 为 175%。详细复现及本机证据见[实施记录](../implementation-tool-docking.md)。

本次 GitHub 源码、五平台独立打包、签名和实际包组合验收及发行链接在完成后补充到此处。正式发布复用同一原始运行的包，不覆盖已发布同版本附件。

## 验证边界

本机结果不代替五平台原生结果。生产服务器、Docker Engine 专项、多屏混合 DPI、其他系统的人工鼠标交互、netem 和历史版本升级未在本轮本机专项中验证；正式原生构建与实际包验收结果以本次运行记录为准。
