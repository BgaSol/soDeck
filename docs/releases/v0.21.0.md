# SoDeck 0.21.0

## 工具按钮与面板共同停靠

侧边只提供工具入口，终端保留中央标签和「＋」新建。工具按钮支持左右拖动及同侧排序，按钮与面板保持同侧；也可通过右键或 Shift+F10 菜单移侧、排序和置顶。

展开工具移动后继续展开，目标侧原工具收起并保留实例；收起或尚未打开的工具保持收起，不因移动创建业务。Esc、失焦、切换服务器或布局修订变化取消手势，同窗移动保留原 iframe、Surface 和业务资源。

两侧更多清单提供全部工具及实际位置，中央工具可显式停靠，其他窗口的工具定位到原窗口。每台服务器和工作台分别保存位置及顺序；兼容旧布局，损坏和未知版本文件保留。保存失败时布局仍有效，重试只保存最新状态。

停靠、布局与持久化由核心管理，插件继续负责业务。配套终端 0.7.2 只清理侧边入口推荐，旧终端清单在新核心上也不再产生侧边按钮；没有新增插件 API 或生产依赖。核心与终端独立版本、独立打包，核心安装包不包含业务插件。
