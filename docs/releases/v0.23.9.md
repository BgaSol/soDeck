# SoDeck 0.23.9

- 服务器与分屏页面标签增加固定翻页按钮、总数和可搜索列表。多标签与长名称保持单行，选择后露出目标，手动浏览与后台刷新保留位置；关闭和隐藏沿用现有生命周期。
- 箭头与离散滚轮使用可打断缓动，连续像素输入跟手，减少动态效果关闭额外缓动。拖拽边缘短暂停留后自动滚动；固定按钮不接收落点，释放前确认目标窗口最新几何，失败提示重试。
