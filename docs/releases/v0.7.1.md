# SoDeck v0.7.1

退役 Hello 和组件交互示例两个演示插件。设置中的官方插件列表仅保留终端、文件和网络隧道；删除两个示例的源码、独立打包与发布配置，以及依赖示例包的旧验收工作流。

升级后的首次启动会移除这两个旧插件的登记，避免再次自动加载。原外部程序目录、插件数据、消息和日志按既有“移除记录”规则保留；不会清理其他插件或服务器资料。

宿主布局、草稿、关闭确认、主题及跨窗重挂载回归改为仅测试夹具，不再作为产品插件分发。正式插件版本继续使用终端 0.1.2、文件 0.2.1、网络隧道 0.1.0，无需重新安装。

本机 Windows x86_64 已通过类型与格式检查、三个业务插件格式检查、62 项 Rust 回归、12 项脚本测试、全部界面测试、NSIS 构建及启动/移窗/重开烟测。Rust 常规测试另有 5 项需要独立 OpenSSH/实际插件环境的场景，由专用验收入口执行。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 的原生构建、打包与实际包内启动均已通过：[核心构建](https://github.com/BgaSol/soDeck/actions/runs/42032077667)。同一提交 `31d8b916` 的三个业务插件独立构建通过：[终端](https://github.com/BgaSol/soDeck/actions/runs/42032345856)、[文件](https://github.com/BgaSol/soDeck/actions/runs/42032357185)、[网络隧道](https://github.com/BgaSol/soDeck/actions/runs/42032365689)。[实际包组合验收](https://github.com/BgaSol/soDeck/actions/runs/42033777128) 五目标全部通过，覆盖真实终端、SFTP 读写与下载、TCP/SOCKS5、移窗、断线清理、重开和退出。

16 个发行附件 SHA-256、更新清单的核心版本与五目标映射均已核对；五个更新包已使用仓库公钥验证 Ed25519 签名。更新包使用 Tauri updater 签名；Windows 未配置商业代码签名，macOS 使用 ad-hoc 签名。原生 CI 不替代真实设备的输入法、混合 DPI 手势和人工升级验收。
