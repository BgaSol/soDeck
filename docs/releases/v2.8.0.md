# SoDeck 2.8.0

- 日志与消息使用“精密工作台”：紧凑摘要列表与独立详情，完整正文、实例身份和结构化字段按需阅读；三主题与窄内容区保持一致操作。
- 日志支持稳定选择、阅读位置保持、移出结果的单条快照和复制本条；暂停中筛选明确标为待应用，继续显示后查询。
- 消息阅读与已读保存独立处理，保存失败保留正文和重试入口；未读行移除保留详情及有效焦点，去重更新不自动标为已读。
- 两页独立管理状态、请求和 DOM，合并在途读取并拒绝过期回包；页面隐藏后停止主动读取。已移除插件的历史来源、存储告警与局部错误可读。

操作、失败和有界历史规则见[日志与重要消息](https://github.com/BgaSol/soDeck/blob/main/docs/features/logs-messages.md)。核心 API、存储格式、插件协议、外壳导航与工作区布局保持兼容；没有新增生产依赖，业务插件不随本次核心发行。

性能分段测量均预热 2 次、采样 30 次，保留完整样本，不设跨机器耗时门槛，也不宣称相对旧版的加速比例：

前两项只测实际页面模板的更新与强制布局，不含磁盘、IPC、原生 WebView 或远端 IO；后两项使用隔离核心的真实 `read_logs`，含磁盘解析/筛选/序列化及 Node pipe，不含 Tauri IPC 和 UI。因此不能直接相加宣称实际点击响应时间，短/长场景差异也不当作稳定性能排序。后端扫描成本仍存在，本轮通过单在途和可见性控制减少重复工作，没有引入索引、存储迁移或无限历史。

真实鼠标/触控板、CJK 输入法、读屏、混合 DPI/多屏、200% 文本缩放、一小时长时运行、其他原生系统交互、生产服务器、远程实际包组合和旧版升级未在本轮自动化中执行。合成 composition、模拟窗口宽度、源码/浏览器与包内页面烟测分别记载，未执行范围不能计为通过。尚无设备证据的原约定已转入[原生专项计划](https://github.com/BgaSol/soDeck/blob/main/docs/plans/native-verification.md)，本页软件重构与发行完成不代表该设备矩阵完成。
