# SoDeck 2.8.0

- 日志与消息使用“精密工作台”：紧凑摘要列表与独立详情，完整正文、实例身份和结构化字段按需阅读；三主题与窄内容区保持一致操作。
- 日志支持稳定选择、阅读位置保持、移出结果的单条快照和复制本条；暂停中筛选明确标为待应用，继续显示后查询。
- 消息阅读与已读保存独立处理，保存失败保留正文和重试入口；未读行移除保留详情及有效焦点，去重更新不自动标为已读。
- 两页独立管理状态、请求和 DOM，合并在途读取并拒绝过期回包；页面隐藏后停止主动读取。已移除插件的历史来源、存储告警与局部错误可读。

操作、失败和有界历史规则见[日志与重要消息](https://github.com/BgaSol/soDeck/blob/main/docs/features/logs-messages.md)。核心 API、存储格式、插件协议、外壳导航与工作区布局保持兼容；没有新增生产依赖，业务插件不随本次核心发行。

## 验证与发行

本版本准备中，尚未发布。包来源提交、原始打包运行与 Release 链接在实际构建验收后填写；不以本机或历史通过代替五平台结果。

本机已通过格式/类型、219 项工程脚本、核心测试及完整 `npm run ui:test`，后者包括聚焦两页、正式 dist、桌面策略、工作区/连接、设置和交互回归。页面回归覆盖 500 条日志、1000 条消息、纯文本与各种 JSON 根、稳定实体与滚动锚点、读取合并/迟到回包、暂停、中文合成 composition、本地时间与区间校验、已读队列/失败重试/未读焦点、去重更新、来源移除、存储告警、三主题及 320/640/1024/1440px 内容场景。320px 仅验证本页内容，不宣称既有外壳支持低于720px的应用窗口。

本机 Windows x86_64 release 构建及隔离实际程序烟测通过：读取日志、查看字段、暂停、消息纯文本阅读、核心已读保存、三主题实际颜色、返回后筛选、保存资料重开与退出。日志/消息的相同原生页面验证已加入现有五平台核心包验收，要求 `logsMessagesNative` 收据；新包结果仍待本次运行。

初次本机原生尝试使用 debug 程序且未启动 Vite，等待页面超时；启用正确开发入口后 debug 验证通过，后续 release 程序独立验证通过。正式产物测试按新折叠时间入口调整；对比度检查从只解析 rgb 数组改为浏览器实际颜色转换，保留4.5:1要求。主题测试遇过一次原有设置焦点断言时序失败，保留最终重跑结果，不当作首次全通过。

性能测量是同机 Chromium 的500条摘要更新与强制布局，不包含磁盘扫描、IPC、原生 WebView或远端IO，也不作为跨机器门槛。完整样本及最终结果在本次交付收尾记录。

真实鼠标/触控板、CJK输入法、读屏、混合DPI/多屏、一小时长时运行、其他原生系统交互、生产服务器、远程实际包组合和旧版升级未在本轮自动化中执行。合成 composition、模拟窗口宽度、源码/浏览器与包内页面烟测分别记载，未执行范围不能计为通过。
