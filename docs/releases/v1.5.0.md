# SoDeck 1.5.0

- 插件可查询所属会话的真实端点与账号摘要。
- 既有非交互命令流支持插件进程分页读取原字节信封、可选执行期限和 worker 完成事实。
- 通用文件复制支持直接写入实际调用插件的数据目录中的新文件，界面可打开该目录；保留路径校验、源检查、取消与独占提交。

这些通用能力支持独立的[AI 排障接入插件](https://github.com/BgaSol/soDeck/blob/main/docs/features/mcp.md)。核心不含业务插件、MCP 服务或模型；核心 API 主版本保持 1，旧插件行为保持兼容。完整契约见[插件 API](https://github.com/BgaSol/soDeck/blob/main/docs/plugin-api.md)，插件独立版本和发行验证见[CHANGELOG](https://github.com/BgaSol/soDeck/blob/main/plugins/mcp/CHANGELOG.md)。核心未新增生产依赖。
