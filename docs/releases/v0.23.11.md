# SoDeck 0.23.11

- 设置、服务器搜索和表单保持同一实体的稳定挂载，连续输入及后台刷新不再拆下活动子树。
- 动态列表与工作台改用固定版本 morphdom，删除自制递归 diff、整页重建恢复与全局按压队列；插件 Surface 保持独立生命周期。
- 下载网络及插件来源草稿参与退出/重启确认；来源保存检查基线，失败和冲突保留输入。
- 后台快照、更新与网络读取分别接收，失败保留有效模型；设置与插件轮询拒绝失效结果。

## 验证与发行

长期回归包含实际正式入口的 CDP 连续 composition、零子树断开、一次提交，隐藏宿主草稿关闭、部分保存失败和恢复，以及分屏/iframe/按压队列销毁。自动化组合输入不等于真实系统输入法验收。

本地类型与 Rust 格式检查、159 项工程脚本和完整核心测试通过（254 项通过、13 项需专项环境的测试保持 ignored）。服务器、工作台、连接、分屏、18 项交互、正式入口、桌面策略、真实 xterm 输入和组件设置回归通过。网络专项通过真实 SSH/TCP/SOCKS 生命周期、协议、curl 互操作及界面验证。Windows x86_64 的正式前端、核心 release、MSI 与 NSIS 构建通过。正式入口读取失败测试持续注入故障直到页面观察到错误，避免共享计量接口的工作台轮询先消费一次性故障。
