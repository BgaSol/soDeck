# SoDeck 0.14.0

新终端默认自动识别远端 Linux Bash（4+）/Zsh 的当前目录，首次提示符和后续 `cd` 自动带动文件侧栏，无需配置主机名或修改远端启动文件。文件树底部显示实际跟随状态和原因，可展开重新定位；手动浏览后执行普通命令不会回跳，嵌套 SSH/容器/子 shell 运行时暂停，返回外层后恢复。

本次独立发行终端 **0.4.0** 和文件 **0.6.0**。请更新核心和这两个插件，重启后新建终端；现有会话不补注入。系统状态与网络隧道保持原版本。核心继续独立打包，不包含业务插件，也不新增生产依赖。

自动报告通过本次 shell 标识和文件服务可读取的临时标记确认来源与文件系统对应关系。无法对应、无法访问、shell 不支持或已有调试钩子冲突时保留普通终端/文件浏览并说明原因。终端设置保留高级 OSC 7 兼容模式和关闭选项。

## 验证与交付

本机类型、核心/插件格式、正式前端构建、89 项脚本、167 项核心测试、终端源码与真实 UI/输入回归通过。核心 10 项原有 ignored 不计为普通套件通过。真实 PTY 验证 Bash 字符串/数组提示符钩子与 Zsh 的启动配置顺序、退出状态、登录标志、特殊路径/软链接、嵌套 shell、Ctrl-C 和正常退出清理。

Windows 三插件高级 PowerShell 兼容模式联动通过；Windows 客户端经真实 SSH 连接隔离 Linux，验证 Bash/Zsh 默认自动跟随、多个终端、手动浏览、隐藏、移窗及重连。浅色、深色、多巴胺主题在 1320px/820px 宽度的展开状态已目视检查，原因和重试入口可见。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 的核心原生构建、updater 签名、实际包安装/解包、启动、资料重开和退出通过，终端与文件的五平台独立包通过。五平台实际包组合使用本次核心、终端、文件及正式网络隧道 0.2.2，验证 SSH、PTY、文件、网络和退出；Linux 实际包另验证自动目录报告、正确文件系统标记通过和错误标记被拒绝。

包来源提交的首次 Check 中，五平台核心/四插件源码、Windows 完整 UI/SSH、Linux ARM64 普通网络和公共检查通过。Linux x86_64 的两组 Bash 启动回归通过，但 Zsh 被 runner 全局补全目录的交互确认阻塞，后续系统状态和三插件联动未执行。修正仅在测试生成的 .zshenv 中设置 skip_global_compinit=1，隔离 runner 配置；提交 401708d 与包来源 b2ee37f 的产品源码及构建输入完全一致。修正后的 Check 全部相关检查通过，包括五平台源码、Windows 完整 UI/SSH、Linux 两架构普通网络，以及 x86_64 文件、终端、Bash/Zsh 真实 PTY、系统状态和默认自动模式三插件联动；netem 按配置 skipped。

核心首次 metadata 上传遇到临时草稿变化，仅重跑同一 run 的失败 metadata 后成功。实际包组合首次准备恰逢原核心 run 重试中，尚未执行业务测试；核心完成后按相同输入重跑并全部通过。没有重建成功的平台或更换包来源。

发布前核对核心 16 个附件、终端和文件各 6 个附件的版本、来源、五平台清单、更新签名及插件 SHA-256；更新说明在草稿阶段同步，二进制和签名沿用原始附件。

实现及限制见[实施记录](../implementation-terminal-directory.md)。自动跨容器、跨主机、SFTP chroot、UNC 或未知视角映射不支持。强制 SIGKILL/掉电可能留下用户私有临时目录；用户的实际服务器与全部自定义启动配置、远端其他系统/shell、真实设备 DPI/多屏、netem 和历史版本对在线升级未在本次验证。客户端五平台通过不代表所有远端配置通过。
