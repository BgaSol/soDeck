# SoDeck 2.12.0

- 网络 TCP 通道保留结构化失败原因、发生阶段、检查建议和有界原始诊断。SSH 禁止转发时明确提示服务器策略拒绝，不再只返回英文库错误；不能确定的目标连接失败不推测成端口拒绝或 DNS 故障。
- 核心 API/SDK 更新为 2.2，网络快照新增 failure，旧 error 形状保留；旧 API 2.1 插件继续可加载，新 SDK 插件要求 2.2 核心。网络隧道和 Docker 分别提供本机监听、目标检查和历史失败的用户展示。
- 核心与六插件保持独立版本和分发，不新增生产依赖、权限流程或后台诊断服务。使用方式和边界见[网络隧道](../features/network-proxy.md)，字段见[插件 API](../plugin-api.md)。

本地 Windows x86_64 通过格式/类型、234 项脚本、核心完整测试、协议/SDK/网络单元、网络进程/命令、真实 OpenSSH 允许及禁止转发、网络三主题窄栏 UI、Docker 进程/UI 和工作台 UI。使用旧网络 0.6.2 包运行新增用例能复现只有文字、没有结构化原因的结果；新包对应源码通过。批量错误帧超限在实现时以紧凑摘要和最坏转义回归修正。

正式发行 [SoDeck 2.12.0](https://github.com/BgaSol/soDeck/releases/tag/v2.12.0)，同一原包共 16 个附件，核心设为 Latest；六插件各自独立发布并保持非 Latest。更新清单仅同步本次说明，不替换已验收程序。先更新核心，再更新所需插件并重启。

发布后匿名下载全部 52 个公开附件，逐项核对大小与 SHA-256；七份在线更新清单的版本、五平台字段和插件 API 2.2 均正确。Latest 仍指向核心 2.12.0，未替换已发布程序附件。各组件永久证据保存本次公开下载结果。

本轮不执行 netem、真实注销登录、物理 IME/DPI/读屏或全部 Docker 远端组合。用户服务器 SSH 配置未修改；本轮错误表达不会绕过服务器禁止转发的设置。
