# SoDeck 2.2.1

修复连接树右键菜单点击原节点后不关闭、焦点离开菜单后 Esc 失效的问题。点击菜单标题或全部操作禁用时仍可取消；左键来源卡片关闭菜单后继续原有单击或展开操作，工具栏新增类型按钮保持再次点击切换。

目录菜单统一管理来源、输入、定位和关闭会话，取消后返回可用来源，外部点击和模态接管不抢焦点。命令在关闭前取得不可变来源，编辑、复制与新增表单继续准确返回原位置。移除关闭后残留的来源状态和重复滚动监听；状态刷新、隐藏、滚动、替换及销毁不会让旧回调恢复菜单。

不改变连接、认证、路径继承、目录格式、插件 API 或生产依赖。行为见[服务器与连接](../features/connections.md#节点右键操作与经节点新增)。
