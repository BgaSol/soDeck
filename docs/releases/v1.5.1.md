# SoDeck 1.5.1

- 新增单色机器人图标，用于独立[机器人接口插件](https://github.com/BgaSol/soDeck/blob/main/docs/features/mcp.md)的插件列表、工作区侧栏和设置入口。

机器人接口插件 0.1.2 将显示名称统一为“机器人接口”。核心与插件独立更新；已有插件身份、数据和客户端连接配置继续沿用。核心 API 主版本保持 1，未新增生产依赖。

Windows x86_64/ARM64、Linux x86_64/ARM64、macOS ARM64 五平台原生核心构建、签名和实际包启动/资料保存/重开/退出通过。安装或解包 NSIS、DEB、DMG 后运行包内程序，AppImage 和 macOS updater tar 另验启动退出。15 个程序包与签名附件的大小及 SHA-256 与五份原生报告一致，正式附件沿用原始打包 run 的已验证字节；公开下载摘要、Release 说明和更新清单 notes 均已核对。[永久核心发行证据](https://github.com/BgaSol/soDeck/blob/main/docs/releases/v1.5.1-assets.json)保存来源、原生报告、附件摘要、重试和跳过范围。
