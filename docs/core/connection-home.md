## 1. 需求理解与范围

T-027后续增量：[F-CORE-031 r1](mixed-route.md) / [T-027 r1](../tasks/T-027-mixed-route.md)根据P-68提出“直接连接 / 经由中转”及统一SSH/SOCKS5有序编辑器，计划替代下文三种互斥方式和“不增加混合链”的原任务限制。保留本页已存SSH选择、代理内联持久保存、草稿和可靠提交；新凭据上下文及MR测试由新规格维护。r3只登记待评审方案，未改变r2的确认/实测，不扩大原任务编码授权。

状态索引：r2 已获实施确认；实现、当前验证范围、交付与用户验收状态统一见 [T-025 结果](../tasks/T-025-results.md)。本页保留获确认方案中的设计时态，不能据此推断目前尚未编码。

用户明确要求舍弃现有“＋”弹框并完整重设计：App 刚进入及点击顶部服务器 Tab 的＋，都在中央内容区域展示左侧服务器列表与新建 SSH 连接、新建代理按钮；右侧呈现相应表单。代理允许在创建服务器时就地添加，服务器节点不允许就地新建。每项字段的位置、默认值和展开条件须由实际操作流程决定。

2026-10-28 用户进一步明确：**就地添加代理后保存，之后可复用**。“临时”描述创建入口，不表示一次性代理或仅本次连接有效。服务器节点包括目标 SSH 档案与路径中的 SSH 跳板；跳板只能从已保存服务器中选择。

设计推断：用户要把“找已有连接”“配置一个新连接”“管理可复用代理”拆成清楚的任务，降低层层跳转、概念混用和表单负担。日常打开已有服务器应一步到达终端，复杂路径按需展开。

本稿推荐完整替换原服务器选择器、新建/编辑服务器弹框及其中的代理/跳板嵌套流程。保留已有服务器、分组、凭据、三种访问路径、多级 SSH、工作区唯一归属和自动首终端能力。代理管理与分组管理也在此页右侧承载，避免从新入口再次绕回旧弹框。

这里“代理”是供 SSH 访问使用的已有 SOCKS5 网络服务配置，不是启动网络隧道插件的 HTTP/SOCKS 服务。本轮不增加 HTTP 连接代理、SSH/SOCKS 混合链、SSH config 导入、批量导入、代理测速、自动探测、SSH Agent/MFA 或新主题。底层网络重写、数据清空和数据库升级均不是此次 UI 重构的默认步骤。

除已明确需求及代理保存含义外，下文布局尺寸、默认值、草稿与按键均为本次推荐方案，等待整体评审；不是已实现功能或编码授权。

## 2. 页面结构与入口

### 2.1 页面归属

- 名称为“新建连接”，是每个工作台窗口至多一份的核心系统页，使用顶部 Tab 导航；不绑定服务器 ID，不算服务器工作区，也不创建插件视图/SSH/PTY。
- 完整启动直接显示该页；已有服务器时左侧立即显示目录，右侧为简短开始提示；服务器为空时右侧直接显示新建 SSH 表单。加载和读取失败分别呈现，不将读取失败当成空目录。
- 顶部**服务器 Tab 的＋**打开或定位此页，重复点击不叠加页面。终端内部 Tab 的＋仍按原规则新建终端。
- 打开服务器后切到该服务器工作区，“新建连接”页保留在同次运行的 Tab 中，方便返回。可关闭系统页；最后一个内容页关闭且窗口仍存在时显示该页。子窗口的系统关闭/工作区关闭继续遵守既有窗口生命周期，不借此阻止关闭子窗口。
- 切到系统页，隐藏该窗口原工作区的插件内容及左右工具面板，不结束其资源，不把旧服务器作为此页上下文；切回恢复原工作区呈现与焦点。系统页不参与工作区拆出/合并，不成为插件观察目标。
- 主窗口收起托盘保留本次草稿；真正退出/崩溃后不恢复草稿或服务器工作现场。保存配置仍按现有同版本规则保留。

- 左侧为目录栏，基准宽 280px，可在约 240～360px 调整；固定搜索/创建操作，服务器列表独立滚动，管理入口与数量在底部。保存宽度偏好如需新增持久字段，在代码方案核对后决定；本稿只要求同次运行保留。
- 右侧内容与左栏顶端对齐，正文最大约 720px，外留白 24～32px；不把表单拉满超宽屏，不将左右两侧做成层层嵌套卡片。

- 右侧标题及动作区保持可达，字段区独立滚动；底部动作条占实际布局空间，不压住末项/焦点。只有当前主提交使用强调色；左侧创建入口、内联代理保存均为次级样式。
- 正常 900×600 保持左右布局；字段区宽度不足约 440px 时主机/端口、名称/分组折成单列。更窄或文字放大后无法维持两列时，左栏可收起为具名“服务器列表”切换，右侧保留“返回列表”；不强行产生整页横向滚动。

## 3. 高频操作与表单

### 3.1 已有服务器：直接打开，编辑单独进入

1. 搜索匹配名称、主机、账号和分组，与分组筛选取交集；列表稳定按显示名称排序，不因刚连接自动重排。保留“全部分组”“未分组”。
2. 行主操作单击即打开服务器，键盘聚焦后 Enter 等价；不要求先选中再在右侧点击第二次连接，也不依赖双击识别。
3. 每行显示名称、`账号@地址:端口`；有跳板/代理时用紧凑文字说明路径类型。已打开只表示存在工作区，不冒充网络在线；未打开不进行后台探测。
4. 编辑是独立的行尾操作，hover/focus 显示且命中区预留；右键及 Shift+F10 菜单提供编辑、在新窗口打开、删除。删除不作为每行常驻高风险图标。
5. 已打开服务器只定位原工作区/原窗口，不重复建终端。新工作区按 F-CORE-010 自动初始化一个终端；连接失败/认证取消保留工作区与重试，不弹回复杂选择器。
6. 编辑打开右侧表单，底部主按钮为“保存修改”，不自动打开/重连该服务器。正在连接或保存时重复操作去重，切换后的迟到结果不抢当前表单或窗口焦点。

### 3.2 新建 SSH：按照“地址 → 身份 → 到达方式 → 整理名称”填写

| 字段 / 位置 | 推荐默认值 | 交互与理由 |
| --- | --- | --- |
| 主机地址，第一行主列 | 空，首次焦点 | 唯一必须先明确的目标；域名/IPv4/IPv6，去首尾空白，不静默拆改带协议/路径的粘贴内容；错误给出正确格式示例 |
| SSH 端口，同一行窄列 | 22 | 常用值直接可见可改，1～65535 整数；不藏到高级设置 |
| 用户名，地址之后 | 空 | 不猜 root、本机用户名或上一台账号；避免默认值把用户带到错误身份 |
| 身份认证 | 密码 | 密码 / 私钥两项直接可见；切换只展示相关字段，不出现未实现的 Agent 等选项 |
| 登录密码 | 空，可选 | 可以提前填写，也可连接时输入；显示/隐藏按钮在框内，默认隐藏；编辑已存凭据时只显示“已保存，留空保持”，不回填秘密 |
| 记住密码，紧邻密码下方 | 勾选 | 延续 P-30；说明“加密保存在此设备”，不勾选则仅本次 App 运行有效，不谎称仅当前一次连接有效 |
| 私钥文件，仅私钥模式 | 空，可选 | 支持本机选择文件及粘贴绝对路径；未填则连接时提供。口令位于路径下，只在此模式出现，可为空；不自动读取默认私钥、不上传远端 |
| 记住私钥凭据 | 建议勾选 | 与预设密码的表单操作一致；为本次新增推荐，复用核心凭据保存语义，私钥内容/口令不进入普通配置与日志；旧认证弹窗行为不隐式全局改写 |
| 连接方式 | 直接连接 | 直连 / SSH 跳板 / SOCKS5 代理互斥；只展示选择后的附加字段，三种方式不各铺一个表单 |
| 显示名称，最后的“名称与分组” | 留空时使用主机地址，非 22 端口附端口 | 名称为可选覆盖值，生成结果就近预览；不要求先想名字。用户填写后不随地址更改覆盖；生成名超现有上限则要求填写短名，不静默截断 |
| 分组，与名称同行 | 未分组；从明确的某个组筛选下创建时预选该组 | 减少重复分类；“全部”不推断归属。下拉内可进入内联新建分组，取消不丢其他字段 |

私钥路径/口令预设是本次表单增量；现有源码只在连接挑战框提供，不能写成新表单已具备。核心已有 `auth.ssh.set` 的相应参数；选择文件能力、秘密提交及跨窗口状态在代码方案中核实，不能仅改 UI 就声称完成。

密码/私钥秘密不随普通表单草稿复制、导出、日志或持久化；切换认证方式清除离开的秘密输入并隐藏明文显示。编辑时修改地址、账号、认证或有效路径，明确提示需要重新提供凭据，遵守已有身份绑定规则，不沿用到新身份。

底部“保存并连接”为主操作：“保存档案/归属 → 保存本次提供的凭据 → 核实成功 → 打开工作区及首终端”。“仅保存”为次操作，适用于提前配置、尤其先建立跳板；只更新左侧列表，不产生 SSH、工作区或终端。保存后右侧进入该服务器编辑状态，显示成功反馈。“取消”离开当前草稿，只有会丢失修改时才确认。

不提供“测试连接”常驻按钮：本轮主要路径就是保存并连接，真实失败可在工作区处理；避免测试触发另一套认证与资源流程。字段失焦或提交时校验，不在用户输入第一个字符时刷红；点击提交后错误定位首个无效字段，不能只有不明原因的禁用按钮。

### 3.3 SSH 跳板：只组合已经保存的服务器

- 切到 SSH 跳板后显示“选择已有服务器”可搜索选择器和已选有序列表；每项是名称、账号/地址、序号、上移/下移/移除。无需额外开弹窗选择，更不递归打开服务器编辑器。
- **没有“临时服务器”“新建跳板”“填写一个地址当跳板”的入口**。候选排除当前目标、已经选择的节点；缺失/删除节点明确标错并阻止保存。
- 路径始终可读为“本机 → 跳板 A → 跳板 B → 目标”；默认无预选跳板。沿用显式 `jumpServerIds`，只取所选节点 SSH 身份，不递归继承节点自身访问路径，简短说明放在列表旁。
- 推荐流程：先用左侧“新建 SSH 连接”建立跳板并“仅保存”，再建目标、选择跳板。配置中途发现缺少节点时，可以通过同一独立入口另建；原目标成为未完成草稿，建好后手动恢复目标并选择它。不在路径编辑器内代建、不自动插入路径、不打开跳板工作区。
- 多级能力和核心预算保持，不以 UI 简化退回单跳；切到其他访问方式暂存非秘密输入，提交只保存当前选择的路径。

### 3.4 SOCKS5：选择可复用代理，就地新增也不离开目标

选择 SOCKS5 后只显示代理选择器和“新建代理”文字按钮；默认不选第一条代理，必须由用户明确选择。已有选择项展示名称/地址/认证方式，不显示秘密；列表为空时说明“还没有代理，可以在这里新建”。

点击就地新建，在当前路径区域**内联展开代理小表单**，保留主机、SSH 账号、滚动和上下文。保存按钮为“保存并选用”，取消按钮为“取消添加”。保存成功后收起，自动选择新代理；不能叠加第二个弹窗、隐藏整份目标表单或出现 SSH 字段。内联草稿未处理时，目标提交显示“请先保存或取消正在添加的代理”，不悄悄丢弃。

内联保存是明确的独立提交：代理在保存成功时即进入共享代理目录；之后取消服务器创建也保留该代理。界面显示“代理已保存，可供其他连接使用”。凭据阶段失败时保留代理 ID，提示“代理已保存，密码未保存”，重试不再新建，未完成本次秘密提交前不自动选用/连接。

“目标域名解析”位于此模式的折叠高级选项，默认“由代理解析”，展开可选“本机解析”；收起时仍显示当前摘要。DNS 属于当前目标，修改不影响其他使用同一代理的服务器。代理端点自身仍由本机解析。路径摘要为“本机 → 代理名称 → 目标 SSH”。

此处不放“编辑共享代理”“删除代理”按钮，防止配置目标时误改所有使用者。对应操作由左下“管理代理”进入右侧管理页，返回目标时恢复草稿；共享修改影响提示及删除依赖阻断沿用 F-CORE-027。

### 3.5 新建代理：独立与内联使用同一套字段

| 字段 | 默认 / 位置 / 规则 |
| --- | --- |
| 协议 | 固定标识 SOCKS5；当前只有一种，不放只有一项的下拉框 |
| 代理地址、端口 | 地址空且首先获焦；端口 1080，同一行。地址不预填 127.0.0.1，避免误连本机服务 |
| 代理认证 | 默认“无认证”；切“用户名和密码”才展开账号/密码，不借用目标 SSH 账号 |
| 代理账号 / 密码 | 均无默认；认证账号必填，密码可留到连接时输入；显示/隐藏与 SSH 一致，受 SOCKS 协议长度限制，按 UTF-8 字节校验并解释错误 |
| 记住代理密码 | 勾选，明确与 SSH 密码是两份凭据；未勾选只保留本次运行 |
| 代理名称，最后 | 可选覆盖值，留空显示并采用 `地址:端口`；IPv6 端点使用方括号避免歧义 |

左侧“新建代理”打开右侧独立表单，主按钮仅“保存代理”。成功后进入右侧代理管理列表并突出刚保存项，不打开服务器 Tab，不启动代理服务，也不隐式替任何目标改路径。

管理页显示名称、端点、认证方式和保存配置引用数，编辑复用右侧表单，删除放在明确的行操作/菜单。删除前由核心核对保存和运行依赖；有依赖时列明并阻止，不删除使用它的服务器，也不停止外部代理服务。共享编辑保存前说明影响的服务器，已有连接保留旧快照，新连接采用新值。

### 3.6 分组与删除

分组仍按 F-CORE-016 的单层分类、名称唯一性、独立 revision 和删除事务执行。新建分组改为字段旁一行内联输入，“创建”成功立即选中，取消仅退出该输入；已保存组不因取消服务器草稿自动删除。完整管理在右侧页，返回原草稿而不是另开模态。

服务器删除沿用现有依赖、运行资源和确认规则；新入口不能绕过依赖阻断。删除结果同步所有窗口，失效的编辑草稿明确显示“服务器已删除”，不能意外另存为同名新档案。

### 3.7 草稿、切换与关闭

- 草稿由该窗口的系统页持有，仅在内存。切到服务器 Tab、搜索、打开其他表单/管理页都保留已输入内容和滚动；不会自动保存或发起网络访问。
- 左侧“新建 SSH 连接”在当前为空白新建表单时定位该表单；当前有修改时开始另一份独立草稿，原稿保留。右侧标题区仅在存在其他未完成配置时显示“未完成配置（N）”入口，按目标地址/名称恢复；这是防丢入口，不是服务器目录中的临时节点。
- 编辑同一服务器重复进入复用该草稿，不复制多份；新代理亦同规则。页面切换不改变已打开连接或复用池。明确放弃草稿及完成保存后清除对应秘密输入。
- 关闭系统页或退出窗口将丢失修改时，提供“继续编辑 / 放弃修改”；无修改不确认。主窗口×收托盘不丢稿不询问；明确退出时参与既有关闭检查。崩溃不承诺恢复或安全擦除内存。
- 跨窗口只同步已保存目录，不共享未保存草稿；提交时检查 revision，过期/引用被删除保留输入并说明重新选择/重新载入的影响，不静默覆盖。
- 保存与凭据阶段的部分成功、结果未知、重复请求沿用现有可靠提交要求。结果未知时核对同一次操作，不能以新 ID 重建；保存中暂时禁止同稿重复提交/放弃，仍可使用其他服务器。提交阶段完成不抢已经切走的焦点。

## 4. apple-design 的具体应用

已读取 `apple-design`，采用 Purpose / Simplicity / Familiarity / Agency / Craft：找服务器与填写表单各占稳定区域，普通直连只需目标和身份；复杂方式逐步展开；一项提交只有一个主要动作；保存、连接、编辑、就地创建使用明确标签。

即时反馈用按下/加载/成功/字段错误状态；表单切换可短淡化，不飞入、不缩放整个工作台、不锁住输入。内联新增与原选择器相邻，取消回到触发处，形成稳定空间关系。原生插件表面的祖先不应用 transform/filter。

全部消费 `@sodeck/ui` 的公开控件及三主题令牌。没有背景内容的常驻页面使用实色，不强加玻璃；高对比保留清楚边界，减少动态使用即时切换，减少透明使用实底。

键盘：进入已有目录默认焦点搜索；空目录/新表单焦点主机地址；Tab 按视觉顺序，列表方向键移动、Enter 执行行主操作，Shift+F10 等价右键。字段内普通 Enter 不直接创建连接，Ctrl+Enter 在有效且无内联待处理项时执行当前主提交；中文 IME 合成期间 Enter 不提交。Esc 先退出菜单/选择层，再退出内联新增；不在主表单内直接丢弃草稿。焦点退出内联回原入口；提交错误跳首个错误，失效引用及展开控件均具名、可键盘操作。系统页上的快捷键不得透传到隐藏终端。

长名称可在列表内视觉裁切并提供完整可访问名/悬停说明，顶部 Tab 不新增省略号字符或更多按钮。系统页不加载/广播远端监控，不虚构在线状态。

## 5. 接口、数据与影响

代码设计见[连接首页代码修改方案r1](../technical/connection-home-implementation.md)：固定模块、系统页选中对象/原生可见性、草稿提交状态机、代理回执/分页、预设凭据条件提交及两阶段关闭，拟增量API/SDK5.3，业务数据库保持v6。本轮仍只设计，不改写其他任务的授权或实测。

本修订将以下边界纳入功能基线：

- 新建/编辑服务器提交时核对已选节点的实际身份；代理/SSH秘密提交前再次核对目标与依赖，冲突保留草稿，不将旧密码写到并发修改的新身份。跳板自身路径、名称和分组变化不作为路径身份变化。
- 配置成功但用户已切到其他任务时，不由迟到的“保存并连接”回执强行跳转；提示已保存并提供连接动作。已经发起的打开操作继续按原operationId核对。
- 每窗口最多16份未完成主草稿，非秘密总量512KiB、秘密输入总量256KiB；超额明确提示处理已有草稿，不静默淘汰。目录/回执预算见代码方案。
- 设置窗口和各工作台草稿在全App退出前一起核对；任一取消时，其他页面已同意放弃的稿也仍保留。子窗口最后工作区关闭/移动会销毁窗口时同样先核对，不先移动再丢稿。保存等待10秒仍未决时由用户明确选择继续核对或放弃等待，超时不自动关闭；已经开始的保存可能完成。

核心目录继续持有服务器/分组/代理和修订；凭据服务持有秘密；外壳只持有呈现与草稿；工作区初始化与插件业务仍走公开核心契约。终端/文件/隧道插件不引用新表单的 React 状态，也不为本页增加插件专用核心方法。

拟复用现有 `servers.catalog.*`、`serverGroups.*`、`proxies.socks5.*`、`auth.ssh.set`、`auth.socks5.set`、`workspaces.open` 和状态订阅；方法是否满足代理保存去重、目录同步、私钥选择和系统页承载，在代码设计阶段逐项核对。不将现有能力“足够复用的方向”写成新增行为已实现。

三种 `accessPath`、显式多级 SSH、目标 DNS、身份绑定、旧连接快照、取消/释放和认证归属沿用 F-CORE-027。私钥预设与自动名称必须满足已有核心校验，不创建绕过路径。本轮预期无需更改持久配置结构；如代码设计发现必须改变数据库/API/插件兼容，应先明确具体影响再确认，不能复用 T-020 的旧库重建授权清空当前配置。

本稿覆盖旧规格中的入口与界面描述：F-CORE-006 的＋选择器、F-CORE-010 的启动欢迎页按钮、F-CORE-016 的模态/嵌套跳板/分组、F-CORE-027 的代理子步骤；那些版本的历史实测保留。网络协议、资源策略及独立插件更新的既有事实不受重设计推翻。

## 6. 验收标准

- CH-AC-01：启动/顶部＋/关闭最后内容后进入统一连接页；每窗口不重复，未主动打开服务器时不建立任何远端连接。
- CH-AC-02：已有服务器一步打开；新建 SSH 能“仅保存”或“保存并连接”，编辑只保存；工作区/首终端去重及跨窗口定位正确。
- CH-AC-03：字段默认、展开、名称/分组、密码/私钥符合表格；校验、焦点、三主题和缩放下可完成任务。
- CH-AC-04：SSH 跳板只能选择持久档案，多级/排序正确；SOCKS 可内联创建并持久复用，身份/秘密/解析规则互不混淆。
- CH-AC-05：草稿切换不丢、关闭有可取消处理，部分保存/未知结果/并发引用变化可恢复、不重复建档、不提前连接。
- CH-AC-06：现有配置和运行连接保持；系统页不冒充服务器工作区，不导致插件上下文串用、资源泄漏或关闭语义变化。
