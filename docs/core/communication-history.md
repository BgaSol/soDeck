## 1. 目标与范围

让用户回答“刚才/昨天哪个服务器传得多、什么资源产生了变化、断线发生前后怎样”。历史默认本机保存，可跨App重启查看；它不恢复工作区、终端或连接，保持P-33。首次启用前、App未运行时和已过留存的数据不可补造。

本次包含时间查询、来源排序、两个区间对比、生命周期事件标记、本机CSV/诊断包导出、留存与清理。测速摘要和连接诊断也使用同一对象身份及时间轴，不建立独立日志数据库。首次交付不引入外部上传、任意SQL、自由报表脚本或计费配额。

## 2. 用户操作与统计语义

从“历史”选择全部服务器或单目标，可进一步选插件/资源、运行/路径和口径。快捷范围为最近1小时、今天、24小时、7天、30天，也可自定义≤30天；日期按界面时区计算，查询返回实际UTC边界。更换范围取消旧查询；迟到数据不能覆盖新选择。

顶部显示所选期间的发送/接收总量、有效时段平均速率、峰值与覆盖率，图中展示双向趋势及断线/重连/测速标记。来源按累计或峰值排序，显示已结束项；“其他”是有数值的聚合项，不将超限资源隐去后仍声称完整明细。

默认平均值包含有效已连接的零流量时段，排除App未运行/采集缺失时段；界面明确标“有效时段平均”。全局区间总量直接聚合本口径字节增量，来源对比使用同一完整性与时间条件。低覆盖时照常显示可知总量，但加“至少/部分数据”，不按比例外推。

“对比”选择同一范围对象的两个时间区间（最长各30天），默认等长前一区间。先对齐口径、时区边界和可用粒度，再并列总量、平均、峰值、有效时长和缺口。可比较不同路径修订但显著标记；区间长度或覆盖不同不给“性能改善xx%”结论，只给数值差异和条件。

图表采用按区间累加的字节量/有效时长计算均值，同时保留桶内最细有效采样峰值及其原始粒度。切换窗口不把平均线抬成峰值；降采样保留峰值信息，缺口断线绘制，不能插值连成连续正常流量。点击事件定位诊断和同时间区间，不触发重连或测速。

## 3. 建议留存、聚合与预算

以下为本次推荐默认值。适用核心内置通信profile，通用插件指标继续遵守F-CORE-021原规则。

| 数据 | 建议保留 | 粒度 / 说明 |
| --- | --- | --- |
| 实时明细环 | 最近60分钟，同次运行内存 | 1秒；受实时32MiB总预算约束，降级及实际起点可见 |
| 近期曲线 | 24小时，本机持久 | 5秒桶，包含字节增量、有效/缺失时长、最细采样峰值 |
| 日常历史 | 7天，本机持久 | 1分钟桶；不删除仍需承接的低分辨率数据 |
| 长期概览 | 30天，本机持久 | 1小时桶，默认保留全局/服务器/插件层及路径段 |
| 资源明细及连接/测速摘要 | 资源明细7天；连接/测速摘要30天 | 明细超期后保留其上级汇总，明确“资源明细已过期” |

通信持久数据总子额度96MiB（含索引/WAL和测速摘要），从F-CORE-022的128MiB诊断类预算内划分，不额外扩张512MiB在线总额。该组预算需要在T-019代码稿与T-016一起核算确认；临时证据/其他诊断至少仍有32MiB。时间与空间任一先到即轮转，界面显示真实最早时间，不能保证高流量/高基数时一定保留满30天。

优先按期生成低粒度桶，再淘汰最老的资源细粒度、其余细粒度，最后淘汰最老汇总；只有成功生成且校验字节总量的汇总才能替代源桶。同一查询每个区间只选择一种权威粒度，不能将5秒、1分钟、1小时数据重复相加。多个来源归并、跨小时/天/夏令时边界均遵守此规则。

目标累计保持于本次运行有界汇总；资源超预算可以合并到所属插件“其他已结束资源”，不能丢字节后仍声称总量准确。过期、清理、崩溃、预算降级分别记录原因；超出明细保留后仍能看总量，不能伪造资源排名。

设置提供“保存通信历史”（默认开启）、已用空间、实际保留范围、清理指定时间段。关闭历史停止后续指标持久化，保留实时环；既存历史不自动删除，公共调用审计不受此开关控制。测速结果此时只在本次运行可读，界面在开始前注明。重新开启只记录以后；该偏好和单位保留，筛选/窗口不跨启动恢复。

清理在展示时间范围、类型和影响后一次确认；不删除当前活动任务所需最小状态及配置。后台按批执行，取消后报告实际已删范围，不承诺回滚。相应问题/证据引用变为过期，不凭空消失。手动导出文件和备份不由自动轮转删除。

## 4. 查询、数据及失败行为

核心拥有历史，字段含schema/profile版本、storeEpoch、bootId、目标/资源稳定ID、路径快照引用、桶起止、单调有效时长、字节增量、峰值/粒度、样本数/覆盖/缺口。存稳定对象身份与安全类型标签；历史UI可解析当前本机名字，删除对象显示类型+短ID及“已删除”。不保存终端命令、文件路径/正文、HTTP地址/正文或自由异常对象。

建议接口：communication.history.query/compare、communication.history.policy.get/set、communication.history.cleanup、communication.export.start/get/cancel。查询固定水位与筛选指纹，默认每页100/最多200项，每次曲线最多1200点，响应≤512KiB；查询超过2秒返回可重试繁忙/超限，不持业务锁等待。放大图表重新查询更细粒度，原始明细已过期则保留当前粒度说明。

状态：idle/loading/ready/empty/partial/failed/canceled；NOT_RECORDED、GONE、CURSOR_EXPIRED、STORE_UNAVAILABLE、CAPACITY及CANCELED分开。历史磁盘失败时实时采集仍可用并提示未保存；不能因可选指标写失败拒绝既有业务I/O。现有新业务调用审计故障策略仍按F-CORE-022。

每5秒批量写入已形成的桶；正常退出最多2秒排空，未完成部分标明缺口。异常退出可能丢最后未提交桶，重启不能把缺失尾部当零或重新采集成故障现场。数据库版本不兼容遵守P-52：提示、完整备份、全新建库；多库协调由公共启动层负责，历史中展示新epoch边界，不自动导入旧备份。

## 5. 导出与证据

“导出”先展示范围、口径、粒度、覆盖和文件格式，用户选本机目标；不隐式发送。CSV用于当前查询的数值分析（带单位、桶时间、来源别名、状态、覆盖字段）；关联诊断则生成F-CORE-021的JSON/JSONL证据包，包含版本、路径稳定引用、事件/问题、测速摘要和缺口说明。

CSV字段避免电子表格公式注入；默认别名替代主机地址/用户名，勾选“包含服务器名称和地址”时在预览列出将增加的定位字段。路径正文/凭据永不导出；本地显示路径拓扑可解析已有配置，但导出默认使用节点别名。

导出固定水位、总任务共享公共证据上限（App最多2个），默认≤50MiB/10000条；超过上限提示缩小范围或显式导出部分，不能暗中截断。用户选好位置后临时写入并原子完成；已存在文件按原生保存交互确认，失败/取消清理本任务临时文件，不影响原记录。关闭监控窗口不取消已经明确启动的本机导出，可重新打开查看进度；App退出按公共任务中断语义处理。

## 6. 验收与专属测试流程

AC-01区间统计/多粒度准确；AC-02留存、缺口与身份真实；AC-03本机导出可核对；AC-04错误/取消/存储不损害业务；AC-05UI可用。

适用r1；Windows隔离存储、真实SQLite/WAL和SSH夹具、受控时钟；禁止在日常数据上做清理/损坏测试。CH入口尚未建立，结果归T-019。

| 用例 / AC | 准备与步骤 | 预期 | 清理 |
| --- | --- | --- | --- |
| CH-01 / 01 | 输入已知字节和短峰值，跨桶边界查询1小时/24小时/7天/30天，放大曲线 | 总字节一致，无粒度重复；峰值与原粒度可查；加权平均准确 | 停采集并清测试库 |
| CH-02 / 01、02 | 空闲、App离线、采集缺口、跨重启；查不同长度/覆盖的对比区间 | 零与缺失区分；平均分母/覆盖明确；不能把数据差异写成性能结论 | 结束两次测试运行 |
| CH-03 / 02 | 删除重建同名服务器、改名/路径、资源超7天，查看历史 | 身份不串；旧路径保留；过期明细标识，汇总不被重命名或关闭清零 | 清测试档案 |
| CH-04 / 02、04 | 加速到各留存边界，逼近96MiB/公共128MiB，插入大量资源 | 成功汇总后再淘汰，实际起点/降级可见，WAL也计预算，其他诊断保留子额度 | 撤销时钟/容量注入 |
| CH-05 / 03 | CSV含特殊标签/公式前缀；导出带事件/测速的证据包；核对水位与缺口 | 数值可重算；默认别名/禁正文；CSV不可执行公式；包自包含且无外部网络请求 | 删除测试导出副本 |
| CH-06 / 03、04 | 导出时写入/轮转、同名目标、不可写位置、超预算、取消/强杀 | 固定水位；明确partial/失败/中断；不静默覆盖或留下无限临时文件 | 解除故障并回收临时文件 |
| CH-07 / 04 | 历史开关来回切、清理指定范围并取消，同时维持终端与查询 | 仅影响声明数据；审计保持；清理部分完成诚实；旧游标/引用过期可见，I/O继续 | 恢复默认策略 |
| CH-08 / 02、04 | 时钟回拨/夏令时、退出未刷盘、损坏与版本不匹配库副本 | 范围边界准确；尾部缺口；备份重建/新epoch符合P-52，不能假装迁移成功 | 恢复时钟，移除隔离副本 |
| CH-09 / 05 | 历史加载中快速切范围/服务器；三主题、键盘、窄窗、空/过期数据 | 迟到响应不覆盖新选择；表格/图表可读，导出范围预览准确；焦点/取消可用 | 关闭窗口并恢复偏好 |
