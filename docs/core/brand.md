# F-CORE-013：应用Logo与品牌资源

规格修订：r1 · 2026-10-26 · 文档就绪：可评审，T-012已确认实施
依据：[产品 P-41](../product.md) · [设计稿 §6](../design/dopamine.md#6-logo-提案pocket-deck) · [T-012](../tasks/T-012-dopamine.md)

## 1. 范围与呈现

应用品牌为SoDeck，采用原创卡通小终端。轮廓、颜色、尺寸变体遵循设计稿；三主题共用品牌，无主题切换造成的图标文件改写。包括欢迎、应用品牌展示、EXE资源、Windows任务栏/Alt+Tab、主/工作区/独立窗口和托盘。图标不改变应用标识、包签名、安装状态、任务栏分组或托盘点击/关闭语义。

资产从一份可编辑SVG母版导出；小尺寸是人工简化变体，不是机械等比缩小。彩色、微型、单色均为同一轮廓体系；所有SVG不含外链脚本或字体依赖，PNG透明边缘无白色脏边。静态设计稿不是最终生产资产，实施后另建资源目录与可追溯输出。

引用失败时使用内置简化命令符fallback并记录诊断，不能因品牌资产缺失使主窗口或托盘入口消失。品牌图在按钮中由按钮提供名称，纯装饰图片aria-hidden；单独Logo标注“SoDeck”。实际动作图标与Logo职责分开，不把Logo充当多个不同操作。

## 2. 验收与测试

BR-AC-01：保持参考风格与SoDeck独立识别；BR-AC-02：所有真实宿主入口使用正确图标；BR-AC-03：小尺寸、高对比、失效与托盘行为可用。

准备：T-012隔离开发包、三主题、Windows浅/深任务栏、100/150/200%缩放、当前EXE和旧包哈希。不得通过删除用户图标缓存、重启Explorer或重置任务栏来掩盖结果；缓存导致旧图标时用新目录构建样本验证并记录限制。

| 用例 | 操作 | 预期与清理 |
| --- | --- | --- |
| BR-01 / AC-01 | 核对母版、各尺寸PNG/ICO及单色变体，与设计稿并排审查 | 轮廓、命令符、配色一致；16px不粘连，图稿无参考品牌商标；保留图板证据 |
| BR-02 / AC-02 | 从含空格的新包路径启动，查看EXE、任务栏、Alt+Tab、三种窗口和托盘 | 使用匹配的实际资源，托盘不再是纯色方块；截图与所测包哈希对应；退出所有测试窗口 |
| BR-03 / AC-01/03 | 三主题、浅/深任务栏、100/150/200%及系统高对比下查看 | 可辨、边缘干净，无彩色Logo与背景融为一体；恢复原系统偏好并记录 |
