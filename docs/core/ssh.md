## 1. 本批范围

本节“首批/暂不提供”保留 T-003 的历史范围；SFTP/有界 exec 已由 [F-CORE-009](remote-read.md)扩展，首终端由 [F-CORE-010](clean-start.md)扩展。核心单层跳板已随 [T-013 r1](../tasks/T-013-ssh-jump.md)确认并实施，结果由该任务维护。用户进一步要求取消固定层数，[F-CORE-014 r3 §7](ssh-jump.md#7-多级路径修订方案r3替代-r1-的单层限制) / T-013 r2 提交任意有限级路径、完整依赖与 MH-01～10，多级方案待确认。涉及跳板时本文 host:port 信任、仅目标修订的复用和删除检查由路径上下文规则扩展；直连回归保持，旧结果不改写为多级已通过。

Windows 客户端直连 Linux/OpenSSH，支持密码和 OpenSSH 私钥文件（含口令），核心保存服务器并为终端提供连接租约和 PTY。暂不提供 SSH Agent、交互式 MFA、跳板、代理、SFTP、通用 exec 或隧道接口；能力查询不列出未实现方法。

这些是首批实施建议，不扩大为全部首发平台或所有 SSH 服务端兼容承诺。独立数据目录与 v1 共存，不读取或迁移 v1 配置与凭据。

## 2. 服务器与认证操作

T-017身份确认视觉修订：单一服务器摘要、完整可复制指纹、算法次级呈现；直连省略冗余路径，多跳显示当前节点并按需展开路径；身份变化同时显示旧/新指纹与醒目说明。取消、challenge与信任持久化语义保持。用户已直接授权重新设计和实施，专属ID-01～03流程见[T-017](../tasks/T-017-identity-tunnel-ui.md)，覆盖三主题、长内容、缩放、键盘、复制/信任失败及隔离原生逐跳认证。

1. 核心服务器页提供新增、编辑、删除、打开工作区。字段为稳定 ID、显示名、主机名/IP、端口（默认 22，1–65535）、用户名、认证类型及秘密引用、修订。主机名不当 URL 或命令执行。
2. 创建工作区不连接。用户打开终端或点击重新连接时才申请租约；状态分别显示连接中、等待主机确认/认证、已连接、失败或已结束。
3. 新主机先显示目标、算法、SHA-256 指纹及“信任并连接/取消”。确认后保存信任。已知主机指纹改变则停止认证，明确显示旧/新指纹，用户单独更新信任后再连接；不自动覆盖、不先发送密码。
4. 密码/口令默认仅本次使用；用户可明确选择记住。选定私钥后由核心读取，需持久保存时加密存储其内容和口令，普通配置只存引用。日志、插件参数和迁移快照不包含秘密。具体平台适配见技术方案。
5. 同一配置修订的并发连接可以合并；等待同一认证的消费者共享提示，取消一个消费者只释放自己的等待，全部取消才结束该次建连。
6. 编辑产生新修订；现有连接保持原目标和账号，新申请使用新修订。删除被运行会话引用的档案时显示影响，用户可取消或明确结束这些会话后删除；失败不假报删除成功。

T-007 r2 已确认的新增入口：添加/编辑服务器时，密码认证提供可选密码和显示/隐藏、默认勾选的“在此设备上记住密码”。留空不改写旧凭据；主机/端口/账号/认证类型改变仍使旧凭据失效。非空密码通过既有 auth.set 单独提交，保存不连接，主机信任校验保持。档案成功而凭据失败必须显示部分成功，重试使用已创建 ID，不重复新增。此处默认记住是用户对服务器编辑入口的明确选择，连接时认证提示仍默认仅本次。功能测试与结果见 [T-007](../tasks/T-007-server-editor.md) SE-01 至 SE-05。

服务器、认证及错误 UI 使用 apple-design：字段分组、即时校验、状态可辨认，错误给出修正位置；认证弹层由核心跨窗口协调，焦点返回发起终端。测试对应 SSH-01 至 SSH-04 及 TERM-09。

## 3. 最小公开契约

请求封装、错误、来源、去重与记录沿用 F-CORE-001/003；字段名称为本批 v1 API 建议，由协议类型与 Rust 类型共同固定。

| 方法组 | 请求 → 结果 | 主要规则及记录摘要 |
| --- | --- | --- |
| `servers.list/get/create/update/delete` | ID/非秘密配置及预期修订 → 配置快照/新修订 | 冲突不覆盖；摘要只含 ID、修订、变更字段名 |
| `connections.acquire` | workspaceId、serverId、configRevision → operationId，最终返回 leaseId、connectionId、generation | 同工作区、相同配置/凭据修订可复用；每消费者独立租约；记录目标及结果 |
| `connections.release` | leaseId → 当前状态 | 幂等，只释放该使用关系；有 PTY 引用时保留底层依赖 |
| `pty.open` | leaseId、cols/rows、`xterm-256color` → operationId，最终返回 ptyId、generation、streamId | 创建后交付失败则回收；首批启动服务端默认交互 shell，不拼入任意启动命令 |
| `pty.write` | 有效句柄、inputSeq、bytes → acceptedBytes、最后已受理序号 | 每次调用留痕，只记长度/序号；不自动重发已受理或结果不明的输入 |
| `pty.resize` | 有效句柄、cols/rows → 当前尺寸 | 最小 2×1，最大 1000×1000；隐藏/零尺寸不发送；只最新有效表面可调整 |
| `pty.close` | 有效句柄 → 关闭状态/operationId | 幂等；关闭通道并释放依赖，不能承诺任意远端派生进程都退出 |
| 快照、事件、流与资源管理 | 沿用公共协议；提供状态查询、订阅、输出读取/确认、显式停止 | 每个流有代次与序号；核心管理入口在终端故障后仍可查询、停止资源 |

身份和输入绑定由宿主产生，参数自报身份不能覆盖。所有已启用插件平等调用已实现接口；SSH 认证和有效租约不是插件权限分配。认证秘密经核心专用交互传入，不把秘密正文作为插件接口参数。

## 4. 生命周期与失败

连接模块拥有传输和通道；PTY 是连接的依赖消费者。一个终端关闭不影响另一个终端租约；最后一份依赖释放后关闭连接。共享连接断开时通知全部受影响会话，不偷偷创建新 shell。

网络/认证错误可由用户重试；每次重连是新代次、新 PTY。旧输入、resize、流帧和旧响应不得作用于新会话。读取结束、shell 退出、网络中断和主动关闭分别显示。结果不明只说明未取得远端确认，不把超时写成未执行。

连接、输出、取消和清理时限以[本批技术预算](../technical/first-terminal.md#3-初始预算与故障策略)为准。按产品决定，主窗口收起、工作区切换和视图移动不释放会话；明确关闭终端释放所属资源；退出结束全部 App 持有连接。

## 5. 验收与本功能测试流程

验收：AC-01 配置和秘密按职责保存；AC-02 主机身份先于认证且错误可恢复；AC-03 多租约/PTY 不误伤；AC-04 断线、重连与退出真实可追踪。

准备：独立 Windows 数据目录，两个隔离 Linux/OpenSSH 测试账号/端点，已知密码、加密/未加密测试私钥，替换用主机密钥。测试服务由任务启动并登记，不使用日常服务器。真实服务验证认证、通道和释放；契约故障注入补充精确竞态。当前 loopback SSH 协议入口及结果见[核心记录](../tasks/T-003-core-results.md)；用户暂时没有 Linux 服务器，实机子场景保持未验证。

| 用例 | 操作步骤 | 预期及关联验收 |
| --- | --- | --- |
| SSH-01 | 新增档案，验证非法端口/空账号；保存后重启；用已记住/未记住两种认证分别连接 | 配置持久且校验明确；未记住则重新询问，普通数据库和日志无秘密正文；AC-01 |
| SSH-02 | 对未知主机先取消再信任；替换测试主机密钥后重连并取消 | 取消不认证，已知指纹匹配才继续；改变指纹不自动覆盖；服务端记录核实未提前提交认证；AC-02 |
| SSH-03 | 分别用密码、加密/未加密私钥连接；输入错误凭据再修正；并发两次连接，取消其中一次认证等待 | 支持的认证可用、错误可辨认；独立消费者不被误取消；AC-02、AC-03 |
| SSH-04 | A 会话连接后编辑档案账号/地址，用新修订打开 B；尝试删除并先取消再确认 | A 保持原上下文，B 使用新修订；删除影响明确且取消无副作用；AC-01、AC-03 |
| SSH-05 | 同一工作区开两个真实 PTY，分别输出唯一标记；关闭一个，在另一个继续输入；再关闭最后一个 | 通道和输入输出独立，关闭不误伤，最终连接/通道计数回基线；AC-03 |
| SSH-06 | 建连中取消、创建完成交付前销毁消费者；注入创建/关闭失败 | 未交付资源被回收，清理失败可诊断；操作记录不假报成功；AC-03、AC-04 |
| SSH-06a | 从主按钮、会话列表及 ended 占位分别发起新建；在握手/认证/PTY 等待时点击所属操作的“取消连接”；并发第二项连接，注入先取消后开始、PTY 迟到和提交前取消 | 每项有独立 operationId；取消立即反馈且只影响该项，其他会话可继续；未提交的迟到 PTY/租约被回收且不新增 Tab；已提交的成功结果不误报取消；缓存饱和或记录存储失败仍能执行取消；AC-03、AC-04 |
| SSH-07 | shell 执行有限测试写入后断网，查询状态，再手动重连并发送旧句柄请求 | 无自动重放；新代次拒绝旧请求，断线及结果不明如实呈现；AC-04 |
| SSH-08 | 多个真实终端运行时收起到托盘再恢复，最后明确退出；外部检查 socket/子进程并重启 | 托盘不结束；退出完成本机回收，重启不恢复旧 PTY；AC-03、AC-04 |

清理：关闭测试 App 和测试服务，核对连接/PTY、本机子进程及远端受控命令均结束；必要时从测试服务管理侧清理远端进程。恢复主机密钥与网络注入，删除测试秘密和临时数据，保留脱敏结果。命令副作用在隔离服务核对，不能仅凭本机资源目录为空判定远端干净。
