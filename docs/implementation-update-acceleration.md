## 范围与来源

2026-11-09 在独立工作区、分支 `codex/update-acceleration` 实施，初始基线为 `origin/main` 的 `dd0335c12a1c82d626d489613101b875eb0a13fe`，实施阶段核心版本保持 0.16.0，未带入原工作区未提交的工作台改动。随后整合 main 已发行的 0.17.0 工作台实现，以核心 0.18.0 准备发行。本文保留初始功能实施和本机网络实验结果；合并后检查及五平台发行来源统一见 [v0.18.0](releases/v0.18.0.md)，不把初始 Windows 验收外推为五平台结果。

未新增生产依赖。普通 HTTPS CDN 重定向有界跟随；代理跳回 GitHub 时重新包入当前前缀。HTTP 回环与线路注入仅供 `test-fixtures`，生产设置仍要求无凭据的 HTTPS。测试用 GitHub token 仅发给原始 API，不随代理或其他主机重定向转发。

## 缺陷复现与回归

代理对相同 blob URL 的 Raw/JSON Accept 缓存未可靠区分，实际能返回另一种响应形态。现改用 GitHub JSON 请求，读取端同时识别原始插件 JSON 和 Base64 envelope；验证编码、长度和解析结果，保留树中 blob ID 的固定引用。

可控服务器回归覆盖：原始地址 503、第一代理返回 HTML、第二代理成功；文件专用地址不接收 API；下载声明长度不足、哈希错误、核心签名错误后换节点；本地已有文件不被覆盖；取消后清理副本并停止；代理重定向不会绕回直连；配置冷却和旧快照隔离。

完整官方安装测试经代理读取目录树、固定 blob、Release、清单和真实原生测试插件归档，最后注册重启生效。核心测试通过官方公开签名向量完成坏包重试、验签、正式缓存与 ready 状态，原有离线缓存篡改/版本篡改和安装前复验继续覆盖。

界面回归还复现了保存后立即诊断时刷新修订号可能清掉新结果的时序问题，保存成功现在同步返回的偏好。地址编辑时进行中的诊断仍可结束，但旧结果不会覆盖新输入。

公网组合复测还发现清单失败会使节点进入文件冷却，随后包下载只剩少数未冷却节点。现将冷却作为尝试顺序：未冷却线路均失败后，在剩余预算内再尝试冷却的备用地址，冷却中的直连放最后；同一资源每地址仍只尝试一次。新增“清单失败节点仍能提供包”的回归验证这一调整。

## 公网复测与边界

此前同日的节点实验曾下载 5 个核心更新包和全部 20 个插件平台包，哈希匹配，并验证 5 个核心签名；那是节点实验，不能代替本实现与当前提交的验收。公开代理的可用性会变化。

本轮用新增显式公网专项测试实际网络实现：

| 线路 | 2026-11-09 的实际结果 |
| --- | --- |
| v4 | 插件目录请求返回 HTTP 403，未到包下载 |
| axisnow | 初次目录请求 403；复测读到 4 个插件，但核心 0.16.0 清单连接中断 |
| gh-proxy.com | 目录可读，插件 blob 返回 403，未到包下载 |
| 默认自动组合（修改冷却前） | 读到 4 个官方插件与核心 0.16.0 原始清单；终端 0.6.0 Windows 包因剩余文件线路首包超时/连接失败未完成 |
| 默认自动组合（修改冷却后） | 完整通过：4 个官方插件、核心 0.16.0 原始清单、终端 0.6.0 Windows 包下载/哈希/解包/登记，运行 18.66 秒 |
| 真实核心下载专项 | 完整通过：GitHub 直连失败后走 axisnow，下载核心 0.16.0 Windows 包，以项目配置公钥通过官方验签并进入 ready，运行 10.85 秒；未运行安装器 |

此前单节点和组合失败如实保留，最终成功只代表本次、本机网络和当前 Windows 目标。命令为开发指南中的 `official_install_live_mirror` 与 `core_download_live_mirror`，`SODECK_TEST_MIRROR=auto` 使用默认组合，其余值指定单一前缀；只修改隔离临时数据，不启动插件或升级用户应用。节点实验、源代码回归与正式包跨版本安装仍是不同的验证范围。

## 初始实施阶段的验证边界与风险

- 初始实施阶段没有执行 Windows ARM64、Linux x86_64/ARM64、macOS ARM64 的原生编译、打包和实际包启动/退出，也没有正式包跨版本安装验收；后续五平台结果以 0.18.0 发行记录为准，选择规则已覆盖新增更新网络模块。
- 初始实施阶段未改版本、未创建或发布 Release；后续合并、版本和发布结果见对应发行记录。
- 公共节点可能共享上游、限流、失效或缓存旧资源；7 个地址不等于 7 个独立可用保障。本轮未在大陆独立运营商网络覆盖验证。
- 插件哈希校验保证与清单一致，代理仍参与元数据传输；核心官方签名校验保留。本功能不引入插件权限或新的签名发布体系。
